> 汇总日期：2026-09-09

- **文字**：ChatGPT 生图易写错字，所有提示词均要求“无文字”；“蛊路求生”四字用 Godot 字体（霞鹜致宋）在代码层叠加，最稳。
- **透明底**：需要透明底（徽记/印章/边框）时，在 ChatGPT 里追加「纯白背景，主体全黑线稿」再在本地抠图转透明，或直接用 Godot 透明色键。
- **批量策略**：20 道徽、17 节点图标用网格图一次生成再裁切，比逐张生成风格更统一。
- **优先级**：A1 敌人 12 张（Boss 5 张最优先）→ A2 NPC → B 徽记 → A3 蛊形 → C 背景 → D/E。
- **落地对接**：生成 PNG 后按上表文件名放入对应目录，Godot 自动导入；敌人图需同步 `gu_enemy_actor_view.gd` 的名称匹配逻辑（当前按“散修/修/道/人”等关键词匹配 6 张通用图，替换为按敌人 id 精确引用）。

## 9. 开源替代 vs AI 定制分类（2026-09-09）

> 原则：**独有实体 + 水墨纸面画风** 的素材必须 AI；**通用图形/纹理** 优先开源（零成本、免生图配额）。开源素材需在 `assets_manifest.json` 登记来源与授权（game-icons 为 CC BY 3.0，需署名）。

### 9.1 可开源替代（不需要 AI 生成）

**来源建议**：项目已有 `assets/wenzhen/icons/game-icons/`（52 枚，CC BY 3.0）＋ 自有 `ic_*`（22 枚）；外部补充用 Kenney.nl（CC0）、OpenGameArt（CC0/CC-BY）、Pixabay（类 CC0）、Openclipart（PD）。

| 材料 | 开源方案 | 说明 |
|---|---|---|
| E1 宣纸纹理 | CC0 纸张/羊皮纸纹理站 | 全屏 overlay，低对比即可 |
| E2 印泥质感 | CC0 印章/印泥纹理 | 供印章组件混合 |
| E3 云纹卷轴边框 | SVG 装饰边框（Openclipart 等） | 透明底，需与纸底调色 |
| 节点图标 14/17 类 | 现有 game-icons SVG 染色朱砂红（#8c5850） | 映射见 9.3 表 |
| 流派道徽框+字 | Godot `apply_seal` 组件代码绘制 | 方框+2×2 竖排字无需位图 |
| 流派道徽纹样 13/20 | game-icons 裁切入框 | 映射见 9.3 表 |
| 通用资源/状态图标 | 已有 `ic_*` SVG | 无需新增 |
| 契约/诅咒/遗物 4/9 枚 | game-icons 勉强映射（blood/coin/worm/leaf_swirl 等） | 质感不如定制，备选 |
