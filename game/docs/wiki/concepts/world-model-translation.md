本项目的设计目标不是"蛊真人题材皮肤"，而是把小说世界规则当作可计算的世界模型，从中推导游戏机制[^1]。此页记录映射关系与判定证据，是判断项目是否偏离核心目标的基准页。

## 权威纪律（2026-09-01 总规格第 0 节）

八条纪律中与前述最相关的：蛊虫是活物和独立实体、卡牌只是操作界面；代价真实存在不得凭空补齐；转数差距明显但非唯一设计轴；玩家自由组合；所有关键结果可预见；中央参数导出最终值；规则引擎本地确定、LLM 不参与判定[^2]。

## 小说概念 → 游戏机制映射表

| 小说概念 | 游戏机制 | 实现证据 | 一致性 |
|---|---|---|---|
| 转数（1-9转）量级差 | rank gating + 下阶折价 | `can_activate` + `2^(gu-cultivator)` 倍率 | 高 |
| 空窍/元海/资质 | 丁丙乙甲四档贯穿 | 局外上限×、战斗上限×、回率、吸收率 | 高 |
| 念头操控 | 行动消耗念头 | 每行动耗 1 念头，回合重置 | 高 |
| 魂魄底蕴 | 行动次数分档 | 1/10/100/10000 底蕴 → 2/3/4/5/6 次 | 高 |
| 寿元 | 可支付死亡轴 | 杀招/洗髓/洗恶名/黑市均可扣，扣到 0 陨落 | 高 |
| 杀招泄密 | revealed_to | 用过即对在场全部敌人公开 | 高（直译原文） |
| 元石=真元电池 | stone_to_essence | 1 石 ≈ 5 真元 × 资质吸收率 | 高 |
| 蛊会饿会死 | 实例生命周期 | 仅 16 只核心蛊有喂养字段 | 低（半成品） |
| 家族/势力/人情 | 声望+5 NPC | 恶名数值化，深交涉缺失 | 低 |

来源：审计报告第 5 节映射总表[^3]。

## 换皮 vs 原创的判定基准

**承认同构（非罪）**：挡格池≈STS Block、刻痕≈中毒（代码注释自认）、休息三选一、pity 保底、分层地图 Boss 门禁[^3]。

**承认原创（需保护）**：真元质量维度（低转真元催不动高转蛊）、杀招知识资产化（配方+化解+泄密）、寿元与魂魄作为可主动透支的支付资源、节点内真元预算制[^3]。
