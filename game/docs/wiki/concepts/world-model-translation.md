《问真》不做题材换皮，也不把旧审计表当世界观。**原著列只引用 `lore/wiki` 已核验事实**；**游戏列是 L6 裁定**，与原著不一致时以“差异声明”写明，禁止回写成原著[^1]。

## 转译总则

1. 原著有明确规则 → 优先同构落地，数值可压缩但语义不扭曲。
2. 原著只有个案/倾向 → 游戏可选稳定子集，但页面必须标“游戏裁定/个案非公式”。
3. 原著无此机制（Roguelike 地图、商店价盘、存档）→ 纯游戏层，不挂原著锚点。
4. 转数是**综合层级轴**（Rank Axis），不是万能倍率；HP/伤害/价格/真元/奖励不得共用同一转数乘数[^2]。

## 原著事实 → 游戏机制映射

| 主题 | 原著蒸馏（真源） | 《问真》落地 | 差异声明 |
|---|---|---|---|
| 修为 | 一至九转，每转初/中/高/巅峰；一至五转凡、六转起仙；真元五档青铜→赤铁→白银→黄金→紫晶[^3] | rank 1–5 门禁与转数内容梯度 | 仙窍/灾劫/道痕属蛊仙阶段，**不进凡人跑局常规模块**[^3] |
| 资质 | 开窍步数分级 + 元海占窍比例（丁丙乙甲）；甲上另有十绝体风险[^4] | 丁/丙/乙/甲四档贯穿局外与战斗资源 | 游戏把资质做成可洗髓升级档位，原著无“10 寿元换档”公式——**纯游戏裁定** |
| 真元 | 储于空窍元海；可自元石抽取补充；转内可提纯；颜色随转[^5] | 节点内 true_qi 预算 + 局外 essence（两轨不互换） | 原著无“节点预算/回合回率%”公式——**游戏压缩** |
| 养蛊 | 持续饲养负担；一般只养四五只同转蛊；养不起+用不起是软上限[^6] | 喂养/炼化成本形成软上限，无硬蛊槽 | 原著无“802 目录/20 流派数值表”——**内容池游戏设计** |
| 炼蛊 | 炼化=抹意志必遭反抗；合炼须秘方；有些蛊不能合炼；推演靠底蕴+灵感[^6] | 三类蛊方（晋升/古方/自由混合）+ 确定性古方 | 原著无“成功率 60% 自由混合/三结局权重”——**游戏裁定**；不得写成原著合成公式 |
| 杀招 | 多蛊组合用法沉淀；必有弊端与后遗症；威力大则真元消耗巨大[^6] | 命名杀招知识资产 + 配方校验 + 解析/泄密 | “化解 tag / revealed_to”是机制直译，数值标签是游戏编码 |
| 流派 | 源流与境界阶梯（普通→无上大宗师）见流派总表；道痕增幅/异道可能冲突[^7] | 多道标签开放集合，不做全局克制倍率 | 游戏 20 流派目录 ≠ 原著流派全集；跨流派罚值是游戏平衡 |
| 死亡/代价 | 寿元、魂魄、真元皆可成为真实代价；杀招后遗症不可避免[^6] | 三轴死亡 + 付费不可致死预检 | “付费不可致死”是产品红线，不是原著明文 |

## 换皮 vs 原创（更新口径）

- **同构（允许）**：转数门禁、资质档、念头行动、杀招组合与代价、蛊实例生命周期。
- **原创（须保护且不得冒充原著）**：节点内真元预算、双轨真元、Roguelike 五段地图、商店价盘、pity 保底、化解标签枚举。
- **已废止旧口径**：`2^(gu-cultivator)` 下阶折价等“转数万能倍率”写法；以 `RUL-2026-09-19-008` 的 Rank Power Budget / Essence Budget 分轴为准[^2]。
