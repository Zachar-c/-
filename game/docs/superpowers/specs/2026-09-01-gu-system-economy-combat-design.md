# 蛊虫、炼蛊、养蛊、经济与战斗总规格

> 日期：2026-09-01
> 状态：**用户已批准的权威机制基线**
> 范围：蛊虫实体、核心蛊、构筑更新、炼蛊、蛊材、养蛊、交易、战利品、信息、真元、念头、魂魄、肉身、野兽与离散回合战斗。
> 权威关系：本文在上述范围内覆盖 `2026-08-25-mechanics-first-lockdown-design.md` 及更早文档；地图、轮回、事件日志、确定性、结局和其他未冲突条款继续沿用旧基线。冲突清单见第 18 节。

## 0. 设计目标与纪律

本系统要让玩家通过合理持有、获取、交换、养育、升炼和组合蛊虫获得构筑满足感，同时避免内容量随着蛊虫数量平方增长。

核心纪律如下：

1. **蛊虫是世界中的活物和独立实体。** 卡牌只是玩家操作蛊虫的界面，不是抽象技能许可证。
2. **万物皆可由蛊承载，但不能无来源地抽象。** 资质、肉身改造、侦察、交易能力和修行服务应优先落到具体蛊虫、杀招、蛊方、人物或场景行为上。
3. **代价真实存在。** 真元、念头、喂养、时间、蛊材、元石、风险和不可逆损失不得在结算后凭空补齐。
4. **玩家可以自由组合蛊虫。** 复杂性由统一数据语法和单一功能收敛，而不是通过禁止自由组合来解决。
5. **转数差距明显，但不是唯一设计轴。** 高一转产生数倍量级差；低转蛊仍可因低成本、辅助、规则能力、聚量和杀招配合进入高转构筑。
6. **所有重要结果可预见。** 会造成死亡、蛊虫死亡、核心损失、稀有资源永久消耗或禁忌后果的行为必须在执行前展示。
7. **中央参数导出最终值。** 内容数据优先声明转数、预算档位、倍率、运作方式和例外原因，不在每个内容对象中重复写死跨转数值表。
8. **规则引擎本地、确定且可复现。** LLM 不参与数值、掉落、炼蛊、战斗、交易、存档或隐藏状态判定。

### 0.1 实施边界

- 规则和数据结构支持一至九转。
- 第一轮完整内容和平衡验收覆盖一至五转；六至九转使用同一中央参数和 Schema 扩展，不另建第二套系统。
- 道标签是开放集合。首批内容不要求一次填满全部道途，但新道只需注册标签及其内容，不得修改蛊虫基础数据模型。
- 规则版本升级可以使旧的进行中 Run 存档失效；大厅存档、已解锁蛊方和图鉴必须迁移保留。不得把旧 Run 的抽牌、蛊槽或魂魄操作状态猜测性转换为新战斗状态。

## 1. 核心蛊与构筑更新

### 1.1 确认核心蛊

- 每局只能同时拥有一只核心蛊。
- 玩家在第一大层中段、已经经历若干获取与战斗后，于炼蛊台、传承或突破前主动确认。
- 玩家可以推迟确认，但会少享受一段核心倾斜；系统不得替玩家自动确认。
- 所有战斗蛊都可以被确认。确认界面必须提前标明：
  - **通用核心**：具有统一核心权益和通用升炼。
  - **传承核心/枢纽蛊**：除通用权益外，拥有人工设计的分支蛊方或专属异炼。
- 该标记表达内容深度差异，避免玩家误以为每只蛊都有相同数量的专属分支；它不否定普通蛊成为核心的资格。

### 1.2 核心权益

核心蛊采用“有限补全倾斜 + 少量专属升炼”：

- 后续获取池可以适度提高与核心主功能、道标签、食性和已有构筑相容的蛊、蛊材、蛊方及交易机会。
- 核心可以获得少量明确的专属改造或异炼入口。
- 倾斜只改善候选分布，不保证毕业、不指定必得产物，也不直接增加无来源的基础数值。
- 通用升阶保留原蛊身份，使任何核心都不会因内容量不足而掉队。
- 枢纽蛊可在特定转数或条件下异炼为新蛊并改变能力结构；异炼是主动选择，不是维持同转战力的必经门槛。

### 1.3 更换核心

- 核心可以更换，但代价显著；通常每局只有一次成功更换机会。
- 第二或第三大层的重大构筑节点保证提供一次“核心更换凭证”选择；凭证与异炼、稀有蛊或其他重大收益竞争，选择凭证意味着放弃当次强化。
- 高代价事件和黑市禁忌交易可以小概率提前或替代提供更换机会，表现机缘遍布世界；它们不允许绕过单局成功次数限制。
- 若玩家已经通过随机机缘更换，后续保证节点应提供其他同级重大收益，不再生成无用凭证。
- 更换时移除旧核心的专属改造，旧蛊保留正常转数和普通身份。
- 新核心从当前状态开始获得倾斜，不继承旧核心路线、专属改造或已经消费的成长资源。
- 代价可由稀缺凭证、元石、蛊材、寿元、魂魄或具体禁忌条件承担；来源必须提前公开。

### 1.4 构筑更新节奏

- 普通战主要提供蛊材、元石、信息和低概率蛊虫。
- 每经过约 `2-3` 个有效节点，路线必须保证一次买蛊、换蛊、炼蛊或定向战利品机会。
- 每个大层提供 `1-2` 次足以改变构筑方向的重大机会。
- 战后蛊虫候选最多三选一，也可以全部放弃。
- 没有“蛊槽已满”判断。持有数量由喂养、炼化、交易和处置成本形成软上限。

## 2. 蛊虫实体与分类

### 2.1 实例和定义

每只蛊虫实例至少记录：

- 定义 ID、实例 ID、转数、炼化状态、核心状态；
- 当前饥饿阶段、下次喂养需求、特殊保存状态；
- 剩余使用次数或生命周期状态；
- 忠主、凶性、寄生、逃遁、封存等实例状态；
- 已获得的实例级改造和来源。

同名蛊是不同实体。交易、喂养、炼化、灭蛊和催动都针对实例，不能只按定义 ID 模糊处理。

### 2.2 单一主功能

每只蛊只有一个主功能：

```text
攻击 / 防御 / 治疗 / 移动 / 侦察 / 辅助
```

- 主功能用于候选池、UI、AI 和预算审计。
- 蛊效应保持一个清晰的基础作用；增强、转化或复合用途主要来自与其他蛊的组合和杀招。
- 若新内容无法归入六类，必须先质疑它是否真的需要成为独立蛊效或独立资源。

### 2.3 多重道标签

- 蛊虫可以有一个或多个道标签，例如血道、气道、力道、魂道、炼道、智道、信道、律道、运道、变化道、光道等。
- 不设置独立“自然属性”轴；金、木、水、火、土、风、雷等若成为规则标签，同样作为道标签处理。
- 难以界定为单一道途的蛊直接拥有多个道标签，不强行归入唯一流派。
- 道标签用于蛊方、交易需求、食性、构筑倾斜、信息和明确的相容性条件，不自动产生全局克制倍率。

### 2.4 生命周期与运作方式

生命周期独立声明：

- 一次使用后消耗；
- 有限次数使用后消耗；
- 正常使用不会消耗的长期蛊。

运作方式独立声明：

- **瞬时型**：催动时消耗念头和真元，结算后释放操控。
- **展开自持型**：展开时消耗念头；效果展开后自行运转，是否继续消耗真元由蛊效声明。
- **主动维持型**：生效期间持续占用念头，并按蛊效声明持续消耗真元或其他资源。

蛊虫催动时必然需要念头；效果已经展开后是否继续需要念头，完全由运作方式决定。念头约束蛊师正在主动组织和操控的过程，不约束所有已经存在于世界中的蛊效。

### 2.5 同转价值

- 转数是量级，不是同转内容的硬上限。
- 同转价值可来自更高数值、效率、适用范围、永久性、不可替代功能、构筑枢纽作用、低真元依赖、规则改变、蛊方绝迹或世界存量。
- 珍稀蛊通常可达到同转标准预算约 `1.25-1.5` 倍；传说价值蛊可以更高。
- 只有接近或跨越高一转完整量级时，才必须特别审查成立条件、机会成本和世界来源。
- 高价值不自动增加真元成本、念头复杂度或食量。玉皮蛊可以与石皮蛊使用相同标准成本，却提供更高防御；只有实际运作确实更昂贵时才提高成本。
- 价值称谓描述同转价值和世界存量，不是脱离转数的统一掉落强度轴。公开出现率仍由来源、地域、势力和库存决定。

## 3. 买蛊、卖蛊与换蛊

### 3.1 买蛊

- 买蛊门槛低、元石价格高，是可靠但昂贵的构筑补全渠道。
- 公开商店主要提供公开流通、同层可用、低价值或常用基础蛊。
- 高价值、绝迹、传承和禁忌蛊即使具有参考估值，也不因此进入普通货架。
- 商店必须展示实例转数、功能、道标签、实际催动成本、食性和下次喂养需求。

### 3.2 普通卖蛊

- 普通商贩低价回收蛊虫，主要作用是清理未来喂养压力并回收少量价值。
- 一只普通常用蛊的基础回收价等于一份同转普通蛊材价值，约能补足一只标准蛊一个大层的普通喂养预算。
- 珍稀和传说价值蛊不套普通回收公式；商贩可以拒收或给出明显不合理的低价。
- 玩家想保留高价值蛊的大部分价值，应寻找有需求的 NPC、换蛊、献炼或蛊方用途。

### 3.3 换蛊与需求交易

- 换蛊门槛高，适合玩家进行有牺牲代价的禁忌交易，或交付 NPC 明确需要的高稀有度、高价值蛊。
- 需求必须限定具体蛊、道标签、转数、实例性质或数量，满足后消失或降低，防止重复套利。
- 高价值交换不能机械折算为“补足若干元石即可成交”。NPC 可以拒绝价值足够但性质不符的物品。
- 交易前必须展示将永久失去的实例、核心状态、未完成喂养价值和可能触发的势力后果。

## 4. 自由组合与杀招

### 4.1 自由组合

- 玩家可逐只催动所有已经炼化、满足转数和状态条件的蛊虫。
- 卡牌是蛊虫实例的操作界面；已持有蛊能否使用不由随机抽牌决定。
- 玩家默认按串行顺序编排，也可以建立明确的并行组。
- 每只蛊先按自身单一功能结算；后续蛊可以读取已经形成的状态、距离、标记和蛊效。
- 基础联动不需要知识门槛。组合本身不额外收取真元，也不凭空生成协同倍率。

### 4.2 命名杀招

- 具有协同倍率、替代步骤、特殊规则或复合结果的命名杀招，需要通过传承、购买、遗藏线索、推演或玩家验证掌握。
- 验证过的自由编排可以保存为杀招，之后一键提交；保存不把多只蛊变成一个不可打断的按钮。
- 杀招默认累加组成蛊的真实真元、念头、蛊材和使用次数成本。任何节省、增幅或额外代价都必须来自明确杀招规则。
- 杀招可以跨回合维持编排。未完成步骤、主动维持和反应预留照常占用念头。

### 4.3 编排和失败传播

- 串行步骤按顺序结算；并行组中的步骤分别结算。
- 某一步被打断，不撤销已经完成或仍能独立完成的其他步骤。
- 显式依赖失败步骤的后续动作自动停止。
- 未执行动作不扣真元、蛊材、使用次数或一次性实体资源；已经分配的念头本回合不返还。
- 玩家可以预设合法分支。没有预设分支时，只有具体蛊效、杀招或临机手段允许改招。
- 不是每个动作都产生反应窗口；窗口必须由动作、蛊效或杀招步骤明确声明。

## 5. 炼蛊

### 5.1 统一术语和标准产物关系

- 所有蛊虫合成关系统一称为“蛊方”，不再并列使用抽象“配方”指代另一种合成系统。
- 标签合炼和核心异炼采用“主蛊被改造为产物”：主蛊与辅蛊的原形都消失，最终只留下一个产物实例。
- 主蛊决定承载路线、核心身份、有效转数边界和部分继承标签；辅蛊提供变化条件并永久消耗。
- 核心蛊可以作为主蛊。核心蛊作为辅蛊时必须强警告并二次确认。
- 盲炼和少数高收益禁忌蛊方可以明确使用其他输入去向或多产物结构；例外必须写在蛊方中，不能成为默认行为。

### 5.2 标签蛊方与精选产物

- 标签蛊方根据输入蛊的主功能、道标签、转数、当前大层和蛊方条件，从人工设计的小型候选池中确定性筛选，或提供 `2-3` 选一。
- 例如攻击主功能与毒道标签可进入毒攻候选族；防御主功能与血道标签可进入血甲候选族。
- 新增蛊只需声明自身标签和可进入的候选族，不必与所有旧蛊逐对编写蛊方。
- 候选池只决定可能产物，不能生成没有人工定义效果和世界来源的程序化蛊。

### 5.3 成功、失败与步骤

- 已知普通蛊方在条件完整、安全且未被打断时确定成功，不使用随机概率吞掉正常材料。
- 随机失败、异常产物和炸炉只保留给盲炼、禁忌蛊方及明确声明风险的特殊炼制。
- 炼蛊步骤、念头占用、真元消耗和材料投入不固定，由蛊方复杂程度分阶段声明。
- 跨回合炼制每回合继续占用其阶段声明的念头；停止投入时按蛊方声明中止、回退或损失。
- 界面在开始前展示完整材料身份、阶段、每阶段念头、真元、耗时、可打断点、失败条件和产物。

### 5.4 材料身份和替代

1. 蛊方点名要求某只蛊、某种蛊材、某个道标签、某个转数或特定媒介时，必须实际满足。
2. 等值的其他蛊材和元石不能自动替代蛊方要求。
3. 只有蛊方明确允许“同道同转材料”“任意媒介”或其他替代关系时，才能换料。
4. 替代是否降低成功条件、增加步骤或改变产物，也由该蛊方明确声明。
5. 元石估值只用于经济预算和套利审计，不是万能炼蛊点数。

### 5.5 低转投入与经济审计

- 低转蛊虫可以作为蛊方输入被大量消耗，形成低转蛊的长期出口。
- 低转蛊材可以聚量、加工或逐转升炼；特定流派允许聚量产生高转效果，见第 15 节。
- 蛊方首先满足真实材料身份和世界逻辑，策划再用元石估值检查稳定套利。
- 传承、绝迹材料、炼制时间、失败风险和炼道手段可以让蛊方明显便宜或昂贵。
- 只要无法通过公开买料、炼蛊、卖出形成可重复、无风险获利，成本不必机械贴近产物售价。

## 6. 蛊材、升炼与可分割性

### 6.1 统一蛊材体系

- 食料也是材料，统一称为蛊材。
- 蛊材覆盖一至九转，并声明道标签、食性标签、是否普通、是否专属、是否可分割、公开流动性和参考价值。
- 同转普通蛊材基础价值统一，便于喂养、炼蛊和经济预算。
- 稀缺、专属、秘密交易蛊材可以有明确价值溢价；溢价影响获取和交易，不直接提高喂养效果。

### 6.2 向下折算

- 高转普通蛊材可按中央转数价值折算为多份低转喂养当量，但必须满足食性。
- 血气等可分割材料可以精确扣取。
- 完整兽骨、魂核等不可分割材料若无加工手段，超出本次需求的价值会浪费，不会自动退回库存。
- 点名专属食料必须继续满足具体名称要求，不能只凭价值或转数向下替代。

### 6.3 有损升炼

低转普通蛊材可以逐转有损升炼：

```text
output_value = input_value * material_refine_efficiency
```

- `material_refine_efficiency` 为中央参数，当前为 `0.5`。
- 当前相邻转数价值倍率为 `2.0`，所以当前等效数量比为 `4:1`。
- 只能逐转提升；跨多转必须逐级结算损耗。
- 蛊方还可以要求同转媒介、元石、特定蛊或炼道手段。
- 高转蛊材仍主要来自高风险区域、同转生灵和高转生产方式，不能靠低转安全区无损工业化获得。

## 7. 喂养、饥饿与食道

### 7.1 结算节奏和食量

- 每个大层结束时统一进行喂养结算；全程显示预计需求和缺口。
- 标准蛊每大层消耗 `1` 份同转匹配蛊材当量。
- 食量使用中央倍率：

```text
small = 0.5
standard = 1.0
large = 2.0
```

- 蛊虫实际转数决定需求价值。低转蛊师持有高转蛊仍按高转全额喂养。
- 未炼化蛊仍是活物，照常参加结算；封存只防止逃走和反抗，不自动取消食量。
- 特殊休眠、食道保存或封蛊手段可以明确降低食量，但必须来自具体蛊虫、杀招或蛊方。

### 7.2 两阶段饥饿

- 本次未喂足后进入“饥饿”，下一大层不能正常催动。
- 下一次结算仍未补足则蛊虫死亡。
- 玩家在结算界面主动决定喂养顺序，并提前看到哪些蛊会饥饿或死亡。
- 释放、交易、献炼、灭蛊或找到特殊保存手段都可以成为结算前的处置方案。

### 7.3 经济软上限

- 无限持有不等于无限养得起。
- 扣除必要成长投资后，若玩家将约 `50%` 的剩余可支配资源价值用于喂养，通常能维持 `4-5` 只标准食量的同转蛊。
- 剩余约一半用于买蛊、炼蛊、交易门槛、应急消耗和囤积。
- 这是路线总价值预算，不是每层固定掉落四五份特定食料；玩家可以通过出售、元石购买、交易、加工和流派自产换取所需蛊材。

### 7.4 匹配食料、通用食料与应急替代

- 匹配食料按正常当量满足需求。
- 普通不匹配蛊材只能作为应急替代，基础最多满足需求的 `50%`；剩余必须由匹配或点名食料补足。
- 通用食料可以拥有自己的替代比例。该比例属于食料本身，不是食道角色的全局被动。
- 龙鱼肉当前参考：

```text
普通龙鱼肉 50%
铜龙鱼肉   70%
铁龙鱼肉   80%
银龙鱼肉   90%
金龙鱼肉   95%
```

- 通用食料品质越高，可替代比例越高；混入低品质食料会按投入喂养当量拉低整体替代能力。
- 多种通用食料混用时采用以下确定性规则，其中 `amount_i` 是同转喂养当量，`replacement_i` 是该食料自身替代率：

```text
mixed_replacement = sum(amount_i * replacement_i) / sum(amount_i)
universal_fulfilled = min(sum(amount_i), total_need * mixed_replacement)
matching_required = total_need - universal_fulfilled
```

  低品质投入因此一定会把混合替代率拉低；额外堆叠通用食料不能突破混合替代率上限。
- 即使替代率为 `95%`，剩余 `5%` 仍必须使用匹配食料；点名专属食料按蛊虫具体要求处理。

### 7.5 食道定位

食道不把所有材料全局变成通用食料。食道通过以下真实渠道经营养蛊：

- 培育铜、铁、银、金龙鱼等更高替代率的通用食料；
- 加工不可分割蛊材，减少向下喂养浪费；
- 保存、休眠、节食和延缓饥饿；
- 提高特定蛊方、食料生产和蛊材处理效率；
- 以具体蛊虫、杀招和生产节点提供上述能力。

## 8. 战利品、收取与处置

### 8.1 四类战利品

所有战利品和收获归入四类：

```text
蛊虫 / 蛊材 / 元石 / 信息
```

商店服务、采集机会和改造机会是节点或 NPC 提供的行动；行动最终产生的持久收获仍归入四类或由具体蛊虫造成明确状态改变。

### 8.2 总价值预算与世界内来源

- 使用“总价值预算 + 世界内来源分配”，不为普通战、精英战和 Boss 战写死固定掉落组合。
- 敌人携带什么、战斗发生在哪里、什么被损毁、玩家采用何种收取手段，决定四类收获的实际构成。
- 敌人蛊虫、蛊材、元石和信息本来就计入其总价值预算。
- 掉落预算用于生成敌人和场景，不能在敌人死亡后强行裁剪真实幸存物。

### 8.3 幸存蛊和炼化残意

- 敌人死亡后，幸存蛊可以被收取，但不会自动成为可立即催动的己方蛊。
- 玩家需要收取并炼化其中残留意志。
- 安全且时间充足时，普通同转及低转蛊确定性炼化，只消耗时间和真元。
- 高于玩家转数的蛊可以收取和持有，但因真元质量不足不能催动。
- 凶性、忠主、寄生、绑定或逃遁蛊必须预先声明额外收取条件。
- 炼化失败只来自条件不足、被打断或特殊蛊虫规则，不能用普通随机判定吞掉战利品。
- 未炼化蛊可以按交易规则封存交易；能否献炼由蛊方声明。

### 8.4 真实携带与损毁

- 敌人真实携带且幸存的蛊，玩家满足收取条件后即可获得。
- 借来的、消耗的、寄生的、绑定的、易损的蛊，其性质必须在战前存在并可被侦察。
- 不得在战后临时判定“这只蛊不掉”。
- 高价值敌人携带完整蛊组意味着更高收益、风险和后续追兵，不需要用虚假掉落保护经济。

### 8.5 释放与灭蛊

- 释放蛊虫是世界内处置行为，不是库存删除按钮。
- 普通蛊可能逃走；危险、忠主或有灵性的蛊可能暴露玩家、回归原主、袭击玩家或在后续节点出现。
- 后果必须在释放前公开；普通无害蛊可以简单释放，不强制为每只蛊生成事件。
- 想确保不留后患，应出售、换出、献炼或使用明确的灭蛊手段。
- 灭蛊不统一返还固定比例蛊材。能否提取残骸、精华及数量取决于蛊种、死亡方式和收取手段；炼道、食道可以提高具体利用率。

## 9. 元石、市场和信息

### 9.1 元石和普通价值刻度

- 元石是唯一一般等价物，始终只有数量，没有转数、品质或面额。
- 一份一转普通蛊材的公开市场标准买价当前为 `10` 块元石。
- 高转普通蛊材标准价值由中央转数倍率导出。
- 公开流通普通蛊材基础回收率为 `50%`；`30%` 仅用于低流动性物品。
- 危险、秘密或禁忌蛊材可以被普通商贩拒收。

### 9.2 NPC 需求价格

- NPC 需求收购档位为公开标准买价的 `80% / 100% / 120%`。
- 这三档仍显著高于普通 `50%` 回收，但是否成交取决于真实需求身份。
- 需求必须限定对象和数量，满足后消失或降低。
- 高价值蛊、绝迹蛊方和禁忌物优先走换蛊或秘密交易，不套普通收购表。

### 9.3 蛊虫价格和大层消费节奏

- 常用基础蛊公开售价约为四份同转普通蛊材价值。
- 普通常用蛊回收价约为一份同转普通蛊材价值。
- 每大层扣除成长与喂养后，玩家通常只剩约一次常用基础蛊级别的自由消费能力。
- 这笔能力可以用于买一只基础蛊、进行价值相近的炼蛊、完成交易、应急支出或囤积，但不能全部同时满足。
- 所有蛊都可以有参考元石估值；只有公开流通蛊才有正常买卖价格，估值不代表能用元石买到。

### 9.4 结构化信息

信息不是万能点数，每条信息记录可验证的具体事实，包括：

- 敌人弱点、携带物和准备状态；
- NPC 需求、库存、底价、暗号和关系；
- 蛊方及其材料、步骤、例外与风险；
- 隐藏节点、追兵、伏击、地盘和路线；
- 遗藏与传承线索，以及线索中实际揭示的内容。

信息价值由真实性、精确度、时效性、可利用对象和独占程度共同决定。

- 已公开、过期或玩家早已掌握的信息可以价值为零。
- 蛊方、遗藏核心线索和紧急需求情报可以价值很高。
- 出售信息不会让玩家忘记，但会传播并降低独占价值。
- 每个买方只为同一事实付费一次。
- 信息可以被使用、出售、验证或失效；不得汇总成万能情报点数。

## 10. 中央转数与效果预算

### 10.1 转数倍率

```text
rank_multiplier(rank) = rank_step_ratio ^ (rank - 1)
rank_step_ratio = 2.0  # 当前平衡参数，不是内容写死数组
```

当前一至五转导出结果为 `1 / 2 / 4 / 8 / 16`。数据表不得重复保存该数组。

高一转产生数倍量级差；低转蛊仍可凭低成本、辅助效果、规则能力、聚量和杀招进入高转体系。

### 10.2 人类与同转标准锚点

普通成年人的制作锚点：

```text
human_base_health = 100
human_base_strength = 100
human_base_body_capacity = 100
unarmed_damage_ratio = 0.2
```

因此普通成年人的常规全力重击为 `20` 原始伤害，约五次有效重击耗尽基础气血。

### 10.3 专职攻击、防御和固定防御

同转专职攻击蛊的标准威力：

```text
standard_gu_power(rank)
  = human_base_health * standard_hit_ratio * rank_step_ratio ^ rank
standard_hit_ratio = 0.2
```

当前一至五转结果为 `40 / 80 / 160 / 320 / 640`。

同转专职主动防御蛊支付正常代价后，标准总防护当量与同转专职攻击预算相同。耐久防护可被一次攻击耗尽，也可由多次攻击逐步消耗；偏转、闪避、转移等非耐久防御明确处理次数和条件。

常规同转身体改造后的蛊师被动固定防御，以及同转野兽的天然固定防御，参考抵消同级有效重击的 `20%`。当前凡人至五转参考为：

```text
4 / 8 / 16 / 32 / 64 / 128
```

对蛊师，该数值来自蛊虫、杀招和道痕改造；对野兽，该数值来自天然肉身。升转本身不赋予蛊师固定防御。

### 10.4 防御结算顺序

```text
攻击原值
-> 临时防护吸收
-> 身体固定防御
-> 比例减免
-> 扣除统一气血
```

- 固定防御可以把伤害降至 `0`，不存在强制最低伤害。
- 不同机制可以叠加；同机制采用递减并受中央上限约束。
- 每个效果必须声明自己的 `stack_group`、叠加方式和上限，禁止 UI 或具体敌人手写另一套顺序。

### 10.5 蛊师治疗

同转专职治疗蛊一次标准治疗约等于凡人基础气血的 `20%` 乘转数：

```text
human_standard_heal(rank) = human_base_health * 0.2 * rank
```

当前一至五转为 `20 / 40 / 60 / 80 / 100`。

- 蛊师气血不会随转数自动增长，高转治疗的优势是恢复更充分并处理高转蛊效、道痕、毒伤和濒死状态。
- 普通治疗只恢复气血；其他特殊状态必须由治疗蛊明确声明可处理。
- 野兽不使用这张表，见第 14 节。

## 11. 真元与资质

### 11.1 空窍显示和资质

- 空窍统一使用 `0%-100%` 尺度。
- 资质决定实际真元海上限。例如资质 `44%` 时，界面显示 `当前真元 31% / 上限 44%`，不能把 `44%` 重新归一为满槽 `100%`。
- 提升资质就是提高这个上限；新增上限不会自动填满。
- 甲乙丙丁等只是实际百分比的区间名称，不取代真实数值。
- 升转提高真元质量，不自动增加资质、真元槽长度或真元当前量。

### 11.2 转数质量和催动门槛

- 普通低转蛊师不能催动高转蛊，原因是真元质量不足，不是数量不足。
- 少数珍稀蛊可以明确声明允许低转真元催动；该例外是蛊虫价值的一部分。
- 高转真元可以按质量折算催动低转蛊：

```text
actual_cost_percent
  = gu_native_cost_percent
  * rank_multiplier(gu_rank)
  / rank_multiplier(cultivator_rank)
```

- 该公式只在蛊师转数不低于蛊虫转数时使用；实际界面展示换算后的百分比。

### 11.3 催动和维持成本

```text
standard_activation_cost = 10%
light_cost_ratio = 0.5
standard_cost_ratio = 1.0
heavy_cost_ratio = 2.0
```

当前轻型、标准、重型原生催动成本为 `5% / 10% / 20%`。

- 每只蛊按自身转数声明催动成本档位、倍率和必要维持成本。
- 杀招默认累加所有组成蛊的实际成本，不因“组合”额外收费。
- 任何增幅、节省或额外代价必须来自明确蛊效、蛊方或杀招规则。

### 11.4 自然恢复和战后时间

```text
natural_recovery_per_turn
  = standard_activation_cost
  * natural_recovery_cost_ratio
  * aptitude_recovery_multiplier

natural_recovery_cost_ratio = 0.1
aptitude_recovery_multiplier = 0.5 + aptitude_percent / 100
```

当前示例：`20% -> 0.7`、`50% -> 1.0`、`100% -> 1.5`。标准资质每个正常战斗回合当前恢复约 `1%` 真元。

- 战斗内自然恢复很慢，只提供少量续航。
- 显著战斗内恢复需要花时间并承担暴露风险吸收元石，或使用具体蛊虫、杀招和场地。
- 安全且时间充足时，战斗结束后可以恢复到资质上限。
- 若被追击、连续接战或没有休息窗口，只按实际经过的离散恢复回合结算。
- 元石吸收的数量换算由中央经济参数和具体手段声明；元石库存本身仍只有一个数量，不获得品质或转数。

## 12. 念头、离散回合与自由编排

### 12.1 念头容量

- 念头与魂魄彻底分离。
- 念头不是路线中积累和消耗的存量资源，而是每个行动窗口的思考与操控能力。
- 每回合开始，本回合已消耗念头清零，重新获得当前容量；主动维持先占用本回合容量。
- 所有普通蛊师基础念头容量为 `3`。
- 各流派通过本流派内具有智道效果的蛊虫通常发展到 `4-6`；智道专精通常达到 `6-8`。这些是构筑区间，不是绝对硬上限。
- 升转、魂魄量级和魂魄质量不自动增加念头。
- 智道蛊可以临时或永久提高容量；非智道流派必须有本流派包装的可获得渠道，确保高阶杀招可用。

### 12.2 念头复杂度和一次性

- 蛊虫念头复杂度基础档位为 `1 / 2 / 3`，由操控复杂度决定，不由转数决定。
- 五转但运作简单的蛊可以只需 `1` 点；一转但要求同时控制许多细节的蛊可以需要 `2-3` 点。
- 瞬时催动结算后不再持续占用，但本回合已经消耗的念头不返还。
- 自持型展开后释放持续占用；主动维持型持续占用。
- 炼蛊由各蛊方阶段声明。
- 玩家可以故意保留未分配念头用于反应。

### 12.3 实体每回合使用权

- 同一回合，每种基础动作最多使用一次：移动、徒手攻击、闪避、擒抱各一次。
- 同一回合，每只蛊虫实例最多主动催动一次。两只同名蛊是两个实体，可以分别催动一次。
- 主动维持中的蛊视为本回合正在运作，不能重复催动。
- 自持型蛊已经存在的效果不等于再次催动该实例。
- 并行组不能重复放入同一种基础动作，也不能重复放入同一蛊实例。
- 跨回合动作在后续回合继续推进时，占用该回合对应动作或蛊实例的使用权。
- 只有具体蛊、杀招、分身或额外实体明确声明时，才允许突破实例唯一性；念头增加本身不允许同一身体动作或同一蛊重复。

### 12.4 离散回合阶段

连续时间轴被废止。每回合按以下阶段结算：

```text
声明动作与敌方意图
-> 瞬时
-> 快速（含明确反应窗口）
-> 标准
-> 蓄势开始或完成
-> 回合结束
```

- 双方在同阶段维护各自动作序列，并逐轮取下一个动作对齐结算。
- 互不冲突的动作同时生效；只有同阶段、同一轮、发生直接冲突时才比较速度。
- 一方动作耗尽后，另一方剩余合法动作继续依次结算。
- 同一方只有明确编成并行组的动作同时结算。
- 前置失败、目标死亡、距离失效或条件不再满足时，依赖动作自动停止。
- 动作分别声明打断条件，不设置“受到任意伤害必定打断”的全局规则。

### 12.5 跨回合动作和暂停

- 蓄势和其他跨回合动作声明需要几个完整回合，不使用时间单位、小数进度或速度倍率换算。
- 玩家上一回合开始擒抱维持、复杂地形移动或炼制，下一回合必须继续投入相应念头。
- 不继续投入时默认中止；已发生的客观结果保留，未完成的抽象进度清除。
- 不设置通用“免费暂停并保留全部进度”。只有动作明确声明可停顿点，例如到达稳定落脚处，才能保留部分进度。

### 12.6 反应窗口

- 玩家可以预留念头用于回合中的临场反应。
- 常见反应可以预设，关键反应允许手动介入。
- 只有动作、基础动作、蛊虫或杀招步骤明确声明反应时点，玩家才能插入临机动作。
- 已分配给尚未执行动作的念头本回合不返还；只有预设分支或明确临机手段允许改招。

## 13. 基础动作、距离和速度

### 13.1 四种基础动作

所有普通人类蛊师默认只有四种通用战斗基础动作，每种消耗 `1` 点念头：

1. **移动**：默认标准阶段，通常改变一个距离带；起身、脱离等作为情境规则。
2. **徒手攻击**：拳、掌、踢共用一个标准动作，不拆为不同卡牌。
3. **闪避**：快速反应，只能在攻击明确开放的窗口使用，不是常驻减伤。
4. **擒抱**：包含发起控制、维持控制与挣脱，不再拆成独立基础动作类型。

等待、取消和预留念头属于回合指令；采血、收魂、吸收元石、炼化等是各自声明规则的世界行动。

### 13.2 动作结算时点

- 基础动作默认在完成时产生主要效果。
- 徒手攻击完成时造成伤害。
- 擒抱完成时进行力量对抗。
- 闪避完成后获得针对该次攻击的闪避资格。
- 移动完成时改变距离带。
- 只有动作明确声明中途检查点，才允许执行期间产生部分客观效果。

### 13.3 四级距离带

```text
接触 / 近距 / 中距 / 远距
```

- 不使用二维战棋格子。
- 基础移动一次改变一档；跨档、飞行、遁地或无视距离由具体移动蛊、杀招或物种能力声明。
- 普通徒手攻击只能在接触距离发起并命中。
- 结算前目标已离开接触，攻击因目标失效而停止；已分配念头不返还，未支付实体资源不扣除。
- 普通移动和徒手攻击不能合并；突进攻击必须来自明确蛊虫、杀招或物种能力。

### 13.4 脱离接触

- 从接触移动到近距时开放一次脱离反应窗口。
- 接触目标不会自动获得免费攻击。
- 对方只有预留念头并拥有合法反应，才能发起擒抱、拦截蛊或声明为脱离反应的攻击。
- 若拦截或擒抱在直接冲突中更快并成功，移动停止；移动先成立后，依赖接触距离的反应失去条件。
- 普通徒手攻击默认不是脱离反应。

### 13.5 小范围速度

```text
普通成年人基础速度 = 3
常见速度范围 = 1-5
常见动作速度修正 = -1 / 0 / +1
conflict_speed = current_speed + action_speed_modifier
```

- 速度只在同阶段、同一轮、直接冲突时比较。
- 较快一方先结算；若结果破坏另一动作条件，后者停止。
- 速度相同则同时结算，允许同时命中和同归于尽。
- 阶段优先于速度；标准动作不能用高速度越过快速阶段。
- 速度不增加动作数、念头、回合或随机命中率。
- 转数不自动提高速度；物种、移动方式、明确状态、场地和蛊效可以修改。

### 13.6 确定性闪避

- 攻击必须声明是否允许基础闪避并开放窗口。
- 玩家必须预留并支付 `1` 点念头。
- 闪避在快速阶段完成，且玩家未被擒抱、束缚或场地限制时，确定避开该次攻击。
- 基础闪避不改变距离带，只表示在当前距离带内避开打击范围。
- 范围、追踪和封锁空间攻击可以明确禁止基础闪避或要求移动蛊等手段。
- 不进行随机命中率检定；失败只来自条件不满足或直接冲突失败。

### 13.7 确定性擒抱

- 只能在接触距离发起，消耗 `1` 点念头，默认标准阶段。
- 发起者声明实际力量；目标可以在开放的反应窗口闪避。
- 未避开时进行力量对抗。目标未投入念头抵抗则擒抱成立。
- 目标支付 `1` 点念头抵抗时也声明实际力量；发起者力量更高则成立，相等或更低则失败，平手有利于防守方。
- 双方都可以主动超过身体承载并分别承担超载自伤。
- 成立后双方保持接触，被擒抱者不能用普通移动拉开距离；不会自动禁止催蛊、攻击或其他行为。
- 维持者每回合占用 `1` 点念头及擒抱动作使用权；停止投入便松开。
- 被擒抱者可用擒抱基础动作挣脱，再次进行相同力量对抗。
- 体型异常和无实体目标由物种、蛊效或状态明确声明，不新增稳定值或擒抱值。

## 14. 蛊师肉身与野兽

### 14.1 蛊师肉身

- 未经蛊虫、杀招、道痕或其他明确手段强化的人类蛊师，本质仍是凡人。
- 升转不自动增加气血、力量、身体承载、固定防御或速度。
- 不设置兵器系统。
- 不设置身体部位、部位血量、结构伤势或通用“身体重伤”状态。
- 普通伤害只扣统一气血；普通气血损失不降低身体承载、力量或移动能力。
- 降低身体承载、禁止移动或妨碍攻击必须来自具体蛊效、杀招或场景状态，并声明数值和持续时间。

### 14.2 徒手伤害和力量超载

```text
unarmed_raw_damage
  = actual_strength * unarmed_damage_ratio * action_multiplier

safe_strength = current_body_capacity
overload_strength = max(0, actual_strength - safe_strength)
overload_self_damage
  = overload_strength * unarmed_damage_ratio * reaction_multiplier
```

- 当前 `unarmed_damage_ratio = 0.2`，标准徒手动作 `action_multiplier = 1.0`。
- 标准反作用倍率由中央参数提供，具体力道蛊或杀招可以明确降低。
- 玩家可以主动超过身体承载。
- 界面提前显示安全力量、实际力量、对外原始伤害和预计自伤；预计会直接死亡时必须二次确认。
- 超载自伤是身体承载失败造成的内部代价，普通外部防护不能抵消；只有明确处理反作用或自伤的蛊效可以减免。
- 不同身体强化机制可以叠加；同机制递减并有上限。
- 流派之间可以有明确承载冲突，例如大量力道改造导致化光失败。冲突由具体蛊声明条件，不维护全局逐对相克表。

### 14.3 野兽独立模型

野兽的天然肉身随转数进入相应量级：

```text
beast_scale(rank) = rank_step_ratio ^ rank
```

当前参考：

| 层级 | 气血 | 天然力量 | 身体承载 | 同级重击 | 固定防御 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 凡兽 | 100 | 100 | 100 | 20 | 4 |
| 一转兽 | 200 | 200 | 200 | 40 | 8 |
| 二转兽 | 400 | 400 | 400 | 80 | 16 |
| 三转兽 | 800 | 800 | 800 | 160 | 32 |
| 四转兽 | 1600 | 1600 | 1600 | 320 | 64 |
| 五转兽 | 3200 | 3200 | 3200 | 640 | 128 |

- 表中结果必须由中央参数生成，不在每个野兽数据中重写。
- 具体物种对气血、力量、承载、防御和速度作显式修正。
- 速度不套转数翻倍表。
- 野兽治疗使用兽类专用、百分比恢复、种族再生或同转兽体治疗，不与蛊师 `20 / 40 / 60 / 80 / 100` 表混用。

## 15. 血道、气道、魂道与食道特例

### 15.1 血气与血道

- 血气是一种同时具有血道和气道标签的可分割蛊材，两道争用同一真实库存。
- 击杀有血生灵时，目标血量、转数、死亡方式和采血手段决定血气产量与转数。
- 玩家可以主动牺牲气血放血，通常只能凝炼不高于自身转数的血气。
- 基础搜刮保留；深度采血额外消耗时间、工具或增加血腥踪迹。只有紧迫场景才要求与普通搜刮二选一。
- 血道是魔修中的魔修，资源难以公开交易；主要进入高门槛秘密交易，并容易引来袭击、追踪和势力敌视。
- 血道可以大量叠加低转血气达到高转蛊材或蛊效量级。
- 多数血道蛊以血类食料为主，形成食性集中、来源危险的养蛊优势。

### 15.2 气道聚量

- 气道可以消耗气道蛊材达到蛊虫效果，投入越多效果越强。
- 聚量关系必须由蛊效声明曲线、上限和最低单位，不能把所有气道材料自动换成万能伤害。
- 血气因双标签可以进入气道消耗，也会因此与血道喂养、升炼和交易形成真实机会成本。

### 15.3 魂道收益和收魂

- 只有有魂生灵提供魂道收益。
- 魂兽由魂魄凝聚而成，死亡后掉落实体魂核；魂核是魂魄精华，可以作为实体战利品收取。
- 普通魂魄不是实体物品，必须通过魂蛊、魂器、杀招或蛊阵收取和储存；具体手段声明容量、效率和损耗。
- 玩家也可以用蛊虫或杀招直接吞魂壮大自身魂魄。不同手段在效率、稳定性、兽性和上限上有差异。
- 魂道以战养战：少量即时汲魂可以提供当场收益，主要魂魄在战后通过收魂手段转化为可储存蛊材、喂养、炼蛊或下一战资源。

### 15.4 魂魄数值

魂魄与念头没有直接关系。魂魄使用以下独立量：

- **魂魄量级**：连续人魂当量，例如 `37 人魂`、`260 人魂`；百人魂、千人魂只是称号和关键阈值。
- **安全承载**：直接显示当前魂魄质量可安全承载多少人魂，例如 `当前 137 / 安全承载 120`，不再增加抽象魂质等级或倍率。
- **安分程度**：`0-100`，表示魂魄是否稳定、服从和安守本体。
- **魂性**：同一时间只允许一种，不做混合魂。
- **兽性**：独立积累项；安分程度决定兽性是否显现、污染和失控。

对应操作：

- 壮魂提高魂魄量级。
- 炼魂提高安全承载。
- 安魂提高安分程度。

允许玩家主动把魂魄壮大到安全承载以上，以虚浮和不稳定换取短期魂道力量。预计会直接膨胀死亡时必须二次确认。

- 魂魄超过安全承载会虚浮，进一步增长可能像气球一样膨胀爆裂。
- 安分不足会导致情绪化、兽性显现、魂魄离体和失控。
- 狼魂蛊等可以提高安全承载，但会使魂魄接近狼并积累狼性。
- 低度兽性可以强化感知、追猎、近战或特定魂蛊；高度兽性公开加入兽念、污染选择并提高失控风险。
- 兽念和阈值必须提前展示，允许玩家主动保留、利用或净化兽性。
- 彻底兽化、失去修行主体性是非死亡特殊结局，必须由玩家在达到危险条件后主动二次确认，不得由数值阈值静默结束本局。

## 16. 战前准备、信息与世界一致性

- 展开自持型蛊可以在战前提前催动。
- 敌人也可以根据其掌握的信息、拥有的准备时间和经营地盘提前展开自持型蛊、陷阱与侦察手段。
- 玩家主动袭击且没有泄露行踪时，可以剥夺敌人准备窗口。
- 玩家暴露、拖延或进入敌人经营的地盘时，敌人可能带着完整防护和布置接战。
- 所有准备状态必须来自真实蛊虫、杀招、场地和已发生事件，并可以被相应侦察手段发现。
- 信息、伏击和时间必须改变战斗起始状态，而不是只提供抽象数值加成。

## 17. 数据、界面、日志与验收

### 17.1 中央数据职责

中央平衡配置至少包含：

- 转数倍率、标准攻击、防护、固定防御和野兽尺度；
- 徒手系数、反作用倍率、治疗基准；
- 真元成本档位、质量折算、自然恢复和资质恢复；
- 念头常见区间、速度范围和动作修正；
- 蛊材价值、升炼效率、买卖回收率、需求价格；
- 食量档位、普通应急替代上限和通用食料替代属性；
- 核心倾斜、构筑机会间隔和大层经济预算。

具体蛊、蛊材、蛊方、敌人和商店优先声明档位、倍率、标签和例外，不复制中央最终值。确有世界观理由的特殊内容可以覆盖，但必须附 `override_reason` 并通过 Schema 校验。

### 17.2 UI 透明要求

玩家不需要理解内部公式，但必须看到换算后的真实结果：

- 蛊虫实际真元百分比、念头、每回合使用状态和维持状态；
- 核心类型、倾斜、异炼结果和更换损失；
- 蛊方输入身份、阶段成本、成功条件、风险和产物；
- 下次喂养需求、匹配比例、通用替代率、饥饿与死亡预测；
- 交易买价、卖价、需求条件、参考估值和不可公开购买原因；
- 安全力量、实际力量、对外伤害、超载自伤和直接死亡警告；
- 敌方意图、反应窗口、距离条件、速度冲突和准备状态；
- 魂魄量级、安全承载、安分、魂性、兽性及失控阈值。

### 17.3 领域和日志

- 所有规则由纯领域逻辑执行，UI 只读取快照并提交命令。
- 每次催蛊、炼蛊、核心确认/更换、喂养、交易、收取、释放、采血、收魂、魂魄变化和战斗结算都写入不可变结构化事件日志。
- 所有随机来源使用统一种子化入口；已知蛊方、普通炼化和确定性闪避不得偷偷调用随机数。
- 预检和执行必须同源，拒绝时不修改状态、不消耗实体资源。

### 17.4 最低验收矩阵

1. 任意战斗蛊可确认核心，通用核心和枢纽蛊显示内容差异。
2. 核心更换正确移除旧专属改造，不继承路线，一局次数受控。
3. 无限持有不触发槽位拒绝，喂养预算自然迫使玩家处置过量蛊。
4. 同一蛊实例和同一基础动作不能在一回合重复；同名不同实例可分别催动。
5. 念头与魂魄独立变化，升转不自动增加念头、蛊师气血或身体承载。
6. 低转真元不能催动普通高转蛊；高转真元向下折算成本正确。
7. 已知普通蛊方确定成功，标签蛊方只从人工候选池出产。
8. 蛊方身份要求不能被等值材料或元石替代。
9. 高转可分割和不可分割蛊材向下喂养分别正确处理余量。
10. 普通、铜、铁、银、金龙鱼混用时，低品质投入会降低整体替代能力。
11. 首次未喂进入饥饿，第二次未喂死亡；未炼化和封存蛊不免除喂养。
12. 幸存蛊不被战后预算裁剪，普通安全炼化无随机失败。
13. 固定防御可把伤害降至零；耐久防护可被多次攻击逐步消耗。
14. 蛊师保持 `100` 气血尺度；同转野兽使用独立倍增肉身模型。
15. 力量超载只按超出身体承载部分自伤，普通气血损失不降低承载。
16. 闪避、擒抱、脱离接触和速度只按离散回合规则结算，不出现连续时间单位。
17. 无魂目标不产魂道收益；普通魂魄无收取手段时不能进入库存。
18. 信息出售保留玩家知识，并正确降低独占价值和阻止同买方重复付费。

## 18. 旧规则废止和迁移

本文明确废止下列旧规则及其所有派生 UI、测试和数据假设：

1. 蛊槽硬上限、扩容道具、槽满强制替换和“卡组上限等于持有上限”。
2. 抽牌、手牌、弃牌堆和洗牌决定已持有蛊虫本回合是否可用。
3. 魂魄派生每回合催蛊数量或炼蛊并发上限。
4. 升转自动增加蛊师气血、肉身、身体承载、速度、念头、资质或真元槽长度。
5. 真元每回合重置为固定行动点；真元改为受资质上限约束、跨战斗持续并缓慢恢复的百分比资源。
6. 连续时间单位、速度倍率换算完成时刻、小数动作进度和全场速度排序。
7. 身体部位、部位血量、结构伤势和通用身体重伤。
8. 普通炼化随机失败、已知普通蛊方随机吞料、战后按掉落预算裁掉幸存蛊。
9. 元石或等值材料自动替代蛊方身份要求，以及灭蛊固定返还材料。
10. 固定普通/精英/Boss 掉落组合和无世界来源的抽象永久改造服务。
11. “五道锁定”为封闭枚举。血、气、力、魂、炼仍可作为首批内容重点，但蛊虫道标签和构筑方向开放扩展。
12. 每个命名杀招强制绑定统一沉重代价。杀招成本由组成蛊和杀招自身明确规则决定，不因“是杀招”自动附加固定惩罚。

迁移纪律：
