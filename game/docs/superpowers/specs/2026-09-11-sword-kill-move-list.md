## 1. 杀招可跨转数：原文证据（v2 新增）

| 断言 | 证据 | 强度 |
|---|---|---|
| **杀招层级由配方蛊决定，蛊升转→杀招升转** | 「杀招剑蛟变，需要蛟鳞蛊、蛟角蛊、蛟爪蛊、蛟睛蛊等等。**若是其中一只蛊虫，为仙蛊劫数，那么就是仙道杀招剑蛟变**」——同名杀招，凡蛊配方=凡级、配入仙蛊=仙级 | 原句（高） |
| 1–5 转区间杀招合法 | 凡道杀招 **190 次**（杀招并非仙级专属） | 频次计数（高） |
| 高转配方→更大威能 | 「**道痕越多越深，使用相应仙蛊时，就能引发更深的共鸣，使得仙蛊威能增幅更巨**」 | 原句（高） |
| 升级是杀招的生命周期常态 | 「改良」共现 **438 次**≈「创 452」（`reports/2026-09-11-kill-move-semantics.md`） | 频次计数（高） |

**⇒ 设计原则**：杀招不钉死转数。**杀招线**（同名配方结构）× **转数形态**（按当转配方蛊生成变体）；
玩家换上高转蛊即完成「改良」，杀招威能随配方蛊水涨船高。

## 2. 统一效果公式（与已上线数据行为保持）

1. **杀招 = 配方蛊动效的有序 `steps` 序列**——每步 = 该蛊的 `v1_effect`（kind 原样保留：strike/heal/shift/status）。
2. **总威力 = Σ 各步 amount**。红线自检：已上线 `km_sword_double_edge` = 锋蛊(2)+刃蛊(2)=**4**，与现有 JSON 一致，不改。
3. **转数 = 配方蛊的最高转数**（资格门槛语义）；同名线的不同转数形态 = 独立变体条目
   （id 方案 `km_sword_<line>_<n>`，纯数据，零引擎改动）。
4. 配方蛊受库存约束：**attack 无三转蛊、defense 无二转蛊**——没有对应转数形态的格子在矩阵中标 `—`。
5. 共鸣增幅（道痕越多威能越巨）**不在 Σ 规则内**——那是跨回合剑意（T8）的钩子，勿混。
