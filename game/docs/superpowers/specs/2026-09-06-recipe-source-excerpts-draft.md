## 4. D1 v2 Schema 目标（本文档可直接产出的表达草稿）

```
{id, output_gu_id, output_rank, inputs: [{school, rank, count}], optional_materials, source}
```

R1 v2 草稿：
```json
{
  "id": "moon_glow_v2",
  "output_gu_id": "moon_glow_gu",
  "output_rank": 2,
  "inputs": [
    {"school": "light", "rank": 1, "count": 1},
    {"school": "light", "rank": 1, "count": 2}
  ],
  "optional_materials": [],
  "source": "蛊真人-clean.txt 17024–17155（月芒蛊=月光蛊×1+小光蛊×2；失败代价小光蛊消亡）"
}
```

> 注：v2 输入以「流派+转数+数量」表达（按主计划"合炼语义按流派标签+转阶表达"），跨流派配方（R4/R5）即 `inputs` 含两个不同 school。具体落地在 D1（用户 U3 审订本摘录后执行）。
