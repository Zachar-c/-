## 0. 范围界定：五转以内保留什么、裁掉什么

原文是九转体系，六转是**凡/仙分界**（「蛊虫六转，就是仙蛊，成就唯一」）。我们的流程止于五转，
因此**所有仙级概念整体裁掉**——这不是遗漏，而是**范围裁剪**：

| 裁掉（≥6 转 / 仙级） | 原文依据 | 裁剪理由 |
|---|---|---|
| 仙蛊唯一性 | 「天地中同一时间，只能存在一只仙蛊」 | **用户裁定：不实现** |
| 仙道杀招（2232 次） | 「仙道杀招是将数种道痕集合在一起」 | 仙级；保留其**结构思想**（见 §4） |
| 战场杀招（514 次） | 「利用蛊虫，形成道痕，搭建临时的战斗环境」 | 需福地/仙窍，仙级环境玩法 |
| 仙窍、福地、大同风 | 「福地消弭……刮起大同风」 | 仙级地理 |
| 仙元石、战功 | 「仙元石：蛊仙硬通货币」 | 仙级货币 |
| 灾劫（地灾/天劫/浩劫/万劫） | 「六转蛊仙：每 10 年地灾」 | 六转起才有；五转内的风险改由**层内战斗与代价机制**承担 |

**保留并作为设计基座**（全部在五转内成立）：道痕、道、蛊、转数、蛊师身体、养用炼、蛊方、
凡道杀招（190 次的那一类）、克制与改良、交易、传承。

> ⚠️ **裁剪的只有"层级（≥6 转）"，不包含"流派数量"**。原文「道路万千，流派无数」，
> 我们落库的 20 道是**待补充的起点**（原计划 26，用户 2026-09-11 裁定方向为"补充而非裁剪"）。
> 候选池与补齐清单见 `reports/2026-09-11-session-consolidation.md` §2.5。

## 1. 节点类型（五层）

> 层级：L1 本体 / L2 身体 / L3 实践 / L4 对抗与社会 / **L5 度量（战力与经济，跨层）**。
> L2 的**容器链**与 L5 的**战力/价值体系**来自 `reports/2026-09-11-stone-aperture-aptitude.md`。

### L1 本体层 —— 世界是怎么构成的

| 节点 | 属性（游戏侧对应） | 原文依据 |
|---|---|---|
| **道痕** | 基本单位；`school`（道归属）、`层数/深浅` | 「第九十三节：**法则碎片，大道之痕**」 |
| **道** | **开放集合**（当前落库 20，原计划 26，**方向是补充不是裁剪**）；`school` 字段 | 「道标签是开放集合」（规格 §2.3）；「**道路万千，流派无数**」 |
| **蛊** | `id / rank / school / role / tags / v1_effect / 成本` | 「蛊是天地真精，**大道载体**」 |
| **转数** | 1–5（碎片规模的刻度） | 「八转七转为什么差距这么大，**道痕就是一项主要的原因**」 |
| ~~仙蛊~~ | — | 裁掉（§0） |

**核心关系（本体层）**
```
道痕 ──属于────▶ 道
蛊   ──承载────▶ 道痕        （"小小的身躯中却蕴藏着大道的法则碎片"）
蛊   ──属于────▶ 道          （school 标签）
转数 ──度量────▶ 蛊的碎片规模
蛊   ──共鸣────▶ 同道道痕（越深越强）   ← 增幅器语义
```

### L2 身体层 —— 蛊师与其身上的道痕

| 节点 | 属性 | 原文依据 |
|---|---|---|
| **蛊师** | 资质（甲乙丙丁）、气血、寿元、魂魄、**身上道痕** | 「蛊仙身上的道痕越多，就越亲近天地」（五转内同样成立） |
| **空窍**（容器实体） | 球形、**光膜**支撑、内含元海；可损/可污染 | 「整个空窍呈**球形**……是一层**光膜**」「**空窍之中，自然就是元海**」 |
| **元海**（容器内容物） | `填充率`（＝资质）、当前真元 / 真元上限 | 「元海只达到整个空窍的**四成四**」 |
| **资质**（**派生属性，非根属性**） | 甲乙丙丁；**由「元海占空窍的比例」定义**；可升可降 | 丁 2–3 成 / 丙 4–5 成 / 乙 6–7 成 / 甲 8–10 成（原句见考据报告 §3） |
| **身上道痕** | 与蛊**同源**、规模更小、不受控 | 「**兽力虚影，是潜伏在人体中的法则碎片**」 |
| **共鸣** | 同道道痕 → 使用该道蛊/杀招增幅 | 「道痕越多，我使用**力道仙蛊就越加厉害**」 |
| **排斥/伤势** | 多道混杂 → 互相干扰、成伤 **→ 污染光膜 → 降资质** | 「**金道道痕排斥**力道道痕」；「污染**光膜窍壁**，使得自身**资质下降**」 |

**容器链（L2 的核心结构，方向不可倒置）**

```
资质 ──决定──▶ 元海占空窍的比例 ──决定──▶ 真元上限 ──决定──▶ 可修到的最高转数
  ▲                                                                       │
  └──── 空窍受伤 / 光膜被污染 ◀──────── 变强的代价（道痕伤势）◀───────────┘
```
⇒ **"资质"不是一个可以直接加减的数值，而是"液面／容器"的读数。**
提升资质的正确做法是改变容器或液面（原文用**蛊**：血颅蛊「灌溉空窍，提升资质」），而不是加 aptitude 数字。

**要点**：道痕在这个图谱里是**双面节点**——既是增幅器，也是排斥源。
这修正了我先前把它当"纯代价"的设计（见 `gu-ontology.md` §6.1）。

### L3 实践层 —— 蛊师做什么

| 节点 | 属性（成本/产物） | 原文依据 |
|---|---|---|
| **养** | 消耗蛊材/元石；维持蛊的数量 | 「养用炼，是蛊师修行的三大方面」 |
| **用** | 消耗真元 + 念头（+ 寿元/气血） | 「所谓杀招，威力惊人，但**消耗的真元也会变得巨大**」 |
| **炼** | 合炼 / 逆炼；含**失败率** | 「炼蛊，大致分为**合炼，逆炼**两大方面」 |
| **蛊方** | 炼的配方（输入→输出） | 「很多蛊师都要千辛万苦地寻找**秘方**」 |
| **杀招** | 多只蛊的组合（详见 §4）；**层级由配方蛊的最高转数决定，同名杀招可跨转数 1–5 升级**（2026-09-11 补） | 「仙道杀招是将**数种道痕集合**在一起」；「若是其中一只蛊虫，为**仙蛊劫数**，那么就是**仙道杀招剑蛟变**」（同名杀招随配方蛊升层，原句） |

**核心关系（实践层）**
```
蛊师 ─持有─▶ 蛊         蛊 ─喂养消耗─▶ 蛊材/元石
用   ─消耗─▶ 真元/念头   用 ─代价─▶ 寿元/气血
炼   ─输入─▶ 蛊(多只)    炼 ─输出─▶ 蛊(更高转)     蛊方 ─指导─▶ 炼
杀招 ─由…组成─▶ 蛊(多只)  杀招 ─属于─▶ 道
杀招 ─层级随─▶ 配方蛊最高转数（同名杀招跨转数升级；剑蛟变原句证据）
```

### L4 对抗与社会层

| 节点 | 语义 | 原文依据 |
|---|---|---|
| **克制** | 针对某类杀招的手段（我们实现的 `tag` / `counter_*`） | 「一个**专门克制暗漩的杀招**」 |
| **泄密（暴露）** | 杀招一被使用/借用，优劣就被洞悉 | 「仙道杀招一旦被借用，当中的秘密就会被其他蛊仙**洞悉**」 |
| **改良** | 在既有杀招上改（**最高频**：共现 438 次） | 「这个杀招是**根据之前的杀招，改良而得**」 |
| **独创** | 首次创造者，拥有署名与**定价权** | 「乃是我本体独创……**因此售价高些**」 |
| **交易** | 杀招是明码标价的商品，且**买前不知细节** | 「**只有当杀招真正被购买之后**，这些内容才会真正的详细彻底」 |
| **传承** | 遗藏/前辈授予 | 「利用庞大的**战功，换取了**……杀招」 |

**核心关系（对抗层）**
```
杀招 ─使用─▶ 暴露（泄密）─▶ 被洞悉 ─▶ 被克制
克制 ─驱动─▶ 改良 ─输入─▶ 杀招 ─输出─▶ 新杀招
独创 ─产生─▶ 杀招（带定价权）    交易 ─交换─▶ 杀招 ↔ 元石
```

### L5 度量层 —— 战力与经济（跨层，不是新本体）

**战力：分级主轴 + 战力公式**

| 分级轴 | 内容 | 原文 |
|---|---|---|
| **转数** | 1–9（转内再分初阶/中阶/高阶） | 频次：一转 671 … 八转 4451 … 九转 1021 |
| **造诣境界** | 大师 608 < 宗师 877 < 大宗师 399 < 仙尊 | 「**宗师可构思全新杀招**」 |
| **兽分级** | 百兽王 → 千兽王 → 万兽王（十进） | 「从低到高，就可以划分为百兽王，千兽王，万兽王」 |

> **⭐ 战力公式（原句）**：「因此**一位五转蛊师的战力，就得看其掌握的五转蛊是什么，有多少只**」
> ⇒ **战力 = 转数（资格门槛） × 蛊的「质量 × 数量」**
> 且**流派不同、度量维度不同**：「**奴道蛊师的实力如何，要看手中的兽群规模**」
> 剑道维度补充（2026-09-11 杀招列表轮考据）：三转锚点=「刀光蛊和剑影蛊齐名，乃是**三转蛊虫中攻击最强**的一种」（原句，高）；
> 「御剑/剑舞/剑式/剑诀/剑法」原文 **0 次**，剑道命名词汇池=飞剑 200 / 剑光 201 / 剑遁 149 / 剑影 40 / 剑气 51。
> ⇒ 图谱里**不应存在单一的"战力"数值节点**，它是 `转数 × 蛊集合` 的**派生读数**（与资质同理）。

**经济：价值 = 能量，货币 = 能量容器**

| 节点 | 类型 | 职能 | 原文 |
|---|---|---|---|
| **元石** | 通货（凡级，`stone`） | **计价** + **可被吸收补充真元**；且**持有时会缩水** | 「元石是……货币，用于衡量一切商品的价值」「**凝聚着天然真元，可以被蛊师吸收**」「随着石内天然真元不断损耗，**体型也会不断缩小**」 |
| **仙元石** | 通货（仙级，**L0 已裁**） | 同构于元石，层级更高 | 「**如果将元石比作凡人，那么仙元石就是蛊仙**」 |

**核心关系（度量层）**
```
资质 ─决定─▶ 填充率 ─决定─▶ 真元上限 ─决定─▶ 修为上限(转数)
元石 ─补充─▶ 真元          元石 ─兑换(≈1:10⁴⁻⁵，单向)─▶ 仙元石
转数 ─门槛─▶ 可催动的蛊     转数 × 蛊(质×量) ─决定─▶ 战力（派生，非节点）
空窍/光膜受损 ─反向拉低─▶ 资质
```
⇒ **元石与真元不是两套系统**：元石本身就是真元容器 —— 所以"花钱"与"耗真元"在原文里可相互转化。
⇒ 原文明确**反对囤积**：「**元石是拿来用的**，像个守财奴积蓄元石，干嘛成为蛊师呢」；且持有会缩水，
构成天然的囤积惩罚 —— 与我们的"资源紧张"设计同向。

```json
  "rules": {"derive_costs": true, "modifiers": []},
  "origin": "authored",            // authored | player | inherited
  "revealed_to": [],               // ★ 泄密语义：被哪些敌人/势力洞悉
  "derived_from": "",              // ★ 改良语义：由哪条杀招改良而来
  "damage": 0, "effect": {"kind": "strike", "amount": 4}
}
```

三个新字段各有原文出处：`origin`（独创/传承/交易三条来源）、
`revealed_to`（泄密）、`derived_from`（改良）。

### 4.2 设计要点（七条，按优先级）

**D1 · 成本累加（P2，规格纠偏）**
实际成本 = Σ 组成蛊成本 + `rules.modifiers` 白名单增减。
现状：802 只蛊里只有 2 只有显式 `true_qi_cost`，其余走 `essence_cost` 默认 → 累加后多数杀招成本 = 蛊数 × 1 真元 + 蛊数 × 1 念头。
**设计含义**：念头是稀缺资源（每回合 2 点），所以**"2 只蛊的杀招 = 一回合全部念头"**——
这天然实现了原文「消耗巨大」与「念头约束战斗操作」的双重约束，不需要额外平衡。

**D2 · 逐步结算（P3，不做原子大招）**
一键提交 = 依次走既有单蛊结算路径；中途失败不撤销已完成步骤（规格 §4.3）。
这是**正确性红线**（原文的对仗是"杀招是组合，不是不可打断的按钮"）。
五转内可简化为"串行 steps"（并行组留待有需要时再开）。

**D3 · 泄密（接 `reveals`，成本最低、收益直接）**
- 语义：杀招**第一次被使用后**，其 `tag` 与结构进入"被洞悉"状态 → 之后同类敌人可带克制标签。
- 实现：使用后把 `km.id`/`tag` 记入 `RunState`（或战斗 `battle`），敌人生成时按该记录掷是否带克制。
- 为什么值得先做：**它让"用什么招"变成一个会被记住的决策**，而不是无代价的无限重复——
  这正是原文对抗层的核心（克制 188 次、洞悉/暴露 62/58 次）。

**D4 · 改良（P4 的核心扩展）**
- 语义：**改良是常态**（共现 438 次）> 独创（452 次的"创"里大量也是改良）。
- 设计：玩家保存的杀招可**基于已有杀招修改**（增减蛊、换顺序），产物记 `derived_from`。
- 与"保存自由编排"的关系：**保存 = 从零建；改良 = 在已有上改**。二者共用同一数据结构与 UI 入口，
  改良只是"以现有杀招为初值的编辑"。
- 收益：让玩家的杀招有**版本谱系**（原文「这三个杀招是一个系列的」）。

**D5 · 获取渠道含交易（P5）**
- 原文杀招是**商品**：明码标价（「一块半的仙元石」→ 我们的等价物是**元石**）、有信息不对称
  （「**只有购买之后**才详细彻底」→ 设计为**买前只见名字与道，买后才见配方与数值**）。
- 渠道：商店/黑市售卖（元石）＋ 传承（遗葬点）＋ 战利品（替代"战功"）。
- 五转裁剪：价格用元石，不引入仙元石/战功。

**D6 · 道痕共鸣（与 `gu-everything-mapping` 的 G2 咬合）**
- 语义：**同道道痕越深 → 使用该道杀招越强**；多道混杂 → 排斥。
- 设计：`school_rules` 增 `school_marks` / `cross_school_penalty`；
  杀招结算时按 `tag` 取同道道痕层数作为增幅（**加法**，不做全局克制倍率，守规格 §2.3）。
- 这让"选什么道、要不要兼修"成为**杀招强度的一部分**——杀招与道痕两个系统在此咬合。

**D7 · 五转内的强度护栏**
- 转数上限 5 → 碎片规模封顶 → 杀招强度上限可由 `rank` 与"组成蛊数"共同约束；
- 不引入仙级资源，因此**成本只能用真元/念头/寿元/蛊材**表达（已足够）；
- 灾劫裁掉后，风险来自**层内战斗 + 侵蚀/排斥**（身体层），不会出现"无法回避的周期劫数"。

## 5. 结论

1. **图谱的本质**是一句话：**道痕（法则碎片）是世界与蛊的共同基本单位，蛊师通过养/用/炼驱动它们，
   而杀招是把多只蛊（碎片）临时聚成一个有署名、有价格、会被克制、需要不断改良的产品。**
2. **杀招接入需要覆盖的语义共 9 条**，其中 5 条已有实现，**4 条是本次探索新增**（泄密、改良、交易、
   道痕共鸣）——它们恰好都在"社会层与身体层"，与我此前那份一致性评估指出的缺口**同一族**。
3. **裁掉仙级不损骨架**：仙蛊唯一、仙道/战场杀招、仙元石、灾劫都是 ≥6 转的概念；
   五转内保留的 9 条语义已经足以支撑"凡道杀招"这一完整形态（含垄断、泄密、改良、交易）。
