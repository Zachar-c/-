## 1. 天道

### 1.1 定义

原文没有"天道就是……"的直陈句，但有三条稳定的内涵表述：

> 「**宿命蛊归属于天道**，**损有余补不足**」
> 「但这**天道是人道当兴的天道**，这**宿命是维护人族的宿命蛊**」
> 「**天道是他突破眼前困境的捷径**」

⇒ **天道 = 宿命 + 天地规则 + 平衡律（损有余补不足）**。它是**不可抗力**与**秩序**的那一面。

### 1.2 特征

| 特征 | 原文 |
|---|---|
| **宿命性** | 「宿命蛊归属于天道」 |
| **平衡律** | 「损有余补不足」 |
| **顶层可及性**（稀有的突破手段） | 「天道是他突破眼前困境的**捷径**」 |
| **天意≠天道** | 「天意」1133 次多为"上天的意志/运数"，与作为流派/规则体系的"天道"不同层 |

### 1.3 专属高层产物：天道道痕（303 次）

> 「方源双目紧紧盯着这条**天道道痕**」
> 「**丝线般的天道道痕**，仿佛在风中漂游，闪烁着**莹莹白芒**」
> 「一道漩涡陡然成形，将这条天道道痕**吞吸**进去」
> 「他虽然同一条天道道痕，但是**小世界的模样**却是改变了很多」
> 「**衍生世界只是表象，他实际上要做的是衍生天道道痕**」
> 「每一轮**小世界的生灭**后，那一条天道道痕通常就会**增长一部分**」

⇒ **天道道痕与世界生灭绑定、可被吞吸、可自行增长** —— 这是**仙尊级**的概念，
**远超五转范围**。我们的五转裁剪应把它**整体降级或裁掉**（见 §4）。

### 1.4 ⚠️ 我们现有文案的偏差

现状（`data/schools.json["heaven"]`）：
> 「掌天地规则与灾劫天意；**道痕可化任何流派**，宿命/灾劫/寿元皆天道碎片。」

| 判断 | 依据 |
|---|---|
| ✅「宿命」正确 | 「宿命蛊归属于天道」 |
| ✅「灾劫天意」贴近 | 天意 1133 次；灾劫已按五转裁剪 |
| ❌ **「道痕可化任何流派」归错了道** | 原文里**道痕转化是变化道的特性**：「一身道痕**化作雷道**」「原本的**变化道道痕都转化为剑道道痕**」「我还有变化道痕，关键时刻，可以**将其转化成光道道痕**」——**变化道 539 次**，才是"可化"的那一道 |

## 2. 人道

### 2.1 定义（有明确的定位句）

> 「**诸多流派当中，人道是最能应付天道的流派**」

这是三道里**唯一的直接定位句**：**人道 = 专门用来对抗天道的那一道**。

### 2.2 源头与载体

> 「**人祖创造人族**，乃是**人道的无上**……」
> 「《人祖传》中记载着**人祖的人道真传**」
> 「《人祖传》中，潜藏着**人族的人道真传**，这部真传堪称是**蛊师世界的第一真传**」
> 「因为阅读《人祖传》收获颇多，又拥有**人道杀招**」
> 「**《人祖传》是蛊道第一经典**」

**人道实体**：
> 「这是**人道大阵**，**千愿树**则是人道的**上古荒植**」
> 「他找到了人道这个妙方……千愿树虽然是人道上古荒植，但品级到底不及众多的天道道痕」

### 2.3 特征

| 特征 | 原文 |
|---|---|
| **对抗天道** | 「人道可胜天道」「**最能应付天道**」 |
| **人族本位** | 「**人道当兴**」「人道之子」「受人道钟意」 |
| **愿念/情感为力** | 「千愿树」（人的愿望）、"以情…" |
| **真传可读** | 《人祖传》——**知识即人道载体** |
| 与天道的**品级落差** | 「千愿树……**品级到底不及**众多的天道道痕」（人道物级低于天道物级） |

### 2.4 ⚠️ 我们现有文案的偏差

现状（`human`）：
> 「掌人心人性与情感愿念；**人祖传诸蛊皆人道**，以情克命、以愿逆天。」

| 判断 | 依据 |
|---|---|
| ✅「以愿逆天」贴合 | 「人道当兴」「人道可胜天道」 |
| ✅「人心人性与情感愿念」贴近 | 千愿树、人道之子 |
| ❌ **「人祖传诸蛊皆人道」不准确** | 原文是「《人祖传》**记载着人祖的人道真传**」——它是**人道经典/真传的载体**，而非"里面所有蛊都属人道"。应改为「**人祖传载人道真传（蛊道第一经典）**」 |

## 3. 炼道

### 3.1 定义与境界

> 「**炼道是准宗师级**，在蛊仙当中，也算能拿得出手」
> 「他境界高绝，**炼道是无上大宗师**，水道也是大宗师」

**三阶境界**（大师 49 / 宗师 54 / 大宗师 25），且**境界决定能力**（`06-炼道` 提炼）：
大师可炼仙蛊但成功率有限；**宗师可构思全新杀招、逆推蛊方**；大宗师可设计完整仙蛊屋。

### 3.2 独有造物：炼道蛊阵（48 次）

> 「造诣深厚的**炼道蛊仙，都有自己的炼道蛊阵**，在炼道蛊阵上还设置许多辅助蛊阵」
> 「石龙瞳进入炼道蛊阵，只是几个呼吸功夫，就被**完全分解**，融入到这个奇妙的炼道蛊阵当中」
> 「在炼道蛊阵形成的光影中，这些**仙材以极快的速度，被顷刻处理**」
> 「这座炼道蛊阵，再近一步，恐怕就是一座**八转的仙蛊屋**了」

⇒ **炼道蛊阵 = 把蛊材快速加工成蛊的生产设施**，是"炼道作为生产力"的实体化。
（"再近一步就是仙蛊屋"说明它**在五转内也有形态**，不必整体裁掉。）

### 3.3 特征

| 特征 | 原文 |
|---|---|
| **战斗弱势**（关键！） | 「**炼道这个流派在作战方面，乃是弱势**」 |
| **专精稀缺** | 「绝大多数的蛊仙，都**不是专修炼道**，炼道连兼修都算不上，炼道造诣可想而知」 |
| **失败代价具体** | 「这就是**合炼失败的代价**——根据合炼秘方的不同，**蛊虫会因此受伤**」；「失败了**三次**，耗费了**大量的资源**，这才合炼成功」 |
| **以境界而非战力衡量** | 全部表述用"大师/宗师/大宗师"，从不用战力描述炼道 |

### 3.4 ⚠️ 我们现有文案的偏差

现状（`refine`）：
> 「掌炼蛊合炼与仙蛊屋营造；炉火炼蛊、以材换力、**炸炉反噬**，是海量合成配方的地基流派。」

| 判断 | 依据 |
|---|---|
| ✅「炼蛊合炼」「以材换力」「海量合成配方的地基」正确 | 合炼是原文两大炼法之一；"以材换力"贴合「仙材以极快的速度被顷刻处理」 |
| ⚠️「**仙蛊屋营造**」属仙级 | 仙蛊屋是八转级；五转内应对应**炼道蛊阵** |
| ❌ **「炸炉」原文 0 次** | 全库检索"炸炉"**零命中**（"炉火"仅 10 次）——这是**我们自创的词**。原文的失败代价是「**蛊虫会因此受伤**」，应改为这个说法 |
| ➕ **漏了最重要的特征**：**战斗弱势** | 「炼道这个流派在作战方面，乃是弱势」——这直接关系流派平衡定位，文案里没有 |

## 4. 三者的相互关系

```
        天道  ── 宿命 / 规则 / 损有余补不足 / 不可抗力
          ▲
          │  对抗轴：「人道是最能应付天道的流派」「人道可胜天道」「人道当兴」
          │
        人道  ── 人族愿念 / 人祖真传 / 千愿树 / 对抗天道
          ▲
          │  支撑：各道的蛊都要靠炼道产出（炼道蛊阵）
          │
        炼道  ── 造物 / 生产 / 三阶境界 / 战斗弱势（元流派）
```

| 关系 | 性质 | 原文 |
|---|---|---|
| **天道 ↔ 人道** | **对立轴**（宿命 vs 抗争） | 「人道**最能应付**天道」「人道**可胜**天道」「人道当兴」 |
| **天道 vs 人道 的品级** | 天道物级更高 | 「千愿树……品级到底**不及**众多的天道道痕」 |
| **炼道 → 天道/人道/各道** | **元流派（生产基座）** | 炼道蛊阵加工仙材；"海量合成配方的地基" |
| **炼道 ↔ 战斗** | **负相关** | 「炼道这个流派在作战方面，乃是**弱势**」 |
| **天道 ↔ 炼道** | 材料层级的上下 | 天道道痕是最高级材料之一 |

**一句归纳**：**天道讲"命"，人道讲"争"，炼道讲"造"**。
天道与人道构成一条**意义轴**（宿命 vs 抗争）；炼道不在这条轴上，它是**给所有道供货的元流派**。

| **炼道** | L3 实践层（"炼"本身） | 炼道蛊阵（生产设施）、三阶境界、失败代价 | 现有 refine 屏 + 配方系统；境界可挂"宗师解锁保存杀招" |

**三条最有设计价值的挂接点**：
1. **人道 ↔ 天道的对抗轴** → 可以直接做成玩家侧的一条**张力线**：
   宿命（既定的局/命定结局）vs 人道（以愿改命）——呼应我们已有的"结局归因"与契约系统。
2. **炼道 = 元流派** → 支持"海量配方"这一核心支柱，且**战斗弱势**给它一个清晰代价：
   专精炼道的人要靠**蛊的质量**而非**战斗动作**取胜。
3. **炼道境界 → 创造权**（宗师可构思全新杀招）→ 与杀招设计 D4（改良）咬合：
   **境界是"能不能改/造杀招"的门槛**，而不是数值加成。

## 6. 结论

1. **三道各自的内核**：天道＝**宿命与秩序**（不可抗力 + 损有余补不足）；人道＝**抗争与愿念**（人祖真传 + 最能应付天道）；炼道＝**造物与生产**（炼道蛊阵 + 战斗弱势 + 三阶境界）。
2. **关系**：天道与人道构成**唯一一条直接对立轴**（原文有明确定位句）；炼道是**不站队任何一方的元流派**。
3. **我们文案的 3 处问题**（建议修正，但属文案而非机制）。
   ⚠️ **2026-09-11 二次核验后修正了其中两条的定性**（原文追加检索推翻了本报告初版判断，保留原文以便对照）：
   - `heaven`：「道痕可化任何流派」——**初版判"应删（属变化道能力）"过于武断**。
     复检发现原文确有「一条天道道痕**化为更多的其他道痕**，扩散到天地之间」「天道道痕……**化为一个个的新生世界**」。
     正确定性：**有依据，但属世界生灭级/仙尊尺度**；变化道的"转化"是**蛊师主动技术**，二者不同层。
     ⇒ 五转内应作**概念降级**（保留"宿命/灾劫/寿元皆天道碎片"），删去"可化任何流派"。
   - `human`：「人祖传诸蛊皆人道」——**基本成立，措辞偏绝对**。原文《人祖传》载人道真传，
     且其中诸蛊（希望/勇气/爱情/胆识…）确属人道。⇒ 建议改为「**人祖传载人道真传**」。
   - `refine`：「炸炉」——**不是错误**。`action_preview_service.gd` / `refine_snapshot.gd` / `data/names.json`
     三处都在用它作**已内化的机制术语**（指向"反噬结果表"），**不应删**。
     该行真正的问题是：① **漏了「战斗弱势」**这一关键定位（原文明确）；② 用「仙蛊屋」（八转/仙级），
     五转内应为「**炼道蛊阵**」。
4. **范围提示**：`天道道痕`（303 次）是**世界级/仙尊级**概念，与"世界生灭"绑定，
   应在五转裁剪中**整体降级或裁掉**；而**炼道蛊阵**有五转内形态，**可保留**。
