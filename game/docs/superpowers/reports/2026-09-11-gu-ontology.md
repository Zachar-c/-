## 二、本体链条：道痕 → 蛊 → 仙蛊

### 2.1 基本单位：道痕（＝ 法则碎片 ＝ 大道之痕）

**术语等价**由原文的章节名直接给出：

> 「**第九十三节：法则碎片，大道之痕**」

即：**法则碎片 = 大道之痕 = 道痕**。这三者是同一个东西的不同说法。

### 2.2 蛊：成规模的碎片载体

> 「蛊是**天地真精**，但是**习性近乎于野兽**」（有生物性，不只是死物）
> 「人是万物之灵，蛊是天地真精，**大道载体**」
> 「蛊虫身躯或大或小，**蕴藏着天地大道的法则碎片**」

⇒ 蛊不是"由道痕拼接而成"，而是**道痕（法则碎片）的载体**，规模不一。

### 2.3 分水岭：碎片的大小决定凡/仙

决定性的一句：

> 「如果说**凡蛊只是天地法则的一块细微碎片**，那么**仙蛊则是大道一角，天地至理的完整一段**」

⇒ **凡蛊 = 细微碎片；仙蛊 = 完整的一段**。蛊的等级 = **碎片的规模与完整度**。

## 三、转数 = 碎片规模（原文的量级证据）

| 原文 | 含义 |
|---|---|
| 「蛊虫**六转，就是仙蛊**，成就唯一」 | 六转是凡/仙分界 |
| 「回溯蛊只是**五转凡蛊**……都是六转级数，**仙体兽体都有道纹道痕**」 | 五转无道痕印记，六转有 |
| 「**八转七转为什么差距这么大，道痕就是一项主要的原因**」 | **转数差 = 道痕量差**（直接支持"大小"论） |
| 「蛊仙身上的**道痕越多，就越亲近天地，亲近大道法则**」 | 道痕多 = 层次高 |
| 「**道痕越多越深，使用相应仙蛊时，就能引发更深的共鸣，使得仙蛊威能增幅更巨**」 | **道痕是共鸣增幅器** |
| 「也只有堪称**准九转的道痕积累，道痕的存在才会令肉眼都可见到**」 | 量变积累到"可见"的规模 |

⇒ **道痕的数量本身就是等级**。这与你的判断一致：仙蛊不是"稀有"，而是**它的碎片规模决定了它只能是唯一的一份完整段**。

## 四、唯一性的原文表述（形式与后果）

| 表述 | 类型 |
|---|---|
| 「而到了**六转的仙蛊，每一只都具有唯一性**」 | 规则 |
| 「**天地中同一时间，只能存在一只仙蛊**」 | 规则（时间+范围限定） |
| 「**仙蛊唯一，名称统一**」 | 命名规则 |
| 「仙蛊唯一，**如果别人已有相同的仙蛊，方源也是炼不成的**」 | 后果（阻挡重复炼制） |
| 「**仙蛊唯一，仙蛊屋自然也唯一**」 | 派生（仙蛊屋随之唯一） |
| 「因为**炼蛊艰难，仙蛊唯一**，就算是一百份仙材都未必能重新炼制出来」 | 稀缺后果 |
| 「更可贵的是，它只有五转，**不是唯一的仙蛊**」 | 反证（五转不唯一） |

这与你说的"因为碎片足够大"完全吻合：**大到"完整"，就不再是可复制的碎片了**。

## 五、⚠️ 对我此前映射方案的修正（层级方向）

在 `2026-09-11-gu-everything-mapping.md` 里我把道痕定义为：

> M1 道痕 = 身体上残留的**无主蛊意**；蛊是其受控形态

**这个层级方向是错的**（本次考据推翻）：

```
正确层级：  道痕（法则碎片，更基本）  ──成规模聚合──▶  蛊  ──完整一段──▶  仙蛊（唯一）
                                    ▲
                    身体上的道痕 ────┘（同源，只是规模与受控性不同）
```

原文依据：
> 「**兽力虚影，是潜伏在人体中的法则碎片**」
> 「它们本身蕴藏着关于"气力"的一段**大道法则碎片，附着在方源的体内**」
> 「荒兽之躯，也是仙体……**印刻道痕**」（蛊仙身体同样印刻道痕）

⇒ 身体上的道痕与蛊**同源同级**（都是法则碎片），区别在**规模、受控性与所属**，
**不是"蛊派生道痕"**。所以：

- ❌ 旧表述：「道痕 = 无主的蛊意」（把道痕说成蛊的下位）
- ✅ 新表述：「**蛊 = 成规模的法则碎片（道痕）；身体上的道痕是与蛊同源的碎片，规模更小、不受控**」

**工程结论不变**（仍复用 `body_imprints` 容器 + curse 通道），但**文档与命名必须改成新表述**，
否则又制造一次语义漂移。

## 六、对游戏实现的三点影响

### 6.1 一个更重要的修正：道痕是"双面"的

我上一版方案把道痕主要当作**代价来源**（伤势、排斥）。原文其实**先把道痕写成增幅器**：

> 「**道痕越多，我使用力道仙蛊就越加厉害**」
> 「道痕越多越深，使用相应仙蛊时，就能引发更深的共鸣，**使得仙蛊威能增幅更巨**」

⇒ 道痕应当是**双面结构**：

| 面 | 机制 | 原文 |
|---|---|---|
| **正面（共鸣增幅）** | 同道道痕越多 → 使用该道蛊/杀招越强 | 「道痕越多，使用力道仙蛊就越厉害」 |
| **负面（排斥风险）** | 多道道痕混杂 → 互相干扰、成伤势 | 「金道道痕排斥力道道痕」「平衡三道流派的道痕，已是大师极限」 |

这也解释了**为什么"兼修"是代价**：不是"多学一门要罚款"，而是**同道越深越强、混道互相冲抵**——
代价来自**结构冲突**，不是来自规则惩罚。这比我原来的设计更贴原文，也更好玩。

### 6.2 仙蛊唯一性：我们**完全没实现**，且与现行红线冲突

- 现状：`data/gu.json` 里 **rank5 蛊可多持有**（无 `unique` 字段，见 `2026-09-11-lore-alignment-audit.md`）
- 原文：「天地中同一时间，只能存在一只仙蛊」「别人已有相同的仙蛊，就炼不成」
- 冲突点：AGENTS 红线是「**不得重新引入蛊槽/持有上限**」——但 **rank5 唯一 ≠ 通用持有上限**，
  它只约束**顶级单一定义**，与"背 40 只低阶蛊"不矛盾
- ⇒ 若要采纳，最小实现是：**rank5 定义全局唯一**（`MetaProgress` 记已炼成，或同局内唯一），
  不触碰通用持有上限。**这需要你裁定**（属红线解释问题，我不擅自动）

### 6.3 「大同风」：世界的回收机制（可作为灾劫/世界层的素材）

> 「福地消弭的那一刻，会刮起**大同风**，和天地融为一体，福地中的一切，
>  都会**还原成天地间最基本的元气**」
> 「撑爆**碎片世界**，导致碎片世界**道痕销毁**，刮起**大同风**，吹毁同化碎片世界中的一切资源」

⇒ 世界是**碎片**，碎片崩溃会被**回收为基本元气**（道痕销毁）。这为"灾劫/世界层"提供了原文机制，
也再次印证 **道痕是世界的本体单位**（连销毁都是"道痕销毁"）。

## 七、结论

1. **你的四条断言全部成立**，其中第 4 条（仙蛊唯一 = 碎片足够大）有**直接原文**：
   「凡蛊只是天地法则的一块细微碎片，**仙蛊则是大道一角，天地至理的完整一段**」。
2. 完整链条是：**道痕（法则碎片 = 大道之痕）→ 蛊（成规模的碎片载体 = 天地真精）→ 仙蛊（完整一段，故唯一）**；
   而**世界本身也是碎片**（「碎片世界」），由道痕的多寡与种类定义。
3. **"万物皆蛊"仍然不是原文字句**（0 次）；但本次考据表明，
   **它作为"道痕是基本单位"这一原文事实的通俗概括，是成立的**——只是更准确的说法应是
   「**万物皆由道痕（法则碎片）构成，蛊是其中成规模、可被驱用的聚合体**」。
4. **对我上一版的修正**：道痕不是"蛊的残留"，而是**更基本的单位**；身体道痕与蛊同源。
   工程复用结论不变，但表述与命名必须更正（§五）。
5. **新增两条待你裁定的设计输入**：道痕的双面性（§6.1，直接影响 `gu-everything-mapping` 的 M1/M2 措辞与数值方向）、
   仙蛊唯一性（§6.2，涉及红线解释）。
