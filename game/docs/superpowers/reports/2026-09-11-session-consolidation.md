## §2 原文考据结论（六大主题）

### 2.1 本体论：道痕 → 蛊 → 转数（证据强度：原文原句，高）

**链式断言（用户提出，四条全部经原文核实成立）**：

| 断言 | 判定 | 原文 |
|---|---|---|
| 蛊是天地真精 | ✅ **原句，37 次** | 「人是万物之灵，**蛊是天地真精**」；墨瑶补全为「蛊是天地真精，**大道载体**」 |
| 蛊由道痕（法则碎片）组成 | ✅ | 「小小的身躯中却**蕴藏着大道的法则碎片**」；**章节名直接给出术语等价：「第九十三节：法则碎片，大道之痕」** |
| 整个世界由道痕组成 | ✅ | 「这个大天地，才是**拥有道痕最多的地方**」；「**碎片世界，道痕稀疏**」 |
| 仙蛊唯一 = 碎片足够大 | ✅ **有直接原文** | 「若说**凡蛊只是天地法则的一块细微碎片，那么仙蛊便是大道一角，天地至理的完整一段**」 |

**链条**：`道痕（＝法则碎片＝大道之痕，基本单位）` →成规模聚合→ `蛊（天地真精／大道载体）` →度量→ `转数 1–5`；
`道` 是**类型维度**。身体上的道痕与蛊**同源**（「兽力虚影，是潜伏在人体中的法则碎片」），只差**规模与受控性**。

**用词校正**：原文用「法则碎片 / 道理碎片 / 天地真精」，**「规则碎片」0 次**；「道痕」出现 **3002 次**。

**转数 = 碎片规模**（原文证据）：「**八转七转为什么差距这么大，道痕就是一项主要的原因**」；
「道痕越多越深，使用相应仙蛊……**威能增幅更巨**」；「六转仙蛊星痕……肉身暂时增添**六百道**星道道痕」。

**仙蛊唯一性的形式**：「六转的仙蛊，每一只都具有唯一性」「**天地中同一时间，只能存在一只仙蛊**」
「**别人已有相同的仙蛊，方源也是炼不成的**」。
**⚠️ 用户裁定：不实现**——理由「流程只到五转，不会出现仙与仙蛊」。**整个仙级（≥6 转）随之整体裁剪**。

**道痕是双面的**（重要，影响机制设计）：正面 = **同道共鸣增幅**（「**道痕越多，我使用力道仙蛊就越加厉害**」）；
负面 = **多道混杂排斥**（「金道道痕排斥力道道痕」；道痕伤势「十分难缠」，连蛊虫疗伤都阻止）。
⇒ **兼修代价来自结构冲突，不是规则惩罚**。

### 2.2 杀招（证据强度：频次计数 + 定义句，高）

- **词频**：杀招 **9972**；仙道杀招 2232 / 战场杀招 514 / **凡道杀招 190**。
- **⚠️ 关键否证**：**「万物皆蛊」「万物皆是蛊」「万物皆为蛊」在原文中均为 0 次**——该命题是**外部概括**，
  不是文本表述。用户当时引用的世界观命题属**正确归纳**，但不可当作原文引语。
- **最近共现（±40 字）**：炼 639｜创 452｜**改良 438**｜仙元 353｜掌握 259｜威力 224｜流派 213｜克制 188｜
  蛊方 140｜传承 129｜隐藏 62｜暴露 58｜**化解 仅 14**。
  ⇒ ① 杀招常态是**改良**（与"创"几乎等频），不是发明；② 我们的 counter 用了原文几乎不用的「化解」，
  原文因果链实为「**出招 → 泄密 → 被研究 → 被克制**」。
- **最接近定义的句子**：「**仙道杀招是将数种道痕集合在一起**，形成多种效果，或者放大某种威能」
  ⇒ 杀招 = **道痕的集合**（原料比蛊高一级；在"万物皆蛊"框架下用蛊作原料可接受）。
- **来源三途**：独创（**有署名与定价权**：「乃是我本体独创……**售价高些，需要一块半的仙元石**」）／
  **改良（最高频）**（「根据之前的杀招，改良而得，适合我的仙僵之躯」）／交易·传承·战功
  （明码标价 + **信息不对称**：「**只有当杀招真正被购买之后**，这些内容才会真正的详细彻底」）。
- **分层量级差 10 倍**：凡道 190 / 仙道 2232 / 战场 514。**战场杀招**是最危险的一类——
  「利用蛊虫，**形成道痕，搭建出临时的战斗环境**」；与仙窍道痕冲突「轻则反噬，**重则道痕排斥**……
  福地毁灭，蛊仙当场身亡」。
- **与「万物皆蛊」的差异**：前者是**本体论命题**（世界是什么），后者是**实践论产品**
  （有署名、有价格、有生命周期）。依赖方向是**杀招依赖蛊/道痕**，反之不成立 ⇒ 二者**不同级**，
  转译应**向下还原**。

### 2.4 天道 / 人道 / 炼道（证据强度：定义句 + 频次，高）

**内核一句话：天道讲「命」，人道讲「争」，炼道讲「造」。**

| 道 | 频次 | 定义与特征 |
|---|---|---|
| **天道** | 702（**天道道痕 303**） | **宿命 + 规则 + 平衡律**：「**宿命蛊归属于天道**，**损有余补不足**」。高层产物天道道痕「丝线般…莹莹白芒」「**每一轮小世界的生灭后…增长一部分**」→ **世界生灭级** |
| **人道** | 612（人道杀招 69） | **唯一有直接定位句的一道**：「**诸多流派当中，人道是最能应付天道的流派**」。源头「**人祖创造人族**」；载体「《人祖传》**记载着人祖的人道真传**……堪称**蛊师世界的第一真传**」 |
| **炼道** | 1491 | **造物/生产**：独有设施 **炼道蛊阵**（48 次）「仙材以**极快的速度**被顷刻处理」；三阶境界（大师 49/宗师 54/大宗师 25，**宗师可构思全新杀招**）；**原文明确短板**「**炼道这个流派在作战方面，乃是弱势**」 |

**相互关系**：**天道 ↔ 人道 是原文唯一一条直接对立轴**（且天道物级更高：「千愿树……**品级到底不及**众多的天道道痕」）；
**炼道不在这条轴上**，它是给所有道供货的**元流派**（炼道→各道，与战斗负相关）。
⚠️ 因此**任何"道与道之间互相克制"的设计，只有天道↔人道这一条有原文依据**，其余（含炼道为各道产蛊）属**生产链关系**。

**⚠️ 三条纠偏（我此前判断过重，此处按证据修正）**：

1. **`heaven` 文案「道痕可化任何流派」——不是错，是层级过高。**
   原文确有「一条天道道痕**化为更多的其他道痕**，扩散到天地之间」「天道道痕……**化为一个个的新生世界**」——
   但它属**世界生灭级、仙尊尺度**。**变化道的"转化"是蛊师主动技术**（「一身道痕化作雷道」
   「变化道道痕都转化为剑道道痕」），二者不是一回事。
   ⇒ 五转内应作**概念降级**（保留"宿命/灾劫/寿元皆天道碎片"），删去"可化任何流派"。
2. **`human` 文案「人祖传诸蛊皆人道」——基本成立，措辞偏绝对。**
   原文「《人祖传》即人道真传」且其中诸蛊（希望/勇气/爱情/胆识…）确属人道；建议改为
   「**人祖传载人道真传**」更准。
3. **`refine` 文案「炸炉」——不是错误，是项目自创但已内化的机制术语。**
   `action_preview_service.gd`、`refine_snapshot.gd`、`data/names.json` 三处都在用它指向"反噬结果表"。
   **原文 0 次**（"炉火" 10 次），但既然已是机制名，**不应删**。
   该行真正的问题在别处：① **漏了「战斗弱势」**这一关键定位（原文明确）；② 用「仙蛊屋」（八转/仙级），
   五转内应为「**炼道蛊阵**」。
