# Q5. `promotion` 是什么？

### 【审计事实】

**当前唯一能真正升转的通道只有 13 条 `fixed`**（`[FACT]`，F4 §2）：

| 流派 | 条数 | 覆盖 |
|---|---|---|
| **sword** | **6** | 唯一能 **1→5 直达**（`ascend_sword_rec_1_10_gu`，⚠️ **已更正：60 石 + 1 獠牙，非零成本**） |
| light | 3 | 1→2 / 2→3（⚠️ **其中 2 条 0 石 0 材料，含 2→3 直达**） |
| earth | 2 | 1→2 |
| blood | 1 | 2→3 |
| **其余 16 流派** | **0** | ❌ 零升转通道 |

- 13 条**全部 `stone_cost` 字段缺失** → **不花元石**。
- 8 条 `default_unlocked = true` → **一半开局即有**。
- 升转是**"换名"**（`sword_atk_1_05_gu → sword_atk_2_12_gu`）→ 属**定向合炼（`output_rank` 路径）**。
- **转 3/4/5 的 424 只蛊零晋升配方**。

### 【审阅者已有倾向】

**（§2.4）** 新增明确的 **`promotion`**：专门表示 **Rank N → Rank N+1**。

**（§2.6）** ✅ **做**，但**不是"424 只全补一遍"**。要求的结构：

```text
流派 / 蛊系
    ↓
明确的升转规则
    ↓
精选关键晋升节点
    ↓
覆盖 Rank 1→2→3→4→5
```

> **建立"可达性骨架"，而不是给每一只蛊机械补方。**

### 【需你裁定】

**Q5.1** `promotion` 的**基本规则**应是什么？

|---|---|---|

| **B** | **蛊系驱动**：沿"蛊系"（如 sword_atk_1_05 → 2_12 → ...）逐级升 | 需先定义"蛊系"数据结构 |
| **C** | **通用规则**：任意 Rank N 蛊 + 材料 → 指定 Rank N+1 蛊（由配方显式指定） | 最灵活，配方数可能多 |

- ☐ 其他（请说明）

**Q5.3** `promotion` 的**成本结构**应与什么挂钩？
> 现状 13 条 fixed 是**零元石**的（疑似 unintentional）。

# Q6. 普通/精英/Boss 的蛊获取分别负责什么？

### 【审计事实】

| tier | 掉蛊率 | 蛊池 | 实际问题 |
|---|---|---|---|
| common | **0%** | 14 只（永不使用） | 完全无蛊 |
| elite | **30%** | 8 只，但 `forced_rarity: epic` 覆盖权重 | **实际只出 3 只**：`moonlight_gu` / `white_jade_gu` / `force_atk_4_02_gu` |
| boss | **0%** | **空**（`gu_pool` 只有键名无内容） | **双保险不掉蛊** |

- **802 只蛊只有 22 只进掉落表** → **97% 不可掉落**。
- **Boss（14–20 血）回报低于精英（6–11 血）**。
- 精英**必然代价**（诅咒 or 恶名 +2）→ **70% 分支净亏**。
- 商店货池 29 条、每店 4–6 槽 → **780 只非掉落蛊中绝大多数整局见不到**。

### 【审阅者已有倾向】（裁定书 §2.3）

> ✅ **批准建立获取通路**，❌ **不批准 5% / 100% 这组数字**。
>
> **理由**：项目另一支柱是**海量蛊虫合成配方**。若 Boss 像开宝箱一样稳定喷高价值蛊，
> 玩家会倾向"打 Boss → 直接拿成品"，而非"打 Boss → 获得资源/情报/材料/关键配方 → 自己炼"，
> **削弱世界模型**。

**要求的三分法**：

| 来源 | 职责 |
|---|---|
| **普通战** | 低概率**基础蛊 / 低转蛊** |
| **精英** | 高质量**定向**蛊或特殊候选 |
| **Boss** | **强确定性的"高价值获取机会"** —— 固定池 / 定向池 / 选一 / 首领特产 / **配方线索** / 高转关键材料 |

> **Boss 定位**：**高确定性、高价值、低随机陷阱** —— **不是"100% 随机掉一只"**。

# Q7. `soul` 到底是不是"经济资源"？

### 【审计事实】

**存在两套魂系统**（`[FACT]`，F7 §2）：

**① legacy `cultivator.soul`（✅ 活）**

| 属性 | 值 |
|---|---|
| 驱动 | **每回合行动点**（`action_points.per_turn(soul)`，`action_points.gd:14`） |
| 入 | `soul_pill` +1（6 石） |
| 入 | 黑市 `lifespan ×20` / `health ×20` → +1 |
| 出 | 黑市 `soul ×1` → 寿元/气血 |
| 出 | `soul_drain`（敌人意图） |
| 出 | `free_mix` 爆炸（`soul_cost: 1`） |
| 上限 | `soul_max` |
| 初始 | **1** |
| F8 实测 | **所有原型所有种子恒为 1，零变化** |

**② `SoulRules` 五量（❌ 无消费者）**

- `soul_magnitude` / `soul_safe_capacity` / `soul_calm` / `soul_nature` / `beast_nature`
- 操作：`strengthen_soul` / `refine_soul` / `calm_soul` / `collect_soul`
- 机制：爆魂致死（`soul_burst`）、兽性终点（`bestiality_endpoint_check`）
- 注释明确：**新键绝不触碰 legacy `soul`/`soul_max`**

**发现**：`soul_pill` 6 石=1 魂 与 `lifespan×20=1 魂` → **1 石 ≈ 3.3 寿元**（与 `lifespan_deal` 互为倒数，唯一有意锚点）。
