# 游戏化改编登记册

每一项偏离原著的可玩性设计都必须登记。这里的条目不是为原创内容背书，而是公开它与原著事实之间的距离。

| ID | 原著依据 | 游戏化转换 | 明确简化或偏离 | 不可越界 |
| --- | --- | --- | --- | --- |
| ADP-RUN-001 | CAN-NANJIANG-001 至 CAN-NANJIANG-004 | 将广阔南疆压缩为一张有三阶段、18--24 个有效节点的山域路线图。 | 单局地图不等于真实南疆尺度；路线与时间均为游戏抽象。 | 低转角色不可表现为毫无代价地跨域游历。 |
| ADP-GU-LOADOUT-001 | CAN-GU-CARE-001 | 不设置世界观意义上的持蛊数量上限；以真元、元石、每阶段自动汇总的养护总账、用途与同阶匹配形成自然负担。界面可按用途整理蛊虫，但不能将整理栏位解释为蛊师只能拥有或使用固定数量的蛊虫。 | 不逐条模拟食料、伤损和培育流程；一局只在第一、二阶段末结算两次，不做节点级记账。具体总额、催发数值和界面承载方式属于游戏规则。 | 不能以固定蛊槽取代养蛊、用蛊的资源取舍，也不能将所有蛊虫无成本地变成随时可用的卡牌。 |
| ADP-GU-SYNERGY-001 | CAN-GU-SYNERGY-001, CAN-GU-SYNERGY-002 | 用标签、冷却、真元与触发条件表达蛊虫互补。 | 标签及其数值效果是原创规则。 | 不把某个原著实例泛化为放之四海皆准的规则。 |
| ADP-SMALL-LIGHT-001 | CAN-SMALL-LIGHT-001, CAN-SMALL-LIGHT-002 | 小光蛊保留为固定开局的辅助型凡蛊，可与光系攻击或信息类改编效果形成连携。 | 信息、照明、伪装等效果属于游戏扩展，不是原著直接能力。 | 玩家文案和图鉴必须标明扩展性质；不可写成原著既定能力。 |
| ADP-FACTION-001 | CAN-NANJIANG-003, CAN-NANJIANG-004 | 首发设计四个原创南疆势力，每局激活二至三个，以关系影响商队、情报、路线、撤离与终局外扰。 | 势力名称、首领、关系阈值和事件均为原创内容。 | 不冒用原著家族的具体人物、历史或既有结局；玩家不能让所有势力永久满意。 |
| ADP-ASCENSION-001 | CAN-ASCENSION-001, CAN-ASCENSION-002 | 在夺取固定遗藏并撤离后，以本局构筑、伤势、资源、情报和势力关系映射为升仙考验中的可读抉择。 | 具体界面、阈值、结局文本、失败形式都是游戏规则。 | 不把升仙做成单一资源校验；不把蛊仙阶段做成可继续游玩的正式首发内容。 |
| ADP-COMBAT-001 | CAN-ECONOMY-001, CAN-GU-CARE-001 | 主动回合制遭遇公开敌方意图、地形与倒计时，以真元、冷却、伤势和蛊虫条件形成决策。 | 原著不是回合制战棋，所有行动节奏均为改编。 | 战斗必须保留交易、调查、设局、伪装或撤离等系统路径，不能退化成纯战斗爬塔。 |
| ADP-CULTIVATION-001 | CAN-APTITUDE-001 | 将原著中资质对修行上限与效率的强约束，在首发收束为清晰的突破门槛：丙等角色可冲二转，但必须先在本局提升资质，才可尝试三转。 | 原文对丙等使用“通常停在二转、少部分侥幸三转初阶”的表述；游戏为可读性和路线价值采用硬门槛。 | 不用击败敌人自动灌经验取代资质、修行条件和机缘；资质提升不得成为局外永久数值成长。 |
