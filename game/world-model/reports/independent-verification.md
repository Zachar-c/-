## 二、V1 原著映射核验（部分成立）

**抽样范围**：canon-index.md 中带原文行号的 `CAN-` 条目 **41 条全部回查**（超出原定 12 条抽样）。

| 项 | 实测 |
| --- | --- |
| 事实性错误 | **0 条** |
| 严格命中（所标行即直接依据） | **31 / 41（75.6%）** |
| 需 ±2~14 行修正 | 9 条 |
| 引文与所标行完全无关 | 1 条（`CAN-BEAST-SWARM-001` 标 15212，实际 15226，+14） |
| 偏差方向 | 几乎全为**正偏**（实际内容在标注行之后），属系统性偏置而非随机错误 |

**另外三点关键发现**：

1. **无原文校验锚点**：登记册只写行号，未记录原文 SHA256 / 行数 / 提交。
   实测原文 `蛊真人-clean.txt` SHA256 前缀 `BF78D414…`、共 437,060 行。
   原文一旦替换，全部行号静默失效且无法自动检出。
   （对比：本项目对派生数据 `world-model/data/` 是逐文件记 sha256 的，工具链已有，只是未用于原著。）
2. **原文自身被清洗改字**：全文含 **782 处 `**` 掩码**。`CAN-APTITUDE-001` 与 `GAME-CULTIVATOR-003`
   所载「甲等八九成」正建立在被掩码的 1358 行上，该数值在当前原文**无法直接读证**。
3. **ADP- 登记册干净**：8 条四栏（原著依据/游戏化转换/简化或偏离/不可越界）齐全，
   措辞未把改编写成原著事实，无悬空引用。
4. **派生层短板**：`docs/lore/*.md` 之外的派生数据中，有 10 条 `source_class: "canon"` 但
   `source_ids` 为空；261 条程序化生成内容被冠以 `canon` 且所引 CAN 条目与内容无关。
   上游 `data/gu.json` / `enemies.json` / `npcs.json` 本身**零来源字段**。
   另有 `data/loot_tables.json` 复用同名字段 `source_class` 表示「掉落来源」，与来源追溯语义冲突。
5. **正向结论**：`source_ids` 指向不存在编号的情况为 **0 / 4551**，编号引用完整性治理真实有效。

## 三、V2 数据一致性审计（基本成立）

**审计规模**：21 条引用链、约 2,600 次引用。

| 项 | 实测 |
| --- | --- |
| 已定义表之间的悬空引用 | **0** |
| 唯一未闭合链 | `synthesis.json` 的 4 个卡片 id（`farewell_grip` / `light_probe` / `vitality_grass_remedy` / `blood_bat_bite`，共 6 处引用）在上游无任何定义表 |
| 重复 id / 同 id 不同内容 | 未发现 |
| `gu_names.json` 同表重名 | 25 组 |

**三项缺陷**：

1. `data/pacing.json` 五层 `category_weights` 权重和均为 **101**（battle+rest+unknown+trade）。
2. `gu.value` 有 **13 条策展蛊**偏离 `gu_value_by_rank` 锚（如 `white_jade_gu` r2 值 30），
   `test_slay_gu` rank=10 越界。
3. 炼蛊图存在 **377 条 `input == output` 的 advance 自环**（同名蛊升转），
   另有 **363 / 802（45%）蛊完全不在任何配方中**，**18 / 32 敌人从未被任何节点引用**。

## 四、V2 与包内校验器的差异裁定（已在本次核验中复核）

| 分歧点 | 审计口径 | 包内校验器口径 | 裁定 |
| --- | --- | --- | --- |
| 权重和 101 | 「应 = 100，破坏归一」 | `abs(total-100) <= 1` 容差内判定 PASS | **实现上无害**：`category_weights` 是**相对权重**（`rng.next_index(total)`），不是概率向量，101 与 100 产出同分布；容差 ±1 已在校验器中显式写明。**但审计提示成立**：该字段名易被误读为归一概率。→ RISK-14 |
| advance 自环 377 | 「按 gu_id→gu_id 建模会全量误报环」 | 视为「同定义 +1 转」，不计为环 | **口径差异**：包内已显式说明该解读（校验报告 §4）。审计的担忧在**外部消费方**身上成立。→ RISK-15 |
| `gu.value` 偏离锚 | 13 条超标 | 只校验 value > 0 与量级范围 | **审计更严**，包内校验未覆盖「与锚一致」这一层。→ 已记为校验器待补项 |

## 五、V3 世界模型反方审稿（部分成立）

**决定性事实**：仓库的 Stage 0 世界规则基准 Gate 已于 2026-09-17 转为 GO，
但生产 `data/` 与 `scripts/` **一行未改**。

1. **设计宪章 §5.3「应删除或禁用」7 条中，5 条在现有实现中明确仍存在**：
   流派当开局固定蛊包、`role` 兜底效果（745/802 走 `v1_battle.json.default_effect_by_role`）、
   寿元与魂在 `shops.json` 中当普通货币、后置任选「核心蛊」槽、NPC 无长期后果。
   1 条部分成立，1 条无证据。
2. **因果链两处硬断**：
   - 「炼化 / 认主」在当前实现中**只是状态标签**（新蛊直接置 `refined`，未见独立炼化流程）；
   - 「知识 / 操控 → 杀招」也是断的（杀招是 `v1_battle.json` 写死的 26 条；
     玩家自定义组合仅有字段、无写入方）。
   → 蛊虫生命周期五环节中「获取 / 晋升」完整、「喂养 / 反噬」部分、**「炼化 / 认主」缺口**。
3. **经济验算**：黑市 50× 不对称**不构成套利**（所有往返均净亏损）；
   但「晋升单点依赖兽骨」更尖锐——468 条配方 381 条用兽骨，`advance` 线 377 条里 **375 条**用兽骨。
   文档层预算全程仅 113 元石，而核心升转只需 16 元石（晋升便宜、买蛊贵）。
4. **审计报告 §26 的 7 项疑似偏移，无一被推翻**；终局 Boss 倒挂（L5 `miasma_vein_lord`
   有效强度 21 < L4 的 27）再次被确认。
