## 一、实测症状（改前）

| 指标 | 改前 |
|---|---:|
| 整备页内容高度 | **3695 px** |
| 可视区高度 | **750 px** |
| 「完成整备」按钮顶部位置 | **3794 px**（要滚约 4 屏） |
| 整页可滚高度 / 可视高度 | 3743 / 750 |

堆叠本身也有具体病灶：

- **蛊仓**是 14 行全宽列表。每行只有一个图标 + 一行字 + 右侧一个「卖」按钮，
  却横跨整个 1200px 宽度，右半边全是空的；14 行约 500px 高。
- **材料**是独立一条全宽带，内容为空时也占约 100px 并带一条分隔线。
- **炼蛊**与**杀招**各自是整段独立区块，直接接在蛊仓下面。
- 区块之间只有 1px 发丝线，没有分组，眼睛找不到东西。

## 二、改后结构

```text
┌─────────────────────────────────────────────────────────────┐
│ 固定头（sticky）：段/节点名 · 资源摘要 · [完成整备 →]        │
├──────────────┬──────────────────────────────────────────────┤
│ 常驻左栏     │ 工作区：[坊市 9] [蛊仓 14] [炼蛊 6] [杀招 5] │
│ 修炼突破     │                                              │
│ 资质蛊       │   当前页签内容（独占宽度，自己滚）           │
│ 材料 · N 种  │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

三条纪律：

1. **头固定，出口常驻。** `.prep-head` 用 `position: sticky; top: 0`，横向负边距做满幅。
   出口从「整页最后」变成「永远在右上角」。
2. **左栏常驻，装高频只读信息。** 修炼突破 / 资质蛊 / 材料进左栏，且左栏自身也 sticky，
   所以「我能不能突破」「我有多少材料」始终可见，不必跟着工作区滚。
3. **工作区按页签分块。** 坊市 / 蛊仓 / 炼蛊 / 杀招一次只显示一块，各自吃满右栏宽度；
   单块内部自己滚（`.prep-pane { max-height; overflow: auto }`），整页基本不需要滚。

页签选中项存在 `journey.js` 的模块级 `prepTab`，**活过整页重绘**——
否则在蛊仓里卖一只蛊，重绘会把你弹回坊市。

## 三、逐块改法

| 块 | 改前 | 改后 |
|---|---|---|
| 出口 | 整页最底部 `.leave-row` | 固定头右上角 |
| 修炼突破 / 资质蛊 | 两列网格的上排 | 左栏 |
| 材料 | 全宽带 | 左栏内小块，自身限高滚动 |
| 坊市 | 全宽带 | 「坊市」页签 |
| 蛊仓 | 14 行全宽列表 | 「蛊仓」页签，**复用 `.gu` 卡片网格**，一屏约 15 只 |
| 炼蛊 | 整段接在下面 | 「炼蛊」页签 |
| 杀招 | 整段接在最后 | 「杀招」页签 |

两处顺带清掉的重复：

- **炼蛊页签开头原本是一份和蛊仓一模一样的 14 张卡网格。** 已删——已炼化蛊虫归蛊仓
  （那里现在带效果文案与卖价），炼蛊页签只留「炼化野生蛊」与「炼蛊台配方」，
  并在开场一行字里指路。信息没有丢，配方行本身就带投入蛊的图标与名称。
- **炼蛊页签里那个「完成炼制并离开」按钮已删。** 它是为「出口够不着」而存在的第二个出口；
  固定头已经解决了这件事，同一个动作不再摆两处。

## 五、明确没做

- **没有动视觉语言。** 配色、字体、按钮样式、卡片外观一律沿用现有 token；
  本次只改布局与信息架构。视觉方向本身仍在 L0 待裁决。
- **没有动数据与规则。** `tools/build_data.mjs` / `js/data.js` 之外，
  规则文件（`run_flow.js` / `rules.js` / `battle.js` 等）一行未改。
- **没有为窄视口做专门设计。** 1100px 以下只是退化成单列滚动，出口靠 sticky 保住。
  本原型的验收目标是桌面宽度。
