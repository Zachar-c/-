# 平衡证据纪律（永久）

> 依据：L0 构筑分叉总计划 Phase 0 · 2026-09-25

## 禁止进入平衡证据的材料

1. **复写引擎模拟结果**  
   任何复刻 / 重写 `main.js` 或其它运行时逻辑的模拟器输出（含 victory、ACTIVE_SOLUTION 次数、理论胜率）**永久不得**作为平衡证据、验收证据或产品结论依据。

2. **未标注的 fixture 合成状态**  
   合成状态必须标明 `FIXTURE` / 非正常 Run；不得外推为可通关或不可通关。

3. **显示漂移前的旧 UI 文本**  
   组件合成与预制 `m.effect` 分裂时期的展示文案，不得当作结算事实。

## 可进入平衡证据的材料

1. 真实 `lab.html` DOM 走盘 / 可见点击轨迹（不注资、不赋值 state）。
2. `node --test tests/*.test.mjs` 的真实输出文本（V1：只看输出，不看退出码）。
3. 受控探针输出，且附可复核命令与结果片段。
4. 已通过 Gate 0 的 UI / 门禁 / resolver 一致性断言。

## 复核纪律

沿用 `AGENTS.md` V1–V6：

- V1 判定只看真实输出文本；
- V2 Worker 结果包分代码 / 数字 / 根因三类复核；
- V3 数值与产品取舍上抛；
- V4 数值论断回到应用点；
- V5 计划与实际不符时作废留痕；
- V6 不假装存在语义上不可能的零漂移拆批。
