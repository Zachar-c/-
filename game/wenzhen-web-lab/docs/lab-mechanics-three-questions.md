# Lab 新机制 · SOURCE / GAME COMPRESSION / RISK

> 依据：`docs/ORIGINAL_POWER_SYSTEM_AXIOMS.md` 附录「新机制三问」。
> 对象：当前 10 分钟 Web MVP 中**非原作直译、为循环而新增**的规则。
> 结论格式：三问齐全 → 可留在 lab；不得未经 L0 长期体验升格为 world 规则。

---

## 1. 逆息（HP→Qi 紧急兑换）

```text
SOURCE:
  原作「以伤换力 / 透支根基再催蛊」的因果（血道、残锋、逆炼等均有
  「用身体或道痕换一次出手机会」），不是某一条具名招式。

GAME COMPRESSION:
  压成固定阀门：1 念头 / 气血 -2 / 真元 +3，CD 2，当回合禁收势与生机草。
  只在「有伤害蛊但真元卡住」时可触发。不做道痕、不做品阶、不做多档兑换比。

RISK:
  若升格为常规回蓝 → 变成「拖回合又有蓝」，破坏资源压力与公理 6。
  用 CD + 当回合禁回复把风险锁在「用命换刀」；仍可能被当成主循环（已用
  autoplay 逆息 ≤2 门看住）。未经 L0 体验确认前 = LAB anti-softlock only。
```

## 2. 普通战胜利 +2 气血 / +2 真元

```text
SOURCE:
  原作战后调息、吸收战利、恢复一定元气的常见节奏；无「每战必 +2」成文公式。

GAME COMPRESSION:
  固定 +2/+2，不做节点、不做选择、不做按伤势缩放。全 lab 唯一稳定回血。

RISK:
  变成无脑白回 → 削弱伤势长期代价（公理 2/5 的「当前环境价值」被抹平）。
  10 分钟切片用它托住跨战 HP 持久性；完整系统应交给休整/资源结构。
  = LAB pacing valve only。
```

## 3. 炼蛊台消耗月光 + 小光 → 月芒

```text
SOURCE:
  原作炼蛊/合炼「以蛊为材、改规则」；杀招与合炼都是「元件重组」。

GAME COMPRESSION:
  单配方、固定两材 + 2 真元，产出「压制反制」的规则件。保炉 = +3 元石退出。
  不做随机合炼、不做古方知识、不做失败炸炉。

RISK:
  消耗工具箱 → 可能锁死输出（V4 soft-lock 已用逆息兜住）；
  不消耗 → 削弱「用工具箱换新规则」的代价感（L1 已否决 Q1-C）。
  当前取「真实结算代价」；= 当前 MVP recipe rule，非 world 合成规范。
```

## 4. 同类反制「观察一次永久识别」

```text
SOURCE:
  原作情报/识货/看破：信息是资源，看懂规则后不再交学费。

GAME COMPRESSION:
  knownCounters 永久标记；后续同型反制 revealed，不再收观察税。
  「读对 + 做对」才 -3。

RISK:
  若「碰巧做对也 -3」→ 观察从资源降为保险（L1 Q4 已维持原案）。
  压缩风险低；属规则层，不进 Budget。
```

## 升格门

任一 lab 阀门要进入 world，必须：

1. L0 长期试玩确认「这就是《问真》应长期拥有的行为」；
2. 重写 SOURCE 指向可追溯原作/裁定（不得停在「常见节奏」）；
3. 重做 RISK（含对公理 3/4/6 的因果破坏面）。
