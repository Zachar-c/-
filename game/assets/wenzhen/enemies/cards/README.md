## 视觉取舍

- **原文明示**：灰黑毛皮、健壮短腿、竖硬鬃毛、直线冲撞、变向能力弱。
- **画面推断**：野猪在月下溪滩迎面冲来；溪水反光和银色装饰边框承接青茅山夏夜氛围。未添加铁甲、异能光效、首领体型或陪衬生物。
- **构图基准**：野猪是第一视觉焦点，占画面约六成高度；溪滩与山林提供环境感但保持次要，沿用用户认可的“主体清晰、场景有层次、真实光影”平衡。
- **提示词摘要**：一头原著普通成年野猪，灰黑粗毛、短腿、竖硬鬃与浅色獠牙，三分之四迎面直冲；置于青茅山夏夜溪滩，主体清晰锐利，月光与湿石反光负责衬托，配精细银边及少量林绿、朱砂装饰；梦幻但具真实材质与光影。禁用铁甲、超自然特效、猪王体型、文字与其他动物。使用 Codex 内置 imagegen 生成，用户示例只作为构图和风格参考。
