# 原著蛊虫卡牌美术

本目录按单只蛊虫建卡，不按流派或类别共用图片。当前范围取自 `game/data/gu_lore.json` 中标记为原文来源的 270 条记录；逐条身份、原文锚点、原文映射状态、美术依据及文件路径见 [`catalog.json`](catalog.json)。

卡面采用 5:7 竖版扑克牌构图，突出单只主体，保持梦幻氛围与真实光影。用户提供的优秀卡图用于校准主体尺度、梦幻氛围、真实光影、材质细节与卡框质感；只提取这些视觉品质，不复用酒虫或荡魂山的场景。每张背景按该蛊原文场景和作用单独设计，避免批次间背景套路化。原文写明蛊体形态时优先遵循原文；未写明时允许依据名称、作用、合炼关系和出场语境推断，并在目录中标明推断。

原有流派示意图不作替换或覆盖。当前独立卡牌已落盘 65 张，另有 205 条尚未入库；其中包含原文身份/流派待校正、按用户要求跳过的条目，详情见交接记录。继续前请阅读 [交接记录](HANDOFF-2026-09-27.md)，并先核对身份冲突与原文锚点。
