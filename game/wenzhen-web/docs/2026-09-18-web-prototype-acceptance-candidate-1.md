# Web Prototype Acceptance Candidate 1

日期：2026-09-18  
对象：当前 `wenzhen-web` 工作树候选版本。验收期间未回写功能改动；TTVC 等价试验使用临时副本。

## 判定

结论：**工程门基本通过，体验门部分通过，AI 生产门暂不通过，技术边界门尚未触发。**

当前版本值得继续作为《问真》的 Web 创作实验，但还不能宣称 Web 原型验收成功，也不能据此决定 Godot 退出。

## 六个数字

| 指标 | 结果 | 口径 |
|---|---:|---|
| 首次启动耗时 | `DOMContentLoaded 51.1ms`；`load 60.4ms` | CDP 真实 Edge，`1366×768`，`gate=0&silent=1` |
| 完整流程错误数 | `0` | IAB 从开场跑到第四幕；CDP 场景复跑也为 0 console error/warning |
| 平均 FPS | `58.8` / `58.9` | 落雨场景，2 秒真实 `requestAnimationFrame` 采样，分别为 `1366×768` / `2560×1440`，静音 |
| 首次加载时间 | `60.4ms` | 同上，浏览器 navigation `loadEventEnd` |
| 5 项修改平均 TTVC | `N/A` | 原题中 3 项不适配当前版本：没有主菜单/标题，没有 30 秒后事件，人物与背景烘焙在同一张图；不能伪造平均值 |
| 完成当前四幕脚本时间 | 约 `95s` 脚本节奏 | 不含玩家停留和犹豫；当前不是交接文档所述的 10 分钟完整体验 |

## 四道门

### 1. 工程

通过项：刷新回到干净开场；三连点没有重复创建场景；核心静态资源请求均为 `200`；`1366×768`、`1920×1080`、`2560×1440`、`520×900` 的标准 Edge 截图均能铺满且选项可读；主要路径无 console error/warning。

未完全通过项：本轮没有完成“同一窗口动态 resize”而只验证了多尺寸冷启动；WebAudio 的真实听感未被自动化环境确认；IAB 方形视口曾出现黑带，但标准 Edge 尺寸未复现。

### 2. 体验

通过：前 10 秒有明确气质，不像常规网页模板；玩家先看，再把三颗元石拖入空窍，资源消耗是可见且有机会成本的；第四幕有“收下 / 追问 / 不要”三路，不直接告诉玩家善恶；画面中的第二个人和含混回应能制造利益怀疑。

未通过：当前没有主菜单、标题或正式结尾；社交选择只改变当下台词/石头状态，没有后续可见代价；“失败多次仍继续”的坚持主题还没有被规则承载。

### 3. AI 生产

等价试验验证了 CSS 布局类小改动可以快速落地到临时副本并得到截图，但没有形成有效的五项平均 TTVC。

重要发现：当前第四幕人物和背景合成在 `assets/visitor.png`，所以“只替换背景、人物/UI/交互完全不变”不是资产替换，而是需要拆层或重新合成；这正是 Web 创作环境需要解决的生产结构问题。

### 4. 技术边界

当前雨幕在两个大视口都约 59 FPS，尚未出现进入引擎的真实理由。但压力测试所需的“3 层视差 + 10–20 移动粒子 + 局部人物动画 + 环境音 + BGM + Shader + 互动事件”尚未作为一个场景存在，因此不能把当前 FPS 当成 Web 上限结论。

## 内容四问

- 真正判断：**部分通过**。追问动机是玩家自己的判断，但缺少后续代价。
- 选择代价：**部分通过**。喂蛊有资源代价，第四幕社交选择没有持久代价。
- 利益怀疑：**通过**。雨中第二人和含混答复提供了怀疑对象。
- 规则承载思想：**部分通过**。稀缺元石与喂蛊承载了“资源投入”的感受；坚持主题尚未进入规则。

## 下一步判定

冻结本候选，不继续堆 Web 功能。下一轮若继续 Web，优先补齐“可测的创作环境”而不是扩展场景数量：先决定人物/背景是否拆层、是否需要正式开局/结尾，以及把一个真实的 30 秒后果事件接上。完成后再重跑五项 TTVC，并对 Godot 做同口径 A/B；在此之前，不能用本轮数据宣称 Web 比 Godot 快几倍。
