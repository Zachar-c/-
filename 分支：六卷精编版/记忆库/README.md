# 重写记忆库 README

本目录位于分支 `分支：六卷精编版/`，是《蛊真人》重写项目的最新权威记忆库。写正文前先读本目录。

事实源只有两个：`蛊真人-clean.txt` 与《人祖传》.txt。读书笔记仅作检索与辅助核对，不作为独立事实源。

## 核心文档

- `../全书总纲.md`：正式落盘的全书总纲，写作时的单一权威骨架。
- `../细纲/卷一-青茅-细纲.md`：卷一详细细纲，落笔时的逐章基准。

## 文件清单

- `00-已确认决策.md`：用户确认的创作决策与修正记录。
- `01-六卷总纲.md`：六卷结构、留白边界、篇幅原则。
- `02-人物弧光.md`：核心人物弧光与关系收束。
- `03-分卷改造方案.md`：每卷保留/删减/合并、新增场景、伏笔衔接。
- `04-人祖传-隐喻索引.md`：《人祖传》38节通读索引与全书互文分配。
- `05-设定集-核心锚点.md`：已核验的原著设定锚点，写作时不可丢设定。

## 来源文件

- 原文：`蛊真人-clean.txt`，UTF-8，正文推进至第4501章处中断。
- 人祖传：《人祖传》.txt，GBK 编码，4368行，38节。
- 读书笔记：`读书笔记/`，按行区间分档。
- 不采用：根目录 `旧稿归档_不采用/` 中的旧总纲、旧样章与外部 AI 终局设计。
