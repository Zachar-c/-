# archive/

历史资料保留位置。本目录只放已明确不再作为当前入口的内容；任何需要继续维护的资料不得移入这里。

## 规则

- 移入前必须在 `docs/debt.md` 登记一行（类型 `ARCHIVE`），写明原路径、现状与保留理由。
- 移入后不得再被 `AGENTS.md`、`PROJECT_MAP.md`、`README.md` 或 `MIGRATION.md` 引为当前入口；引用只允许出现在历史记录语境。
- 不存放完整原始小说与《人祖传》全文；本地原文只在被忽略的 `source/`。
- 不存放嵌套 `.git`、worktree、缓存、构建产物与临时输出；本地恢复材料保留在原地并被根规则忽略。
