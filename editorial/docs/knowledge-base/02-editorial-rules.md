# 编辑规则速查

来源：`outlines/README.md`、`notes/editorial-notes.md`、`notes/full-book-editorial-review-2026-08-08.md`。

## 正文修改分级

| 级别 | 对象 | 约束 |
| --- | --- | --- |
| 保留 | 剧情、心理转折、行动过程、关键对话、场景信息、伏笔、高潮前后积累 | 不得删除 |
| 压缩 | 重复环境、同义解释、重复回顾、无信息过渡句 | 只合并重复，不得把过程压成结果摘要 |
| 润色 | 转码残缺、语法、指代、语序、节奏 | 保持原意、视角、情绪强度 |
| 校正 | 时间线、称谓、数字、设定冲突 | 仅在全书证据足够时修复；不足则登记 FD |
| 不得改写 | —— | 不得新增原文没有的剧情/动机/能力/关系/真相；不得用作者解释取代人物行动 |

## 信息释放规则

1. 总纲可剧透（标记"编辑后见/后文回收/正文当时人物未知"）；正文不得提前泄露。
2. 早期叙述的误认、传闻、家族史、人物自我判断，除非明确错误或噪声，不用后见真相替换。
3. 后文证明早期说法不完整时，正文保留悬念，细纲注明回收点。
4. 未获全书多处证据确认的数字/时间/称谓/死因/制度 → 查 `notes/fact-disputes.csv`（FD 编号），正文用中性表述。
5. 伏笔功能不只答案本身：等待、误导、心理预期、揭示反差都要保留。

## 证据引用格式

- 单点：`[源文：第 X 节《标题》，索引行 source_line=NNN]`
- 跨章节：`[综合：第 X—Y 节；后文回收：第 Z 节]`
- 后见信息必须注明；只依据当前批次则写"当前批次证据"。

## 位置定位

章节号在网页稿中出现重启、重复、缺失，定位统一用：部名或事件名 + 原章节标题 + `source_line`（例如 `source_line=426`）。`source_line≈` 表示审计范围定位。

## 静态约定

- 正文 UTF-8；原文 CP936 底稿不覆盖、不入库。
- 不弱化关键气势：绝境、杀机、决断保留笃定感与心理压迫（如开篇"群敌环伺，早已经没有了生路。大局已定，今日必死无疑"）。
- 世界观说明只在首次建立概念时完整呈现，后文用场景与行动承接。
- 同一结论重复三次以上且无新功能的，压缩为最有力一次。

## 争议处理流程

1. 发现数字/时间/称谓冲突 → 对比全书证据。
2. 证据 ≥ 2 处可被取代 → 直接修正本地，下游复核受影响章节。
3. 证据不足 → 登记 FD（编号从 FD009 起），正文中性表述，避免机械统一。
4. 修改验收标准："保住情节功能和人物锋芒"，不得为正确性把战斗、心理、反转或哲思压成提纲。
