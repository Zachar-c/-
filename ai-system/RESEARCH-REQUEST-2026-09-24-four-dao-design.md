## 1. 需要 L1 交付的判断

请据下列证据，为血、魂、光、力四道给出一版可供 L0 裁定的 Web 玩法设计。四道是当前首批设计范围；**本件不裁定其它道是否永久排除，也不要求扩展设计范围**。

请回答：

1. **四道的可辨识身份**：各用一句话描述玩家在该道的核心选择；指出哪些身份有原著证据，哪些是游戏设计推导。
2. **可重复的行动结构**：每道给出核心行动循环、主要取舍、可被敌人针对的弱点，以及玩家如何应对。避免只用不同伤害类型包装同一种打法。
3. **四道之间的边界与交互**：说明每道如何与其他三道形成可组合但不互相吞并的构筑；指出证据不足或需要 L0 选择的部分。
4. **最小可实现切片**：优先复用现有 Web 战斗、观察情报、蛊虫、杀招、奖励、商店、炼方和构筑提示；逐道指出可先复用的内容类别、必须补齐的接线，以及任何需要新增核心机制的提议。若新增机制确实必要，请标出其范围和为何现有能力不能替代。
5. **正常局验收方法**：提出能证明四道打法不同的可见操作轨迹和验收条件。规则夹具不能代替正常局证据。
6. **未决事项**：精确数值、胜率或费用曲线不在本次请求中裁定。若设计依赖这些数值，请列出应用点与待测假设，留待独立 L1 数值请求。

请把答案分成【原著事实】【L1 推导】【需要 L0 选择】【实现建议】【未验证项】；不要把下方 L2 观察当作既定结论。

## 2. 上位产品约束

- 《问真》PRD v1.0 定义 Web 为完整长线单机载体：五层修行、单局目标 3–5 小时、200–300 个有效节点；这不是《蛊真人》剧情复刻。
- 核心循环是观察敌人 → 获取信息 → 制定策略 → 使用蛊虫 → 承担结果 → 调整方案。构筑选择应改变后续打法、资源或目标。
- 力量必须有来源、条件、消耗、限制与风险；体验来自多种有效取舍，不是堆叠数值。
- Web 不做材料库存、材料掉落、材料交易或材料合炼投入。成本可落在真元、蛊虫、时间、风险与机会；不得以恢复材料循环绕开此边界。
- 不因设计四道就新增剧情复刻、全世界地图或其他无关核心系统；新核心机制和显著扩大的世界范围须另行裁定。
- 公开运行入口是 `game/wenzhen-web-lab/lab.html`，离线打开。正常局行为和可见控件是最终验收对象。

## 4. 原著证据（本地《蛊真人-clean.txt》逐段核验）

每条短引少于 60 字。行号以本地 `source/蛊真人-clean.txt` 为准。此路径与本地项目来源映射一致；原文不进入 Git。

### 血道

- 血海老祖临死前广布传承，数十万个传承密地遍及多域（31912–31914 行）。短引：「数十万个传承密地」。
- 一段对话把血海真传称为九道，并列出血颅、血手印、血气、血汗、经血、血影、血战、戾血龙蝠与血神子（75640–75642 行）。短引：「据说血海有九道真传」。原文保留“据说”口径。
- 特定传承关卡以血道野蛊、血兽供血道蛊师收服或吞食，帮助增长血道修为（108780–108782 行）。短引：「用来增长血道修为」。
- 血道蛊师受到正道追杀，魔道也会暗算；叙述将其与战力速成相连（108784–108788、134792–134794 行）。短引：「血道战力可以速成」。
- 鹤风扬批评血道修行为害生灵、令战力暴涨（129262–129264 行）。短引：「殃及万物生灵」。这是角色的批判性陈述，不能推成每一只血道蛊都必须伤生。
- 血颅蛊曾被用于屠杀亲族、提升资质（75614 行）。这是一个极端个案，不是通用晋升公式。

### 魂道

- 魂道专注魂魄修行，原文说它与力道齐名，上古辉煌且仍经久不衰（78240–78250 行）。短引：「魂道和力道齐名」。
- 幽魂魔尊把壮魂与炼魂分别联系到荡魂山、落魄谷（78254–78256 行）。短引：「壮魂首选荡魂山，炼魂首选落魄谷」。
- 魂道修行有壮魂、炼魂、安魂三要素，三者相辅相成（332470–332474 行）。短引：「分别是壮魂、炼魂、安魂」。
- 常人魂魄增长有百人魂极限，再多一丝会爆散（78228–78236 行）。短引：「俗称百人魂」。
- 魂道蛊虫涉及多方面，组合成套可相互增益；奴道也从魂道衍生（81812–81834 行）。短引：「构成一套，更能相互增益」。

### 光道

- 风道、光道、暗道在上古时代产生（246664–246668 行）。短引：「风道、光道、暗道也在这个时代产生」。
- 萧芒称光道长于速度和净化，破坏力不及炎道（72700 行）。短引：「光道长于速度、净化」。这是针对一处关卡的角色判断。
- 一转小光蛊是辅助蛊；三转光栅蛊能成栅栏并禁控目标（103412–103422 行）。短引：「变化栅栏，禁控目标」。
- 三只五转光道蛊分别用于增长速度、治疗和攻击（103424–103428 行）。短引：「治疗之用的春光无限蛊」。
- 虚光甲胄是光道仙级防护手段（157509–157512 行）。短引：「光道的仙级防护手段」。
- 光道道痕能改变特定仙窍的光照；一次白天、黑天碎片碰撞因光道/暗道道痕排斥导致白天碎片破碎（200036–200050、434880–434882 行）。短引：「道痕之间相互排斥」。这是高阶与特定环境案例。

### 力道

- 狂蛮魔尊开创变化道与力道（246664–246668 行）。短引：「狂蛮魔尊开创变化道、力道」。
- 人体拳脚不能将积累的力量全部转成一次攻击；永久增力蛊的投入也可能无法充分转化为实战效果（51294–51298 行）。短引：「拳击脚踩，只能发挥出人体的一部分力量」。
- 力道蛊虫真元消耗低，但持续使用仍会耗尽真元（51644–51648、55222–55224 行）。短引：「力道蛊虫对真元的消耗最少」。
- 原文称多数力道蛊师偏近战、远程攻击薄弱、容易被针对；力气蛊是弥补这一缺口的个例（59612–59616、95124–95128 行）。短引：「远程攻击十分薄弱」。
- 力道蛊虫当时大多用于攻击，防御、侦察、辅助类别较少（81808–81812 行）。短引：「大多用作攻击」。
- 身体强度不足时，过度使用力道蛊虫会导致筋肉撕裂、骨头自断（90802–90804 行）。短引：「筋肉撕裂，骨头自断」。
- 原文记述力道在当时已式微，高转与出彩者较少（53814–53818、81808–81810 行）；这是时代处境，不是永久不变的世界规则。
