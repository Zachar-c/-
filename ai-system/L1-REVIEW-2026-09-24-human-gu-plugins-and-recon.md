# L1 评审摘录 · Web 人类敌人蛊虫插件与侦查蛊

> 2026-09-24；来源：L1 任务《四道玩法设计评审》对独立 Research Request 的回复。本文是实施摘录，原著事实仍以 `lore/wiki/gu/cultivator-effects-and-scouting.md` 的逐条行号为准。数值另案送审。

## 已裁定的模型

- 玩家与人类敌人使用同一 `HumanState`：统一基础值、转数相关真元、实际蛊实例、当前资源、蛊虫来源修正账本。敌人额外只有行动偏好，不能获得身份、精英、层主或转数附赠的非真元属性。
- `ModifierLedger` 记录属性、蛊定义与实例、效果、持续类型、依赖、建立时间和失效原因。局内永久修正不依赖来源蛊继续持有；白豕蛊须经催动或修行产生永久增力，蛊本身不因获得增力而消耗。持续催动效果依赖蛊仍持有、未封印和维持成本支付；战斗结束解除。一次效果结算后不追溯撤销。
- 当前没有已核实的最大气血、念头增益蛊，不为填满六轴发明候选。石皮蛊可作持续防护，胆识蛊与狼魂蛊可作魂魄强化，白豕蛊/黑豕蛊可作永久增力，酒虫优先影响真元品质；各自映射到 Web 属性的数字仍属游戏改编、待数值裁定。
- `ReconKnowledge` 以观察者和目标为索引记录事实、来源侦查蛊、时间、可信度与是否过期。公开信息仅含当前气血、已发生行动和外显结果；敌方本轮计划与未用携蛊默认未知。侦查分别规定目标覆盖与信息深度，从目标异常、行动大类、当前具体计划到携蛊识别逐层加深。现有证据不支持首批任意蛊“读取全部携蛊”。
- 敌方先从合法基础行动或可付费蛊虫生成 `PlannedAction`。玩家改变其合法性后，旧预测变为过期。敌人侦查玩家也要付费、记入敌方知识；AI 不得私读玩家隐藏蛊实例。
- 人类敌人采用必带蛊、有限可选池、预催动策略与行动偏好；种子只在合格池内取实例。原手写阶段仅可改变行动偏好；意图必须指向基础行动或蛊实例；无对应蛊的手写反击暂停。掉落候选必须来自死亡时仍持有、未消耗的实际蛊实例。

## 首批纵切与验收顺序

1. 共用属性、来源账本及蛊实例生命周期。
2. 石甲蛊师：基础气血 10，真实携带并维持石皮蛊，资源不足或封印时退效；同蛊给玩家同效。
3. 白豕蛊：修行后局内永久增力，随后卖出或合炼仍保留已获得效果。
4. 默认隐藏敌方计划；建立侦查知识后移除固定观察。可用侦查蛊只能揭示自身覆盖与深度允许的信息。
5. 实际携蛊奖励、其余 13 类人类敌人、受约束的种子变体，最后用离线正常局验证。

## 仍需 L0 或数值裁定

- L1 建议所有人类保留相同的基础拳脚攻击；用户计划已允许基础行动，但其数字待数值请求。
- L1 建议持续催动不跨战斗；用户计划已经明确战斗结束停止。
- 战斗封印是否随敌人死亡而解除、首批敌人是否允许只留历史永久增益而不携带来源蛊，L1 推荐分别为“解除”和“暂不使用”。
- 小光蛊现有 `inspect:true` 不是已核实的原著侦查能力。L1 建议移出侦查白名单，除非 L0 要求以《问真》改编保留。
- 侦查蛊身份与“预测攻击、识别蛊虫”的改编边界待 L0 补充选择；数值请求另见 `RESEARCH-REQUEST-2026-09-24-human-gu-plugins-numerics.md`。
