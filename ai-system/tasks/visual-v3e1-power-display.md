# v3-E1 力量表现（一至七转，27 例）

> 判定口径：①“是否纯能量表现”= 无形状/材质/可辨认物象（仅光·雾·响·无形态）判"是"；有刃·龙·蛛·手·兽影·冰雪·火海等具体物象判"否"。② 转数按力量发出者（或其蛊虫/劫兽载体）在原文就近明确的转数计；混合战斗取发出者转数。③ CANON CONSTRAINT 只答"原著允许自由到什么程度"。④ 检索：关键词（月刃/冰刃/狼烟/油龙/火龙/兽影/龙象/杀招/剑光/魂压/大手印/离歌/光柱/自爆等）定位→读命中行±120行。⑤ 【分析】为归纳判断，非原文事实。

- 力量来源：月光蛊＋白银真元（三转，3610行「学堂家老是三转境界」）

- 是否纯能量表现：否（月牙形刃具）
- 是否实体或半实体：半实体（光凝成刃，可消散）
- 是否只有结果没有过程描写：否
