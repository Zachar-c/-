### 原著身份

```text
它是什么：
一转月道蛊虫，方源早期使用的攻击型本命路线之一。

它解决什么问题：
催动后可形成月刃攻击，也可参与月芒蛊等合炼路线。

它代表什么力量：
月光、月道、清冷、锋锐，以及以真元换取攻击的能力。
```

## 二、本体约束

### 必须保留

```text
1. 弯月形核心轮廓。
2. 淡蓝、晶莹、半透明的玉质或晶体质感。
3. 小型生命体尺度：掌心可托，约玉坠大小。
4. 幽蓝或月光类低强度光感。
5. 一眼可识别为“活着的蛊”，不是单纯武器或装饰。
```

### HARD

```text
弯月、淡蓝晶体/玉质、小巧尺度是对象身份的重要识别点。
不得改成非月牙形、非淡蓝材质或大型生物。
不得改变月光蛊的名称、月道属性、攻击功能来源。
```

### SOFT

```text
内部结构、表面纹理、边缘细节、灵气流动方式可以重演。
“像昆虫”还是像晶体生命，可在不脱离原著描述的前提下调整。
环境光、微距摄影感、材质精度可以设计。
```

### OPEN

```text
原著没有规定的微观纹理、内部发光结构、周围少量月辉与悬浮粒子。
可在本体上加入与月道、玉质和生命感一致的原创细节。
```

## 七、Prompt Draft

```text
问真世界观的本体层蛊虫概念图。画面中的对象是月光蛊：一只掌心大小、弯月形的淡蓝玉质晶体生命体，半透明，晶莹剔透，内部有克制的幽蓝光源和细密晶体纹理。它像活着的蛊，而不是普通昆虫、宝石饰品或发光武器。弯月核心结构必须清晰可见，两尖完整，轮廓一眼可辨。材质以玉、晶体和半透明生命组织为主；光感为冷月光、局部高光、低强度自发光，环境保持干净。单体静物构图，主体居中，轻微三分之二侧视，极简中性暗背景，突出材质与生命感。高质量幻想生物设定图，细节清晰，材质可信，比例克制，东方幻想基底，适合作为同一项目的本体参照图。负面约束：不要人物化，不要角色立绘，不要普通昆虫写实照片，不要满屏特效，不要珠宝堆砌，不要巨大生物，不要武器化替代本体，不要文字、水印、边框和多余角色。
```
