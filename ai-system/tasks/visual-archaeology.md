## 三、五个采集维度

每条素材都必须归入下列之一，并填写对应字段：

1. **环境视觉** — 空间类型 / 尺度 / 材质 / 光照 / 天气 / 危险感 / 文明痕迹
2. **生物视觉** — 生命形态 / 功能 / 成长方式 / 危险来源 / 与人的关系（含蛊虫、荒兽、异兽）
3. **力量表现** — 来源 / 媒介 / 过程 / 结果 / 代价
   （重点不是「技能特效」，而是**力量如何出现**。例：蛊虫催动不是「发光攻击」，
   而是「某种生命规则被调用」。）
4. **文明视觉** — 组织结构 / 财富体现 / 权力体现 / 技术水平（宗门、家族、城池、洞天）
5. **精神氛围** — 人物面对什么 / 世界如何限制人 / 力量带来什么
   （**不要简单写「黑暗」**。）

## 五、必须输出的报告结构
