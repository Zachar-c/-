## 四、素材对象格式（**L1 指定，逐字段照做**）

每个对象必须完整填写下列六项。**三层必须可辨识**：

```text
对象名称：<如 月光蛊>
原文位置：行号 <N>（必要时附章节名）
原文视觉描述【事实】：（只摘取原文可见事实，禁止推测）
    颜色：<原文怎么写>
    形态：<原文怎么写>
    材质：<原文怎么写>
    动作：<原文怎么写>
    声音：<原文怎么写；原文没写就写「原文未提供」>
    环境：<原文怎么写>
  短引：行号 <N>：「<≤60 字原文短引>」      ← 每条对象至少 1 条，用于 grep 复核
视觉关键词【转译】：（转换成游戏可理解的语言，如 半透明 / 玉质 / 冷光 / 月纹 / 生命感）
游戏视觉价值【评级】：★★★★★ 1–5 星
    ★★★★★ 必须进入游戏视觉核心
    ★★★★  适合重要资产
    ★★★   普通素材
    ★★    世界背景
    ★     不建议转化
```

**关键纪律**：
- 「原文视觉描述」是【事实】层——**原文没写的字段就写「原文未提供」，禁止用想象补全**。
  六个子字段允许缺项，**缺项本身是重要数据**（它说明原文的视觉密度在哪）。
- 「视觉关键词」是【转译】层，允许你的语言。
- 「★ 评级」是【评级】层，是你的判断，**不得伪装成事实**。
