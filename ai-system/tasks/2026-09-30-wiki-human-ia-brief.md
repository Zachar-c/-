# 人向 Wiki 导航重构 brief（2026-09-30）

## 目标

让**人**（你、访客、同人作者）能从入口看懂「这库有什么、按什么顺序读、我要找的东西在哪」。
AI 检索能力不回退；不删知识正文。

## 不做什么

- 不批量改写实体/事件正文事实
- 不建数据库、不上 GraphRAG
- 不把「结构优雅」本身当唯一目标——每条导航要能说出服务谁

## 受众与阅读路径（根入口必须显式给出）

| 路径 | 读者 | 顺序 |
|---|---|---|
| 五分钟看懂世界 | 普通访客 | 骨架 → 修炼/资质 → 五域 → 蛊虫循环 |
| 跟上方源一生 | 剧情读者 | 故事弧 → 人物总表 → 关键事件簇 |
| 写同人 | 创作者 | 人物动机/关系 → 时代背景 → 世界限制 → 禁止误读 |
| 查设定 | 研究者 | 规则索引 → canon → 证据回查 |
| 做《问真》 | 开发 | 规则/数值边界 → 游戏数据分界 |

## 各目录职责

| 目录 | 人类要能立刻回答 |
|---|---|
| `index.md` | 这是什么库、怎么用、我该点哪条路 |
| `events/` | 故事按什么发生；每页何时/谁/为何重要 |
| `characters/` | 人是谁、关系网、马甲归一、性格与动机 |
| `gu/` | 有哪些蛊、按流派/转数/用途怎么找 |
| `world/` | 世界怎么运转（体系、地域、经济、流派） |
| `rules/` | 成文规则/机制命题在哪 |
| `themes/` | 《人祖传》与主题冲突 |
| `web/` | 网站窗口如何浏览上述内容 |

## 页面头部约定（被触碰的索引/导航页）

```markdown
# 标题
> 一句话：这页给谁、解决什么。
## 怎么用本页
## …分组导航（带一句人话描述，不是裸链接表）
## 相关阅读路径
```

分组导航禁止只丢文件名；每条链接后用「——一句说明它讲什么」。

## 验收（人向）

1. 从根入口 3 次点击内能到任意大类代表页
2. 新访客能说出「先读什么」
3. 同人作者能指出「人物动机/时代/限制」入口
4. `lore/wiki/tools/check.ps1` 仍全绿
5. `node tools/docs-lint.mjs` FAIL 0
