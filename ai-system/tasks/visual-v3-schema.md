# v3 视觉语义取证 · 公共约定（所有子包共用）

> 上游：L1 视觉语义与设计自由度取证 v3 任务书。READ ONLY：只读原文与已有采集件，只写自己的产出文件。
> 目的：确定「原著真正稳定的视觉规律 / 哪些只是局部案例 / 《问真》哪里必须忠于原著 / 哪里有设计自由」。
> **不得提出最终画风、配色、UI、角色造型或美术方案。**

## 0 通用纪律（违反即返工）

1. **定向检索，不许随机开窗**。每个对象先定位（grep 关键词/蛊名/流派词 → 取命中行号），再读该行号 ±120 行取证。
2. **每条记录必须带原文证据**：行号 + ≤60 字短引。短引必须是**原文连续复制**（可 grep 命中）。
   行号统一写成 `行 12345：`（或简写 `L12345`），**不许把非连续的两段拼成一条引文**。
   ❌ 禁止把采集包的「转述」当引文写进「」；转述只能写成不带引号的转述句。
3. **原文没写就写「原文未提供」**。不许外推、不许用同类对象类比补全。
4. **边查边写**：每定位并读完一个对象，立即把该条追加到产出文件，再做下一个。禁止攒到最后一次性写。
5. **额度不足时**：先保已写条目的真实性与字段语义，配额可以让步；不足配额如实报 PARTIAL，不许凑数。
6. 不许把分析写成事实；归纳与判断必须显式标注【分析】。
7. **「」只放原文**。字段名、命题复述、自查表占位文字一律用直引号 `"…"`，不许用「」，
   否则会被机检误判为待核引文。（2026-09-20 按 v3-E1 实检结果补。）
8. **锚点写法**：行号统一 `行 12345：` 或 `L12345`，或紧邻引文写 `（12345）`。
   不许在引文后留裸数字（如 `」22166，`）；若确实要标区间，写成 `（124180–124186）`
   并保证**每条引文都落在该区间内**。（同上补。）

## 1 统一标签词汇（不许自创）

- 转数：`一转`…`九转`；原文没写 → `未标明`
- 流派：气道 / 力道 / 血道 / 魂道 / 智道 / 奴道 / 炼道 / 月道 / 星道 / 梦道 / 阵道 / 土道 / 炎道 / 冰道 / 风道 / 雷道 / 光道 / 时间（宙道）/ 空间（宇道）/ 人道 / 天道 / 其他 / 原文未标明
- 本体形态分类（可多选）：生物型 / 植物型 / 矿物型 / 器物型 / 人形拟人型 / 概念抽象型

## 2 CANON CONSTRAINT 三级（每个对象就地标注，F 包汇总）

| 级 | 判据 |
|---|---|
| **HARD** | 原著直接规定外观，改动会改变对象身份（明确的形状、材质、颜色且有剧情意义） |
| **SOFT** | 有描述，但不决定其本质，可以重新设计 |
| **OPEN** | 原著几乎没有视觉约束，可以自由创造 |

只回答「原著允许自由到什么程度」，**不评价该方向好坏**。
