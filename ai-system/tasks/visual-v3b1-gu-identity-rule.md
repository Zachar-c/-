## 0 本包要回答的问题

本包不回答"这只蛊好不好看"，只回答一件事：**原著给出的外形与功能 / 规则绑得有多紧**。
用途：判断《问真》重新设计这只蛊的外观时，会不会改变它的身份。这是给 L1 判设计自由度用的输入，不是设计结论。

## 2 判定口径（本包唯一标准，先读此节再看记录）

对应强度**三选一**，只依据"原著写出的外形"判，不做外推；原著没写外形者不入本包。

- **强对应**：外形与功能之间存在**可直接指认的同一性 / 模拟关系**，看到外形即可说出该蛊大致做什么。可指认关系限以下三种模式，判强时必须注明模式编号：
  - （S1）**材质 / 颜色同形**：外形的材质、颜色就是功能所改变 / 所防护的对象（铜皮蛊之铜色金属壳 ↔ 使皮肤泛黄硬化）。
  - （S2）**形态同类**：外形是功能作用对象或功能行为的同类形态（狼形乌云 ↔ 治狼躯；蟆形 ↔ 吞吐江河；吸血飞虫 ↔ 吸血）。
  - （S3）**部件 / 介质即通道**：本体的部件或本体所发之物，就是功能使用的介质（五角星光点 ↔ 发光照明；月牙 ↔ 月刃）。
- **弱对应**：外形与功能**没有 S1–S3 的可指认关系**，只在名号、典故或单一属性上留下可联想到功能的线索——可由名字猜到功能方向，但不能由外形直接指认（春秋蝉之蝉形、树叶翅、年轮纹理 ↔ 时光意象，但"逆转时光"无法由外形推出）。
- **无明显对应**：外形（含所属系列的共性形，如"形似臭虫""蚕形"这类通用虫形）与功能之间找不到可指认的呼应，也不能由外形联想到功能（通用虫形 ↔ 存储 / 提纯 / 提升修为等抽象增益）。

边界规则（避免两可）：
- 外形是通用虫形、功能是抽象增益 → 判 **无明显对应**，不因为名字里有线索而升级（名字线索归 **弱对应**，但前提是名号本身构成可辨识的典故或动作）。
- 外形与功能同属一个可指认的隐喻链（面具 ↔ 态度；缩小版自己 ↔ 靠自己；方圆 ↔ 规矩）→ 判 **强对应**。
- 一只蛊"本体无描写、只有用时之形"时，用"用时之形"判对应强度，但在该条内注明**外形证据来自用时之形**，并在 CANON CONSTRAINT 上按"本体无约束"处理（OPEN）。
- 一只蛊横跨两档时，按**最强的可指认关系**判，并在判据里写出另一档的理由（不写"无法判定"，除非确实缺证据，此时说明缺什么）。

## 3 记录

### 一转（7 只）

#### 1. 月光蛊
- 转数：一转。证据：L1492「都是一转的月光蛊，差别极其细微。」
- 流派：原文未标明（原文称其为古月一族标志蛊虫，L3602）。
- 外形：弯弯的月牙 / 蓝色月亮状，蓝水晶质感，小巧玲珑、晶莹剔透。
  证据：L1826「月光蛊静静地躺在方源的掌心中，就好像一个弯弯的蓝色月亮」；L1836「月光蛊就像是一片弯弯的月牙」；L1844「蓝水晶一样的月光蛊表面」。
- 功能：远程攻击蛊，催动后发出月刃杀敌。证据：L18636「现在的月芒蛊，只要催发出一记，往往就能收割掉五六只石猴的性命」（由其晋升形态月芒蛊述其攻击性）；使用演示 L3602「接下来就老夫就亲自演示，如何催动月光蛊进行攻击」。
- 代价：原文未提供（只有炼化耗真元的描写 L1840）。
- 喂养：吞食月兰花瓣，每天两顿、早晚各一顿、每顿两片。证据：L3812「月光蛊需要吞食月兰花瓣，每天两顿，早晚一顿，每顿两片花瓣。」
- 限制：攻击有固定射程（其路线说明见 L17154「月刃的攻击范围仍旧是十米远」）。
- 使用结果：月刃外放斩杀猎物（同功能条证据）。
- 对应强度：**强对应**（S3）【分析】。判据：本体的月牙形状与蓝水晶表面，就是其攻击手段"月刃"的形态与材质，外形即功能介质；不是靠名字联想。
- CANON CONSTRAINT：HARD（弯月蓝水晶为古月一族镇族标志级外观，改动即改变对象身份）。

#### 2. 酒虫
- 转数：一转。证据：L2404「它虽然是一转蛊虫，但是其价值，却比一些二转蛊虫还要珍贵。」
- 流派：原文未标明。
- 外形：体型如蚕宝宝，通体珍珠白光，胖胖的、外形可爱。证据：L2400「酒虫体型如蚕宝宝，通体散发着珍珠一样的白光，有点胖胖的，外形很可爱。」
- 功能：精炼真元。证据：L9698「酒虫只能精炼真元」；谱系说明 L60664「一转的酒虫。能提纯青铜真元一个小境界。」
- 代价：原文未提供。
- 喂养：饮酒。证据：L3812「酒虫呢，则需要饮酒。一坛青竹酒，能支撑它四天。」；L2402「它以酒水为食物，能够凌空飞行。」
- 限制：原文未提供（原文明示其价值低于黑白豕蛊，L9696）。
- 使用结果：提升真元品质（同功能条证据）。
- 对应强度：**弱对应**【分析】。判据：外形是通用蚕形（其它酒虫谱系共用），本身不提示"提纯真元"；可联想处只有名号"酒"与酿造 / 提纯的隐喻。不满足 S1–S3。
- CANON CONSTRAINT：SOFT（蚕形为酒虫谱系通用形，可重设计，但谱系连续性会被触及）。

#### 3. 小光蛊
- 转数：一转。证据：L103414「这都是一转的小光蛊。十分出名的光道辅助蛊虫。」
- 流派：光道。
- 外形：形状奇特、体型袖珍，只有指甲盖的一半大，像五角星，散发乳白色微光。证据：L103412「体型袖珍，只有指甲盖的一半大，像是五角星」；L103412「散发着乳白色的微光」。
- 功能：光道辅助，用于照明 / 驱散黑暗。证据：L103416「将地洞中的黑暗尽数驱散」。
- 代价 / 喂养 / 限制：原文未提供（另有增幅规则：L17148「一只小光蛊能增幅月刃一倍的攻击力」，且增幅不叠加）。
- 使用结果：照亮地洞（同功能条证据）。
- 对应强度：**强对应**（S3）【分析】。判据：本体就是发光体，所发之光即功能介质；形态（五角星 + 乳白微光）与"照明"可直接指认。
- CANON CONSTRAINT：SOFT（五角星光体具体但为辅助蛊，可重设计）。

#### 4. 白豕蛊
- 转数：一转。证据：L9980「白豕蛊和黑豕蛊齐名，都是一转中的珍稀蛊虫。」
- 流派：原文未标明（豕蛊系列，与花豕蛊 / 粉豕蛊 / 黑豕蛊同族，L9670）。
- 外形：体型圆润，能振翅飞行。证据：L9978「体型圆润的白豕蛊则振翅飞在上空，盘旋着。」
- 功能：改造蛊师身躯，从根本上增长气力（永久性，蛊死后力量仍留）。证据：L9688「黑、白豕蛊的能力，就是改造蛊师的身躯，从根本上增长蛊师的气力。」
- 代价：原文未提供（饲喂成本高，见喂养条）。
- 喂养：猪肉，食量大，每五天一顿、每顿一整头成年猪的肉。证据：L10066「白豕蛊的食物，是猪肉。」；L10070「每五天一顿，每顿都得要吃上一整头成年猪的肉。」
- 限制：原文未提供（同系列花豕蛊为临时增力并注明后遗症，白豕蛊为永久增益，L9692）。
- 使用结果：入体化光；催动时放白光罩身。证据：L10954「白豕蛊，立即化作一道乳白色的光，射入到野猪体内」；L10996「白豕蛊顿时绽放出炫目的白光，白光照耀着方源的身体」。
- 对应强度：**弱对应**【分析】。判据：名号"豕"与同系列规则（花豕蛊一猪之力、粉豕蛊增肥）把"猪"与"体魄 / 力量"挂上，但外形仅"体型圆润 + 振翅"这一通用虫形，不满足 S1–S3，不能由外形推出"增长气力"。
- CANON CONSTRAINT：SOFT（圆润振翅为豕蛊家族共性，可重设计）。

#### 5. 铜皮蛊
- 转数：未标明（原文只注明属铜 / 铁 / 石 / 玉 / 兽皮蛊系列，L9610）。
- 流派：原文未标明。

- 代价 / 喂养 / 限制：原文未提供。

- CANON CONSTRAINT：HARD（铜色金属光泽与外显的"浑身泛黄"绑定，改动即改变对象身份）。

### 4.2 结论【分析】

1. **总体：外形与功能不是"普遍强绑定"，但强对应仍是显著多数（22/32）**。原著在**材质型**（皮蛊系列、玉 / 石 / 铜）、**兽力型**（鳄力蛊、狼烟蛊、血滴子、吞江蟾）、**光与刃型**（月光蛊、小光蛊、月芒蛊、血月蛊、雷翼蛊）三类上，稳定地让外形直接充当功能的介质或作用对象；这三类的身份与外形绑定最紧。
2. **抽象增益类普遍脱钩**（无明显对应 2 只 + 弱对应中的大半）：提纯真元（酒虫、九眼酒虫）、提升修为（黄金舍利蛊）、存储 / 治疗等"不给外形留位置"的功能，原著只给通用虫形或不给形体。这类对象重设计外观不会改变其规则身份。
3. **《人祖传》概念蛊反而全部是强对应**（态度蛊之面具、规矩蛊之方圆网、自己蛊之缩微自身像）：概念越抽象，原著越倾向于用一个可佩戴 / 可展开 / 可见的"符号形体"承载它——这与"抽象功能不给外形"的凡蛊规律相反，是两类不同的命名—造型语法。
4. **名号提示 ≠ 外形提示**。弱对应的 8 只里，多数能由**名字**猜出功能方向（春秋蝉之"春秋"、千里地狼蛛之"地"、竹君子之"君子"），但由**外形**（蝉 / 黑蛛 / 竹节虫）指认不出关键功能。对设计自由度而言，两者应分开对待：名字可以保留，形体可换。
5. **对《问真》的直接含义（供 L1 用）**：重设计一只蛊的外观时，风险集中在强对应的 22 只——尤其是 S1（材质色）型（皮蛊系列、天蓬蛊、白玉蛊、血颅蛊、血月蛊）与概念符号型（人祖传三蛊）；弱对应与无明显对应的 10 只，外观可换而不动身份，但**名号与谱系关系（如酒虫—四味—七香—九眼、月—月芒—血月）仍需保留**才能保住身份（谱系连续性问题超出本包范围，需 L1 裁决）。
6. **本包不能回答的**：原著没写外形的蛊（血神子、化石蛊等）不在此列，此类对象的外观自由度**不低于**本包中的无明显对应类；以及"哪种外观更好看 / 更适合《问真》"——属设计决策，本包不涉及。
