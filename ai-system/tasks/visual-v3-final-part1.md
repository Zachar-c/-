## 第 1 节 已证实规律（8 条）

### 规律 1：蛊的本体形态不存在统一语法——同一转段内跨大类并存，且相当一部分本体原文根本不写

- **证据**：
  1. `visual-v3a1`（一至三转 22 只）**L103412**：「体型袖珍，只有指甲盖的一半大，像是五角星」（小光蛊，一转；五态判定为器物化）
  2. `visual-v3a1` **L9602**：「石皮蛊和铜皮蛊外形相似，只是身体灰扑扑的」（石皮蛊，一转；器物化）
  3. `visual-v3a1` **L2400**：「酒虫体型如蚕宝宝，通体散发着珍珠一样的白光」（酒虫，一转；生命化）——与第 1、2 条同为一转，三类并存
  4. `visual-v3a2`（四至五转 22 只）**L33606**：「水晶模样的头骨上」（血颅蛊，器物化）；**L84764**：「一团狼形的乌云悬浮着」（狼烟蛊，气烟形态）
  5. `visual-v3a3`（六至九转 25 只）**L13898**：「态度蛊外形就像是一张面具」（器物化）；**L142466**：「它形如蜘蛛，黑白两色」（宿命蛊，生命化）
- **计数（本文复核）**：A1+A2+A3 共 69 只。五态字段全部为 "原文未提供" 者 24 只（A1 5 / A2 8 / A3 11）。有判定者中：生命化=是 24、器物化=是 5、植物化=是 5、人形拟人=是 0、抽象概念化=是 1。
- **覆盖范围**：只管 "本体形态层面是否有一套统一语法"，答案是 "没有"。**不管**形态与规则的对应（见规律 2）、**不管**用时之形（见规律 8）、**不管**杀招/蛊阵/蛊屋/人物。

### 规律 2：外形与规则身份的绑定只集中在三类蛊上，抽象增益类普遍脱钩

- **证据**（`visual-v3b1`，32 只；本文复核：强对应 22 / 弱对应 8 / 无明显对应 2）：
  1. **L9596**：「通体都黄橙橙的，散发着铜一样的金属光泽。」（铜皮蛊，强对应；铜色即防御效果的外显）
  2. **L333188**：「舍利蛊是一种圆球状的凡蛊，只有拇指大小，外形普通毫不起眼。」（黄金舍利蛊，无明显对应；原文自述外形普通）
  3. **L60704**：「九眼酒虫如蚕宝宝，浑身洁白细腻，犹如珍珠。」（九眼酒虫，无明显对应；九眼是谱系转数标识而非功能提示）
  4. **L13898**：「态度蛊外形就像是一张面具」（态度蛊，强对应；抽象概念用可佩戴的符号形体承载）
- **覆盖范围**：只覆盖 B1 的 32 只取样。**不能外推**到 "原著没写外形的蛊"——那类对象的外观自由度不低于本包的 "无明显对应" 类。本条不涉及 "哪种外观更好"。

### 规律 3：炼蛊、杀招、蛊阵、蛊屋在原文里同属 "多蛊组合"，但四者的机制语义各不相同

- **证据**：
  1. `visual-v3c1` **L16910**：「合炼后的新蛊虫，常常只能留取一只蛊虫的能力」（合炼＝消耗性合成，输入不再独立存在）

  3. `visual-v3c1` **L88420**：「将多只蛊虫进行巧妙的搭配，在短时间内接连使用」（同行另句：这就是杀招；杀招组判 SUPPORTED，且如实列出 3 条反例）
  4. `visual-v3c2` **L104594**：「因此，从本质上而言，蛊屋是数种、十数种蛊虫相互集合的固化定型的杀招」

- **覆盖范围**：17 例炼蛊 ＋ 22 例杀招 ＋ 16 例蛊阵 ＋ 15 例蛊屋，共 70 例。不含战斗结算、数值与胜负判定。

### 规律 4：蛊屋与核心蛊不是 "同生共死"；原文给的关系是 "核心蛊存续决定屋能否重建 / 能否维持"

  1. `visual-v3c2` **L117378**：「只要保住那几只八转核心蛊虫，再给我充足的时间，我还能重建真阳楼！」

  4. `visual-v3c2` **L142470**：「监天塔乃是九转仙蛊屋，可惜第一核心宿命，遭到致命的创伤，濒于毁灭」（功能性绑定：核心修复后屋可恢复威能）

- **覆盖范围**：15 座屋中 4 座有 "屋—核心蛊" 关系记载（真阳楼、近水楼台、炼炉、监天塔），其余 8 座原文未提供（C2 §3 已登记）。本条只回答 "原文怎么写的"，不含设计结论。

### 2a L2 八条规律逐条判定

#### 规律一：视觉重心在 "物" 与 "代价"，不在 "能量特效"——**部分成立**

- 成立侧：一至七转 27 例中 21 例为具体形态（E1 判 SUPPORTED）；物质层证据（蛊阵、蛊屋、蛊本体、器物）在 C1/C2/A1–A3 大量存在。
- 不成立侧：**八至九转出现 "纯光 / 不可见 / 零形态" 群体**，E2 因此判 PARTIAL，而非 SUPPORTED。
- **反例行号**：L184240（「全是光。」）＋L184242（「白色的光。」）：九转监天塔——E1 与 E2 各自独立把它标为 "最强反例"；E2 F-2 众望所归（318200，只有白色光晕与气势）；E2 F-4 气墙（315446，无形墙壁）；E2 F-5 神不知（173416，全程不可见）。
- 【分析】该规律的可用表述是 "具体化是主体倾向，且层级越高越松动"，不能写成 "原著不做能量特效"。

#### 规律二：尺度是主轴，沿 "体内→聚落→亚世界→时间" 单向升级——**本轮证据不足以判定**

- 十个子包没有一个以 "尺度轴" 为取证单元。仅有的零散触点：A3 的仙蛊尺度表述全部以人体部位为参照（**L137394**：「此蛊形如白皮天牛。有半个手掌大小」）；E2-19 前有古人涉及光阴长河（358868 / 358872）；C2 的 B14 仙蛊屋以光阴长河为用途（**L301440**，该条原文作 "以宙道仙蛊为主"，详见 C2）。
- 缺口：没有 "体内（真元海 / 窍壁）→ 聚落 → 亚世界 → 时间" 的四级对照样本，也没有 "变强＝空间扩张" 的序列证据。
- **反例行号**：无——本轮既未取证到支持该轴的序列，也未取证到反驳它的案例，故不判成立也不判推翻。

#### 规律三：每个尺度自带 "天气"，越高层的危险越慢、越躲不掉——**本轮证据不足以判定（并有 1 条反向案例）**

- v3 无 "灰雾 / 灾劫 / 兽潮" 事件级取证。
- **反向案例**：**L126868**：「悄无声息地接近，如毒蛇出击，闪电般砸下」（E1-17，七转地劫所化的冰瀑神猿）——高位威胁被写成 "快而无声"，与 "越高层越慢" 方向相反。单例不足以推翻。
- 另注：v3 全库 "缓慢" 命中 4 处，全部与威胁无关（C2 L301446 仙蛊屋在河水中缓慢穿梭；E2 316420 八转仙蛊屋动作缓慢了数倍；E2 242900 逆流河河水缓慢增长）。

#### 规律四：生物设计的等级信号是 "拼合度"，不是 "体型"——**本轮证据不足以判定（并有反向线索）**

- 十个子包**零处**以 "拼合 / 部件" 为取证口径；规律四的关键证据 **L348780** 在 v3 全部产物中 0 命中（本文 grep 复核）。
- **反向线索**：A3 的 25 只中 14 只有本体描写，其中 8 只是单一虫形（蝉 / 兜虫 / 天牛 / 蝴蝶 / 蜻蜓 / 蜈蚣 / 蜜蜂 / 蜘蛛）、6 只非虫（蚕茧 / 气泡 / 水流 / 圆球 / 气运 / 面具），**0 例被原文写成 "多虫部件拼合体"**；E2 的高位杀招显形也多为单一兽形或器物形（炎龙、黑熊、白鹤、剪刀、扇）。
- 【分析】"未出现" 不等于 "被推翻"：A3 只覆盖六至九转 25 只，且选样条件是 "原文有转数明示"，不足以否证 v1 在未采样段落的孤例。
- **反例行号**：本条无单条反例行号可给（属 "L348780 未出现在 v3 任何产物" 的缺证），故只登记为 "不足以判定"。

#### 规律五：死亡不是终点，是 "有后续流程" 的状态——**本轮证据不足以判定**

- 仅 3 处边缘触点，且都属其它专题：A1 木魅蛊 **L21030**（「使得肌肉木化，最终变成一具树人尸体」）；E2-09 流言笼 **L313456**（「尸体化为一蓬蓬的银白琐碎的光芒，四下迸溅飞散」）；E2-26 井井有条 **L299290**（「一颗颗的魂核被方源抛到荡魂山去」，魂核作为可搬运材料，间接触及 "魂魄可开采"）。
- 缺口：无 "尸体陈列 / 魂魄拘拿 / 魂核开采" 的事件级取证。
- **反例行号**：无——同上，属缺证而非反例。

#### 规律六：光照＝审查（明亮不是美，是 "会被看见"）——**本轮证据不足以判定**

- v3 无相关取证单元。"灯火" 仅 C1 的 K21 七星灯（**L94476**：「七盏灯火功效各异」），是杀招组成而非照明机制。
- 最接近的是**遮蔽物**而非光照：墨瑶的黑纱条 **L120176**（「脸罩黑纱」）；铁血冷的青铜面具条 **L29554**（该条无短引，见第 1 节规律 7）。
- 缺口：v1 的行 324 / 82642（同一盏灯的庆典 / 暴露两义）未被 v3 任何一个包覆盖。
