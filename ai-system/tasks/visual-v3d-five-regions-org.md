# v3-D1 五域组织制度（25 个组织案例）

> 检索口径：定向检索原文。先以组织名/制度词 grep 定位行号，再读命中行原文取证，每条短引为原文连续复制且不超过 60 字，行号写法为 L 数字。原文没有写的字段一律写原文未提供。分析句以后缀【分析】显式标注。

## 0 检索口径与五域分布

- 检索线索：家族 / 族长 / 家老 / 太上长老 / 宗祠 / 門派（门派） / 部族 / 联盟 / 弟子 / 招收 / 长老 / 大殿 / 仪式 / 血脉 / 王庭 / 附庸。
- 五域分布：南疆 5（武家、商家、铁家、罗家、翼家）、北原 5（黑家、刘家、耶律家、东方一族、马家）、西漠 5（房家、万家、唐家、萧家、孙家）、东海 5（汤家、苏家、华家、青岳家、僵盟总部）、中洲 5（仙鹤门、灵缘斋、风云府、万龙坞、古魂门）。合计 25 条。
- 小域处理说明：太古两天、洞天福地等小域在原文中没有常驻凡人组织制度描写（仅为异人、荒兽、仙僵活动背景），无法取出符合 9 字段的组织案例，故未纳入；跨域组织由僵盟一條覆盖（总部在东海、四域各有分部）。
