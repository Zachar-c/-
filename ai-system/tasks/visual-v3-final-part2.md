### 4.1 南疆（家族制 + 山寨聚落）

01 组织形态：
- 家族是基本单位，家族内部以血缘亲情维系、族长之位由亲生儿女继承：L62304「家族中，以亲情维系，族人为栽培对象」；L38130「族长之位通常是由族长的亲生儿女继承」。
- 家族之上并称"超级家族"：L65740「翼家是和商家、武家、铁家并称的超级家族」。
- 家族内部权力是族长 + 太上家老的双层：L46572「商家族长有五转修为，却不是最高。商家还有太上家老」。
- 家族同时以山寨聚落形态出现：L31658「铁家山寨中矗立的镇魔塔，关押着无数魔道蛊师」。（子包：v3-D1）

02 人群构成：
- 聚落里凡人（农人、采药者、猎户）与蛊师同街混行、服饰一眼可分：L4950「还有一些则是蛊师。他们往往穿着一身蓝色武服，干练精悍」。
- 外部人员进入家族靠"认祖归宗"，以宗祠置放魂灯蛊、命牌蛊为标志：L227566「今后都要置放在武家的宗祠之中，算是方源正式认祖归宗的标志」。（子包：v3-D1 / v3-G1）

03 交易与交换：
- 商家城是南疆的贸易中心、元石流通：L40786「都知道南疆的商家是贸易的中心，商家城是如何的繁华似锦，遍地元石」。
- 翼家商队专走空路，是别家没有的运力：L65740「他们的飞天蓝鲸商队，专走空路，连商家都没有」。（子包：v3-D1）

04 权力展示：
- 执法体系有专属头衔"神捕"：L29584「他就是五转蛊师，执法天下，破案如神，追捕第一的南疆神捕铁血冷！」。
- 霸主地位以"盖压诸家"表述：L40490「因此武家乃南疆第一家族，盖压铁家、商家、飞家」。（原文此处作"飞家"，与 L65740 的"翼家"用字不同，本节照录。）
- 镇魔塔被定义为"正道巨头的象征"：L31658「关押着无数魔道蛊师，是正道巨头的象征」。
- 祭祀由族长与家老主持：L326「一身素白庄重的祭祀服装，跪在棕黄色的地板上」；L330「都是家族中的家老、话事人，执掌着各方面的权柄」。（子包：v3-D1 / v3-G1）

05 建筑：
- 宗族祠堂即凡蛊屋：L250476「坐落在武仪山上的宗族祠堂，是一座凡蛊屋」；山寨内另有镇魔塔（L31658，同上）。（子包：v3-D1）

06 服饰与器物：
- 山寨内部制服 + 腰带品级制，修为一眼可读：L4950「他们往往穿着一身蓝色武服」；L4952「一转蛊师就是青色腰带，正面是镶着铜片，铜片上有一个“一”字」；L4954「二转蛊师的腰带，是赤色的，正中央镶着铁片，上面刻着“二”字」。
- 家族成员的个人身份件（品级腰牌、面具）：L29582「他戴着青铜面具，腰带上紫晶方片上，刻着一个字——“五”」；L29566「此人腰带却镶着一面银片，银片上刻着“三”字」。（子包：v3-G1）

07 语言与称谓：
- 族内称谓"族长 / 家老 / 太上家老"（L46572、L330，同上）；执法头衔"神捕"（L29584，同上）。
- 方言 / 口音句：本批材料内未见南疆方言句（对照 4.2 北原的 L78948）。

### 4.2 北原（家族 / 部族双轨 + 王庭共主）

01 组织形态：
- 家族与部族两称并存：L79038「各部联合起来推翻黑家部族的统治，重新角逐王庭之位」；L89956「我们马家成为大型部族，很不容易」。
- 存在王庭共主轮替机制，"入主王庭"是部族的顶层目标：L79032「最后由黑家族长黑楼兰成功问鼎，成为王庭十年之主」；L89956「那就只有入主王庭！」。（子包：v3-D1）

02 人群构成：
- 巨阳血脉部族统称"黄金家族"：L101436「体内流着巨阳仙尊血脉的蛊师部族，被统称为黄金家族」。
- 北原有人类之外的异人（石人、蛋人、毛民、墨人）：L91592「石人、蛋人、毛民、墨人，皆不是人祖后代，而是异人」。
- 部族内有奴隶身份：L81630「也不知道马鸿运现在，有没有成为马家的奴隶」。（子包：v3-D1 / v3-G1）

03 交易与交换：
- 本批材料内未见北原专属的交易 / 交换制度句。与资源相关的材料只到"部族扩张吞并"层面：L81630「为了争夺王庭，这些年积极扩张，吞并了不少部族」。【分析】本节不以其它域的商队 / 贸易中心材料代填。

04 权力展示：
- 王庭之争以"猛将 / 精兵统帅"标定实力：L91896「正是此次王庭之争的北原第一猛将——墨狮狂」；L94004「东方射乃是东方一族的羽箭精兵的统帅，有四转高阶的修为」（此句出自 v3-D1 组织条目）。
- 黄金血脉是政治资本，连续未入主王庭会被公开议论：L94658「耶律家虽然是黄金血脉，北原有数的超级家族之一」。（子包：v3-D1 / v3-G1）

05 建筑：
- 本批材料内未见北原建筑形制的直接描写；与空间相关的只有僵盟的"仙僵墓地"：L169200「非要在我北原僵盟最重要的仙僵墓地里面」。【分析】"王庭"在材料中是制度名（L79032），无建筑句。

06 服饰与器物：
- 北原有成文的地域服饰共性：L78898「少女穿着北原特有的皮袍，长袖的袍子蓝白相间，边角处绣着金边」。
- 北原衣袍带金银玉石雕缀：L96412「美貌的少女穿着北原的衣袍，带着金银玉石的琳琅雕缀」。
- 北原有"特有的肤色"表述：L78904「她的皮肤微黑，又透出红晕，是北原特有的肤色」。（子包：v3-G1）

07 语言与称谓：
- 口音被点名为地域标识：L78948「你骗人！咱们北原哪有你这样的口音」。
- 政治称谓"王庭 / 草原之主"：L79032「成为王庭十年之主。也是后世最饱受争议的草原之主」。（子包：v3-D1 / v3-G1）

### 4.3 西漠（十四家并立）

01 组织形态：
- 超级势力为十四家并立：L431090「西漠超级势力共有十四家，分别是：习家、萧家、田家、房家、董家」（同句续列万家、孙家、莫家、唐家、秦家、石家、弓家、左丘家、拓跋家）。（子包：v3-D1）

02 人群构成：
- 超级势力之外存在可被随手处置的散修：L281366「若是寻常散修，我杀了了账」。（子包：v3-D1）

03 交易与交换：
- 资源点可以被买卖：L431318「房家将这资源点卖了，真的好狠呐」。
- 势力之间用游说 / 联盟重组关系：L433772「西漠的超级势力仍旧愿意答应房家，组建讨房联盟呢」。原文对"讨房联盟"的发起方用字不一致——L431318 作"万家…组建讨房联盟"，L433772 作"答应房家，组建讨房联盟"；本节照录，不做取舍，留 L2 复核。（子包：v3-D1）

04 权力展示：
- 权力由"太上"层出面表态与游说：L430268「孙家太上大家老如此言语，也不奇怪」；L281366「房家的太上二长老房睇长，可是西漠有名的智道贤能」。（子包：v3-D1）

05 建筑：
- 无城郭描写；蛊屋是西漠的标志物：L281994「房家本身就以蛊屋闻名于世」；L281992「线索中提到的那座仙蛊屋豆神宫，更是元莲仙尊所创，留在西漠之物」；L152124「萧家拥有仙蛊屋万里丝廊」。（子包：v3-D1）

06 服饰与器物：
- 本批材料内只有个体描写（见下），没有"西漠特有"的服饰 / 肤色句（对照 4.2 北原 L78898 / L78904）：L432510「万古愁一身白衣，满头银发，老态龙钟的模样」。（子包：v3-G1）

07 语言与称谓：
- 称谓层为"太上二长老 / 太上大长老 / 太上大家老"：L281366「房家的太上二长老房睇长」；L430268「孙家太上大家老」（同上）。（子包：v3-D1）

### 4.4 东海（家族 + 跨域联盟总部）

01 组织形态：
- 家族为基本单位，且以中洲门派作地位标尺：L192916「汤家是东海的超级势力，地位相当于中洲的十大古派之一」；L192928「汤家虽然在东海堪称霸主，但和它不对付的，还有沈家、苏家」。
- 跨五域联盟"僵盟"总部在东海，其余四域各一分部：L121688「东海是总部，北原、中洲、南疆、西漠则各有一个分部」；总部强于本土势力：L121694「但东海的僵盟总部，却要超过东海的超级势力一筹」。（子包：v3-D1）

02 人群构成：
- 蛊仙群体按榜单式称号分布（美人榜、强者榜）：L162608「年轻貌美的宋亦诗，是东海蛊仙中的六大美人之一」；L164138「说的就是东海公认的智道三大强者」。
- 僵盟成员以仙僵之躯出现、有自创体型：L161402「光头上带着一个铜箍，一对瞳仁冰蓝。浑身皮肤如老树」。（子包：v3-G1）

03 交易与交换：
- 僵盟资产可租借，账目以"贡献分值"结算：L149162「耗费不菲的代价从僵盟中租借来了玄冰屋」；L149208「回到僵盟，就得支付一大笔的贡献分值！」。（子包：v3-D1 / v3-C2）

04 权力展示：
- 除榜单称号外，家族名誉可作正式担保：L192914「我以汤家名誉保证」；L164138 / L162608（同上）。（子包：v3-D1 / v3-G1）

05 建筑：
- 本批材料内未见东海城郭 / 驻地的建筑描写。现有唯一与"场所"相关的实体是作为租赁资产的可移动仙蛊屋（玄冰屋）：L149164「只见这屋体积不大，宛若一个圆球，外表好似用厚重的冰砖堆砌」；L149182「东海平静的海面上，忽然冲出一颗巨大的冰寒流星」。【分析】东海建筑面在本批材料中缺失，不与其它域材料混用。（子包：v3-C2）

06 服饰与器物：
- 个体服饰差异大，且可用颜色 / 材质一眼区分阵营：L164138「是一位身穿金袍的男子，身躯肥胖，宛若富家翁」；L180650「身着白衣，仙光似雪，冰清玉洁」；L161402（同上，僵体特征为铜箍 / 冰蓝瞳 / 鱼蹼）。（子包：v3-G1）

07 语言与称谓：
- 家族权力层称"太上大长老"、以血裔定义身份：L278516「乃是东海超级势力青岳家的蛊仙」；同句「当今青岳太上大长老青岳安的嫡亲血裔」。担保类表态以家族名誉起句（L192914，同上）。（子包：v3-D1 / v3-G1）

### 4.5 中洲（门派制）

01 组织形态：
- 门派以师徒关系取代血脉亲情、广收门徒：L62304「但在门派里，师徒关系取代血脉亲情。门派广收门徒，只要有资质，有品性，就可收录门内」。
- 十大古派为核，大派之下还有附庸小派层：L121840「仙鹤门乃中洲十大古派之一，势力之强。还要胜过北原的超级部族」；L128774「钧天剑派附庸我仙鹤门，已经近千年历史」；L150724「当代五德门门主乃是天莲派的长老」。（子包：v3-D1）

02 人群构成：
- 弟子 / 精英弟子是基本身份，入门靠考试选拔：L62296「方正成为八年中考的第一名，击败孙元化，成为仙鹤门的精英弟子」。
- 凡人层持续向门派供给天才：L129992「凡人中不凡天才、鬼才、怪才不断涌出」。（子包：v3-D1 / v3-G1）

03 交易与交换：
- 附庸向宗主定期交纳资源：L128782「本身就是仙鹤门的附庸，每隔一段时间都需要向上交纳大量的资源」。（子包：v3-D1）

04 权力展示：
- 核心资源（寿蛊等）由掌门与太上长老掌管：L36742「一直牢牢掌管在掌门和几位太上长老的手中」。
- 门规可以废修为、逐出门派：L152240「因为违背了门规，被废去修为。逐出门派」。（子包：v3-D1）

05 建筑：
- 山门可悬空、驻地可压深渊，另有"辖区 / 版图"领土语汇：L62122「飞鹤山雄壮而又飞逸，悬空在玄白云海之中」；L381584「古魂门的驻地之下，有一座巨大的地下深渊」；L128774「我派对西北的掌控力就要大减」。（子包：v3-D1）

06 服饰与器物：
- 本批材料内只有个体标志装，没有"中洲特有"的服饰句（对照 4.2 北原 L78898）：L36712「他此刻身着白袍，系着黑腰带，大袖翩翩」；L68052「她头戴凤冠，丹凤眼，金眉修长入鬓，眉心一点红痣」。（子包：v3-G1）

07 语言与称谓：
- 称谓层为"掌门 / 太上长老 / 门主 / 弟子"：L36742、L150724、L62296（同上）。（子包：v3-D1）

### 4.6 两域对照（说清"A 有而 B 没有"）

- C1 门派 vs 家族（中洲有，南疆材料没有）：中洲把"师徒取代血脉 + 广收门徒"写成并列对比句（L62304）；南疆材料只有"家族中，以亲情维系"（L62304 前半句）与"族长之位通常是由族长的亲生儿女继承"（L38130），没有门派准入句。
- C2 王庭共主轮替（北原独有）：北原有王庭问鼎与轮替（L79032、L79038）；南疆 / 西漠 / 东海 / 中洲材料内没有"王庭"层级的权力机制句。
- C3 专职商队与贸易中心（南疆有）：南疆有"贸易的中心"（L40786）与"专走空路"的商队（L65740）；北原 / 西漠 / 东海材料内没有同类的专职商队分工句（西漠的交换证据是资源点买卖，见 4.3）。

## 第 7 节 仍无法回答的问题（9 条）

1. **五域是否存在"域级"视觉规则（服饰 / 肤色 / 建筑按域区分的成文约束）？**
   为什么答不了：现有材料只有散点——北原"特有皮袍 / 特有肤色 / 口音"（L78898、L78904、L78948）、南疆山寨内部制服一套（L4950–L4954）、其余域只有个人标志装或个体描写；没有任何一处原文把"某域视觉特征"作为制度性规则写出。
   要答它需要采：五域同口径平行提取（每域 ≥10 个对象：人物 + 聚落 + 器物统一字段），或对"×域特有"句式做全文穷举。

2. **凡人 / 市井层的视觉证据够不够用于判自由度？**
   为什么答不了：v3-G1 的 32 人里凡人只有 3 位（商心慈、沈翠、赵怜云），且都在各自出处场景；街市 / 民居 / 店铺的系统描写本批材料基本没有（南疆只到"街道上归家的人群"一类一句，L4950）。
   要答它需要采：凡人衣食住行专项（街市、民居、劳作场景）。

3. **建筑与室内空间证据够不够？**
   为什么答不了：v3-C2 的 15 例蛊屋中只有 5 例写了内部空间（B1 水晶走廊 L102612、B3 三层树屋 L104578、B6 圆珠内含小兽 L127412、B8 广场大殿十六石像 L122294、B10 巨型球形空间 L149168）；五域建筑证据是点状的（宗祠 L250476、飞鹤山 L62122、古魂门深渊 L381584），没有城市 / 街区 / 室内的成组描写。
   要答它需要采：建筑与室内专项（按域与按建筑类型分层）。

4. **蛊与宿主的"寄居 / 印记"是否通用规则？**
   为什么答不了：材料里已有多例掌心印记 / 纹身式寄居（血月蛊 L27302「化为一个红色的月牙印记」、雷翼蛊 L27304「如同两道闪电纹身」等），但没有任何一包对全文"印记 / 纹身 / 寄居"做过穷举，无法判断这是普遍机制还是部分样本。
   要答它需要采：全文检索"印记 / 纹身 / 寄居 / 空窍"做全量计数与例外清点。

5. **蛊阵与蛊屋的边界判据是否唯一（可移动性）？**
   为什么答不了：原文判据句只有一条（L266044"可以移动的仙道蛊阵"），而样本的可移动性呈梯度：不可移动（L158580）、阵旗蛊收纳（L265538）、随荒兽移动（L163790）、种子回收（L104578）、可取出携带（L149164）。
   要答它需要采：把 v3-C2 的 A / B 两组按统一字段重排（可移动 / 可收纳 / 有无核心蛊 / 是否需人主持），判断边界是否由单一判据决定。

6. **非战斗场景中的阵 / 屋有没有外观约束？**
   为什么答不了：材料里的阵 / 屋多数以战斗或防御场景出现；非战斗用途有功能句（当仙窍栽种 L170252、处理仙材 L159672、炼化他蛊 L159644），但"不在战斗时它们摆在哪里、什么样"的描写只剩零星。
   要答它需要采：居住 / 生产 / 经营场景中的阵与屋专项。

7. **五域之外的"小域"（太古两天、洞天福地等）要不要纳入自由度判定？**
   为什么答不了：v3-D1 明确这些小域没有常驻凡人组织制度描写、未予采集；其余包也没有覆盖。
   要答它需要采：先由 L1 明确是否涉及域外场景；若涉及，另开小域子包（组织、人群、器物）。

8. **是否存在"时代"维度？**
   为什么答不了：原著时间跨度大（含《人祖传》段与五域乱战前后），但所有子包按对象选样、跨全书混采，没有一个包按叙事时代分层；同域不同时代的差异无法从现有材料判断。
   要答它需要采：把现有行号案例按叙事时代重排（材料已在手，属重组而非新采），必要时补时代专项。

9. **现有"有描写 / 无描写"比例能否外推为全书的自由度分布？**
   为什么答不了：A 包的选样口径是"转数明示 + 至少一条形态描写，缺一即弃"，G 包是"至少两项有原文着落"；因此各包给出的"本体无描写"数字只在其配额口径内成立，不能回答"原著对全部对象的外观约束率"。
   要答它需要采：一次分层抽样普查（按对象类别随机抽，统一只记"有 / 无直接描写"），并把结果与现有配额口径样本分开列。
