### 2a L2 八条规律逐条判定

#### 规律一：视觉重心在 "物" 与 "代价"，不在 "能量特效"——**部分成立**

- 成立侧：一至七转 27 例中 21 例为具体形态（E1 判 SUPPORTED）；物质层证据（蛊阵、蛊屋、蛊本体、器物）在 C1/C2/A1–A3 大量存在。
- 不成立侧：**八至九转出现 "纯光 / 不可见 / 零形态" 群体**，E2 因此判 PARTIAL，而非 SUPPORTED。
- **反例行号**：L184240（「全是光。」）＋L184242（「白色的光。」）：九转监天塔——E1 与 E2 各自独立把它标为 "最强反例"；E2 F-2 众望所归（318200，只有白色光晕与气势）；E2 F-4 气墙（315446，无形墙壁）；E2 F-5 神不知（173416，全程不可见）。

## 第 3 节 《视觉设计自由度矩阵》

**口径**：只回答"原著允许自由到什么程度"，**不评价该方向好不好、不给方案**。
三级判据（每个对象由取证 Worker 就地判定，L2 汇总）：
- **HARD** = 原著直接规定外观，改动会改变对象身份（明确形状/材质/颜色且有剧情或制度意义）
- **SOFT** = 有描述，但不决定其本质，可以重新设计
- **OPEN** = 原著几乎没有视觉约束，可以自由创造

**计数口径**：只统计每个子包里的 `- CANON CONSTRAINT：` **字段行**（即每个被取证对象恰好一票），
不统计正文里的等级提及。计数由 L2 独立脚本重跑，不采信子包自查表。

### 3.2 自由度的边界说明（三条）

1. **HARD 的共性 = "身份即外观"的三类**：① 镇族/标志级蛊（月光蛊的弯月+蓝水晶）；
   ② 配方产物（炼蛊与杀招，材料与形态绑定，C1 的 HARD 占比 30/39 是全批最高）；
   ③ 已被原文写成"无形质/化光"者（鸿运齐天蛊的无形无质本身是规定，不是留白）。
   → 凡改动会让读者认不出"这是哪一只"，就是 HARD。
2. **SOFT 的共性 = 只给了功能或单一特征**：绝大多数蛊给了"虫形 + 一个可辨特征"（如蚕形白光、
   灰扑扑如石制品），特征可换、功能不能换。四至五转段尤其明显（10 SOFT / 8 OPEN）。
3. **OPEN 的共性 = 制度与关系类**：五域组织（D1 有 17/25 判 OPEN）与蛊阵外形（C2 12/31）几乎无视觉约束——
   原著写的是**谁和谁有什么关系**，不是**长什么样**。这一块是设计自由度最大的区域。

### 3.3 一条使用提醒

矩阵的 HARD 不等于"必须照做"，只等于"改了会改变对象身份"，L1 可据此决定哪些身份必须保留。
矩阵的 OPEN 也不等于"随便做"，只等于"原著没给约束"——**约束的来源可能需要另定**（那属 L1 的裁决范围，本件不做）。

## 第 7 节 仍无法回答的问题（9 条）

1. **五域是否存在"域级"视觉规则（服饰 / 肤色 / 建筑按域区分的成文约束）？**
   为什么答不了：现有材料只有散点——北原"特有皮袍 / 特有肤色 / 口音"（L78898、L78904、L78948）、南疆山寨内部制服一套（L4950–L4954）、其余域只有个人标志装或个体描写；没有任何一处原文把"某域视觉特征"作为制度性规则写出。
   要答它需要采：五域同口径平行提取（每域 ≥10 个对象：人物 + 聚落 + 器物统一字段），或对"×域特有"句式做全文穷举。

2. **凡人 / 市井层的视觉证据够不够用于判自由度？**
   为什么答不了：v3-G1 的 32 人里凡人只有 3 位（商心慈、沈翠、赵怜云），且都在各自出处场景；街市 / 民居 / 店铺的系统描写本批材料基本没有（南疆只到"街道上归家的人群"一类一句，L4950）。
   要答它需要采：凡人衣食住行专项（街市、民居、劳作场景）。

3. **建筑与室内空间证据够不够？**
   为什么答不了：v3-C2 的 15 例蛊屋中只有 5 例写了内部空间（B1 水晶走廊 L102612、B3 三层树屋 L104578、B6 圆珠内含小兽 L127412、B8 广场大殿十六石像 L122294、B10 巨型球形空间 L149168）；五域建筑证据是点状的（宗祠 L250476、飞鹤山 L62122、古魂门深渊 L381584），没有城市 / 街区 / 室内的成组描写。
   要答它需要采：建筑与室内专项（按域与按建筑类型分层）。

4. **蛊与宿主的"寄居 / 印记"是否通用规则？**
   为什么答不了：材料里已有多例掌心印记 / 纹身式寄居（血月蛊 L27302「化为一个红色的月牙印记」、雷翼蛊 L27304「如同两道闪电纹身」等），但没有任何一包对全文"印记 / 纹身 / 寄居"做过穷举，无法判断这是普遍机制还是部分样本。
   要答它需要采：全文检索"印记 / 纹身 / 寄居 / 空窍"做全量计数与例外清点。

5. **蛊阵与蛊屋的边界判据是否唯一（可移动性）？**
   为什么答不了：原文判据句只有一条（L（266044）「可以移动的仙道蛊阵」），而样本的可移动性呈梯度：不可移动（L158580）、阵旗蛊收纳（L265538）、随荒兽移动（L163790）、种子回收（L104578）、可取出携带（L149164）。
   要答它需要采：把 v3-C2 的 A / B 两组按统一字段重排（可移动 / 可收纳 / 有无核心蛊 / 是否需人主持），判断边界是否由单一判据决定。

6. **非战斗场景中的阵 / 屋有没有外观约束？**
   为什么答不了：材料里的阵 / 屋多数以战斗或防御场景出现；非战斗用途有功能句（当仙窍栽种 L170252、处理仙材 L159672、炼化他蛊 L159644），但"不在战斗时它们摆在哪里、什么样"的描写只剩零星。
   要答它需要采：居住 / 生产 / 经营场景中的阵与屋专项。

7. **五域之外的"小域"（太古两天、洞天福地等）要不要纳入自由度判定？**
   为什么答不了：v3-D1 明确这些小域没有常驻凡人组织制度描写、未予采集；其余包也没有覆盖。
   要答它需要采：先由 L1 明确是否涉及域外场景；若涉及，另开小域子包（组织、人群、器物）。

8. **是否存在"时代"维度？**
   为什么答不了：原著时间跨度大（含《人祖传》段与五域乱战前后），但所有子包按对象选样、跨全书混采，没有一个包按叙事时代分层；同域不同时代的差异无法从现有材料判断。
   要答它需要采：把现有行号案例按叙事时代重排（材料已在手，属重组而非新采），必要时补时代专项。

9. **现有"有描写 / 无描写"比例能否外推为全书的自由度分布？**
   为什么答不了：A 包的选样口径是"转数明示 + 至少一条形态描写，缺一即弃"，G 包是"至少两项有原文着落"；因此各包给出的"本体无描写"数字只在其配额口径内成立，不能回答"原著对全部对象的外观约束率"。
   要答它需要采：一次分层抽样普查（按对象类别随机抽，统一只记"有 / 无直接描写"），并把结果与现有配额口径样本分开列。
