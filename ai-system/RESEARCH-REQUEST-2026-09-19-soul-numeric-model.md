## 1. 你被要求做什么

给「魂」这条成长轴做**数值模型的顶层设计**——即回答「这套体系长什么样」，
而不是「某个数字该改成多少」。具体是：

1. 定骨架：魂（魂魄底蕴）在我们的游戏里以什么形态存在，玩家怎么增长它、怎么消耗它、它拦住什么
2. 定换算：原著的数量级（百人魂 → 亿人魂）与我们当前的数值标度如何建立对应
3. 定妥协：原著里哪些机制**必须改造**才能做成游戏，改造的原则是什么
4. 判取舍：原著中若干「看似是设计」的表述，哪些该保留为硬约束、哪些该弱化

**不要**输出逐项数值表。我们要的是骨架与原则；具体数字由我们在骨架下派生。

## 2. 产品意图（L0 已裁定，是前提而非议题）

魂 = **可成长的成长轴（Build Axis）**，对应**魂道玩法**，同时承担四重身份：

1. 魂魄生存值
2. 魂道能力资源
3. 魂道攻击 / 防御基础
4. 长期成长属性

**明确撤回**的产品方向（旧口径）：魂 = 生命周期风险资源、上限保留 4、起始魂量作为主要难度旋钮。

**L0 明令禁止的四条**（设计不得违反）：

1. 不得直接删除高魂档位的行动点收益
2. 不得再以「魂上限 = 4」为前提调难度
3. 不得把「起始魂量」定为主要难度旋钮
4. 不得只把魂当作第三条死亡条

**L0 已确认的一条设计口径**：魂与肉身 / 真元 / 资质 / 修为**共用同一份资源池**（元石等）。
「2000 元石买了提升魂魄底蕴，就买不起提升修为和肉身的蛊虫」——**这是设计意图，不是缺陷**。

## 3. 原文的魂道体系（`[原文]`，已逐条取证）

### 3.1 定义

- **魂魄底蕴 = 魂道的修为**，是一个**可比较、可增长的量**。
  `[原文]` 幽魂现身段以「远超亿人魂」来衡量魂魄底蕴（185618 行）。
- 原文把「魂道的极致」定义为**魂魄由虚返实、干涉物质、凝如肉身**（185618 行）。

### 3.2 量级阶梯

`[原文]` 幽魂真传中把魂魄底蕴**详细划分了许多层次**，从低到高：

> 一人魂、十人魂、百人魂……百万人魂、千万人魂、亿人魂……（273660 行）

- `[原文]` 「十人魂」的含义是**魂魄底蕴相当于十个成年人的总和**（273662 行）。
  → 即这是一条**以「人」为基准单位的量纲**，不是抽象点数。
- `[原文]` 原文另有多处更高档表述：十万人魂 3 次、百万人魂、千万人魂、三千万人魂 10 次、
  九千万人魂 6 次、亿人魂 46 次；再往上还有一档叫**荒魂**。
- `[原文]` 「万人魂也绝不是终点，上面还有亿人魂等等」（81944 行）。
- `[原文]` 方源本人的达成记录：**百万人魂**（273656 行）。

### 3.3 一条硬约束（**这条最重要，请重点判断**）

`[原文]` **常人的魂魄上限是一百倍（百人魂），这是生死极限**：

> 常人只能将魂魄提升到一百倍，俗称百人魂！这也是生死极限。若令魂魄壮大一丝，
> 整个魂魄就会砰的一声，发生爆炸。就好像是吃撑了把肚子涨破一样。
> 但魂魄爆炸，比肚子涨破要严重无数倍。魂魄彻底消散，顷刻毁灭。（78230–78236 行）

即：**壮魂有致死风险，且原文明确「多一丝就爆」**。

### 3.4 三要素

`[原文]` 魂道修行有**三要素**，与智道的「念意情」并列：

> 智道修行三要素有念意情，魂道修行也有三要素，分别是壮魂、炼魂、安魂。（332472 行）

- `[原文]` 三者的极致手段：**前两者的世间极致就是荡魂山、落魄谷；安魂首选迷魂湖中的安魂汤**
  （332474 行）。安魂汤同样记载于《人祖传》。
- `[原文]` 缺安魂手段的后果：魂魄修到一定程度会**与肉身脱离**，造成魂不守舍、魂不附体的修行事故
  （332476 行）；有安魂汤则修行效率「更快更恐怖」（332470 行）。
- `[原文]` **壮魂管数量、炼魂管质量**：

  > 魂魄光是壮大，只是数量上的优势。还得精炼凝结，才是质量上的优势。（78240 行）

- `[原文]` 两者须配合：「落魄谷炼魂去杂质如锻铁成钢，荡魂山胆识蛊令魂魄数量节节攀高，
  质变与量变相互结合则底蕴一日千里」（182802–182808 行）。

> 必是一场万劫不复的灾难。（76090 行）

### 3.6 巅峰与极致

- `[原文]` 魂道的开辟者是**幽魂魔尊**，九转蛊仙，横霸一个时代（78246 行）；「开创魂道，
> 是玩弄魂魄的大行家」（110686 行）。
- `[原文]` 其魂魄「**绝对超越了亿人魂**」，形象为「**千臂千手，三个头颅**」，
  三颗头颅各有异相（龙角狮鬃蛇瞳象牙 / 桃额草发三眼如花 / 云鬓电眼火耳金口）（81948 行）。
- `[原文]` 「魂道的极致」=「魂魄由虚返实，干涉物质，凝如肉身，强大得不可思议」（185618 行）。

### 3.7 跨流派价值（这是「抢资源」的原文依据）

- `[原文]` 「事实上，**不仅仅是魂道蛊师需要，奴道、炼道等相关流派，也需要魂魄的底蕴**。
  蛊师升仙，魂魄也是人气是否浓郁的重要因素，谁也不会嫌自己的魂魄太强。」（130436 行）
- `[原文]` **奴道从魂道衍生**：「奴道最初就是从魂道方面衍生的分支，后来蛊师们结合了太古智道，
  令奴道真正的独立出来。驭兽蛊、奴隶蛊，就是对魂魄上的控制，针对心智的主宰。」（81830–81834 行）
  ——即原文里魂道是**上游流派**，不是并列的小分支。
- `[原文]` 另有多处把魂魄底蕴与「升仙」挂钩（如「提升底蕴，虽然困难，但并非毫无办法」134242 行）。

### 3.8 经济与稀有度

- `[原文]` **狼魂蛊**：三转，一只**七千七百枚元石**（81838 行）——这是原文中少数明确的魂道蛊市价，
  也是我们目前唯一可用的魂道定价锚点。方源「大采购，一下子扫空了店家的存货，将八只都买下」。
- `[原文]` 胆识蛊曾经是方源的**垄断暴利生意**，「幽魂魔尊都推崇的宝物，壮魂的效率极高，
  是普通手段的十多倍」（130436 附近）；他因怕提价促使别人回去用旧手段而**主动不胡乱提价**。

### 3.9 原文的已知空缺（我们没能取到证据的部分）

- 魂道与其他流派的**克制关系表述极少且单向**，我们没能取到系统的克制表。
- 「凝魂」的**具体操作方式**（仪式？催动？吞服？）原文未展开到可复现的程度。
- 安魂 / 炼魂的**时间成本与消耗**原文没有给出可比的量化。
- `[L2判断]` 原文对魂道的描写**远多于数值**：它给的是一套有风险、有质变/量变、有圣地与蛊虫层级的
  修行体系，而不是一张数值表。

## 4. 游戏现状（`[游戏]` / `[实测]`）

### 4.1 魂目前有两套互不相通的实现

| | A 套（在用） | B 套（有引擎、无玩法） |
|---|---|---|
| 字段 | `soul` 当前值 / `soul_max` 上限 | `soul_magnitude` / `soul_safe_capacity` / `soul_calm` / `soul_nature` / `beast_nature` |
| 初值 | `soul` = **1**，`soul_max` = **4** | magnitude 1.0 / safe_capacity 4.0 / calm 60 / nature "human" |
| 上限性质 | **硬顶**，全代码库**零写入路径**（无任何机制能提高 `soul_max`） | **软顶**，允许超载可视化；致死线为容量的 2.0 倍 |
| 成长操作 | **无** | 有（strengthen / refine / calm 三个函数） |
| 玩法接线 | **有**：行动点、多线作战上限、战斗结算、死亡判定、商店、黑市、事件、界面 | **零**：只被界面快照读取，加一个 `absorb_soul` 命令写入 |
| 调参入口 | 无 | 有（5 个常量） |

`[游戏]` 两套代码里都有注释声明**永不互通**。另有第三个残留键 `soul_control_limit` = 2，已无消费者。

### 4.2 行动点档位（原文门槛的落地处）

`[游戏]` 当前生效表：魂值 **0–9 → 2 点**，**10–99 → 3 点**，**100–999 → 4 点**，
**1000–9999 → 5 点**，**≥10000 → 6 点**。每回合行动数即由此决定。

`[L2判断]` 这张表的 100 / 1000 / 10000 三个阈值，与原文的
**百人魂 / 千人魂 / 万人魂** 一一对应——L0 已确认为原始设计意图。但**游戏当前的魂上限是 4**，
即玩家**永远只能停在第一档（2 点）**，上面四档全部不可达。这是当前最大的结构断裂。

### 4.3 魂的收支清单（全部现存路径）

**增长（只有 2 条，且都被上限 4 截断）**

- `[游戏]` 商店魂丹：**6 元石 → 魂 +1**
- `[游戏]` 黑市：**20 寿元 → 魂 +1**；**20 气血 → 魂 +1**
- `[游戏]` 事件中**没有任何**加魂的条目（0 条）

**消耗**

- `[游戏]` 炼蛊配方：全表 468 条配方里**只有 1 条**会扣魂（某个自由配方的爆炸分支，扣 1）
- `[游戏]` 事件延迟代价：**6 条**事件会挂账扣魂（数额 1 或 2），在出行时结算
- `[游戏]` 黑市反向：魂 → 寿元 / 气血

**敌方攻击魂**

- `[游戏]` **只有 1 个敌人**会打魂（`demon_path_adept`，意图「噬魂」，每次扣 1）
- `[游戏]` **玩家 → 敌人的魂攻击通道完全不存在**：没有任何一只蛊、杀招或效果能对敌人造成魂伤害

### 4.4 魂道蛊的真实度（重点）

`[游戏]` 魂道流派现有 **40 只蛊**（转数分布 1–5 转 = 11/10/9/4/6 只；
角色分布 攻击 17 / 防御 5 / 移动 5 / 治疗 5 / 侦查 4 / 后勤 4）。

`[实测]` 我们把这些蛊名拿回原著全文做了整词比对（不能直接数字符串——短名会被长名包含，
例如「灯蛊」数出 40 次，其实 39 次都是「魂灯蛊」的一部分，独立出现 0 次）：

- **只有 4 只**能在原文站住：**净魂仙蛊**（原文 105 次，且是杀招「万我」的核心蛊）、
  **命牌蛊**（47 次）、**魂灯蛊**（39 次）、**摄魂蛊**（2 次）
- **31 只在原文一次都没出现过**
- 另有 5 只是别的词被切出来的误会（如「落魄蛊」实为「落魄蛊仙」被切开、「魄蛊」全在
  「气魄蛊/体魄蛊/云魄蛊」里面）
- 40 只里**只有 1 只**有显式战斗效果（挂一个「封印」状态）；其余 39 只走通用兜底，
  即**打出去和普通蛊没有区别**
- 名字有一半是机器拼的：「魂」+ 已有蛊名（`火蛊` → `魂火蛊` → `魂魂火蛊`），
  还有从别的流派搬来的（`丝蛊`[金]、`雾蛊`[气]）；而被当词根的名字在原文**也全是 0 命中**

`[实测]` 另一处方向相反的问题：原文真有的魂道蛊**在我们的数据里被挂到了别的流派**——
**胆识蛊**（原文 514 次命中，魂道壮魂的看家蛊）被登记在**人道**，不在魂道。

`[L2判断]` 魂道内容目前是**占位状态**，不是「弱」。因此「改造现有魂道蛊的效果」这条 L0 授权，
大概率要**连同重做这批蛊一起做**，而不是在原样保留名字的前提下打补丁。

### 4.5 战斗与死亡

`[游戏]` 魂是三轴死亡之一（气血 / 寿元 / 魂），**阈值均为 0**。
`[游戏]` 战斗中魂的流向：只有敌方「噬魂」能扣玩家魂；玩家无法反制。

| 元石 / 材料 | 节点、事件、售卖；开局 12 | 魂丹、炼蛊、真元兑换 | 否（库存） | 无 |

`[L2判断]` 注意上表第二列：**魂只有两条增长路径，且价值锚点只有「6 元石」这一条**；
而原文给了「三转狼魂蛊 = 7700 元石」这样的高价值锚点。两者相差三个数量级。

### 4.7 已测的难度事实（`[实测]`，只改内存、不改数据）

在一套固定的脚本化决策器下跑 4 组、每组 200 局同一随机种子：

| 组 | 通关率 | 魂死因 | 气血死因 |
|---|---|---|---|
| 基线 | **68.0%** | 61 | 3 |
| 把魂预算放宽（开局 1 → 4） | **97.0%** | **1** | 5 |
| 把行动点门槛放宽（3 点档的魂门槛 10 → 1） | **70.0%** | 60 | 0 |
| 两者同时放宽 | **99.0%** | 2 | 0 |

`[实测]` 现有唯一难度旋钮（敌人血量倍率）**非单调**：1.0 倍 → 67%、**1.5 倍 → 70%（更简单）**、
2.0 倍 → 42%。原因推测是战斗拖长反而带来更多掉落与恢复机会，而战斗本身几乎不致死（200 局里 2 次）。

`[L2判断]` 这组数据的含义是：**当前版本的死亡几乎全部由「魂的存量」这一条轴造成**
（61/64），而不是战斗难度。但请注意——这条结论是在「魂上限 = 4、无成长」的旧结构下测出来的，
**不能直接用来给新结构定难度**。它证明的是「魂这条轴在被设计之前就已经是硬约束」。

## 6. 需要你裁决 / 设计的问题

**Q1. 换算原则。** 原文是「百人魂 → 亿人魂」的十进制量级序列，是**以「人」为单位的真实量纲**
（十人魂 = 十个成年人的总和），且**常人生死极限就在百人魂**。我们游戏的行动点门槛恰好
落在 100 / 1000 / 10000（= 百/千/万人魂）。
→ 请给出**换算骨架**：游戏里「1 点魂」应当锚定原文的什么量级？开局角色应处在阶梯的哪一档？
是让玩家一局内跨越百→千人魂，还是只走完百人魂以内？这决定了整条曲线的形状。

**Q2. 「百人魂生死极限」要不要保留。** 原文说常人多一丝就魂魄爆炸、彻底消散。
这是一个**内生的风险机制**，而且是「壮魂」这个动作自带的。
→ 请判断：做成游戏时，保留为**硬性致死**、弱化为**阈值惩罚**、还是**改造为其它形式**？
如果保留，它如何与现有三轴死亡（气血/寿元/魂）共存而不同质？
注意这条与「魂是成长轴」的张力：**一个会因成长而致死的轴**。

**Q3. 三要素如何落成系统。** 原文的壮魂（数量）/ 炼魂（质量）/ 安魂（固持）是三条并列且有
配合关系的线（质变量变结合则「底蕴一日千里」）。
→ 请给出**骨架建议**：三者在我们游戏里各自对应什么玩家动作？
是三个独立资源、一条链上的三个阶段、还是一个动作的三个参数？以及「缺安魂则魂不附体」
这种缺失后果要不要做成机制。

**Q4. 凝魂名录 15 只蛊的角色。** 原文这一族「都能凝魂」且**各有妙处**
（冰魂增幅冰类蛊虫、龙魂裨益龙力）。
→ 请判断：这一族应当是**魂道的主干内容**（即玩家靠收集它们来养魂），
还是**辅助手段**（圣地类手段才是主路径）？以及「各有妙处」是否意味着它们应与其他流派产生联动。

**Q5. 兽魂改造（狼魂蛊 → 狼人魂）的定位。** 原文：可叠加、9 只把百人魂改成狼人魂、
改造后仍可继续壮魂、且与奴道强联动（「自古奴魂不分家」）。
→ 请判断这是**单条构筑路线**（魂道的一个流派分支）、还是**通用机制**（任何玩家都可做的人魂改造）。
以及它和「魂道是上游流派、奴道由其衍生」这条关系要不要在游戏里体现。

**Q6. 与肉身 / 真元的机会成本如何建模。** L0 已定：共用同一份资源池（元石），
「买了魂就没钱买修为和肉身」是设计意图。
→ 请给出**骨架**：魂的投入应当与哪些轴直接竞争、竞争发生在**元石**这一层还是更深
（例如是否要让「培养魂」占用时间/回合/机会位，而不只是花钱）。

**Q7. 魂道蛊的内容重做方向。** 现状是 40 只里 36 只无原文依据、39 只无战斗效果、
真蛊（胆识蛊）还被挂错了流派。
→ 请给出**重做原则**：以原文 19 只真名（4 只有据 + 15 只凝魂名录）为基础重建？
还是保留部分现有占位名做效果改造（L0 已授权「让它们利用自身魂道积累打出更好效果」）？
两条路各自的内容成本与风险是什么？

**Q8. 难度分档该挂在哪条轴。** 当前唯一旋钮（敌人血量倍率）非单调、且被打在错的轴上；
而实测显示「魂的存量」才是当前真正的硬约束。
→ 请判断：难度分档应挂在哪条轴（敌人强度 / 资源预算 / 魂的起始量 / 其它），
以及**是否应该挂在与魂无关的轴上**（因为魂是成长轴，动它等于动玩法）。

**Q9.（元问题）你建议的整体顺序。** 上述 8 问彼此耦合（换算原则决定死亡设计，
死亡设计决定内容重做的规模）。请给出**建议的决策顺序**，指出哪些必须先定、哪些可以后置。
