## CURRENT PHASE

v3 视觉语义与设计自由度取证已完成，并从“找素材 / 提假说”转入“建立约束边界”。

L0 已确认 v3 的核心价值不是决定画什么，而是区分：

- HARD：改动会改变对象身份；
- SOFT：有表达约束，但可以重新设计；
- OPEN：原著几乎没有视觉约束，可以原创。

因此下一阶段不再继续泛化的 Lore 取证。只有某个候选方向真正触碰 HARD，或出现现有证据无法裁决的具体冲突时，才回查原文。

## L0 已生效的视觉宪法

以下七条是 L0 对 v3 结果的采用结论，作为视觉定位候选的共同上游约束。

1. **蛊不是“特殊虫子”，而是规则能力的身份载体。**
   设计问题不是“它像不像虫”，而是“玩家能否看一眼就理解它承载什么规则”。

2. **拟人、角色化只能进入表现层，不能改写已明确的本体。**
   可使用化形、投影、催动形态、使用状态等；不得把原文明确写出的本体替换成人形。69 只本体样本中，人形拟人型为 0，但 35% 的本体没有直接描写，且 OPEN 区仍存在。

3. **效果必须属于规则变化的结果，而不是无来源的通用技能爆点。**
   力量视觉主体是具体形态或半实体；八至九转开始明显松动，允许纯光、无形和概念化表现。关键不是禁止效果，而是效果必须能追溯到蛊、杀招、阵、屋或其代价。

4. **组合成长是《问真》的高价值核心。**
   原文关系链是：

   ```text
   蛊 → 炼蛊 → 杀招 → 蛊阵 / 蛊屋 → 战斗结果
   ```

   其中蛊屋被原文定义为“数种、十数种蛊虫相互集合的固化定型的杀招”。该链条天然支持单卡、卡组、构筑、组合技和永久成长，不是普通技能树。

5. **五域差异先从社会运行方式推导，不从地貌标签反推。**
   当前已确认的差异包括：中洲门派与师徒体系；南疆家族、山寨、商贸中心与品级腰带；北原部族、王庭、黄金血脉与皮袍制度。建筑、服饰、NPC 与界面应从制度、权力、交易和生活方式推导，不能先贴地域颜色。

6. **HARD 保留，SOFT 重演，OPEN 原创。**
   282 条记录的约束分布为：

   | 等级 | 数量 | 比例 | 使用含义 |
   | --- | ---: | ---: | --- |
   | HARD | 96 | 34% | 不得随意改动身份级形态、配方关系和明确规则 |
   | SOFT | 117 | 41% | 可保留功能与识别点，重新设计表达 |
   | OPEN | 69 | 24% | 原著没有视觉约束，可进行原创建设 |

7. **蛊虫视觉采用本体层与主题层双层表现体系。**
   - 本体层 = 蛊在游戏世界中真实存在的形态，承担世界观、战斗识别、Lore 对齐与规则理解；
   - 主题层 = 玩家可解锁、收藏、切换的视觉表达，包括人格化、半人化、角色化与概念化；
   - 本体层不得替换蛊名、能力、流派、功能来源或已明确且承担身份识别的形态；
   - 主题层不得修改本体身份、能力规则或世界设定，也不得让玩家误以为主题外观是世界事实；
   - 主题层的人格化不能破坏能力语义，也不能退化为统一模板；
   - v2.0 取消 A/B/C 人格化生产档，统一为少量高完成度主题皮肤；
   - 主题皮肤按高辨识度、高使用率、高收藏价值、高情感潜力筛选，不对全部蛊平均制作；
   - 详细原则见 `docs/superpowers/specs/2026-09-20-wenzhen-gu-dual-layer-visual-design.md`。

## 必须先分开的两类 HARD

v3 的 HARD / SOFT / OPEN 回答的是“原著对外观有多少约束”，不是“游戏规则可以随意改”。

因此本件采用两层约束：

| 层 | 例子 | 是否可由视觉设计改动 |
| --- | --- | --- |
| **世界规则 HARD** | 炼蛊配方关系、蛊屋结构、五域组织制度、代价机制 | 否；属于系统与叙事契约 |
| **视觉 HARD** | 已明确且承担身份识别的形状、材质、颜色、标志件 | 否；改动会改变对象身份 |

需要注意：v3-D1 的五域组织在**视觉约束**上为 `HARD 0 / SOFT 8 / OPEN 17`。这不是说组织制度可以改，而是说原著对组织“具体看起来怎样”大量留白。候选方向必须同时做到：

- 不改世界规则 HARD；
- 不碰视觉 HARD；
- 优先在 SOFT 重演、在 OPEN 原创。

## 设计问题

> 在不碰 HARD、重用 SOFT、发挥 OPEN 的前提下，《问真》应该成为一个什么样的蛊道世界？

本阶段只决定“世界定位与视觉预算分配”，不决定具体资产、配色、界面或绘制方式。

## 期望 L1 交付

### 文件：《问真视觉定位决策稿 v1》

建议包含以下七节。

#### 1. 一句话世界定位

用一句话说明《问真》是什么类型的世界，以及它与普通修炼世界最根本的区别。

#### 2. 三个候选视觉母方向

候选的差异必须是“视觉预算表达什么”，不是表面风格差异。

L0 给出的以下名称仅作示例，不构成已选候选，L1 可沿用、改写或替换：

- 东方规则炼成世界；
- 超凡生态收藏世界；
- 蛊道文明模拟世界。

三个候选应满足：

- 彼此可辨，不可只是换词；
- 都能解释“人是如何利用蛊改造世界的”；
- 都能同时覆盖个体成长、战斗、聚落和长期建设中的至少三层；
- 不要求立即决定最终画法。

#### 3. 每个候选的约束适配

每个候选分别列出：

- 保留哪些对象身份；
- 如何重演 SOFT；
- 主要利用哪些 OPEN；
- 如何处理拟人化与角色化表达；
- 如何让效果成为规则结果；
- 如何把组合成长变成可读的视觉结构；
- 如何从五域制度推导差异，而不是只换地貌颜色。

#### 4. 每个候选的玩法连接

说明该方向如何服务：

- 单蛊与组合技；
- 炼蛊与配方发现；
- 杀招 / 蛊阵 / 蛊屋的层级跃迁；
- 代价、喂养、限制和风险；
- 五域的社会与商业差异；
- 玩家成长过程中最值得反复观看的状态变化。

#### 5. 商业辨识与传播

只回答辨识机制，不写具体资产方案：

- 玩家第一眼能记住什么；
- 哪类画面能证明“这不是普通修炼游戏”；
- 哪个核心对象最适合成为长期品牌信号；
- 哪些部分容易被同类产品同质化。

#### 6. MVP 可验证切片

给出一个不扩张产品范围的最小验证切片，说明：

- 使用哪些已存在或可快速创作的蛊与关系；
- 要验证哪一个核心体验假设；
- 哪些部分可以暂时不进入；
- 什么结果算验证成功，什么结果算方向不成立。

#### 7. L0 决策项

明确列出：

- 推荐哪个候选或候选组合；
- 为什么；
- 有哪些真正互斥的取舍；
- 需要 L0 明确批准或否决的边界；
- 哪些问题应在方向批准后进入计划，而不在本件解决。

---

## 禁止项

本件不要求 L1 输出：

- 最终画风；
- 配色；
- 字体；
- 界面布局；
- 具体角色或资产清单；
- 制作排期；
- 将候选直接转成实现任务。

本件也不允许用“现代化”作为免约束口号。任何现代化、高级化、角色化或原创化，都必须逐项说明：

```text
它利用了哪一层自由度：
SOFT / OPEN
```
