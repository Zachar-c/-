## CURRENT PHASE

v3 视觉约束取证与《问真》蛊虫双层表现体系 v1.0 均已获 L0 采用。

在把双层体系转成后续视觉任务验收条件前，L2 发现一处必须由 L1 裁决的解释冲突。

## QUESTION

《蛊虫双层表现体系 v1.0》写道：

> 如果原著已经明确描述外形、材质、特征、功能表现，则本体层优先遵循。

这与 v3 的 HARD / SOFT 口径存在潜在冲突。需要 L1 回答：

1. “原著明确描述”是否等同于视觉 HARD？
2. 如果不是，什么条件下明确描述升级为 HARD，什么条件下仍属于 SOFT？
3. 同一只蛊同时存在“明确本体描述”和“明确的用时形态”时，哪一层进入本体层，哪一层可进入主题层或表现层？
4. 后续 Worker 能否只凭 v3 的 HARD 标签执行，还是必须同时满足双层体系的额外门槛？

## WHY CODEX CANNOT DECIDE

- 这是两套已批准原则之间的解释与优先级问题，不是仓库内可通过搜索、测试或机械检查解决的实现问题。
- 若 L2 自行选择一种解释，会改变 117 条 SOFT 记录的实际设计空间，也可能让后续 Worker 对同一只蛊产生两套验收标准。
- 最终结果可能影响产品范围与内容商业化，涉及设计取舍时仍需 L0 批准。

## KNOWN FACTS

### v3 现行口径

- HARD：原著直接规定外观，改动会改变对象身份。
- SOFT：有描述，但不决定其本质，可以重新设计。
- OPEN：原著几乎没有视觉约束，可以自由创造。
- 282 条记录汇总：`HARD 96 / SOFT 117 / OPEN 69`。

### L1 双层体系现行口径

- 本体层：蛊在游戏世界中真实存在的形态，承担世界观、战斗识别、Lore 对齐和规则理解。
- 主题层：玩家可解锁、收藏、切换的视觉表达，不得修改本体身份、能力规则或世界设定。
- 本体层要求“原著明确形态优先”。
- 主题层允许人格化、半人化、角色化和概念化。

### 现有示例

- 石皮蛊具有石质特征。
- 月光蛊具有玉质/月光相关特征。
- 69 只本体样本中，人形拟人型为 0；24 只本体形态未提供。
- v3 已发现部分对象的主要视觉证据来自“用时之形”，而不是本体形。

## CONFLICTS

### 冲突 A：明确描述与身份约束不是同一概念

如果“明确描述”自动等于 HARD，那么大量 v2/v3 中只记录了形态但没有证明其承担身份识别的对象，会被重新锁死。

### 冲突 B：本体与用时形态

部分蛊有明确本体描写，也有明确化形、投影或催动后的形态。若将两者都视为本体层 HARD，会堵塞主题层和表现层；若只承认本体层，又需要判定“用时之形”在哪个层面展示。

### 冲突 C：执行口径不统一

只有 L1 给出统一优先级，L2 才能把结论转成 Worker Task Packet 的可验收条件；否则每个任务都可能重新解释一次。

## CONSTRAINTS

- 不重新讨论 v3 已确认的样本数、转数、五域或力量表现事实。
- 不输出具体美术风格、资产方案、配色、界面或角色设计。
- 不改变双层体系的基本定义：本体层是世界真实，主题层是玩家表达。
- 不新增 Provider、Schema、数据库或其他基础设施。
- 结论必须能转译成 Worker 可执行的是 / 否判定。

## DESIRED OUTPUT

请 L1 给出一页以内的《双层体系与 HARD/SOFT 绑定裁定》，至少包含：

1. **优先级规则**：双层体系与 v3 三级标签冲突时，谁先适用。
2. **升级条件**：哪些明确描述升级为视觉 HARD。
3. **降级条件**：哪些明确描述仍可作为 SOFT 重演。
4. **用时形态规则**：化形、投影、催动形态分别属于哪一层。
5. **主题层边界**：主题层能否覆盖 SOFT 描述；哪些情况下仍不得进入主题层。
6. **Worker 判定表**：给出 6–10 条是 / 否条件，能直接用于后续 Task Packet 验收。
7. **需 L0 批准的项**：只列真正涉及产品范围或商业取舍的部分，不把所有解释问题都推给 L0。

## OUTCOME
