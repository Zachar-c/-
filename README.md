# 《蛊真人》授权文本精编版

本仓库用于保存授权文本精编工作的正文、工作底稿、编辑台账和辅助脚本。

## 项目性质

- 原作状态：小说已经完本，当前使用的是完整原文。
- 工作性质：对完本原文进行授权文本精编，不是续写、补写、连载或剧情大纲制作。
- 分批方式：按六部结构和批次处理、校验、提交，批次只表示编辑与版本保存单位，不代表原作尚未完成。

## 当前精编进度

- 第一部《魔性不改》
- 已完成第一至第二十节的两批精编稿
- 原始完整文本不存放在本仓库中，源文件位于本地独立路径

## 目录

- `volumes/`：精编正文
- `working/`：按批次抽取的 CP936 原文底稿
- `notes/`：编辑说明、伏笔台账、人物台账和逻辑问题台账
- `index/`：章节索引与源文件元数据
- `scripts/`：批次抽取和索引脚本

## 编辑约定

- 保留主线剧情、心理描写、场景细节、剧情铺垫和伏笔。
- 删除站点推广、作者按语、打赏、推荐票和连载通知等噪声。
- 修复明显转码缺字、时间线、称谓和设定冲突。
- 精炼不以削弱关键段落的气势、心理压迫和人物决断为代价。
- 原始完整文本不覆盖、不提交；每批精编稿独立保存并通过台账追踪。
