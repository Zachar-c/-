联合结论

闭环在「战斗 → 元石 → 突破 → 真元/催动」这一条线性强度线上是通的； 在「战斗 → 掉落 → 炼蛊 → 杀招 → 新解法」这条构筑成长分支上大量断开。 玩家主要靠 Rank / 真元上限变强，而不是靠获得新力量形成新的战斗解法。 当前问题不只是价格或伤害偏高偏低，而是多条反馈没有兑现： 材料难转成新力量、层主不给新蛊、杀招显示与结算不一致、新蛊不触发重推。

SEGMENT 01 · LOOT

战斗收入与掉落

毛收入成立 层主空心

  • 普通战毛收入 3 石 + 2 材料 + 6% 三选一；精英 8–14 石；层主 15–27 石。恢复（+8 血/回满真元）是状态回补，不折成钱；战斗消耗未建模，故只称毛收入。
  • 公式 stone = base[tier] + trunc(base*20%*(layer-1))（run_rules.js:89-94）。
  • 蛊几率：common 6% / elite 35% / boss 55%，但 boss gu_pool.by_rarity 为空 → rollGu 直接空返。120/120 空（6 seed × 20 tick）；对照 common 300 tick 19 中，证 harness 有效。
  • 图结构为一次性 DAG、只向前推进——无连刷机制。
SEGMENT 02 · ECONOMY

元石经济与商店

无套利 主石槽是突破

  • 25 个可上架 purchase 全部买价 > 自身卖价（逐项核对，非全局 min/max）。材料不能卖出。
  • 成交价 = 挂牌 + 层加价（L1 +0% … L5 +50%）。上架还受 tier ≤ 层、school、非 npc_only 三重门。
  • 月光 t3 最早 L3（非 L1），L3 实战 2 战；血滴子 npc_only 永不上架；剑系商品非剑流派不可见。
  • 元石主要消费是突破（R2 5 / R3 12 / R4 20 / R5 30）与少量商店蛊。古方购买当前无机械收益。
SEGMENT 03 · MATERIALS

材料库存 → 消费

B1 · 77/80 无用途

  • 命名材料 80 种；有消费点的仅 3 种：boar_king_tusk / beast_blood / beast_bone。
  • 全仓 state.materials 写操作仅 3 处：掉落 +1（main.js:676）、炼制 -n（:879）、商店购买 +1（:1478）。
  • 其余 77 种（含精英保底 venom_sac、可购月蓝花瓣/传承信物、全部 mat_*_*）零消费、零出售，只有库存展示。
  • 含义：无法形成「为了炼某只蛊，主动去打某类敌人」的定向目标。
SEGMENT 04 · REFINEMENT

炼蛊图与选择

B3 · 无成长链 必成 100%

  • 全库 77 蛊 / 6 配方 / 4 输出；70/77 无任何配方边。无 r2+ 产出配方，无数值递进链。
  • 6 配方 successRollMax 全 100——失败分支为死代码。两个 advance_* 为自环且严格为负（同 ID 投入产出，净 -6 石 -材料）。
  • 月芒双配方、白玉双配方均存在严格被支配的劣势写法；UI 全量渲染无过滤。这是重复劣势配方，不是套利。
  • 新蛊五选：保留/出售/炼掉/上杀招/无「替换核心」。获得新蛊后不自动重推旧杀招，须手动回杀招页。
SEGMENT 05 · KILL MOVES

杀招：组合、门禁、显示

B4 · 显示≠结算 固定配方，非自由推导

  • 结算 = 组件 battleEffect 按 recipe 顺序合成；门禁/延迟仍读预制 m.effect；卡片文本也读预制。三套语义不一致。
  • 改解法（3）：明光壁（盾 3+回 1 vs 显示盾 6）、血昙（纯伤 6 vs 显示回 2+伤 3，且组件 hp<50% 条件在合成路径丢失）、剑痕索命（隐藏剑意 setup）。
  • 仅增伤/误导（2）：双锋引一致；凝光合成伤 4+支援闩 vs 显示伤 5。
  • 实际 lab 走盘：满血单用血别离被门禁挡下；组成血昙后满血一击秒 5 血铁皮山猪——条件绕过已复现（fixture/规则反例路径，非正常开局）。
SEGMENT 06 · CULTIVATION

修为：Rank 实际开放什么

线性强度成立 qi 语义易误读

  • 小突破只动 stage，qiMax / 催动 / 炼制 / 组合零变化。大突破 → Rank+1，qiMax ×3，按 canActivate 解锁该转蛊催动。
  • 炼制/组合无 rank 门禁；「维持」成本随 qiMax 放大。突破后 state.qi = min(oldQiMax, newQiMax)——旧 qi 当前值被丢弃，耗尽态会回填旧上限。
  • 初始 14 跨转蛊：核心双挂载（月光/小光/石皮/生机草/血别离/血滴子/玉皮/白豕）；鬼火/雨/才华开局不可催动，突破后补延迟/消耗/弱意图解。
  • 血手印 r5 开局死重（不可催动、无配方、无杀招）；卖价最高但卖即断未来 r5 解。

五个断点

BREAKPOINTS · 循环未兑现处

不是数值失衡清单，而是「反馈应当存在却没接上」的结构缺口。

B1

材料难转成新力量

80 种命名材料仅 3 种有消耗；77 种零消费零出售。打击特定敌人的「定向 farm」目标不成立。

B2

层主不给新构筑机会

配置 55% 出蛊，池为空 → 120/120 空奖。挑战更强敌人主要只换更多元石。

B3

炼蛊没有成长分支

6 配方全 100%、无等级链；两自环净亏；两对被支配重复。炼制不改变战斗解法。

B4

杀招显示 ≠ 真实结算

预制文本、门禁条件、组件合成三套语义；血昙满血打出且组件条件丢失。玩家按错误信息决策。

B5

新蛊几乎不进构筑

掉落/商店新蛊不进 5 杀招配方，也不触发重推。实测 14 节点仅 1 次经后续战斗验证的构筑变化。

杀招显示 vs 结算

点击卡片展开 · 空载组件合成

「改解法」= 改变动作顺序/目标选择/应对机制/资源转换；单纯增减伤害不计。 文本漂移本身不是玩法质变，但会误导平衡判断，必须先从强度问题中剥离。

三个调整候选

RESEARCH CANDIDATES · 非已生效裁定

以下仅供 L0/L1 评审。本轮不改变核心玩法、产品方向或阶段目标；数值与架构取舍必须上抛。

候选 A · 打通材料目标

让掉落材料进入消耗

目标：恢复「为了炼某只蛊，去打某类敌人」的定向循环。

  • 为 venom_sac / moon_dew / 流派 mat_* 接上配方或替代突破/参悟消耗
  • 或给材料一条诚实的出售/兑换路径（当前零出口）
  • 保持：无重复净增资产循环（不引入套利）
候选 B · 让强敌给新力量

兑现层主与精英的构筑回报

目标：「挑战更强敌人 → 获得新构筑机会」成立。

  • 补齐 boss gu_pool（或删掉虚假 55%），使配置与行为一致
  • 层主/精英三选一偏向「能进杀招或炼制图的新组件」，而非纯元石
  • 先修显示-结算，再谈强弱，避免围着错误卡面调参
候选 C · 兑现构筑选择

杀招诚实化 + 新蛊重推通路

目标：获得新力量后能看见并测试新解法。

  • 卡片文本/门禁/组件合成对齐；血昙类条件不得在合成路径静默丢失
  • 获得新蛊后提示或自动列出可解锁/可强化的杀招与配方
  • 声明式自动推导属未授权设计，本轮不恢复；只补「固定配方」的可达与提示
