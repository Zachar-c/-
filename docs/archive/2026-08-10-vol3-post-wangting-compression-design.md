# 第三部后王庭段压缩设计

## 目标

压缩方源进入王庭福地、八十八角真阳楼后至脱身前的过程性剧情，使该段的主要阅读回报集中于“天无绝人之路”。

不以固定字数或章节比例为目标。压缩后的段落必须保留：真阳楼的秩序压迫、巨阳特意的反扑、墨瑶和黑楼兰的互相利用、退路逐条被封以及方源以既有条件主动造路的翻盘。

## 结构结论

将原有的多任务、连续刷楼和资源收集，收束为一条不断失去选择的反转线：

`进入真阳楼取利` -> `确认遗产会反噬` -> `巨阳特意主动猎杀` -> `盟友与资源失控` -> `三重退路被封` -> `方源造路脱身`

压缩后不再让读者逐层跟随“获得了什么”，而应让每一次获利都成为更接近暴露和失控的代价。

## 保留的六个单元

### 1. 第一次得手

保留一次最能代表方源利用前世信息、密语和现场判断撬开真阳楼的行动。该场景必须同时完成三项功能：

- 获得后续翻盘可调用的关键资源、信息或条件；
- 让墨瑶意志进入可见的合作关系；
- 留下被真阳楼体系追溯或锁定的隐患。

其他同类取宝、试楼、获利过程改为结果性过场，除非其改变控制权。

### 2. 规则反噬

以一次明确的权限受限或行动失败，说明真阳楼不是可无限搜刮的宝库。血脉、楼主令、密语、仙元、楼层规则和传承意志应在同一冲突中形成限制，而不分散为多次重复教学。

### 3. 马鸿运与巨阳特意转为主动变量

保留一处足以改变局势的证据：前世路线因马鸿运、气运或真阳楼体系的反应而失效，巨阳特意从背景压力转为主动猎手。反复解释气运机制、旁支势力反应和同类争夺不单独成场。

### 4. 黑楼兰的交易与裂痕

黑楼兰保留三处不可合并的戏：一次明确利益交换、一次彼此试探、一次使双方不得不继续捆绑的事件。十绝体、升仙压力、复仇和主体性不能被删成方源的工具说明。

### 5. 三重封路

“天无绝人之路”前必须连续、可感地封死至少三类退路：

1. 常山阴身份及北原秩序不能再提供掩护；
2. 真阳楼内部的权限、资源、藏身处或常规退路失效；
3. 外部撤离手段被巨阳特意、敌方包围、大同风幕或同等阻断条件切断。

本单元只允许加压和收束，不插入新的寻宝、炼蛊、旁观者讲解或支线战报。

### 6. 造路与脱身

完整保留“岂不闻天无绝人之路？只要我想走，路就在脚下！”及紧接的行动证明。翻盘不能依赖临时新增设定；它必须重新组合前文已经出现的残缺资源、信息、蛊虫、身份或杀招条件。保留策略推演、执行阻力与代价，删去对同一理念的重复申说。

## 场景压缩规则

以场景是否改变控制权，而非字数或章节位置，决定保留力度：

| 场景作用 | 编辑处理 |
| --- | --- |
| 不改变信息、权限、资源、盟约或退路 | 合并为短过场或删除 |
| 改变其中一项，但与相邻场景同类 | 保留结果和必要代价，删除完整过程 |
| 同时改变两项以上 | 保留完整场景 |
| 为最终绝境新增一层封路 | 保留完整场景，并在后文回收 |
| 为最终翻盘提供必要条件 | 以前置埋设方式保留，不重复强调 |

## 优先压缩对象

- 重复的楼层环境、关卡规则、传承说明和闯关流程；每类规则最多保留首次建立、一次变通和一次反噬。
- 不改变路线或控制权的资源收集、仙蛊价值说明、旁观者惊叹、追兵移动和部族战报。
- 墨瑶意志的重复劝诱和解释；保留她建立专业权威、一次越界/误导、绝境时劝方源使用春秋蝉三类节点。
- 以“方源算无遗策”收束的重复内心独白；由失控、修正和脱身的行动呈现其能力。

## 不可削弱的因果

- 墨瑶意志既是帮助者也是潜在控制者，不能退化为说明书。
- 巨阳特意并非完整巨阳仙尊，但必须具备遗产系统的压迫感；其权限、资源依赖与命令限制可集中交代，不能删成无能反派。
- 黑楼兰是独立行动者。她的十绝体、升仙压力和与方源的互相利用必须保留足够重量。
- 真阳楼崩解至少保留三层因果：方源如何撬动体系、巨阳特意为何无法立即压死他、崩解后各方付出的代价。
- 太白云生仅保留与关键资源、撤退、黑楼兰升仙或方源关系成本直接有关的场景。

## 验收标准

压缩后的阅读体验应从“多次取宝后遭追杀”转为“第一次越界后不断失去选择，最终自行造出唯一出路”。

审校时逐项确认：

1. 最终翻盘调用的每一个关键条件都已在前文埋设。
2. 每次获利都对应暴露、资源消耗、盟约风险或权限收紧。
3. 三重封路连续发生，且没有被新的支线打断。
4. “天无绝人之路”由行动验证，而非作者代言式总结。
5. 巨阳特意、墨瑶、黑楼兰和太白云生均保留各自的因果作用，未因压缩而工具化。
