# 后王庭压缩版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不覆盖第三部既有精编稿的前提下，生成一套可独立审阅的后王庭剧情压缩版，使终局的“天无绝人之路”成为连续受压后的行动回报。

**Architecture:** 新版本只写入 `volumes/03-魔头乱世-王庭压缩版/`，原 `volumes/03-魔头乱世/` 始终作为基线。第121-150节以未经改写的入口对照稿保留；第151-244节按“获得收益即失去控制权”的单线重组，章节号、核心人物因果和终局锚点均连续可检索。

**Tech Stack:** UTF-8 plain text, PowerShell, Git, repository validation scripts.

## Global Constraints

- 不修改或覆盖 `volumes/03-魔头乱世/` 内任何既有精编文件。
- 不以固定字数或压缩率裁剪；删除内容必须由相邻场景承接其叙事功能。
- 保留墨瑶、黑楼兰、太白云生与巨阳特意的独立因果，不能工具化人物。
- 保留真阳楼失控、三重封路和“天无绝人之路”的完整因果链。
- 不新增人物、道具、设定或事后补丁；只重组既有剧情资源。
- 不提交或推送，除非用户另行明确要求。
