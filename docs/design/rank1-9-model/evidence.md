# 事实依据与游戏推导

日期：2026-09-27。入口：[README](README.md)。本页是研究证据表，不回写 Lore Wiki。

## 证据等级

- 原著锚点：Wiki 已核验且给出原文行号，仍保留叙事、对话、信念的区别。本轮引用 Wiki 核验结果，没有再通读原文。
- 显式分析：从多条事实归纳约束，不称为原著公式。
- 纯游戏：为构筑肉鸽选择的数字、概率、压缩时间、容量、奖励与回合制。
- 未知：Wiki 未确证、存在冲突或只有角色推测；完整游戏模型可在旁边提出候选，不能修改事实状态。

## 明确排除的旧口径

Canon 表「适用系统／禁止误读」中的首发范围、跑局限制、下压敌人数值、历史用户战力阶梯等是旧改编，不作为世界规则。本次仅读取其证据事实列并对照 Wiki。

根导航中现有 Web 方向只用于避免覆盖在途项目；本模型未读取其平衡表。项目协议要求的独立 L1 评审未完成，研究规格与正式应用之间仍有此门槛。

## 仍未知但不阻止建模的位置

1. 各转仙元通用换算、每蛊精确消耗和仙窍产率：给出可调设计参数。
2. 全部成尊条件、九转自然灾劫周期：保留未知；九转使用明确标注的设计目标推进。
3. 寿命的普遍转数公式：不从少数尊者寿命拟合。游戏使用有限阶段数作为时间压力，不宣称是原著寿元。
4. 天意、运道与人气的普适数值关系：没有足够证据建立实证公式。随机种子不是世界观「气运值」。
5. 全流派克制、任意材料替换、全体蛊方：不靠名称猜测，使用待内容填充的白名单接口。
6. 仙人四小阶与具体劫数之间的精确对应：模型只使用修行进度采样，不把二者绑定。
