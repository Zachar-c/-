## 模型的核心取舍

1. 分离转数、真元品质、资质、流派境界、道痕和蛊的品阶；不以一个等级值替代六个变量。
2. 一至五转以真元容量、蛊的搭配和修炼投入为主；六至八转加入仙元存量、仙窍生产、内部时间、灾劫与道痕；九转加入研究/开创、天道封锁条件与更高层资源争夺。
3. 保存绝对战力尺度，但以同阶归一化预算设计战斗。生命表示战斗耐受，不声称是肉身生命的原著计量。
4. 轮回只保留蛊方知识；不保留角色修为、蛊虫、道痕、货币或流派境界。玩家的理解可进步，角色的成尊资格须在局内取得。
5. 仙蛊唯一；全派通修、无限升炼、死亡自动重生都不是普通蛊师规则。轮回本身明确属于游戏设定。
6. 九转是本模型最高层，不自动推导十转或永生。未知的九转灾劫周期不填假数字。

## 运行与验收

在仓库根目录运行：

```powershell
node docs/design/rank1-9-model/validate.mjs
node docs/design/rank1-9-model/validate.mjs --builds docs/design/rank1-9-model/gu-library.json --supply docs/design/rank1-9-model/supply.json --scenarios supply_limited,key_gu_missing,refine_tail
node tools/docs-lint.mjs
git diff --check -- docs/design/rank1-9-model docs/README.md PROJECT_MAP.md docs/debt.md CHANGELOG.md
```

验证器重新生成本目录 `results.json` 和 `validation.md`，不读取游戏数值。每次调整参数后必须同时再生结果，避免文档表格与实际公式漂移。来源哈希指向本次读取的工作区版本，既有未提交的 Wiki 编辑未覆盖。

验收区分三层：公式可计算与账本闭合、模拟情景中的行为、真实玩家体验。当前完成前两层的注明范围，第三层不以模拟代替。

## 产品长度判断

完整参考路径为 42 个筹备阶段、126 场战斗，另有修炼与关键灾劫选择。按每战 1–2 分钟粗估，仅战斗即 126–252 分钟；总时长尚未实测，不能称为 20 分钟肉鸽。

一至九转更适合作为可中途保存的长局或连续章节。首个可玩版本可截取一至二转验证构筑；截取不改变本模型的完整研究覆盖，也不宣布正式首发范围。本规格不为压成短局而把九转偷偷改成九个普通关卡。
