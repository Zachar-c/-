# 八屏规格（桌面 **3840×2160 / 4K** 为基准；1080p 等比缩放）

公共骨架：`TopBar` → `Stage 舞台` → `ActionDock`。  
背景：`bg/page` + 极弱星尘/丝线插画（不抢操作）。

---

## 01 主界面 Hall

**目标**：3 秒内知道「开始修行 / 继续 / 看旧录」。

| 区 | 内容 |
| --- | --- |
| 左主 | 题字「宿命修真」`type/d1` + 一句苍凉副标 + 难度 `SegmentedControl` |
| 主行动坞 | **继续当前局**（金） / 无档时 **踏上修行** |
| 右栏 | 五段刻度示意 · 种子 · 最近 3 局旧录卡片 |
| 底注 | 设置 IconButton · 版本号 |

状态：无档 / 有进行局 / 有终局摘要（Sheet 浮层可关）

---

## 02 战斗 HUD Battle

**目标**：看清敌意图 → 用蛊/杀招/拳脚 → 结束回合。

```
[敌意图条 IntentBadge]
[敌卡组 MapNode 式立绘槽]     [战报 log]
[蛊手牌横排 GuCard M]          [杀招列 KillMoveCard]
[ActionDock: 结束回合 / 主输出]
```

- 顶资源条：`ResourceBar Qi/Hp/Life/Thought`  
- 选中 GuCard → Dock 变「催动 · 真元 n」  
- 危险招式 `Danger` + 代价红字  
- 受击：卡面闪 + 飘字（勿永久动画）

---

## 03 背包 Inventory

**目标**：持有蛊、材料、杀招一览；可标记/出售（若规则允许）。

| 区 | 内容 |
| --- | --- |
| 页签 | 蛊 / 材料 / 杀招（`SegmentedControl`） |
| 列表 | `GuCard S–M` 网格 4–6 列 |
| 详情抽屉 | 右侧 320px：效果、道痕、喂养、关联杀招 |
| Dock | 关闭背包（Quiet） |

---

## 04 设置 Settings

**目标**：音量、文字速度、辅助、存档管理。

- Dialog/Sheet 居中，不离开局  
- 组：音频（Slider）· 显示（Toggle）· 辅助（减动效 Toggle）· 存档（导出/清空 Danger）  
- Dock：**完成**（金）· 取消 Quiet

---

## 05 结算 Settlement

**目标**：一局结束的苍凉史诗感 + 可核对的数据。

- 大题（胜/败）`type/d1` 宋体  
- 时间长河 `TimelineStep` 五段  
- 数据三列：行程 / 收获 / 根源  
- 旧录摘要行  
- Dock：**重入轮回**（金）· 回主界面 Quiet

---

## 06 地图 Map

**目标**：选下一站；读懂风险与未来。

```
左：五段纵向时间河 TimelineStep
中：当前段 3 列 MapNode 网格
右：选中节点详情 + 敌人/掉落倾向
Dock：进入节点（金） / 返回当前行止
```

- 可走节点 `Available` 微光  
- 图例：战斗/精英/层主/坊市/休整/异闻  
- 自由意志：不自动锁定唯一路径，多后并列可点

---

## 07 商店 Shop

**目标**：元石有限，买什么改变构筑。

| 区 | 内容 |
| --- | --- |
| 货架 | `ShopRow` 或卡格：图 + 名 + 价 + 一句效果 |
| 已购 | 灰态 +「已入囊」 |
| 侧栏 | 元石 `StatChip` · 出售入口（背包） |
| Dock | **离开坊市**（金） |

价签用 `type/num-md` 等宽；买不起 Disabled + 「元石不足」Tooltip。

---

## 08 合成界面 Synthesis

**目标**：材料/蛊 → 新力量；看清配方与失败风险。

```
左：配方列表（可筛选流派）
中：[槽A] + [槽B] → [产物预览 GuCard]
右：成功率 / 代价 / 道痕要求
Dock：开炉合成（金） · 清空槽（Quiet）
```

- 槽 `SynthesisSlot` 支持拖入或点击选取  
- 缺料：槽虚线 + 红字「缺 xxx」  
- 成功/失败 Toast + 产物飞入背包微光
