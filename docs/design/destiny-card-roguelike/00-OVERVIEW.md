## 1. 叙事气质（风格关键词落地）

| 关键词 | 视觉转译 | 落到 UI |
| --- | --- | --- |
| 宿命修真 | 墨蓝长夜 + 银丝织命 | 底色、分隔线「命运丝线」 |
| 逆天改命 | 暗底上唯一暖金裂光 | 主 CTA / 关键抉择高亮 |
| 自由意志 | 卡牌可拿可舍，界面不逼选 | 取消/跳过始终在场 |
| 永生执念 | 时间刻度、寿元条 | HUD 常驻寿元/时辰 |
| 孤独求道 | 大留白、单点光源 | 舞台只亮当前行动 |
| 信念不灭 | 微光不灭的粒子/描边 | 残血/低资源时仍保留光晕 |
| 苍凉史诗 | 宋体大标题、衬线叙事 | 标题字体 + 结算长文案 |
| 黑暗中的微光 | 夜空底 + 局部自发光 | 整体低亮度，强调区发光 |
| 蛊虫 | 有机核 + 晶壳 | 蛊卡：核色（流派）+ 晶缘 |
| 道痕 | 细刻线、符纹角标 | 卡面刻痕、稀有度 |
| 命运丝线 | 1px 金银细线 | 连接线、进度脊、边框 |
| 时间长河 | 横向刻度流 | 地图纵轴 / 结算时间线 |

**一句话**：在近乎墨色的长夜里，用一丝不灭的金光串起蛊、道痕与命运——克制、苍凉、可读。

参考图仅取气质：**半透明晶体、金银冷光、丝缕漂浮、大暗底**。不引入写实人物立绘作为 UI 构件。
