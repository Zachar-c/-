# 旧试玩原型的历史记录

日期：2026-10-03。状态：归档说明，不是当前玩法实现、产品规格或原著机制完整性声明。唯一主实现与试玩入口为[问真 Web 实验室](../../../game/wenzhen-web-lab/lab.html)。本目录不再维护可运行的玩法原型。

## 离线网页原型

旧六蛊实验曾以单页离线网页在 Windows Edge 手动走盘。记录的操作覆盖购买、培养、路线奖励、持续防护、两种合炼、三场战斗胜利和刷新后续局。另有规则边界检查与浏览器按钮流程检查；相关原型数据、页面、检查脚本及 `tools.py` 的原型生成逻辑已删除。历史检查只表明当时实验流程可执行，不能证明可访问性、玩家趣味、平衡性或正式产品适用性。

当时实验采用公开设定的气血、真元、元石、行动、蛊虫效果、奖励和敌人数据。网页端曾演示月系攻击与合炼、防护维护、永久身体投入及路线获得选择。这些数值是实验参数，不是原著数值或正式游戏规则；当时实现也没有覆盖完整喂养周期、炼制失败流程、完整养炼或所有原著使用条件。

历史记录中包含的构筑假设：月系同催和合炼之间的资源取舍；身体存量与远程攻击答案之间的转换；真实伤势、苦力与治疗之间的风险选择。旧原型的轨迹曾显示组件移除、资源变化和路线选择会改变部分战局。它们是待后续产品验证的设计观察，不足以证明这些构筑已完整实现或有趣。

## Windows 模组验证

曾在隔离副本中构建并加载 Slay the Spire 模组框架，验证自定义状态、存档往返、持蛊状态查看以及部分购买、奖励和战斗操作接入。存档检查覆盖合炼或失蛊后的身体进度保留、材料不足时不部分扣除、真元边界、损坏载荷处理、旧档缺字段和新局清空。模组代码与构建脚本已删除；原验证不再是当前可复现流程，也未证明完整游戏回路、正常开局到结局的稳定性或玩家趣味。
