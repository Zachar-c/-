# 《问真》产品需求文档 PRD v1.0

## 文档定位

本文件是《问真》的最高产品定义文件。

它回答：

-   为什么制作《问真》；
-   玩家应该体验什么；
-   当前阶段做什么；
-   明确禁止做什么。

本文件不是技术方案，不规定实现方式。

------------------------------------------------------------------------

# 一、产品定位

《问真》是一款以《蛊真人》世界运行逻辑为灵感的策略构筑游戏。

它不是：

-   小说剧情复刻；
-   方源模拟器；
-   世界观百科；
-   单纯仙侠数值游戏。

它希望将《蛊真人》中最有价值的部分转化为游戏体验：

> 力量如何获得，如何组合，如何受到限制，以及为了力量必须承担什么代价。

------------------------------------------------------------------------

# 二、核心玩家幻想

玩家应该产生的核心感受：

> 我是一名真正的蛊师。

而不是：

> 我正在点击技能按钮。

玩家需要经历：

## 获得力量

发现蛊虫。

理解：

-   它是什么；
-   它有什么用途；
-   它如何成长；
-   它有什么限制。

## 构筑道路

不同选择形成不同道路。

例如：

-   爆发型；
-   防御型；
-   控制型；
-   信息型；
-   资源经营型。

不存在唯一正确答案。

## 承担代价

强大力量必须支付成本：

-   真元；
-   材料；
-   时间；
-   风险；
-   机会。

## 理解规则

胜利来自理解世界。

不是简单堆叠数值。

------------------------------------------------------------------------

# 三、核心体验原则

## 规则优先

所有能力必须拥有：

-   来源；
-   条件；
-   消耗；
-   限制；
-   风险。

禁止凭空技能。

------------------------------------------------------------------------

## 选择优先

游戏乐趣来自取舍。

玩家应该不断面对：

"现在获得什么？"

"未来失去什么？"

------------------------------------------------------------------------

## 代价优先

没有无代价力量。

越强大的能力，应越需要考虑：

-   使用时机；
-   消耗；
-   后果。

------------------------------------------------------------------------

## 信息优先

战斗不应该只是：

攻击力 \> 防御力 \> 胜利。

应该包含：

-   观察；
-   推理；
-   预测；
-   反制。

------------------------------------------------------------------------

# 四、核心循环

## 战斗循环

观察敌人 → 获取信息 → 制定策略 → 使用蛊虫 → 承担结果 → 调整方案。

------------------------------------------------------------------------

## 成长循环

探索 → 获得资源 → 培养蛊虫 → 形成组合 → 挑战更高风险 → 获得成长。

------------------------------------------------------------------------

# 五、MVP目标

第一阶段不是制作完整游戏。

目标：

验证核心体验是否成立。

必须证明：

1.  玩家是否会观察敌人；
2.  玩家是否因为蛊虫组合改变打法；
3.  奖励是否影响下一步选择；
4.  失败是否产生重新尝试动力。

------------------------------------------------------------------------

# 六、MVP范围

允许：

-   一个角色；
-   少量蛊虫；
-   少量敌人；
-   短流程循环；
-   构筑选择。

暂不追求：

完整世界。

------------------------------------------------------------------------

# 七、明确非目标

当前阶段禁止：

-   完整剧情复刻；
-   五域地图；
-   天庭战争；
-   完整仙道体系；
-   大量NPC；
-   大量外围系统。

------------------------------------------------------------------------

# 八、最终产品定义

《问真》不是制作一个《蛊真人》主题游戏。

而是：

> 创造一个玩家能够亲身体验《蛊真人》世界运行逻辑的游戏。

核心问题：

> 在充满规则、限制和代价的世界里，你如何找到自己的道路？
