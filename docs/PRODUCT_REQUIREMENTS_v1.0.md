# 《问真》产品需求文档 PRD v1.0

## 文档定位

本文件是《问真》的最高产品定义文件。

它回答：

-   为什么制作《问真》；
-   玩家应该体验什么；
-   当前阶段做什么；
-   明确禁止做什么。

本文件不是技术方案，不规定实现方式。

**当前产品方向（L0，2026-09-24）：**浏览器 Web 版是《问真》完整长线游戏的当前产品载体，以 `game/wenzhen-web-lab/lab.html` 为主要入口。Web 版本按完整修行过程打磨，不以短流程切片作为最终交付；Godot 规则与内容数据可按需复用，美术可以原创设计。Web 游戏不保留独立材料循环：材料不掉落、不交易，也不作为合炼投入；修行成本由真元、蛊虫、元石、时间、风险与机会承担。

------------------------------------------------------------------------

# 一、产品定位

《问真》是一款以《蛊真人》世界运行逻辑为灵感的策略构筑游戏。

它不是：

-   小说剧情复刻；
-   方源模拟器；
-   世界观百科；
-   单纯仙侠数值游戏。

它希望将《蛊真人》中最有价值的部分转化为游戏体验：

> 力量如何获得，如何组合，如何受到限制，以及为了力量必须承担什么代价。

------------------------------------------------------------------------

# 二、核心玩家幻想

玩家应该产生的核心感受：

> 我是一名真正的蛊师。

而不是：

> 我正在点击技能按钮。

玩家需要经历：

## 获得力量

发现蛊虫。

理解：

-   它是什么；
-   它有什么用途；
-   它如何成长；
-   它有什么限制。

## 构筑道路

不同选择形成不同道路。

例如：

-   爆发型；
-   防御型；
-   控制型；
-   信息型；
-   资源经营型。

不存在唯一正确答案。

## 承担代价

强大力量必须支付成本：

-   真元；
-   蛊虫投入；
-   时间；
-   风险；
-   机会。

## 理解规则

胜利来自理解世界。

不是简单堆叠数值。

------------------------------------------------------------------------

# 三、核心体验原则

## 规则优先

所有能力必须拥有：

-   来源；
-   条件；
-   消耗；
-   限制；
-   风险。

禁止凭空技能。

------------------------------------------------------------------------

## 选择优先

游戏乐趣来自取舍。

玩家应该不断面对：

"现在获得什么？"

"未来失去什么？"

------------------------------------------------------------------------

## 代价优先

没有无代价力量。

越强大的能力，应越需要考虑：

-   使用时机；
-   消耗；
-   后果。

------------------------------------------------------------------------

## 信息优先

战斗不应该只是：

攻击力 \> 防御力 \> 胜利。

应该包含：

-   观察；
-   推理；
-   预测；
-   反制。

------------------------------------------------------------------------

# 四、核心循环

## 战斗循环

观察敌人 → 获取信息 → 制定策略 → 使用蛊虫 → 承担结果 → 调整方案。

------------------------------------------------------------------------

## 成长循环

探索 → 获得资源 → 培养蛊虫 → 形成组合 → 挑战更高风险 → 获得成长。

------------------------------------------------------------------------

# 五、产品目标

目标不是交付短流程切片，而是让核心体验支撑完整、可反复游玩的修行过程。单局目标为 3–5 小时、200–300 个有效节点；内容应覆盖从初入山道到冲击终局的完整成长弧。

每局都应让玩家：

1.  观察敌人并据情报选择交锋方式；
2.  因获得的蛊虫与蛊方改变杀招和行事路线；
3.  在资源、关系、风险和修为之间持续取舍；
4.  看到选择留下的记录与结局归因，并有理由开启下一局。

------------------------------------------------------------------------

# 六、当前产品范围

-   以浏览器为交付平台，单机、离线可玩，保留五层修行路线与多种结局；
-   以内容密度、路线差异、事件变化和可追溯的选择后果打磨长期游玩体验；
-   继续围绕蛊虫组合、杀招构筑与代价决策，不以重复堆数值延长游戏；
-   美术资产可原创制作，不要求沿用任何既有风格或素材。

本范围不要求重做已经成熟的实现。新增核心机制或显著扩大世界范围，仍需单独裁定。

------------------------------------------------------------------------

# 七、明确非目标

当前产品不以以下内容为目标：

-   完整剧情复刻；
-   五域地图；
-   天庭战争；
-   完整仙道体系；
-   为追求体量而增加与核心循环无关的外围系统。

------------------------------------------------------------------------

# 八、最终产品定义

《问真》不是制作一个《蛊真人》主题游戏。

而是：

> 创造一个玩家能够亲身体验《蛊真人》世界运行逻辑的游戏。

玩家通过一局完整修行经历道路选择、蛊虫构筑、代价承担与结局复盘；再以不同种子和路线重走，逐步发现世界并不会为自己让路。

核心问题：

> 在充满规则、限制和代价的世界里，你如何找到自己的道路？
