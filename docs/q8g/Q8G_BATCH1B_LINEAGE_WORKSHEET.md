## 0. 本单要解决什么

1-A 用一条 light 跨 role 实验链证明了 **promotion schema 能跑通**。但 D7 冻结链被审阅者明确裁定：

> **"这次不是在'设计一条合理的最终游戏配方'。"**
> **"🔴 不能拿垂直切片的实验链反向定义最终内容设计。"**

1-B0 就是这条分界线：**从"架构已证明可行"到"开始真正设计游戏内容"**。

产出物 = 19 张流派谱系表（§6，1-B0-L 提案）+ 1-B0-R 材料事实库（§3.R，产出文件 `Q8G_1B0R_MATERIAL_FACT_BASE.md`）。每张谱系表回答：

```text
school
  ├─ Rank 1 candidates → Rank 2
  ├─ Rank 2 → Rank 3
  ├─ Rank 3 → Rank 4
  └─ Rank 4 → Rank 5

每条：input definition → output definition → role 是否延续
      → 世界语义解释 → 候选材料关系 → 成本档位
```

材料的世界模型（"我要晋升四转，必须去更危险的地方找四转级资源"）是**1-B0-M 的裁定目标**，
而它的输入必须来自 1-B0-R 的原文事实库——**本单只负责把这条链路建好，不负责替考据下结论**。
这套语言一旦从原文考据中建立，后面的参考价值、流派归属、掉落、交易和炼蛊才会自然落到同一个模型里（蛊真人是世界模型，而不是皮肤）。

## 3. 材料世界模型：先考据（1-B0-R），后建模（1-B0-M），再裁定
> 🟡 **v2 的"材料阶梯"章节（下方 3.1–3.8）已整体退回为候选假设，全部不冻结。**
> 原因（用户裁定 2026-09-13）：七族模型本质是现代 RPG 的资源分类法，不是从《蛊真人》原文考据出来的世界模型；材料族分配、等级、稀有度、来源层级必须等原文事实库建立后，由 1-B0-M 裁定。

### 3.R 1-B0-R：原文材料考据任务规格（🟢 已批准执行，2026-09-13 审阅裁定，附 R16–R18 约束）

> **Agent 的任务不是"设计材料"，而是从原文建立材料事实库。**
> 方向纠正（用户裁定 2026-09-13）：不能先设计一个"合理"的材料体系，再拿《蛊真人》世界观去解释它；必须反过来——**先考据，再审阅是否忠于原文，最后才抽象成游戏数据模型**。

#### 3.R.0 核心指令（硬规则 R14，逐字执行）

> **不要设计《蛊真人》里应该有什么材料；只从原文寻找已经存在的材料、资源、来源、道属性、炼蛊用途和经济关系。对于原文没有明确支持的关系，只能标记为"推断"，不得直接升级成设计事实。**

#### 3.R.1 四层分离（不得跨层，R15）

```text
① 原文事实（必须带出处：卷/行号 + 原文短句引用）
② 结构化推导（D0–D3 分级；引用依据事实的 E 级；正式中间层，不是猜测）
③ 我们的世界模型判断（用户审阅层，1-B0-M 的输入）
④ 最终游戏设计（1-B0-M 裁定后才产生）
—— 另设【假设】：无充分依据的命题，永远不得冒充 ①②
```

#### 3.R.2 考据方法（示例：不能"骨 → 骨道"直连）

```text
"骨"不能直接得到 骨 → 骨道。应继续追：

某种骨
├─ 是什么生物的骨？
├─ 是否带道痕 / 道属性？
├─ 出现在什么环境？
├─ 被什么人物 / 势力使用？
├─ 用来炼什么蛊？
└─ 原文有没有明确称为某一道材料？
```

完全可能得到（🟡 待考据验证，不是结论）：

```text
普通兽骨     → 兽类资源
火属性荒兽骨 → 火道资源？
水属性异兽骨 → 水道资源？
某种骨属于某道资源，但被另一道拿去炼蛊  ← 正交性证据？
```

#### 3.R.3 核心验证问题（考据要回答的，不是预先回答的）

1. **《蛊真人》到底按什么维度组织蛊材**：物质种类（骨/血/皮）？道痕/属性（火/水）？来源/生物层级（凡兽/荒兽/兽王）？还是多维度同时存在且正交？
   - 典型问题（🔴 不得先答，去原文找证据）：火属性荒兽的骨是不是火道资源？水属性异兽的血是不是水道资源？
   - **R17 硬门**：本问题（正交性）必须"**≥1 正向案例 + ≥1 冲突/跨道案例**"齐备才允许下判断；找不到冲突案例不等于不存在，须登记"反证检索无果"本身。
2. 材料的"转数/品级"在原文中如何表达（等阶、年份、品级……）？
3. 材料稀缺性与价值在原文由什么决定？（已知线索：`肉鸽设计-原始数据/07-经济系统-原始数据.md` 检索命中"炼蛊材料：稀缺性决定价值"，行 98566/98572）
   - ⚠️ v3.1：**稀缺 ≠ 价值 ≠ 交易价格**，三者必须分开记录，不得互相推导。
4. 不同持有者身份（荒兽 / 家族蛊师 / 散修 / 商队 / 异兽 / 特殊环境 / 资源点）**为什么**拥有不同材料？（现有敌人 theme=beast/faction/anomaly/cultivator/neutral 与材料结构几乎脱节——这是考据的优先切入点）

#### 3.R.4 考据字段（v3.1 拆分版；事实库每条记录）

> 🟡 v3.1 审阅裁定：**"它是什么"和"它属于什么道"必须拆开**——"骨"描述物质形态，"火"描述承载的道，"哪道人在用"是第三件事，"是否专属"是第四件事。不得压成一个 `school`。

```text
材料/资源名（原文原词）
├─ material_form       它是什么（骨/血/皮/花/矿……物质形态，原文原词）
├─ source_creature     从谁身上来（原文明确才填；不明确 = 无证据，不得猜）
├─ elemental_affinity  有无属性/道痕（原文明示才填；含原文明示的五行/属性描述）
├─ dao_affinity        原文是否明示属于某道（E 等级标注，见 §3.R.5）
├─ school_usage        哪一道 / 什么人在使用它（使用者身份 ≠ 道属性归属，两者分开记）
├─ exclusive           是否专属于某道（原文有无"非某道不可用/某道专属"表述）
├─ purpose             用途（喂养 / 炼蛊 / 交易 / 其他）
├─ refine_target       用于炼什么蛊（原文明示才填）
├─ acquisition_mode    获取方式（击杀 / 采集 / 炼制副产 / 交易 / 夺取 / 继承 / 资源点 / 事件）
│                      —— 🟡 v3.1："掉落"不得成为所有材料获取的统一抽象
├─ who_can_obtain      谁能够获得
├─ value_evidence      原文价值证据（稀有程度 / 获得难度 / 使用需求 / 交易行为 / 交易价格——
│                      只记录原文表述，🟡 不叫"参考价值"，不写数值；1-B0-M 决定哪些可作 reference_value 输入）
└─ evidence_grade      每条关系单独标 E0–E4（见 §3.R.5），不得汇总平均
```

#### 3.R.5 关系证据等级（R16，强制）

| 级别 | 定义 | 示例 |
|---|---|---|
| **E0** | 原文完全没有证据 | 游戏自创材料在原文中无对应物（如"传承信物"需验证） |
| **E1** | 仅共同出现 | 某骨出现在火道蛊师手里——**共现不等于归属** |
| **E2** | 存在用途关联 | 原文显示该材料可用于某类炼蛊/喂养，但未提道 |
| **E3** | 原文明示用于该道炼蛊 | "X 道炼制 Y 蛊需要 Z"类明示 |
| **E4** | 原文明示该材料具有某道属性/道痕 | "此骨蕴含火道道痕"类明示 |

**使用规则**：
- 事实库中每条"材料→道/用途/来源"关系**单独标级**，禁止汇总平均、禁止"总体而言原文支持"；
- **E1 不得写成"原文支持"**——引用时必须带级别；
- 同一材料的不同关系可以不同级（如"用于炼蛊 E3，属于火道 E1"）。

**推导等级 D0–D3（v3.2 新增，R15 ② 层的约束）**：

> **"推导"不是降低考据标准，而是正式增加"基于考据的可验证推导"层。**
> 我们不要求原文替我们设计好 RPG 数据结构；我们要求的是**从原文提取规则，再做受约束的结构化推导**。

| 等级 | 含义 |
|---|---|
| **D0** | 无法推导，只能假设 |
| **D1** | 单条事实的弱推导 |
| **D2** | 多条独立原文事实共同支持 |
| **D3** | 多条事实 + 正向案例 + 反例/边界条件共同支持 |

**使用规则**：
- 每条推导必须**引用其依据事实（含 E 级）**，D2 起要求依据来自**相互独立**的多条事实；
- 推导可以成为后续设计的**正式依据**（进入 ③ 世界模型判断），但不得回写成 ① 原文事实；
- 典型示例："火属性的骨能不能算火道资源？"——原文无此命名，但若"骨是载体、道痕决定属性"由多条 E4 事实推出，则该命题标【推导】，**进入世界模型判断，而不是被考据门槛直接否掉**；
- 【假设】继续保留给无充分依据的命题（如游戏自创名的原型猜测）。

#### 3.R.6 反证搜索硬门（R17，强制）

- 每个倾向性结论（如"该材料属火道"）必须附**反向检索记录**：换了哪些反证关键词、命中/未命中什么；
- 正交性问题（§3.R.3 Q1）须 **≥1 正向案例 + ≥1 冲突/跨道案例** 才允许下判断；
- "同一材料跨多道使用"或"某道使用非本道材料"的案例是**最高价值证据**，命中即单独登记；
- 反证检索无果必须**明示登记**（"搜了 X/Y/Z 无果"），不得省略。

#### 3.R.7 检索纪律：假设隔离（R18，强制）

> 🟡 v3.1 审阅裁定：正文里保留的候选结构对 Agent 有**锚定效应**——"施工单都这么写了，考据时自然去找支持它的证据"。

- **1-B0-R 禁止以 §3.1–3.5 候选结构（七族 / 二转材~五转材 / 等级错位 / Boss→高阶材）作为检索前提**；
- 正确顺序：**先搜索原文 → 建立事实 → 再与假设对照**（对照只发生在事实库的"假设对照"专节，且必须同时记录"假设被支持/被削弱/无关"三种结果）；
- 事实库正文中不得出现"验证了假设 N"式表述；假设是否成立是 1-B0-M 的结论，不是 1-B0-R 的结论。

**两项"不得先于考据设计"的推论（v3 用户裁定）**：

| 项 | 错误做法 | 正确顺序 |
|---|---|---|
| **参考价值** | "我觉得二转材应该值 5/10/20" | 原文稀缺程度 + 获取难度 + 炼蛊用途 + 需求范围 + 产出风险 → 倒推 → Batch 2 数值校准（既有 `value`/`reference_value` 是旧参考价体系，其失衡——兽骨高度集中——正是考据要解释的现象） |
| **掉落** | "二转材来自 Elite、三转材来自 Elite/Boss"（游戏设计习惯） | 原文资源 → 谁拥有/产生 → 什么环境出现 → 玩家如何获取 → 对应什么敌人/节点 → 才设计 drop table。"Boss = 五转材料"不是《蛊真人》世界模型 |

> Batch 2 负责"材料**值多少钱**"（`gu_value` / 定价 / 经济模拟）；
> "材料是什么、属于什么道、从哪来"也必须先经 1-B0-R/M——**两个问题都不得由 Agent 拍脑袋**。

#### 3.1 三维模型 【候选假设，待 1-B0-M 裁定】


| 维度 | 回答 | 举例 |
|---|---|---|
| 来源族 | **这是什么东西** | 兽骨是兽材，月华露是天地材 |

## 4. 谱系语义设计原则（"什么东西晋升成什么东西"的裁判标准）

1-B0 为 19 派统一采用以下四种**世界语义谱系模型**（每派选其一，写入每张表的首行）：

| 模型 | 含义 | 典型 |
|---|---|---|
| **M-A 量级递进** | 同一物的力量/单位/规模逐级放大 | force 斤→十斤→钧→十钧；water 泉→涟→潮→瀑→河 |
| **M-B 品阶递进** | 同一体系的等级/品第逐级升高 | gold 青铜舍利→白银→黄金→紫晶；human 兵卒→伍长→什长 |
| **M-C 历程叙事** | 链上五只蛊连起来讲一个完整的故事/典故 | dream 梦魇→黄粱→黄粱梦→南柯→梦蝶（一枕黄粱→庄周梦蝶） |
| **M-D 工序递进** | 同一门技艺的工序从粗到精 | refine 熔→合炼→提纯→凝→九转升炼 |

> 设计目标：玩家看一眼配方链就能理解"我在把这只蛊养成什么"，
> 而 1-A 实验链（月旋→月芒→月影→皎→太光）这种"拼凑可达"的链不满足这一点。
