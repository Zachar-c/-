## 1. 阻塞点清单（按因果链）

### B1 🔴 promotion 没有执行入口：refinement 节点整局期望 < 1 个

- **现象**：四局合计 promotion 0 次；第 3 局全程仅 1 个 refinement 节点（L4 层）。
- **根因**：`refinement_hollow`（type=refinement）放在 pacing **rest 类池**内，rest 类权重仅 5%，rest 池内又只占 1/4 → 期望 ≈ 160 节点 × 5% × 25% ≈ **0.6 个/局**。
- **已临时调参（working tree，未提交）**：rest 权重 5→6、rest 池内 `refinement_hollow` ×2 → 期望约 1.2 个/局。
- **世界模型**：炼蛊是核心支柱（海量合成配方，用户裁定 2026-09-05）——支柱级玩法在地图上期望出现 < 1 次，是 slice 时代 pacing 与 Batch 1 经济循环的结构冲突。
- **设计选项**：
  - (a) 维持临时调参（~1.2 个/局，单次探访可连续多步 promotion）；
  - (b) refinement_hollow 升格为**独立 category**（占用 category_weights 槽位，地图级保证）；
  - (c) 休整三选一卡面中固定出现"炼蛊"选项（UI 侧保证入口）。

### B2 🔴 promotion 材料 ×2 → 3 件 > craft_cap 2（soul 1–2）——低魂玩家被完全卡死

- **现象**：唯一一次炼蛊尝试被拒 `refinement_capacity_exceeded`。
- **根因**：1 蛊 + 2 材料 = **3 件**；`SoulCapacity.craft_cap_for_soul`：soul 1–2 → 上限 **2**。而 soul 获取冻结为"初始 1、稀缺低频"（Batch 0 §8）→ **低魂玩家永远无法晋升**。
- **已临时修复（working tree，未提交）**：76 条 promotion 材料统一 **×1**（2 件 ≤ 2，soul 1 可炼）。依据：1-A 的 D7 链先例就是 ×1（`beast_bone ×1`，Gate 1–7 验收通过）——×2 是 1-B1-a~d 施工时的 provisional 选择，从未对照 craft_cap 复核。**本修复需你追认**。
- **世界模型**：见 §3 W1（一心多用靠炼蛊实践积累——容量本身随修行成长，低魂期容量小是原著设定的一部分）。
- **红线连带**：sword 链累计成本随之 66 → **55 = 44 石 + 11 材料 value**（仍 < 直取 70），拆解已同步进 recipe `source` 与批次文档。

### B3 🔴 soul 1–2 玩家的成长出口：Soul 经验值提案（本轮新指令）

- **你的指令**：使用蛊虫击败敌人、炼制蛊虫，增加少量 Soul 经验值；大多数 soul 等级通过蛊虫提升；避免低等级玩家因 soul 卡关。
- **与 Batch 0 §8 的张力（必须写明）**：§8 曾冻结"获取稀缺、低频；不要设计成成长属性，否则变成第二条等级成长线"。本提案与之冲突，但有三重缓解：①经验**只来自蛊途**（战斗/炼蛊），不独立刷取；②成长**小步线性**（建议 10 XP/级，单局 soul 1→3~5 封顶量级）；③成长结果恰好服务 craft_cap（不是战力直通）。
- **世界模型**：§3 W1/W2（一心多用靠修行积累 E4；念头积蓄-消耗机制 E4）。
- **设计选项**：
  - **(a) 双源经验（你的指令）**：战斗胜利（用蛊击败敌人）+1、炼蛊成功 +2，10 XP/级。
    分层诚实声明：炼蛊→念头成长是 **E4**（15902 明示"积累修行"）；战斗→念头成长是 **[设计]**（原文中战斗更多是念头**消耗**侧，见 121236/119528），其成长解释为"剧烈思索磨砺念头"属推导/设计。
  - (b) 仅炼蛊给经验（更贴 E4，但战斗侧成长缺位）；
  - (c) 维持 Batch 0 §8 稀缺口径 + 改用其他方式解 B2（如 promotion 豁免容量）。
