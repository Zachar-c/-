## 1. 【§21-1】M 的可接受边界

### 1.1 方法

`M` = Common opportunity 的数量/作用范围。因 §20/§21 已确认**同产量下作用域几乎无差异**，
本轮以 **全层** 为 M 的规范作用域，扫描"目标 Common 总量"，用**配对份额搜索**把每个目标落到真实可实现值，
再测其收益与代价。

### 1.2 前沿扫描（32 局，64 复现流）

### 1.3 边界裁定建议

1. 🔴 **死区 = 149–202 个 Common**：这段区间 `f1zero` **完全不动（6.61/8）**，
   而 elite 从 **82 掉到 29**（−53 场）、`crude` 从 149 涨到 201、gu 期望从 33.5 掉到 20.8。
   **纯代价、零收益，属于明确的"不可接受区"。**
2. **效率峰值 = 101 个 Common**（`dF1/dElite = 0.1437`，是全表最高）。
   ⇒ 若只求性价比，**101 附近是拐点**（+2.25 次修复，−20 elite）。
3. **131 处收益几乎停滞**（0.0014），随后 141 才再次跃升（0.1031）——
   说明收益**不是连续的**，而是由"某些局跨过阈值"驱动的阶跃。
   ⇒ **不应把 M 当作可微调的旋钮来线性外推。**
4. **天花板 231**：需要 `elite = 0`（精英战斗彻底消失）。这在设计上等同于删除一个 tier，
   **远超任何可接受范围**；且 `f1zero` 也只到 **7.38/8**，**结构上到不了 8/8**。
5. **建议的可接受边界**：**≤ 141 个 Common**（即约 +60）；
   且**必须避开 149–202 死区**。**该数值不是批准值**，只是"边界在哪"的测量结论。

## 2. 【§21-2】G1（K=2）与 G2（K=4）独立对比

### 2.1 结果

```text
  variant       f1zero  inWindow  shortZero   elite   curse    noto   guExp  pieces   crude
  BASELINE      2.67/8     19.66       4.97     150      75     150    49.9   389.0    83.3
  G1 K=2        6.00/8     23.19       1.64     138      69     138    47.0   389.0    95.0
  G2 K=4        7.02/8     24.73       0.63     123      62     123    43.4   389.0   109.5

  head-to-head:
    G1 vs base : f1zero +3.33 | elite -12 | gu -2.9
    G2 vs base : f1zero +4.34 | elite -27 | gu -6.5
    G2 vs G1   : f1zero +1.02 | elite -15 | gu -3.6    <- 最后一步的代价
    efficiency : G1 0.2773 vs G2 0.1609  (repairs per elite sacrificed)
```

### 2.2 裁定建议

1. **G1 效率是 G2 的 1.72 倍**（0.2773 vs 0.1609）。
2. **从 G1 走到 G2 的那一步很贵**：`+1.02` 次修复要付 `−15` elite（效率仅 **0.068**，
   是 G1 首步效率的 **1/4**）。
3. 🔴 **跨变量交叉对比（本次最重要的效率结论）**：

   ```text
   G2      : f1zero 7.02/8 , elite 123  (代价 -27)
   M@149   : f1zero 6.61/8 , elite  82  (代价 -68)
   ```

   ⇒ **G2 用 40% 的 elite 代价，拿到了比 M 更多的修复。**
   即 **在"修复 f1=0"这个目标上，`G` 支配 `M`。**

4. **两档共存的价值**：
   - `G1 K=2`：性价比档（付 elite −8%，拿 87% 的可得收益）
   - `G2 K=4`：强度档（几乎清零短局遗留 `shortZero` 4.97→0.63，但 elite −18%）
   **建议把两档都作为候选保留**，由产品在"精英密度"上做取舍，而不是二选一直接定案。
5. **两档的件数都恒为 389.0** ⇒ 均未增加固定产量（红线满足）。

## 3. 【§21-3】T 的 refinement 转化窗口分析

### 3.1 指标定义（本轮新引入）

按 §21 要求，**T 只作为"转化率辅助指标"，不得当作 F1 供给修复**。定义：

```text
转化窗口      = [首次 refining 访达, 末次 refining 访达]（取自日志 visit_marks）
可转化投放    = 战斗序号 <= 末次访达 的 f1 投放
转化率 convRate = 可转化投放 / 总投放
```

（日志中 `common_after_last_refinement>0` 即"供给存在但已无法花掉"的情形。）

### 3.2 结果

```text
  variant               f1zero  deliveries  convertible  convRate  runsConv supplyDelta
  BASELINE              2.67/8       46.83        41.06     87.7%   19.7/32        0.00
  T1 front-load         2.67/8       46.83        43.88     93.7%   21.4/32        0.00
```

### 3.3 裁定建议

1. 🔴 **投放守恒已证明**：`supplyDelta = 0.00` ⇒ **T 只搬运、不创造**。
2. **T 改善转化率 +6.0pp**（87.7% → 93.7%），可转化的局数 19.7 → 21.4（/32）。
3. **但对 `f1zero` 零效果**（2.67 → 2.67）⇒ **§21 的定性完全成立：T 不是 F1 供给修复。**
4. **T 的 headroom 只有约 12pp**（基线已 87.7%，上限 100%）——
   即使把转化率推到 100%，也修不了一个饥饿局。**T 不具备成为主杠杆的结构条件。**
5. **定位建议**：T 适合作为**"已有供给的交付质量"优化项**，
   与 M/G 的"增加供给"分开陈述、分开裁定。

## 4. 【§21-4】natural f1 pooled-rate 假设与选择效应

### 4.1 选择效应（量化）

```text
  pooled (all runs)          : 43/81 = 0.5309
  f1=0 runs only             :  0/6  = 0.0000   <- 结构性为 0（选择效应）
  non-zero runs only         : 43/75 = 0.5733
```

- **失败局只贡献 6 个 Common 胜场、0 次命中。**
- 用**失败局自身的观测率（=0）**去预测它未来的自然命中，是**循环论证**，且被选择效应压向 0。
- 这正是 R7 中 `--natural=observed` 会把握手塌到 `0/3` 的原因。

### 4.2 三种估计器 + 敏感性

```text
  rateFamily       base f1zero  base deliv   M+30 f1zero    M+30 elite
  pooled                2.67/8       46.83        5.14/8           120
  loo                   2.67/8       46.67        5.14/8           120
  shrink k=2            1.61/8       45.72        4.17/8           120
  shrink k=5            2.25/8       45.55        4.73/8           120
  shrink k=10           2.47/8       45.86        4.92/8           120
```

- `loo`（留一法，**去掉循环性**）与 `pooled` **结果完全一致**（2.67 / 5.14）
  ⇒ **本语料上 pooled 假设未被实质污染**，可直接沿用。
- `shrink`（Beta 收缩）随先验强度 `k` 从 2→10 单调收敛到 pooled（1.61 → 2.25 → 2.47），
  **这正是收缩估计应有的行为**，不是异常。
- 🔴 **关键稳健性**：五族估计器下 **`M+30` 始终显著优于基线**（4.17–5.14 vs 1.61–2.67），
  且 **`elite` 恒为 120** —— **rate 假设只影响收益侧的绝对水平，不影响成本侧，也不改变方向排序。**

### 4.3 裁定建议

1. **可以继续使用 pooled 率（0.5309）**，并有 LOO 作为独立佐证。
2. 但**所有绝对修复数应标注为"依赖自然命中率假设"**，建议报告时给出 `pooled–shrink_k2` 的区间
   （本轮 = 基线 `1.61–2.67/8`，`M+30` = `4.17–5.14/8`）。
3. **禁止使用"每局自身观测率"**（选择效应 + 小样本循环）。
