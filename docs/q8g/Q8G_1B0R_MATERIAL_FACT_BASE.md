## 0. 方法声明

- 本文以原文事实为基础，**并允许记录由多个原文事实严格推导出的世界规律**；原文事实、推导、世界模型判断、最终游戏设计必须分层，不得混称。
- **五类标注，不得混用**：

| 标注 | 含义 |
|---|---|
| 【原文事实】 | 原文原句 + 行号（① 层） |
| 【推导 D1–D3】 | 基于原文事实的结构化推导，必须引用依据事实（含 E 级）（② 层，正式中间层） |
| 【世界模型判断】 | 用户审阅层的结论（③ 层，本库不产生） |
| 【游戏设计】 | 1-B0-M 裁定后才产生（④ 层，本库不产生） |
| 【假设】 | 无充分依据的命题（如游戏自创名的原型猜测），**永远不得冒充①②** |

- **推导等级**（规格见工作单 §3.R.5）：D0 无法推导只能假设 / D1 单条事实弱推导 / D2 多条独立事实共同支持 / D3 多条事实 + 正向案例 + 反例边界条件。
- **"推导"不是降低标准**：我们不要求原文替我们设计好 RPG 数据结构；我们做的是**从原文提取规则，再做受约束的结构化推导**。推导可以成为后续设计的正式依据（进入 ③），但不得回写成 ①。
- 每条"材料 → X"关系**单独标注 E 级**（E0 无证据 / E1 共现 / E2 用途关联 / E3 明示用于该道炼蛊 / E4 明示属性或道痕）。
- 未命中关键词的**反证检索**明示登记于 §7，不得省略。

## 2. 世界模型级证据（原文如何组织蛊材——通用规则）

### 2.1 🔴 核心规则：材料按"道痕"组织，道痕决定用途与转数

**【原文事实 · 行 170534-170542】**（仙材理论段，完整语境）

> "仙材之所以能够炼成仙蛊，是因为**仙材本身蕴含着丰富的道痕**。"
> "蛊是大道的载体，为什么能够有威能？就是因为小小蛊虫的身上，蕴含着更多的道痕。"
> "**蛊虫身上的道痕越多，转数就越高**，威能就越奇妙。"
> "炼成仙蛊，便是将无数凡蛊、无数仙材身上的**道痕，提取出需要的部分，然后集于一处**。"

- 炼蛊本质 = 从材料与蛊身上**提取道痕**：**E4**
- **转数 = 道痕数量**（等级维度即道痕量）：**E4**
- 炼蛊 = 材料 + 蛊 双输入：**E4**（与游戏"蛊 + 材料"成本结构同构）

**【原文事实 · 行 170552】**

> "这块疑似斑虎蜜蜂的蜂翅，主要蕴含的是**金道道痕**。我若要炼制**金道仙蛊**，这就很有用途。可惜目前，对我炼制**星念仙蛊**没有多少帮助。"

- 材料带道属性 → 用于该道炼蛊（道专属性）：**E4**
- 同场景反例：金道材料对星念蛊无用（道专属性的否定侧证据）：**E4**

**【原文事实 · 行 398318】**

> "这里盛产**腐泥**，这是一种蕴含**毒道、土道道痕**的大众蛊材，极其普遍，烂大街的那种，**市价很低**。"

- 材料可携带**多重道痕**：**E4**
- 道痕普遍性 ↔ 市价（烂大街 → 市价低）：**E4**
- 同一材料跨两道（毒+土）：**E4**（跨道共存的正面案例）

### 2.2 材料形态 × 道属性的正交性案例（Q1 正向证据，R17）

| 案例 | 引文（行号） | E 级 |
|---|---|---|
| **骨 → 力道** | "象腿上的肉已经被他吃完，但**骨头也蕴含着天然的力道道痕**"（142182） | **E4** |
| **草 → 魂道** | "有一株幽冥草……身上蕴含着大量的**魂道道痕**，对魂道蛊仙相当有利"（165064） | **E4** |
| **蜂翅 → 金道** | "蜂翅，主要蕴含的是**金道道痕**"（170552） | **E4** |
| **泥 → 毒道+土道** | "腐泥……蕴含毒道、土道道痕"（398318） | **E4** |
| **尸躯 → 道痕载体** | "仙僵身躯中蕴含丰富的道痕。的确是**上佳的炼蛊仙材**"（168784）；"狐仙生前的肉身，却是纯净的**奴道道痕**"（152014） | **E4 / E3** |

> 【推导 D3】**材料形态与所承载的道痕属性是两个可分离的维度；同一形态不天然决定唯一道属性，道属性可以多重。**
> 简称：**形态 × 道痕正交**（仅此简称，不得推出更强命题——如"任意骨可承载任意道"——原文未证明）。
> 依据：4 条相互独立的 E4 正向案例（骨→力道 / 草→魂道 / 翅→金道 / 泥→毒+土）+
> 反例/边界条件 3 条（蜂翅金道对星念蛊无用 E4；精血用途受承载者道痕约束 E3；兽血≠蛊师精血按用途二分 E4）。
> 正交性无一句原文直接定义，但由多条独立事实严格推出——**此类推导可成为后续设计的正式依据**。

### 2.3 获取方式多样性（acquisition_mode 的原文证据）

| 方式 | 原文证据（行号） | E 级 |
|---|---|---|
| **交易 / 市场** | "集市中主要买卖的便是奶、酒等食物，或者是**兽皮、兽骨等等蛊材**"（279988） | **E3**（兽骨被明确称为蛊材并上市交易） |
| **击杀获取（兽体部件）** | 野猪"猪肉、皮毛、獠牙"三件收获（10970）；"荒兽身上的部件"为高价值参照（78018） | **E3** |

| **批量采购** | "收购了不少蛊虫，以及大量的炼蛊材料。一共花去他八块仙元石，数十万块元石"（87800） | **E3** |
| **喂养消耗（材料是需求端）** | "一块元石，能购买十片花瓣，**月光蛊每天消耗四片**"（3834） | **E3** |

> ✅ **审阅结论（2026-09-13）：可冻结**——1-B1 起材料系统直接把 `acquisition_mode` 当**正式设计维度**，

## 4. 正交性验证（Q1，R17 硬门）

**问题**：材料形态（物质种类）与道属性，是同一个维度还是正交的两个维度？

**正向案例**（形态 A 承载道 B）：象腿骨→力道（E4）｜幽冥草→魂道（E4）｜蜂翅→金道（E4）｜腐泥→毒+土（E4）｜仙僵尸→各类（E3）。

**冲突 / 反向案例**：
1. 蜂翅金道道痕"对炼制星念仙蛊**没有多少帮助**"（170552）——**E4**：道专属性成立，材料不是万能提痕机；
2. 力道仙僵的精血"无法供养祸心"（136242）——**E3**：承载者的道痕约束材料/资源的可用方向；
3. 兽血 vs 蛊师精血按用途二分（28492）——**E4**：同形态（血）不同来源层级，用途不同。

**反证检索**（详见 §7）：以"骨道材料""骨道蛊师用骨"等方向检索，未找到任何"骨=骨道专属材料"的明示；"道痕驳杂"命中均为福地/魂魄/真元语境，无材料语境。

**【推导 D3】（供 1-B0-M 审阅的核心推导，2026-09-13 审阅收紧表述）**：
> **在炼蛊语境下，道痕是材料用途与适配性的核心属性，物质形态本身不是用途分类的充分条件。**
> 原文明确证明的是：仙材蕴含道痕（E4）；炼蛊提取所需道痕（E4）；材料主要蕴含的道痕决定它适合炼什么（E4）；同一材料形态可对应不同道痕（E4，§2.2）。
> ⚠️ 本推导**不**声称原文存在一个叫"按道痕组织材料"的分类体系——只声称上述规律成立。
> 配套维度：来源生物层级（凡兽/荒兽/兽王/蛊仙/异人）与稀缺性共同影响**价值**（【推导 D2】，§5）。
> "某材料专属某道"的排他性**未获证实**（反证检索无果，§7）——按 R17，以"排他性不存在"的**弱命题**进入 ③ 层。
