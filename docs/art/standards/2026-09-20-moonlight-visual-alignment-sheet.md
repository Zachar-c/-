## 二、共享识别母题

本体层与收藏投影层必须稳定共享：

- 弯月主轮廓；
- 月核 / 月轮核心；
- 冷白到淡蓝的发光逻辑；
- 玉质、晶质、半透明材质；
- 圣洁、清冷、灵性；
- 柔美但带锋锐感。

识别问题：

> 不看名字，是否仍能判断她/它来自月光蛊？

## 三、收藏层不得脱源

主题层是本体层的投影，不是另起炉灶。

| 收藏投影元素 | 必须追溯到本体层 |
| --- | --- |
| 弯月头饰 / 月弧结构 | 本体弯月壳体 |
| 发光核心 | 本体月核 |
| 垂链 / 悬挂晶体 | 本体触须与晶体边缘感 |
| 服装流线 | 本体壳体与弧线逻辑 |
| 冷白淡蓝光 | 本体月辉与晶体内蕴光 |

如果某个设计无法说明来源，删除。

## 四、材质统一

两层统一使用：

- 冷玉；
- 晶体；
- 月辉；
- 半透明生命组织。

允许：

- 少量金属点缀；
- 少量月相纹样；
- 少量垂坠结晶。

禁止：

- 普通布料仙女风；
- 珠宝堆砌风；
- 宫廷换装风；
- 与本体材质割裂的另一个角色。

材质判断：

> 去掉角色轮廓后，剩余材质是否仍像同一只蛊？

## 五、光影统一

统一光影语言：

- 深色背景；
- 冷月主光；
- 克制的自发光；
- 静谧、空灵、干净；
- 强调内蕴发光。

禁止：

- 廉价特效爆闪；
- 全屏光爆；
- 颜色越亮代表越强；
- 神圣万能光；
- 与本体层光源逻辑冲突的独立打光。

光影判断：

> 光是否在说明力量状态，而不是只负责好看？

## 六、气质统一

冻结气质：

> 圣洁、灵性、清冷、静谧、锋锐、可亲近但不可轻佻。

收藏投影即使角色化，也不能变成：

- 轻佻卖肉；
- 俗艳媚宅；
- 普通手游老婆模板；
- 脱离蛊之本质的泛二次元换皮。

## 七、Prompt 必备块

后续月光蛊 Prompt 至少包含：

```text
[世界定位]
规则生命收藏世界

[资产层级]
Canonical Form / Collection Projection

[对象身份]
月光蛊

[共享识别母题]
弯月、月核、冷白淡蓝、玉晶、清冷气质

[来源追溯]
每个收藏投影元素必须对应本体层来源

[材质]
冷玉、晶体、月辉、半透明生命组织

[光影]
深色背景、冷月主光、克制内蕴发光

[气质]
圣洁、灵性、清冷、静谧、锋锐、不可轻佻

[禁止项]
普通仙侠、普通二游、旧水墨、珠宝堆砌、独立角色换皮
```

## 八、验收清单

每张候选图必须逐项通过：

```text
□ 是否仍能识别为月光蛊？
□ 是否共享弯月、月核、冷白淡蓝、玉晶材质？
□ 收藏投影是否明确不是世界事实？
□ 收藏投影是否能逐项追溯回本体层？
□ 材质是否与本体层同源？
□ 光影是否与本体层同源？
□ 气质是否保持圣洁、清冷、灵性、锋锐？
□ 是否没有变成普通仙侠、普通二游或独立角色？
□ 是否没有旧水墨回潮？
```

任一失败，退回。

- 恢复 A / B / C 档比较。

## 十、一句话标准

> 本体层证明“它是什么规则生命”，收藏投影证明“玩家为什么想拥有它”；两者必须看起来来自同一个美术宇宙。
