    工程教训

    我们曾经已经掌握了原作力量体系，却在抽象、数值化和 MVP 化过程中， 把原作规律从「系统约束」降级成了「内容参考」，最终重新发明出一个普通 Roguelike 的技能预算体系。

    抽象越漂亮、公式越统一时，必须检查：是否同时抽掉了这个世界真正独特的因果关系。有些「不规则」「不公平」「无法直接换算」的东西，本身就是《问真》的价值。
