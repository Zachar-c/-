## 1. 提取方法

不是"读一遍找名字"，而是三条互相印证的检索线：

1. **阶层检索**：先找原著自己给出的**战力阶梯**定义，再据此定 `rank`/`tier` 语义。
2. **命名收割**：按原著命名句式（`一头/一只 + 名`、`上古荒兽X`、`书名号`）做正则词频，剔掉
   "白眼狼"这类**成语/比喻用法**（它出现 9 次，全是骂人，不是生物）。
3. **行为取证**：每个候选回原文取上下文，抽取**可机制化的行为特征**（惧什么、怎么打、群体还是独行），
   而不是抄外观形容词。

### 决定性的第一条检索：原著自带战力阶梯

`蛊真人-clean.txt:18746-18754` 直接给出了可用于定档的口径：

> 兽王的威胁，比普通的野兽要高出许多倍。原因在于，它们的身上都会有一两只蛊虫寄生着……
> 兽王一旦遭受攻击，蛊虫也会出力帮助。
> ……从低到高，就可以划分为**百兽王，千兽王，万兽王**。
> - 千兽王（野猪王）："往往需要三支小组合作，才能艰难狩猎"，**前提是它早受了重伤**
> - 百兽王（石猴王）："一支寻常的五人小组，就能妥妥地收拾掉"
> - 万兽王（雷冠头狼）："则需要一干家老和族长合力，才能正面对抗"

这条直接把 `tier` 的语义锚定了：**百兽王 = common，千兽王 = elite，万兽王 = boss**。
而且"兽王身上寄生蛊虫、受击时蛊虫出力相助"正是既有 `reactions`（受击反制）字段的**原著依据**——
原来这个机制不是凭空设计。

### 第二条检索：僵尸阶梯与兽王阶梯互相印证

`45952` 写青毛僵尸"在夜间战力**相当于千兽王**"。两条独立检索线给出同一个量纲，
所以 `white_fur_jiangshi` → `black_fur_jiangshi` → `roaming_jiangshi` → `blue_fur_jiangshi`
可以直接沿用同一套 rank 语义，不需要另立一套。

## 4. 刻意**排除**的候选（避免把蛊仙级生物塞进凡人局）

原文 `87696` / `85466` / `315590` 给出生物层级：野兽 → 异兽 → （万兽皇）→ 荒兽 → 上古荒兽 → 太古荒兽，
且明确**荒兽"可媲美蛊仙战力"**。据此排除：

| 候选 | 原文定位 | 排除理由 |
|---|---|---|
| 太古寒蛟 | 独角、十多丈白鳞、"方圆百里空气温度急剧下降" | 太古级，远超凡人局 |
| 飓风狐 / 凤翼狐 | 原文称"普通荒兽" | 荒兽 ≈ 蛊仙战力 |
| 九尾狐 / 白角麒麟 / 冰瀑神猿 / 歧牙猪 / 天地沙鸥 / 戾血龙蝠 | 上古荒兽（蛊仙级战力/坐骑/食料） | 同上 |
| 六臂天尸王 | 是**杀招**（方源的招式），不是敌人 | 不是生物 |
| 白眼狼 | 成语用法（骂人），非生物 | 命名收割会误收，已剔除 |

保留在池内的 **血森狼属"异兽"**（原文列于"狼类的异兽"，非荒兽），**毒须狼王为百兽王**（可被常规小队处理），
两者都在凡人局的量程内。

## 6. 数据契约

- 新增敌人与既有 12 条**完全同构**：`id / theme / tier / rank / hp / turn / essence / clues / intent / reactions[/phases]`。
- `hp` 全部用小数值（3–20），不触碰中心 `beast_scale(rank)` 禁值（100/200/400/800/1600/3200）。
- `intent.kind` 只用在 V1 引擎**真实结算**的四种上：`attack`（默认）/ `seal` / `soul_drain` / `counter`。
- `reactions[].counter_status` 只用既有值 `bound` / `guarded`（`sparked` 是既有孤例，未扩散）。
- ~~顺带发现：`turn` 与 `essence` 在 V1 引擎中零消费点~~ → **已退役（2026-09-10 用户裁定）**：
  两个字段已从全部条目移除，`content_catalog` 的 `turn ∈ 1..5` 校验一并删除。
  退役时按用户要求**明确战力阶梯**（见下节）。

## 7. 战力阶梯（2026-09-10 用户裁定，随死字段退役一并立起）

    凡人 < 普通野兽 < 一转蛊修 < 二转 < 三转 < 四转 < 五转

- **蛊修最低一转** ⇒ `grade == "cultivator"` 的条目 `rank` 必须 `>= 1`；
  反过来 `rank 0`（未入转档）只可能是**普通野兽 / 凡人 / 不入转的异变体**。
- 新增 `grade ∈ {mortal, beast, cultivator, anomaly}`（阶梯**类别**），与 `theme`（阵营/态度）正交——
  散修 `theme=neutral` 但 `grade=cultivator`，山间猎户 `theme=neutral` 但 `grade=mortal`，
  所以类别不能由主题反推。
- 立起这条规则时**抓到两处既有不一致**，已按原著修正：

  | 条目 | 原值 | 现值 | 依据 |
  |---|---|---|---|
  | `neutral_stone_wanderer` 石甲散修 | rank 0 | **rank 1** | 散修就是蛊修 → 最低一转 |
  | `white_fur_jiangshi` 白毛僵尸 | rank 1 | **rank 0** | "战力最弱，还不如寻常野兽"（`L45664`） |

- 补齐阶梯底部的两条（此前 rank 0 只有草人傀儡，普通野兽与凡人缺席）：
  `mountain_boar` 山猪（普通野兽，`L10702`/`L2066`）、`mountain_hunter` 山间猎户（凡人，`L2028`）。
- 校验落在 `enemy_catalog.validate`：类别白名单 + "蛊修最低一转"；守卫见
  `test_enemy_catalog.gd::test_real_catalog_keeps_the_cultivator_floor_at_one_turn`。
