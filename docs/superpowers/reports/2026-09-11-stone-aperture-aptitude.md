## 1. 元石：货币 + 真元电池，且会物理缩水

| 属性 | 原句（高） |
|---|---|
| **本质** | 「**元石是这个世界的货币，用于衡量一切商品的价值**」 |
| **物理** | 「元石是一种**椭圆体半透明的石块，灰白色**，随着石内**天然真元不断损耗，它的体型也会不断缩小**」 |
| **性质** | 「元石是**大自然的瑰宝，凝聚着天然真元，可以被蛊师吸收**」；「在这个世界上，元石是**硬通货**，购买力很强」 |
| **购买力** | 「对比一下黄金，因此元石的购买力也相当的惊人」 |
| **使用观** | 「**元石是拿来用的**，像个守财奴积蓄元石，干嘛成为蛊师呢」 |

**⚠️ 最关键的一点：元石是双重职能，不只是钱。**

- 作为货币：「掏出元石购买」「十七块元石还不够呢，至少得三十块元石」
- 作为**真元补充**：「侄儿正需要**元石来补充真元**呢」「他本身只有丙等资质，但为了追求修行速度，一直在**利用元石补充真元**」
  「一组五人……其余三人在**用元石快速地补充真元**」

⇒ **元石 = 可携带、可计价、可被吸收的真元容器**。它把「经济」与「修行」焊在同一个物品上。

**获取途径**（原句）：**考核与晋升奖励**为主——「获十块元石奖励」「率先晋升到一转中阶……获得三十块元石之奖励」「年末考核的第一，似乎可以获得一百五十块的元石奖励」；
另有「之所以修行就是为了赚取更多的元石」（动机层面）。

## 2. 仙元石：同形异级的另一档通货

| 属性 | 原句（高） |
|---|---|
| **物理** | 「仙元石同样是鸭蛋大小，却不是椭圆，而是**圆珠状**」 |
| **层级比喻（原文自己给的）** | 「**如果将元石比作凡人，那么仙元石就是蛊仙**」 |
| **职能** | 「仙元石十分珍贵，可以用来**补充仙元**，同样的也是**蛊仙交易时采用的珍贵货币**」 |
| **稀缺** | 「这两块仙元石，价值极高，**两亿块元石也换不来**」 |

**量级锚点**（原句，用以估算比值）：
- 「用**一块仙元石**，将南海龟仙手中**三万头龟背狼**买下，同时还有一只龟背万狼王」
- 「一共花去他**八块仙元石，数十万块元石**」（同一次交易中两者并列 ⇒ 1 仙元石 ≫ 10⁴ 元石）
- 拍卖：「**四十五块仙元石**，拍卖两百多万亩的天魁云」
- 服务定价：「毒气吐纳需要**两块仙元石**，群力蛊的蛊方则也卖两块仙元石」

⇒ **比值无精确原文，量级约 1 : 10⁴–10⁵**；且**结构上与元石完全同构**（形态不同、职能相同：补充对应层级的能量 + 充当该层级的货币）。
**这正是"元石比作凡人，仙元石就是蛊仙"的机制含义**：货币层级 = 修行层级。

## 3. 资质：它不是独立属性，而是「元海/空窍」的填充率读数

**原文把四档与修为上限逐条列全了**（高，一段之内）：

> 「**丁等资质，元海占据空窍两三成**，往往最高能修行到**一转二转**。
> **丙等资质，元海是空窍的四五成**，通常会停在**二转境界**，只有很少一部分能侥幸突破到**三转初阶**。
> **乙等资质，元海占据整个空窍的六七成**，能修到**三转，甚至四转**。
> **甲等资质，元海充足，是空窍的**成**，这样的人自然天赋最高，最适合蛊师修行，能修行到**五转**。」
> 「至于**六转向上的蛊师，每一个都是传奇**……我们古月一族，也没有出现过六转蛊师」

（原文甲等那处有缺字，从语义与上下文推断为「八九成 / 十成」——`推断（低）`）

**由此得到核心机制链**：

```
资质（甲乙丙丁）
   │ 决定
   ▼
元海占空窍的比例（2-3成 / 4-5成 / 6-7成 / 8-10成）
   │ 决定
   ▼
真元总量上限
   │ 决定
   ▼
可修到的最高转数（一二转 / 二转 / 三四转 / 五转）
```

**资质还会动**（双向，均有原句）：
- **可升**：「**血颅蛊**，可以斩杀亲族，提纯出血泉，**灌溉空窍，提升资质**」
- **可降**：「**空窍一旦受伤，轻则修为下降，重则资质降低**」
- **可被污染致降**：「留在空窍中，时间长了，更会**污染光膜窍壁**，使得自身资质下降」
- **真元回复速率也随它变**：「像方源这种丙等资质，**大约一个小时补充四分真元**」
- 佐证：「元海只达到整个空窍的**四成四**，这是方源**丙等资质的局限**」

⇒ **资质 = 容器（空窍）与填充物（元海）的比例读数**，可被提升（蛊）、被损伤（受伤）、被污染（滞留物）三条路径改变。

## 4. 空窍：球形光膜容器，内含元海

| 属性 | 原句（高） |
|---|---|
| **异空间** | 「空窍玄妙异常，虽然**寄托在方源体内，但是却不和五脏六腑同处一个空间**」 |
| **别名** | 「不过更多人称之为**元海空窍**」 |
| **形状** | 「整个空窍呈**球形**，空窍表面流动着白光，是一层**光膜**」 |
| **结构必要** | 「正是因为有了这层**光膜**，才**支撑着空窍，不会塌陷**」 |
| **内容物** | 「**空窍之中，自然就是元海**」 |
| **可损** | 「**光膜窍壁**」会被污染 ⇒ 资质下降（§3） |

⇒ 空窍是**容器**，元海是**容器内的液面**，真元是**液面的量**。三者是 `容器 ⊃ 填充物 ⊃ 可耗资源` 的**包含关系**，不是并列。

## 5. 四者关系闭环（本报告的骨架）

```
        ┌──────────────── 元石（货币 + 真元容器，会缩水）
        │                   │ 补充            │ 兑换（极不对称 ~1:10⁴⁻⁵）
        │                   ▼                 ▼
        │              真元（可耗资源）    仙元石（仙级同构物，已裁）
        │                   ▲
        │                   │ 上限由…决定
        │            ┌──────┴──────┐
        │            │   元海(液面) │
        │            └──────┬──────┘
        │                   │ 填充率 = 资质
        │                   ▼
        │            空窍（容器 · 球形 · 光膜支撑）
        │                   │
        │   受伤/污染光膜 ───┘─── 反向拉低资质
        │
        └──→ 资质 ──决定──→ 可修到的最高转数 ──门槛──→ 可催动的蛊
```

**两条最易被设计做错的**：
1. **资质是"读数"不是"根属性"**——原文里它由元海/空窍比例定义，所以提升资质的正确做法是"改变容器或液面"，而不是"直接加一个 aptitude 数字"。
2. **元石与真元不是两套系统**——元石本身就是真元容器，所以"花钱"和"耗真元"在原文里可以互相转化。

## 6. 战力观

**分级主轴：转数（1–9）+ 造诣境界**

| 维度 | 内容 | 频次 |
|---|---|---|
| 转数 | 一转 671 / 二转 696 / 三转 1077 / 四转 1050 / **五转 1388** / 六转 1583 / 七转 2604 / **八转 4451** / 九转 1021 | 频次（高） |
| 转内细分 | 初阶 / 中阶 / 高阶（「三转初阶」「五转高阶」） | 原句（高） |
| 造诣境界 | 大师 608 < 宗师 877 < 大宗师 399；**宗师可构思全新杀招** | 原句（高） |
| 顶层 | 仙尊 3928 / 准无上 98 / 无上 344 | 频次（高） |
| 兽分级 | 「**百兽王，千兽王，万兽王**」（十进） | 原句（高） |

**⭐ 战力公式（原文直接给出）**：

> 「因此**一位五转蛊师的战力，就得看其掌握的五转蛊是什么，有多少只**」

⇒ **战力 = 转数（资格门槛） × 蛊的「质量 × 数量」**

**且不同流派判定维度不同**（重要，防止做成单一战力值）：
- 「**奴道蛊师的实力如何，要看手中的兽群规模**」
- 「若是按照兽群的规模大小……从低到高，就可以划分为百兽王，千兽王，万兽王」
- 佐证速度维度：「是北原屈指可数的**飞行大师**」

## 7. 经济观

| 层面 | 原文 |
|---|---|
| **货币层级** | 元石（凡）↔ 仙元石（仙），**原文自设比喻**：「元石比作凡人，仙元石就是蛊仙」；**单向升级**（凡→仙），无反向兑换记载 |
| **价值来源** | 元石 = 「大自然的瑰宝，**凝聚着天然真元**」→ **价值来自能量本身**，不是信用 |
| **损耗性** | 「随着石内天然真元不断损耗，**体型也会不断缩小**」⇒ **持有即有损耗**（天然的"囤积惩罚"） |
| **流通场所** | 店铺（砍价、掏元石）、**拍卖行**（四十五块仙元石/天魁云）、商队（`caravan_offers`）、宝黄天（物资漂浮售卖） |
| **获取途径** | 考核奖励（10/30/150）、晋升奖励、任务、狩猎与贩卖战利品 |
| **消费观** | 「**元石是拿来用的**，像个守财奴积蓄元石，干嘛成为蛊师呢」⇒ 原文**反对囤积** |
| **稀缺表达** | 「瑶池地下有元石矿脉」（产地）；「两亿块元石也换不来」（极端稀缺） |

⇒ **经济观一句话：价值＝能量，货币＝能量容器，持有会损耗，所以钱必须流动。** 这与我们"资源紧张"的设计意图同向。

## 9. ⚠️ 对我方实现的启示

### 9.1 同构度高的部分（**不需要改，只需知道它同源**）

| 项 | 原文 | 我们 | 判定 |
|---|---|---|---|
| 资质→容量 | 元海占空窍比例 → 真元上限 | `essence_max = essence_base(10) × aptitude_factor(4/3/2/1) × cultivation_factor(1/3/9/27/81)`（`essence_capacity.gd:5-18`） | ✅ **我们的 `aptitude_factor` 就是"填充率"的抽象** |
| 资质→回复 | 丙等「一小时补四分真元」 | `regen_pct = {jia:40, yi:30, bing:20, ding:10}`（`aptitude.json`） | ✅ 同向 |
| 空窍 | 球形光膜容器，内有元海 | `state.cave_aperture{essence, essence_max, essence_regen_per_turn}` | ✅ 同构 |
| 资质可升 | 血颅蛊灌溉空窍 | `raise_aptitude`（洗髓换骨：**10 寿元 + 8 元石**，限 1 次/局，`aptitude.json.paths`） | ✅ 有；但原文是**蛊**驱动，我们是寿元+元石 |
| 战力公式 | 转数 × 蛊（质×量） | `stage_base{one:10,two:30,three:60,four:100,five:150}` + `boss_layer_mult` + `aptitude_mult` | ✅ 同构 |
| 货币层级 | 元石↔仙元石（凡↔仙） | 单货币（正确裁剪） | ✅ 合理 |

### 9.2 缺口（3 项，按价值排序）

1. **元石缺"补充真元"职能**（`推断（低）`→但原句密集）
   原文里元石**最日常的用途之一就是补真元**，我们只有计价职能。
   现成钩子：`aptitude_recovery_multiplier`（`balance.json:17` = 0.5）+ `GuBalance` 的 `natural_recovery_cost_ratio`。
   ⇒ 可做「**花元石换真元**」的动作（等价于原文的"用元石补充真元"），零新系统。
2. **缺"资质可降"路径**——原文有**三条**降资质通道（空窍受伤 / 光膜污染 / 滞留物），我们完全没实现。
   ⇒ 这正是 `gu-everything-mapping.md` 里 **M3 道痕伤势**该挂的落点：**道痕伤势 = 污染光膜 ⇒ 降资质**，
   天然形成"变强→留痕→伤身→上限下降"的闭环，把原文的因果链补全。
3. **空窍缺"光膜/窍壁"受态度**（当前只有数值容量，没有损伤态）。
   ⇒ 与 2 是同一件事的两面（容器受损 ↔ 读数下降）。

### 9.3 发现的两处**命名隐患**（非 bug，但会误导改动）

| 隐患 | 详情 |
|---|---|
| **`regen_pct` 同名双源、数值不同** | `aptitude.json.regen_pct = {jia:40,yi:30,bing:20,ding:10}` → **真元回复**（`essence_capacity.gd:22`）；`v1_battle.json.regen_pct = {jia:35,yi:30,bing:25,ding:18}` → **战斗内 true_qi 回复**（`v1_battle_resolver.gd:72`，`_ceil_pct(true_qi_max, …)`）。两者服务**不同资源**却同一个键名 ⇒ 建议改名 `essence_regen_pct` / `battle_qi_regen_pct` |
| **`aptitude_factor` 与 `aptitude_mult` 同一张表两次定义** | `aptitude.json.aptitude_factor` 与 `v1_battle.json.aptitude_mult` 都是 `4/3/2/1` ⇒ 双源，改一处会漂移 |

（两处均**未改动**，仅报告；改名涉及契约与测试，需单独任务。）
