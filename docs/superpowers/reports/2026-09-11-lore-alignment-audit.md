- 日期：2026-09-11
- 评估对象：本项目当前实现（tip `8bdec86` 之后的代码与数据）
- 评估依据：`分支：六卷精编版/蛊真人-clean.txt`（23MB 原文）与 `肉鸽设计-原始数据/`（13 份带行号索引的检索提炼）
- 方法：先归纳文本核心理念 → 逐条对照实现（每条给「原文依据 + 代码依据」）→ 判定符合/偏离/未覆盖

## 一、文本核心实践理念（我的理解）

### 1. 蛊是「手段」，蛊师是「主体」

> 「蛊师以自身元海为基石，以蛊虫为手段。蛊是蛊师的必备之物，没有蛊，就谈不上蛊师。」（行 15724）
> 「蛊师用蛊，其实利用的是各种大道法则的碎片。蛊是碎片的载体，是一种天然的工具。」（行 53880）

蛊不是宠物也不是装备，而是**载着法则碎片的工具**；主体是蛊师自身的元海/身体。

### 2. 养·用·炼三支柱，且「都要花钱」

> 「养用炼，是蛊师修行的三大方面。」（行 50186）
> 「蛊师炼蛊用钱，养蛊用钱，练习使用蛊虫也得耗钱。」（行 4036）

三支柱不是三条平行的技能树，而是**共同压在同一个经济池上**——这是文本最稳定的张力来源。

### 3. 蛊的数量被「养得起」硬约束

> 「一般的蛊师，都只能喂养同转蛊虫四五只的数量。所以，往往蛊师并非是单人行动，而是形成五人小组，最少也会有三人。」（行 10874）
> 「蛊师在前期，很难独自面对复杂的环境……因此常常以小组形式行动。」（行 14008）

限制蛊数量 → 逼出**组队**这一社会行为。数量上限不是数值设计，而是**社会关系的成因**。

### 4. 高阶 = 高代价，用蛊有风险

> 「蛊虫越是高级，喂养的费用就大大增加。越到高阶，蛊虫用起来就越不方便，需要付出一定的代价。就好像是婴儿挥舞大铁锤。」（行 21664）
> 「用蛊有风险，炼蛊须谨慎。」（行 52524）
> 「铁骨蛊……一经使用，就是极限剧痛。偏偏这种痛楚只能忍受住，一旦在中途晕厥过去，那就前功尽弃了。」（行 41310）

强度与代价绑定，且代价是**身体性的、要忍的**。

### 5. 炼蛊必然失败，失败即浪费

> 「你有没有考虑过，炼蛊过程中的失败？你不可能不失败，一旦失败，就会浪费仙元。」（行 71068）
> 「不败传承奖励，消除失败概率……一道成功道痕仅用于六转仙蛊……无法夺取和转移。」（行 153842）

失败是常态；**消除失败本身就是极稀有的奖励**。

### 6. 道痕：身体的修行积累，会干扰、能致伤、可观测

> 「每一次渡劫成功，蛊仙身躯都会增加本道道痕。」（行 138684）
> 「金道道痕，排斥黑楼兰仙体的力道道痕，抵制了大力仙体的恢复能力。」（行 131742）
> 「荒兽造成的伤口，就遗留道痕。道痕伤势，十分难缠，不仅抵消本身的恢复能力，而且还会阻止蛊虫的疗伤效果。」（行 131976）
> 兼修两道时「两种道痕混杂」，而变化道靠「用相应的蛊虫冲刷身体，将残留的道痕印记洗干净」（行 131610）
> 线迹蛊可显化道痕、据残留道痕推测对手境界与手段（行 132322）

道痕是**刻在身体上的修行史**：可积累、会互相排斥、能造成难缠伤势、可被观测（情报手段）。

### 7. 灾劫：周期性风险，渡劫即收获

> 六转：每 10 年地灾、每 100 年天劫；七转：外加每 50 年天罚；八转：每 10 年天劫、每 50 年浩劫、每 100 年万劫（`03-灾劫` 摘要）
> 「搬走资源可降低灾劫难度」，但「灾劫威力暴降，道痕收获不变」（行 150130 / 171180）

灾劫是**无法回避的周期**，也是道痕的主要来源——风险与成长同源。

### 8. 炼道有境界层级，且境界决定「创造」能力

> 大师级：可炼制仙蛊但成功率有限（行 92324、93336）
> 宗师级：**可构思全新杀招**、逆推蛊方（行 105532、124444）
> 大宗师级：可设计完整仙蛊屋（行 109570、159694）

「创造权」由修行深度解锁——这与"玩家自由组装"是同一件事的两个尺度。

## 三、判断依据与偏离性质分析

### 3.1 骨架一致度：高

文本的**主轴**（蛊为手段、养用炼共担经济、失败常态、高阶高价、代价须真实）在我们的数据模型与规则里**逐条可对应**，
且多处不是"照抄名词"而是"复刻结构"：

- 行 4036「炼蛊用钱、养蛊用钱、练习也得耗钱」→ 我们把它做成**念头作为跨系统的共用预算**（既是战斗操作上限，
  也是炼蛊投入），这正是三支柱共担经济在机制上的同构物。
- 行 37030「炼蛊分合炼、逆炼」→ 我们合炼（refine）与拆解（dismantle）都在，**逆炼没被漏掉**（这点常被做丢）。
- 行 71068 的失败浪费 → `success_roll_max` 真 roll 且**快照直显失败率**，代价对玩家可见。

### 3.2 偏离的三类性质（这是评估的重点）

**A 类 · 有意取舍（与文本冲突，但有产品理由）——1 项**

- **#9 蛊数量无上限**。文本用"养不起"逼出组队；我们是**单人 roguelike**，组队前提不存在，
  于是改用喂养成本 + 念头做软约束。**代价**：文本里"资源紧张"的锐度被明显钝化——
  现在玩家可以囤积大量低阶蛊而不受结构性惩罚，而这是原文最真实的压迫感来源。
  **判断**：取舍合理，但**软约束是否够硬需实测**（当前没有"蛊太多导致喂养崩盘"的体验证据）。

**B 类 · 真空缺，且缺失的是「身体/修行层」——5 项（#10–#14）**

它们有一个共同点：**文本里"越强越危险、越深越受限"的机制层，我们整体没有**。

- **道痕**缺失影响最深：它是原文里唯一同时承担**成长（积累）、代价（排斥/清净）、伤势（难缠）、情报（观测）**
  四种功能的概念。我们把它降级成了一个**无规则效果的分类标签**（`school` 字段）。
  ⇒ 直接后果：**兼修多道没有任何代价**（原文：两道道痕混杂会互相干扰），这使得"跨道构筑"变成免费加餐。
- **灾劫**缺失 ⇒ 玩家没有"必须面对的周期性风险"，风险全部来自玩家主动选择（进战斗/进节点），
  与文本"劫数自来找你"的体感相反。
- **熟练度**缺失 ⇒ 蛊只有"有没有"，没有"用得好不好"，少了一条低成本的成长轴。
- **炼道境界**缺失 ⇒ 原文"宗师可构思全新杀招"是**创造性玩法的解锁门槛**，而我们的杀招设计（见另一份 spec）
  没有境界门槛，任何玩家一开局就能保存杀招。

**C 类 · 未覆盖但可不覆盖（层级/篇幅原因）——#14、#15 的大部分**

仙蛊唯一性、三层货币、垄断与贬值，都属于**高转层**内容；Demo 的 `cultivation` 上限为 5（one–five），
尚未进入"蛊仙"尺度，属于可接受的范围裁剪。

### 3.3 一个值得注意的结构性观察

文本的实践理念呈现**「三支柱 × 三层深度」**结构：

```
         经济（钱/元石/仙元石）
              │  压力
   ┌──────────┼──────────┐
  养         用          炼
   │          │          │
 喂养成本   熟练/代价   失败率
   │          │          │
   └────── 道痕（身体层的统一载体）──────┘
              │
            灾劫（周期性风险与收获）
```

我们实现了**下面一行（三支柱）**，而**道痕这一"身体层"整体缺席**——
它是把三条支柱与风险系统缝在一起的那根线。这是本次评估最主要的发现。

## 四、结论

| 维度 | 判定 |
|---|---|
| 蛊为核心的数据模型与实例结算 | **高度符合** |
| 养·用·炼三支柱及其经济共担 | **高度符合**（念头共用预算是亮点） |
| 合炼/逆炼双通道 | **符合** |
| 失败率与代价可见性 | **符合** |
| 高阶代价、用蛊风险、预检红线 | **符合** |
| 蛊数量约束 | **有意偏离**（单人局取舍，但软约束力度待实测） |
| 道痕（成长/代价/伤势/情报） | **未覆盖（最大缺口）** |
| 灾劫、熟练度、炼道境界 | **未覆盖** |
| 仙蛊唯一性、多层货币、组队 | **未覆盖（层级裁剪，可接受）** |

**总体判断**：实施抓住了文本的**机制骨架**（这比名词还原更重要，也是多数同类项目会做丢的部分），
但在**"身体层/风险层"**整体留白——道痕、灾劫、熟练度、炼道境界属于同一族缺失。
它们不是彼此独立的功能点，而是同一条线：**文本用"身体上的积累与伤痕"把成长和代价绑在一起，我们目前把成长和代价分开了。**

## 五、若要收敛缺口，优先级建议（不涉及本次改动）

| 优先级 | 项 | 理由 | 最小切入 |
|---|---|---|---|
| P1 | **道痕**（先做"兼修代价 + 道痕伤势"两点） | 同时补上"跨道构筑的代价"与"伤势难缠"，且能复用一个 `school_rules` 风格的域函数 | 身体上的 `school_marks` 层数 + 跨道干扰惩罚 + 治疗减益状态 |
| P2 | **炼道境界闸门**（大师/宗师） | 与已设计的杀招系统直接咬合：宗师解锁"保存全新杀招"，让创造权成为成长奖励 | 复用 `cultivation`/图鉴，按转数或炼蛊次数解锁保存权限 |
| P3 | **灾劫的轻量版** | 给"周期性风险"一个 Demo 尺度的对应物（按层数推进的固定劫数） | 层间事件 + 渡劫给道痕，不做十年/百年周期 |
| P4 | **用蛊熟练度** | 低成本成长轴 | 按实例的使役次数给微幅增益，进事件日志 |
| 观察 | **蛊数量软约束力度** | 判断 A 类偏离是否需要补强 | 实测"大量低阶蛊"是否真的造成喂养压力 |
