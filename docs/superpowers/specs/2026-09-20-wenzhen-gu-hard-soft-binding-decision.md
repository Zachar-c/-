## 一、核心裁定

结论：

> **“原著明确描述”不自动等同于视觉 HARD。**

原因：

原著描述存在不同层级：

```text
对象身份约束
      ↓
稳定本体描述
      ↓
功能表现描述
      ↓
使用状态表现
      ↓
文学修辞描述
```

只有会影响“这个对象是什么”的描述，才升级为 HARD。

因此：

```text
v3 HARD/SOFT 标签
+
双层表现体系
```

不是互斥关系。

实际优先级：

```text
身份约束判断
        ↓
HARD / SOFT / OPEN 分类
        ↓
本体层 / 表现层 / 主题层分配
```

## 二、HARD 判定规则

### HARD 定义

视觉 HARD：

> 改变后会让玩家无法确认这是同一个蛊，或者破坏原著明确身份识别。

满足以下任一条件：

### HARD-1：原著明确规定核心外形

例如：

```text
石皮蛊
= 石质外观是其核心识别
```

如果改成：

```text
纯水流生物
机械少女
```

则改变对象身份。

判定：

```text
HARD
```

### HARD-2：外形与能力不可分离

例如：

某蛊的能力依赖：

- 身体结构；
- 材质；
- 特殊器官；
- 明确形态。

修改会导致：

“为什么它能拥有这个能力？”

则：

```text
HARD
```

### HARD-3：原著反复强调且作为识别符号

单次描写不一定。

如果：

- 多次出现；
- 人物通过外形识别；
- 剧情依赖该形态；

则：

```text
HARD
```

## 三、SOFT 判定规则

### SOFT 定义

> 有视觉描述，但该描述不是对象身份的唯一来源。

例如：

原著描述：

- 像某种东西；
- 类似某种生物；
- 某种光影效果；
- 某种气质。

但没有证明：

“这就是它存在的本质”。

则：

```text
SOFT
```

### SOFT 可以重新设计

例如：

原著：

> 某蛊散发月光。

不能直接推出：

```text
必须是一只月亮形昆虫
```

可以设计：

- 晶体结构；
- 灵体结构；
- 器物形态；

只要：

```diff
月光属性
+
能力识别
+
世界逻辑
```

成立。

## 四、OPEN 定义

OPEN：

> 原著没有足够视觉限制。

允许最大创造。

但仍需满足：

```diff
能力逻辑
+
流派逻辑
+
世界观一致
```

## 五、双层体系优先级

最终关系：

```text
             原著身份
                |
        -----------------
        |               |
     本体层          表现层
        |
   HARD约束

SOFT/OPEN
可进入：

- 本体创新
- 主题层
- 表现层
```

## 六、本体层规则

本体层不是：

“原著所有描写的集合”。

本体层是：

> 玩家在《问真》世界里认为真实存在的蛊。

因此：

### HARD

必须进入本体层。

### SOFT

默认进入本体层，但允许设计空间。

条件：

不能违反：

```text
能力
身份
流派
功能
```

### OPEN

自由创造。

## 七、用时形态规则

蛊存在：

```diff
本体形态
+
能力表现形态
+
特殊状态形态
```

三者必须区分。

### 1. 本体形态

定义：

蛊真实存在的形态。

归属：

```text
本体层
```

例如：

某蛊本身是一块玉。

### 2. 用时形态 / 催动表现

定义：

蛊发动能力时产生的外在效果。

例如：

- 光芒；
- 巨大虚影；
- 能量投射；
- 法相。

归属：

```text
表现层
```

不能反推：

“蛊本体就是这个效果”。

### 3. 化形

需要进一步区分。

#### 如果化形是能力状态产生的人格投影

归属：

```text
表现层
```

例如：

战斗时出现的人形虚影。

#### 如果化形是蛊真正生命阶段变化

归属：

```text
本体层
```

因为它改变存在状态。

## 八、主题层边界

主题层允许：

```text
HARD以外
+
不破坏身份
```

进行表达。

### 可以覆盖：SOFT

可以。

例如：

原著：

“类似某种虫”

主题：

“拟人化角色”

允许。

### 可以覆盖：OPEN

完全允许。

### 不可以覆盖：HARD

禁止。

除非主题明确说明：

> “幻想皮肤 / 角色化表现”。

且玩家仍可识别：

这是同一只蛊。

## 九、主题层禁止事项

### 1. 把能力外观替代本体

错误：

```text
月光蛊皮肤：
月光少女

然后游戏认为：
这就是蛊本体
```

### 2. 改变规则身份

错误：

```text
防御蛊皮肤
变成攻击型武器少女
```

### 3. 完全失去蛊识别

错误：

玩家看到：

```text
这是一个普通角色。
```

不知道：

```text
这是某只蛊。
```

## 十一、原待 L0 事项与裁定结果

L0 已在《蛊虫双层表现体系 v2.0》中完成裁定。

### 1. HARD 蛊是否允许完整人格化主题皮肤

例如：

```text
石皮蛊

本体：
石质蛊

主题：
石灵少女
```

这属于商业表现取舍。

裁定：

- 主题层允许达到角色级质量；
- HARD 蛊可以进入主题层，但前提是主题皮肤明确标注为幻想表现，且玩家仍能识别其对应的蛊；
- 主题皮肤不得替代本体，也不得改变世界事实。

### 2. 主题层覆盖范围

主题层是否开放：

```text
全蛊
```

还是：

```text
指定收藏蛊
```

这是内容规模问题。

裁定：

- 不对全部蛊平均开放制作；
- 主题皮肤按高辨识度、高使用率、高收藏价值、高情感潜力筛选；
- 第一批只考虑核心代表蛊、具有人格空间的蛊、商业收藏蛊三类；
- 三类是筛选类别，不是 A/B/C 生产档。

### 3. 拟人化比例

例如：

```text
轻度人格化
|
半人形
|
完整角色化
```

这是产品审美取舍。

裁定：

- 取消 A/B/C 人格化生产档；
- 统一为高完成度主题皮肤；
- 允许拟人化、角色化、概念化和风格化；
- 不制作低价值过渡档。

## 十二、最终裁定摘要

```text
原著明确描述 ≠ 自动 HARD。

HARD 判断核心：
是否影响“它是谁”。

本体层承载真实世界。

主题层承载玩家表达。

SOFT 是最大的设计空间。

用时形态属于表现层，
除非原著证明其为真实存在形态。

Worker 不得只看 HARD 标签，
必须同时检查：
身份、能力、流派、本体/表现层归属。
```
