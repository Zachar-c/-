# 「問眞命簿」视觉方向设计

> 日期：2026-09-04  
> 状态：✅ 2026-09-06 用户复核通过，**视觉方向定稿**（「問眞命簿」冷峻旧宣纸志怪绘卷）；实现按 `2026-09-05-architecture-refactor-master-plan.md` Phase A 推进

## 1. 设计结论

本项目采用 **「問眞命簿」——冷峻旧宣纸志怪绘卷** 作为统一视觉方向：

> **浅纸墨规则界面 × 暗色南疆志怪叙事插画 × 稀有概念色**

界面像一本冷静记录修行者一生的旧宣纸命簿，以墨线、契书、朱批和路线呈现规则；界面之下展开湿冷、辽阔、带有生物恐怖感的中国志怪世界。

核心矛盾是：

> 用秩序井然的纸墨系统，记录一个弱肉强食、万物皆可炼化的世界。

核心判断是：

> **规则是纸上的，代价是活的。**

这不是对现有“問眞”浅色 UI 的推翻，而是为它补足叙事插画、蛊虫生命感、世界尺度和高阶概念表达，使现有界面从“整洁的纸墨工具”成长为“记录一世因果的命簿”。

## 2. 目标

1. 让玩家第一眼辨认出项目属于中国志怪与蛊道世界，而非通用仙侠卡牌游戏。
2. 让每项资源、契约、路线和选择都像一笔会结算的因果，而不是孤立数值。
3. 保持战斗、地图、炼蛊与结局的信息清晰度，不让装饰压过规则。
4. 建立凡俗、蛊仙、尊者三个层级不同但连续的视觉尺度。
5. 让蛊虫显得是需要喂养、炼化并承担风险的生命与资产，而非一次性法术图标。
6. 以少量、准确的动效和概念色表达重大变化，避免用效果密度冒充力量感。

## 3. 非目标

本方向不追求：

- 金边、宝石、镜面高光组成的商业仙侠卡牌质感。
- 霓虹法阵、彩色辉光和持续粒子构成的法术奇观。
- 纯黑底、血红字占主导的暗黑 HUD。
- 日式华丽卡框或角色立绘压倒规则信息的收藏卡牌界面。
- 堆叠卷轴、祥云、窗棂、印章等符号形成的伪古风装饰墙。
- 玻璃卡片、渐变文字、大圆角和无语义的现代应用样式。
- 为尚未确定的系统预建主题框架、Shader 管线或第二套 UI 体系。

## 4. 与现有视觉系统的关系

### 4.1 延续的现行基础

生产界面继续遵守现有展示层架构和“問眞”主题约束：

- 正式屏幕使用原生 `.tscn` 场景与绑定 GDScript。
- 屏幕继续通过 `instantiate() → mount_snapshot(snapshot, commands)` 装载。
- UI 只读取快照、发出命令；规则、数值与状态转换仍由领域层负责。
- `scripts/presentation/gu_style.gd` 继续作为基础视觉 token 来源。
- 字体继续使用霞鹜智宋 CL，同一宋体家族承担标题与正文。
- 图标继续使用项目自有 SVG，并通过 `GuIconView.ICON_PATHS` 注册和加载。
- 纸面、墨色、细分隔线、小圆角、大留白仍是界面的基本语法。

### 4.2 本设计新增的上层方向

本设计补充四项现有系统尚未完整覆盖的内容：

1. **叙事插画层**：人物、敌人、地点和事件拥有统一的南疆志怪美术语言。
2. **蛊虫图鉴层**：蛊牌以异常自然志和生物标本方式呈现，而非普通技能卡。
3. **尺度变化层**：力量增长体现为空间、制度和世界规则的变化，而非粒子数量增长。
4. **因果结算层**：地图路线、契约、消耗、死亡和结局形成可回读的一世记录。

本文件不改写 `docs/ui/UI_RULES.md`，也不顺带修复既有规范漂移；后续实现仍以现行代码和权威 UI 规则为边界。

## 5. 三层视觉结构

### 5.1 规则层：浅色旧宣纸命簿

常态 UI 是一本被长期翻阅、批注和修订的记录册，而不是悬浮在世界前方的魔法 HUD。

- **底材**：暖灰、低饱和旧宣纸；避免纯白和明显黄色滤镜。
- **文字**：近黑墨色；标题靠字重、字号与留白建立层级，不靠渐变或发光。
- **结构**：1px 细线用于普通分隔，2px 只用于当前路线、选中对象或关键裁定。
- **容器**：优先使用版面分区和留白，仅在需要明确交互边界时使用面板。
- **批注**：朱砂用于危险、代价、死亡、不可逆决定和关键裁定，如同命簿上的判词。
- **契书**：契约蓝用于规则、约束、正式义务和冷静的制度信息。
- **轨迹**：地图路线、事件记录和结局因果应共享“此世留下的笔迹”这一概念。

纸面允许轻微纤维、墨色浓淡和磨损差异，但这些纹理必须安静，不降低小字号文字和控件状态的可读性。

### 5.2 叙事层：暗色南疆志怪绘卷

插画负责表现界面无法承担的湿度、危险、生物性和世界尺度。

- 主要环境是夜雨、山雾、湿石、竹影、洞窟、狼烟、积雪、骨骸和幽暗水面。
- 画面以大环境压住小人物，强调人在地势、族群、制度和天意之下的渺小。
- 暗色来自环境与叙事，不把整个 UI 变成黑色。
- 亮部应像月光、纸灯、雪、磷光、蛊虫甲壳反光或短促火光，而非统一轮廓光。
- 血肉、虫体和寄生结构应有可信的生物逻辑；恐怖感来自功能和代价，而非无目的猎奇。

叙事插画与纸面 UI 的关系是“画卷被命簿收录”：图像可以暗而深，承载文字的区域仍必须保持清楚、克制和稳定。

### 5.3 概念层：稀有且不可日常化的颜色与符号

涉及命运、光阴、天意、尊者和世界级异变时，可以临时突破常态色轨，但必须满足三项条件：

1. 该颜色对应明确且不可互换的概念。
2. 它只在相关事件、角色或结局中出现。
3. 它不会变成普通按钮、稀有度或装饰边框的通用颜色。

例如红莲之红、事实浮冰之白、黑火的去材质化黑、光蛊的日光色，都属于事件级视觉事实，而不是新增的常驻 UI token。重大力量应改变一个根本事实——太阳消失、河流逆转、命网断裂、文字被抹除——而不是给所有对象增加更多光效。

## 6. 色彩与材质规则

### 6.1 常驻语义色

沿用现有语义，不重新发明第二套色轨：

- **朱砂**：危险、死亡、血、代价、不可逆决定、关键焦点、封印与裁定。
- **契约蓝**：契约、规则、正式义务、限制、冷静智谋与逆流护序。
- **异变黄**：DDA、突变、天灾预警、征兆与不稳定炼蛊。
- **玉色**：护盾、恢复、正向效果、可挽回状态和有限的生命安全。
- **墨色与纸色**：承担绝大多数普通信息、背景和结构，不把语义色当装饰色使用。

稀有度颜色只用于辨认稀有度，不扩大为页面主色，也不覆盖危险、契约等更重要的状态语义。

### 6.2 材质

允许的材质感：

- 宣纸纤维、渗墨、干笔、旧册页边。
- 湿石、竹木、骨、甲壳、皮膜、丝线和水迹。
- 低反射金属与石质器物，只在叙事对象确实需要时出现。

不允许的材质感：

- 大面积黄金、珐琅、玻璃、霓虹和塑料亮面。
- 用强噪点假装年代感。
- 为所有控件加纸卷边缘、破损角或印章。
- 纹理穿过正文并降低信息可读性。

## 7. 人物、势力与敌人

### 7.1 人物

人物设计强调轮廓、处境和行动能力，不以夸张表情或奢华服装代替性格。

- 低阶人物的衣料、工具和伤痕应表现资源匮乏、地域气候和真实劳作。
- 姿态保持克制，情绪更多通过距离、遮挡、手势、视线和环境体现。
- 主角不应长期占据英雄式中央光位；画面必须保留世界大于个人的感觉。
- 人物状态变化优先改变衣物、身体负担、携带物、蛊虫痕迹和所处空间，而不是只改变 aura 颜色。

### 7.2 势力

势力识别依靠制度如何塑造空间和人，而不是给每个阵营分配一套高饱和品牌色。

- 家族与门派：谱牒、账册、队列、资源分配、规训空间。
- 商盟与交易组织：契据、估价、货物流向、表面中立的秩序。
- 天庭式秩序：高墙、塔、棋局、档案和超越个人的轴线。
- 魔道与游离者：不等于凌乱或全黑，而是缺少制度保护、工具临时化、空间不稳定。
- “大爱”式机构：视觉上可以洁净、开放、理性且可信；讽刺来自它与被舍弃者、隐蔽榨取和真实结算之间的差距，不使用滑稽反派符号提前替玩家下结论。

### 7.3 敌人

敌人首先是世界机制的产物，其造型应能解释它的行为、资源和威胁。

- 野兽与异兽强调栖息地、捕食方式和受蛊影响的身体结构。
- 蛊师敌人通过流派工具、蛊虫寄生位置、消耗痕迹和战斗准备体现意图。
- 高阶敌人的威胁来自对地形、经济、人口、规则或时间的支配，不依赖体型和粒子无限升级。
- 敌人意图必须使用正式图标和可读文字表达，不以 emoji 或模糊符号承担生产信息。

## 8. 蛊虫与卡牌

蛊虫是本项目最重要的识别对象。其表现采用 **“异常自然志图鉴”**：像被观察、命名、饲养和记录的真实生物，同时保留不可完全理解的异质性。

每张蛊牌应优先回答：

1. 它是什么生物或器官结构？
2. 它如何行动、寄生、摄取或释放力量？
3. 它需要什么喂养与使用代价？
4. 它属于何种流派、品质和风险？

视觉规则：

- 主体是蛊虫本身，不以人物施法姿势替代蛊虫图像。
- 允许虫体、植物、骨骼、液体、器官、器物和抽象法则的混合，但结构必须可辨认。
- 卡框服从纸墨 UI，只承担名称、成本、品质、状态和交互，不与插画争夺注意力。
- 品质变化优先表现为标本完整度、墨线精度、纸张层次和局部概念痕迹，不简单叠加金框。
- 危险、饥饿、受损、污染和炼化不稳应改变蛊虫状态或记录痕迹，而非只增加红色角标。
- 小尺寸下先保证轮廓识别；细部解剖、联动、代价和不可用原因放入共享 tooltip。

本设计不假设完整蛊牌插画已经存在。现有图标仍承担小尺寸功能识别，后续资产制作需单独排期和验收。

## 9. 环境与地图

地图不是节点菜单的背景，而是一世选择如何展开的因果图。

- 路线像在旧地图和命簿上逐步落下的墨线。
- 已走路线比未来路线更实、更重；未知道路只提供必要的模糊信息，不制造虚假细节。
- 地点插画应体现资源来源、统治关系、气候和风险，而不是只有风景差异。
- 普通节点保持克制；当前节点、可达路线和不可逆选择才获得明确强调。
- 地图、事件日志和结局页应能够复用同一条“此世轨迹”，让选择在结算时可回读。

南疆是视觉基准：潮湿、山林、雾、寨、洞窟和资源争夺构成低阶世界的触感。进入其他地域或高阶阶段时改变地理、气候和制度形态，但不丢失纸墨命簿这一界面框架。

## 10. 三种力量尺度

### 10.1 凡俗与低阶蛊师

- 关键词：湿、冷、近身、饥饿、局促、肉体、地方性。
- 常见材质：泥、水、血、竹、石、洞穴、兽皮和粗纸。
- 资源变化必须可感：少一块元石、蛊虫断粮或一处伤口都足以改变决策。
- 镜头靠近生存细节，但环境仍压迫人物。

### 10.2 蛊仙

- 关键词：领地、地理、工程、经济、人口、资源点与制度。
- 力量不再只是攻击更大，而是能够改造山河、经营仙窍、部署大阵并把城市与族群转化为资产。
- 视觉从单体冲突扩展到流向、边界、产出和控制范围；命簿也从个人账目扩展为领地档案。

### 10.3 尊者与世界级冲突

- 关键词：极简、抽象、宇宙尺度、规则变化、巨大留白。
- 主要意象：命网、棋盘、光阴长河、红莲、事实浮冰、天庭高墙、世界壁、天地秘境、生死门和消失的太阳。
- 越高阶，画面越应安静而根本。一个规则被删改，应比满屏爆炸更有力量。
- 人物可以缩小为点、剪影或落款，让被改变的世界事实成为主体。

## 11. 符号词汇

符号必须在叙事含义成立时使用，不作为通用花边：

- **墨与水**：历史、重生、污染、记忆被重新扩散。
- **朱砂与印**：不可逆、契约、死亡、代价和裁定。
- **蛛网与丝线**：命运蛊、被规定的轨迹、牵连和断裂。
- **棋盘与棋子**：天意、制度操纵、个体被当作工具。
- **河流**：光阴、坚持、回溯与逆流。
- **莲**：红莲、悔意、时间裂口和反抗命定。
- **塔与墙**：天庭、制度秩序、封锁和命运边界。
- **骨、虫与肉**：蛊道的生物代价和炼化现实。
- **账簿与路线**：一生由选择、交易和后果累积而成。
- **事实与冰**：冰冷事件本身与人的情感解释之间的距离。
- **缺失的太阳与火雨**：世界级力量直接改写环境事实。

同一屏不应为了“丰富”而并列多个无关母题。每个场景选择一个主符号，其他元素退为支持关系。

## 12. 动效与视觉反馈

动效遵循 **短、功能性、由状态变化触发、完成后归于安静** 的原则。

建议词汇：

- 墨迹扩散：揭示新记录、污染、重生或状态落定。
- 翻页与纸层错动：屏幕切换和档案层级变化。
- 路线落笔：确认旅行和展示已走轨迹。
- 朱砂盖印：危险确认、死亡、契约生效和不可逆裁定。
- 契约线收紧：规则生效、义务增加或选择被限制。
- 命网短暂显形：命运相关事件，不作为常驻背景。
- 蛊虫微小有机动作：呼吸、触须、甲翅或液体流动，用于生命感而非持续吸睛。
- 文字划除：死亡、失去资格、资源永久消失。
- 墨入水：重生、记忆污染或一世结束后的扩散。
- 黑火去材质化：对象不只是烧焦，而是纹理、色彩和形体被抹除。

沿用现有约 `0.14s` 的屏幕淡入与约 `0.22s` 的过渡遮罩作为常规速度基准。重大结算可适当延长，但不得用长动画替代即时、清晰的状态反馈。

禁止：持续辉光、环境粒子雨、卡牌常驻漂浮、无状态意义的呼吸缩放，以及每次普通点击都触发的戏剧化转场。

## 13. 屏幕落地方向

本节只规定未来设计意图，不授权本轮修改场景。

- **大厅**：一世档案的入口。人物与青茅山等具象图像应成为第一视觉信号，菜单退居记录与选择工具。
- **地图**：一世路线的主视图。可达性和真实点击优先，墨线路线同时服务旅行和因果回读。
- **战斗**：建议作为首个视觉基准屏，因为它同时暴露人物、敌人、蛊牌、资源、意图、危险确认、tooltip、语义色和动效规则。
- **遭遇、商店、休整、炼蛊**：像命簿中的不同记录类型；通过内容结构和主图变化区分，不为每个屏幕建立独立主题。
- **结局**：不应只是统计面板。它应把地图路线、关键契约、获得与失去、死亡原因或升仙代价组织为可回读的因果结算。
- **内容错误**：保持纸墨系统内的清楚诊断，不用叙事装饰掩盖错误信息。

## 14. 资产与技术边界

- 首轮实现应复用 Godot 原生 `Control`、Theme/StyleBox、Tween、Line2D 或现有自绘节点，优先避免新增依赖。
- 不为纸张纹理、墨扩散或转场预先建立通用 Shader 框架；只有在基准屏证明原生方案无法达到目标时，才单独设计最小 Shader。
- 插画资产、蛊牌资产和地点资产必须按屏幕实际需求逐批生产，不先制作完整世界图库。
- 现有大厅图片已注册但尚未证明在生产界面中有效使用；它们只能作为待接入资产，不能计入已完成覆盖。
- 当前缺少完整角色、敌人、蛊牌和地点插画集。本设计描述目标，不把缺失资产写成现状。
- 所有生产图标必须进入 `GuIconView.ICON_PATHS`；Unicode 与 emoji 不作为正式图标替代品。
- 所有视觉实现不得修改领域规则，也不得绕过快照/命令边界。

### 已知简化上限与升级路径

第一阶段只选择一个基准屏验证视觉语法，不同时重做全部屏幕。这个简化的上限是：它只能证明核心组件和色彩层级成立，不能证明地图与结局的长程因果阅读已经成立。

升级路径是：基准屏验收后，依次验证地图的一世轨迹、结局的因果结算，再将已验证的共享规则推广到其他屏幕；每一阶段单独确认范围，不预建未被使用的抽象。

## 15. 验收标准

### 15.1 方向一致性

- 第一眼能辨认“旧宣纸命簿 + 南疆志怪”，而非通用仙侠、暗黑 HUD 或现代卡牌应用。
- 纸面 UI 负责规则清晰，暗色插画负责世界氛围，两者没有互相吞没。
- 朱砂、契约蓝、异变黄和玉色的用途与既有语义一致。
- 概念色只出现在对应的重大概念或事件中，没有退化为普通装饰。

### 15.2 信息与交互

- 正文、数值、成本、不可用原因、敌人意图和确认状态均可直接读取。
- 具象图像是重要页面的首要视觉信号，但不遮挡交互或状态信息。
- 卡牌在小尺寸下能凭蛊虫轮廓和正式图标辨认；详细信息由 tooltip 承担。
- 普通、悬浮、选中、禁用、危险和已确认状态不只依赖颜色区分。
- 动效结束后界面恢复稳定，不存在持续争夺注意力的装饰运动。

### 15.3 世界与叙事

- 凡俗、蛊仙、尊者的差异体现为生存细节、领地系统和世界规则三个尺度，而非单纯特效升级。
- 人物、敌人和蛊虫的造型能说明其处境、功能与代价。
- 重大选择能够在路线、记录或结局中留下可回读痕迹。
- “大爱”等制度性反讽通过整洁表象与真实结算的差距成立，不靠旁白或反派化装饰强行解释。

### 15.4 工程验收

进入实际实现阶段后，每个受影响屏幕必须：

- 通过现有结构烟测与像素探针，避免空白或静默白屏。
- 在 `1920×1080`、`1366×768`、`1280×720` 截图中无裁切、遮挡和不可达操作。
- 对关键卡牌和地图操作执行真实鼠标事件验证。
- 保持 `mount_snapshot(snapshot, commands)` 契约和领域/表现边界。
- 不引入未经批准的第三方依赖或第二套主题系统。

## 16. 后续实施边界

本文件只持久化视觉方向，不包含实现授权。本轮明确不执行：

- 修改 Godot 场景、GDScript、主题 token 或生产路由。
- 生成或接入人物、敌人、蛊牌、地点插画。
- 创建 Shader、粒子系统或新动画框架。
- 修复历史 UI 文档漂移或遗留视觉验收批次。
- 重做 Battle、Map、Ending 或其他屏幕。
- 编写实现计划。

用户复核本文件后，下一项任务仍需单独确认。若进入实施，首选范围是仅以 Battle 作为视觉基准屏，验证纸墨规则层、志怪插画层和蛊虫图鉴层能否在同一屏成立。
