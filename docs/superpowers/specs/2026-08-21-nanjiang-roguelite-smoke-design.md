# 历史设计稿：南疆凡人修行肉鸽：45–90 分钟冒烟版设计

## 1. 目的与边界

本版本验证一件事：玩家是否愿意在一名南疆散修冲击蛊仙的修行路上，为了活下去和争取未来，在元石、真元、情报、人情、风险之间做取舍。

它不是方源剧情复刻，不以青茅山为舞台，不是连续战斗游戏，也不是蛊仙经营模拟。原著人物、事件和蛊方资料只用于抽取可信的世界规则、事件因果和物品关系；本模式每局扮演另一位无名蛊师。

本版本是单机作品：随机种子、地图、资源、战斗、判定、存档和复盘全部本地执行。允许联网调用云端 LLM，但断网时必须仍可完整游玩，改用本地模板文本。

### 版本验收

- 一局从新开窍的一转凡人开始，正常游玩时长 45–90 分钟。
- 在 10–14 个有效决策节点内，玩家至少一次面对元石、真元或局势代价的取舍，一次形成蛊虫搭配，一次处理人际纠纷，一次处理机缘争夺，并进入升仙终局。
- 战斗不是唯一解。至少在商队纠纷与机缘争夺两个节点中，存在可验证的非战斗解法和撤离解法。
- 结局固定为成功、险成、失败求生；致死只来自明示的不可逆冒险或战斗失败。
- 玩家能在结局的修行札记中看到每项关键条件的来源、缺口和后果，且归因来自结构化事件日志而非事后推测。

### 明确不做

- 北原、东海、中洲、两天、跨域旅行和多身份开局。
- 开放世界、全量原著蛊虫、完整流派、复杂势力模拟和局外成长。
- 多轮自由聊天、LLM 裁定数值或世界事实。
- 蛊仙阶段可玩内容。升仙后的福地仅为结局尾声。
- 强制教学关、炼蛊小游戏、卡牌战斗、材料背包、食料维护、残蛊方和凡人期道痕成长。

## 2. 单局身份、时间与修行节奏

玩家固定为一名刚开窍、离开原生聚居地寻找生路的南疆散修。初始只有小光蛊、少量元石和基础行囊；不随机资质、家世、本命蛊和流派。

一局不是现实时间内从一转直升五转。地图每一层代表数月到数年的修行阶段，日常修炼、赶路和普通养蛊被压缩，只有改变人生方向的节点被保留。每层末的修为门槛决定角色是否踏入下一转；叙事必须在节点间显示时间流逝、伤势和寿命代价，避免把仙凡之别做成普通经验条。凡人阶段不出现可堆叠道痕或通用境界资源；道痕与流派境界差距留给升仙后的版本。

| 阶段 | 冒烟版目的 | 节点预算 | 必须留下的决定 |
| --- | --- | ---: | --- |
| 一转：生存层 | 证明活命和机会都要付代价 | 2–3 | 用元石、真元、寿命或风险换取立足条件 |
| 二转：构筑层 | 证明小光蛊可成为搭配核心而非教程道具 | 2–3 | 取得第二蛊，并决定装备、出售或为传承预留蛊槽 |
| 三转：关系层 | 证明人情、证据和交易可以比战斗更有价值 | 2 | 处理商队纠纷，留下援手、债务或仇怨 |
| 四转：布局层 | 证明短期收益会改变后续道路 | 2–3 | 处理地脉机缘争夺，选择借势、设局、撤离或开战 |
| 五转：升仙筹备层 | 证明升仙是资源、情报和风险的总清算 | 1–2 + 终局 | 准备、争机缘并决定何时冲仙 |

一次游戏生成 10–14 个有效节点，包含机缘争夺和升仙终局。表中的数字是内容预算，不要求每局逐项跑满；每层让玩家在 2–3 个可选节点中选 1–2 个，未选节点消失或转化为后果。因此路线选择真实存在，但首版无需大量内容。

地图层之间使用月、季或年作为宏观时间单位；节点内部可进入数小时至数日的紧急事件期。商队纠纷的“三日援军倒计时”只在该节点及其紧接的余波节点内推进，不与跨阶段的时间跳跃混用。

## 3. 核心循环与地图

地图采用分层节点图。下一层尚未完全可见，只展示大致风险、距离和可能类型；小光蛊、购买的情报、关系帮助和侦查行动能揭示不同信息，而不是一键开全图。

每到一个节点：

1. 系统展示已知局势、时间压力、可见人物、地形、资源变化和可行动作。
2. 玩家选择行动标签，必要时附加已经拥有的蛊虫、证据或物品；重大交涉可以再输入一句自由文本。
3. 本地规则判定行动是否合法、消耗多少真元或时间、对谁产生影响；LLM 只为允许的交涉生成回应和结构化意图。
4. 系统结算并更新元石、修为、真元、关系、追击、线索、伤势和地图信息。
5. 玩家选择下一节点；所有恢复、修炼与蛊虫效果均来自已装备蛊虫或当前节点行动。

### 节点类型与最低内容集

首版制作 17 个内容模板，每局按条件选 10–14 个。除固定关键节点外，其余模板以参数变化复用，不再追求大规模随机文本。

| 类型 | 最低模板数 | 作用 |
| --- | ---: | --- |
| 山道、毒瘴、险地 | 3 | 生存、探路、真元、伤势或寿命压力；小光蛊显著有用 |
| 野蛊、传承、换蛊 | 3 | 第二蛊、传承线索、四槽取舍和蛊虫联动选择 |
| 寨市、商队、委托 | 4 | 交易、情报、债务、证据与一轮受限交涉 |
| 兽群、追击、伏击 | 3 | 回合制战斗、脱身、伤势、资源损耗 |
| 遗藏、地脉、势力争夺 | 3 | 多方博弈、终局资格和后续外部干扰 |
| 闭关、筹备、肉身改造 | 1 | 修为门槛、一次性根基印记和结算前准备 |

固定锚点是“商队失货纠纷”“地脉异动的机缘争夺”“升仙窗口”。首局可以固定前两次出现的相邻节点类型，剩余路线随机，以保证所有试玩者都能验证 LLM 交涉与组合终局。

## 4. 最小可玩资源系统

首版只保留会推动选择的状态，所有数值都显示清楚。

| 状态 | 作用 | 冒烟版规则 |
| --- | --- | --- |
| 修为与真元 | 使用蛊虫和晋阶的根基 | 修为决定五个阶段的门槛；真元用于行动，只能由蛊虫、节点效果或明确代价回复 |
| 伤势 | 战斗、险地与失败行动的长期代价 | 轻伤、重伤两档；重伤提高冲仙外扰，并按 NPC 的伤势反应改变交涉结果池 |
| 元石 | 凡人阶段唯一通用货币 | 购买一只蛊、情报、一次明确服务、临时人情或脱身条件；不能无限购买属性 |
| 蛊槽与蛊虫 | 主要手段和构筑 | 初始 1 槽，最多 4 槽；超出承载不允许装备 |
| 肉身印记与局势 | 稀少且具体的人生差异 | 铁骨、冰肌、三更等印记只由传承或高风险事件获得，带来明确收益和副作用；伤势、寿命、关系、证据、追击与线索均是局势状态，不能当货币兑换 |
| 关系账 | 外部干扰或帮助的来源 | 每名关键 NPC 仅记录立场、债务、仇怨、知情和援军倒计时 |
| 升仙准备 | 终局资格 | 空窍底蕴、天地二气、护道、地点、外扰五项的已知进度 |

### 小光蛊与最小蛊虫池

小光蛊固定开局。一转，食月光，可发出隐蔽微光弹；原著中其威力接近月光蛊但更不起眼。本作将它作为通用信息工具，而非专属光道锁定。

首版总计只做 8 种可获得凡蛊，加上小光蛊共 9 种。每种必须同时定义：转数、真元消耗、槽位职责、战斗效果、非战斗用途、明确联动钩子、出售或替换价值，以及 2–3 个能力标签。最小职责集合是攻击、守御、疗伤、移动/脱身、侦查、伪装、控场和节奏改变；疗伤蛊必须占据蛊槽，并与输出或工具蛊竞争。命名和具体蛊虫资料在数据整理阶段按原著核验后落表。

首版不做残蛊方、材料和炼蛊。蛊虫标签只能驱动节点反应、验证显式联动条件和解释玩家已达成的效果，绝不从标签自动生成未设计过的杀招。玩家可自由组合四个蛊槽；系统只记录首次达成的有效联动，玩家可自行命名，不弹出强制教程。

首版只放 3 部传承杀招，作为明确的构筑锚点。每部传承声明必需蛊虫或标签、可主动施放的效果、每场限制和一项专属 buff；满足条件即可施放，不需要把杀招装入额外槽位。传承 buff 必须改变规则而非只提高百分比，例如减真元、揭露隐藏优势、保留一次撤离或无视一次控制。三部传承分别覆盖小光蛊的情报/揭露线、木道或血道式的疗伤兼反击线、毒道或隐匿式的脱身/控场线。传承用于启发而不替代自由联动；LLM 不生成蛊虫联动或杀招。

## 5. 战斗、交涉与撤离

### 回合制战斗

战斗采用固定蛊槽加真元行动。每回合玩家从已装备蛊虫中选择一次行动，敌方按固定行为表行动；伤势、地形、冷却、真元、蛊虫状态和已取得的信息影响结果。战斗目标可以是击退、夺物、拖延或脱身，不默认杀死敌人。

首版仅需 4 个敌人行为原型：兽群、贪利散修、势力护卫、意志坚定的精英。每类有 2–3 个数值变体。撤离必须可用，但依据地形、移动手段、追击状态和敌方控制能力判定，且会付出资源、伤势、丢失物品或关系代价。

### 人际与智斗

每个关键 NPC 有本地维护的目标、底线、恐惧、原则、意志、知情范围、利益、退路、阵营、援军和伤势反应。伤势反应固定为轻视、同情、警惕、趁火打劫之一；它改变可提出的条件和本地结果权重，但不会绕过证据、利益或意志判定。玩家可使用试探、交易、施压、设局、伪装、结盟、依附、投降、脱身、开战等行动标签。

劝降没有固定“低血量按钮”。它仅在敌方存在可接受利益、退路被切断或保留、敌我力量对比、伤势、援军、证据、阵营风险、性格意志等条件满足时进入可行结果池。意志坚定的敌人即使受伤也可能拒绝；弱敌若有援军或退路，也可能反向拖延。

## 6. LLM 使用契约

LLM 的职责是增加有限、受控的随机人物反应，不能代替游戏规则。

### 本地交涉状态机与调用预算

- 玩家可在一个关键事件内连续选择 2–4 次行动标签；本地状态机每次更新证据、时间、让步、威胁、退路和 NPC 倾向，并立即给出结构化结果。
- 普通商谈或冲突：最多调用 LLM 1 次。
- 商队纠纷、机缘争夺中的关键人物：最多调用 LLM 2 次，分别用于首次试探和最终决断；中间行动由本地模板和状态变化叙述承接。
- 每次模型回复 80–150 字，必须先输出结构化字段，再输出角色口吻文本。

### 本地规则层

本地保存并判定所有资源、地图、随机种子、NPC 隐藏状态、事件历史、已装备蛊虫、传承条件、交易价值、盟约条款、证据、战斗、肉身印记、升仙资格与结局。读档直接重放已保存的结构化响应，不再次请求模型。

### LLM 输入与输出

模型只接收经过筛选的“当前可知事实”、NPC 已知目标和允许影响的利益项，不能看到种子、隐藏数值或未发现内容。输出只能是：意图分类、置信度、提出的条件、情绪/口吻文本、是否请求澄清。所有字段要经 JSON Schema 校验；非法、越权或无法解析的回复立刻改用本地模板。

LLM 不得新增或删除蛊虫、资源、证据、地图、关系、历史和隐藏目标；不得裁定交涉、洞察、战斗、蛊虫联动或升仙成功；不得泄露玩家尚未取得的信息。

## 7. 组合终局与三种结局

### 第一段：机缘争夺

四转末至五转初，毒瘴深处发生地脉异动，形成短暂的升仙机会。至少两方 NPC 争夺同一机会，各有明确目标、元石或人情筹码与时间压力。玩家可以抢夺、交易、伪装、挑拨、结盟、尾随、撤离或战斗。结果至少产出一项：升仙地点、天地二气线索、护道手段、传承机会或外部干扰。

### 第二段：升仙窗口

玩家在有限时间内决定立刻冲仙、补足一个短板后冲仙、以资源/关系换条件，或主动放弃。系统对五项准备逐项结算：空窍底蕴、天地二气、地点、护道、外部干扰；再将真元、伤势、蛊虫状态、人情债、追兵和情报纳入风险。

| 结局 | 条件 | 尾声 |
| --- | --- | --- |
| 成功 | 资格完整，风险未越过容忍阈值 | 晋升蛊仙；用福地初始印记概述本局留下的资源、人情和隐患 |
| 险成 | 资格完整但存在重大风险，或以高代价换得门槛 | 晋升蛊仙，但核心蛊受损、福地条件差、欠债、强敌、重伤或寿命亏空至少保留一项 |
| 失败求生 | 资格不足、外扰失控，或玩家主动退却 | 角色生还，修行札记逐项显示缺口与可替代的前序决策 |

明确死亡节点可以存在，例如明示毒瘴失控后强闯，或无撤离机会的战斗中失败；它不替代失败求生，也不可由隐藏信息直接触发。

失败求生按最终状态路由为四种有尊严的落点：守住资源后成为一方寨主、带着人情债成为势力客卿、保住传承线索后远走他乡、或伤重归隐而留下被后人谈论的修行札记。它们不新增可玩章节，只改变结局文本、关系账和因果归纳，确保失败是这名蛊师的人生结果，而不只是通关失败提示。

## 8. 首局验证路线

为可测试性，首局使用固定随机种子和以下骨架，随机性只放在非关键奖励、路线支路和 NPC 态度小变体中：

1. 开窍后离寨：选择毒瘴山道或寨市短工，消耗或获得第一笔元石、真元或局势代价。
2. 小光探路：用小光蛊揭示险地、制造信号或保留真元绕行。
3. 野蛊/传承线索：捕获、交易或放弃第二蛊来源，第一次面对四槽构筑取舍。
4. 闭关或肉身改造：以时间、元石、伤势或寿命换取修为推进、一次根基印记或一次传承线索。
5. 商队失货纠纷：一名管事、两种证据、受伤护卫、节点内三日援军倒计时；支持侦查、交易、试探、伪装、威胁、撤离、战斗。最多调用 LLM 两次。
6. 修行跃迁：以修为、伤势、寿命和蛊虫状态判定是否顺利进入三转叙事阶段。
7. 商路余波：获得人情、债务、仇怨或情报的后续价值。
8. 遗藏入口：选择地图、关系或资源路径进入地脉区域。
9. 机缘争夺：重大交涉或高压战斗，决定升仙关键条件与外扰。
10. 筹备：仅可补一个短板，必须舍弃另一项资源、关系或时间。
11. 升仙窗口：选择冲仙、再赌一次或退却。
12. 三结局尾声和修行札记。

## 9. 数据、测试与扩展原则

### 数据驱动的最低结构

蛊虫、传承杀招、节点、NPC 原型、地域标签、战斗行为、结局条件都以独立数据表定义。每条数据应记录原著来源位置或标记为“游戏新增”；不能把原著事实、游戏平衡数值和 LLM 文案混在同一文件。传承杀招显式声明必需蛊虫、标签约束、主动效果、场次限制和专属 buff；数据变更时，校验脚本必须验证所有引用存在、标签满足且效果 ID 合法。

判定函数只消费结构化状态并返回结构化事件。每次关键状态变化都追加一条不可变关键事件日志，最少包含阶段/时间、节点 ID、行动、变更前后值、原因、来源与影响目标。文本渲染、LLM 响应和 UI 不应直接改写状态；修行札记只读取事件日志和玩家已知事实。这是后续增加北原、东海、中洲地域包、更多身份和长链交涉时不推翻首版的前提。

### 冒烟测试清单

- 固定种子可在不调用 LLM 的情况下走通成功、险成、失败求生三条结局。
- 小光蛊至少在探路、交涉/伪装、战斗或脱身中分别具有一次有价值的使用机会。
- 商队纠纷至少有两种非战斗结果和一种撤离结果，且结果会在机缘争夺中兑现。
- 机缘争夺中，硬开战并非总收益最高；至少一种信息或关系路径能降低冲仙外扰。
- 断网、超时、Schema 校验失败时，交涉能用模板文本继续，存档和结算保持一致。
- 读档不再次请求 LLM，且重新播放同一已保存事件得到相同状态结果。
- 修行札记能从关键事件日志归因每个结局的五项升仙准备、主要资源收支、关系账与关键转折，且不泄露玩家未发现的信息。
- 修改任一蛊虫或传承数据后，校验脚本能报告失效引用、标签不匹配或非法效果。

### 扩展顺序

先把南疆的 45–90 分钟切片打磨到验收通过，再把单局扩到 2–3 小时：增加每阶段的分支节点、蛊虫与传承杀招、NPC 关系延续和地域势力。数值和构筑只借鉴《大巴扎》所体现的条件联动、槽位取舍、时机与触发链原则，不复制其自动战斗或交易场景结构。之后以同一数据接口增加北原、东海、中洲地域规则包；最后才考虑多身份、随机资质/家世/本命蛊、跨域行脚、多轮 LLM 关系线，以及升仙后的道痕与流派境界系统。
