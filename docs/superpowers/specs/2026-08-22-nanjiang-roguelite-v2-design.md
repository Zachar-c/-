# 南疆凡人肉鸽 V2 设计

## 状态与目标

状态：已确认流程骨架，等待规格审阅后编写实施计划。

本设计定义《南疆凡人一局制》第二版的正式首发方向。它替代当前可运行但规则循环不完整的验证原型目标，不将原型 UI 或临时数据视为正式体验。

首发目标是在 Windows 键鼠环境中，完成一局时长约 60--90 分钟、可反复游玩的南疆凡人肉鸽。玩家是原著大势中的无名南疆散修，不参与或改写方源等原著主线。商家城、古月、铁家等只作为未精确标年的远方背景锚点；活跃势力、NPC、首领与遗藏使用原创地方内容。

首发只支持中文。开发初期采用清晰的占位美术，先证明玩法循环，再替换为选定的原创 2D 美术。现有调试窗口标题保持 `Nanjiang Smoke (DEBUG)`，图形兼容性保持 `renderer/rendering_method="gl_compatibility"`。

## 非目标

- 不做局外数值成长、开局资源加成或永久属性提升。
- 不做其他地域、开放世界、多人、联网、商店发布或手柄支持。
- 不做可玩的蛊仙阶段、仙窍经营、灾劫、道痕堆叠或高转内容池。
- 不把战斗做成格子、前后排、掩体或距离战棋。
- 不使用随机抽手牌或战前固定蛊槽；已养且已炼化的蛊虫均可在战斗中合法催发。
- 不将预设“正确杀招”伪装成自由探索，也不把自由杀招完全替换为内置传承。

## 一局流程

```text
固定散修开局
  -> 第一阶段分叉路线
  -> 节点接触、选择与可能的冲突
  -> 初步构筑与二转突破机会
  -> 第一阶段养蛊总账和构筑调整
  -> 第二阶段分叉路线
  -> 势力、商队、交换、炼蛊、传承与资质机缘
  -> 主力构筑与三转资格争取
  -> 第二阶段养蛊总账和构筑调整
  -> 第三阶段分叉路线
  -> 遗藏争夺、固定守关首领
  -> 夺取遗藏并撤离
  -> 携遗撤离结局，或主动进入不可逆升仙考验
  -> 结局札记、图鉴、挑战记录和可选内容解锁
```

一局由 3 个阶段构成，每阶段约 6--8 个有效节点，总计约 18--24 个。第一、二阶段结束后各结算一次养蛊总账；第三阶段后直接进入守关、夺藏、撤离与结局，不设第三次总账。

## 开局与角色

玩家固定为一名无名南疆散修，所有跑局从相同的角色底子开始：

- 一转初阶。
- 丙等资质，元海容量为四成四。
- 固定起始蛊虫组合，包含小光蛊；完整起始蛊表由首个内容切片确定。
- 少量元石和基础物资。
- 无角色职业选择，无局外数值继承。

蛊师为一至九转的角色类，每转有初阶、中阶、高阶、巅峰。首发可玩范围为一至三转：一至五转为凡人蛊师，六至九转为蛊仙，九转尊称尊者。玩家初始资质不随机化。

资质与修为分离。资质决定元海可储真元比例与基础恢复能力，不直接决定伤害、财富或战斗胜负。固定丙等散修可冲击二转，但在当前跑局获得提升资质的稀有蛊虫、遗藏效果或特殊机缘前，不可冲击三转。提升资质不是局外成长，且不由普通商店稳定直售。

## 路线图与阶段

每阶段是一棵向前展开的分叉路线。玩家能查看前方数层的节点类型、连接关系与部分公开信息，再选择下一条路径。路线选择必须表达即时战力、资源积累、构筑修补、势力关系、资质机缘与终局准备之间的取舍。

| 节点方向 | 主要收益 | 主要风险或代价 |
| --- | --- | --- |
| 冲突与狩猎 | 元石、材料、战利品、情报、威慑 | 伤势、真元、敌对、时间 |
| 商队与寨市 | 买蛊、卖蛊、换蛊、情报、构筑修补 | 元石、人情、价格、势力条件 |
| 传承与遗迹 | 稀有蛊、炼制方向、资质机会、遗藏线索 | 高风险、竞争者、失蛊可能 |
| 炼蛊地点 | 合炼、升炼、平炼、逆炼 | 材料、时间、炼制失败毁蛊 |
| 修行与机缘 | 小境界修行、二转突破、突破条件 | 元石、真元、时间、安全窗口 |
| 势力与人物 | 交涉、委托、欺骗、求援、设局 | 人情债、关系变化、后续后果 |
| 避险与撤路 | 保命、规避强敌、替代路线 | 放弃收益、时间、路线优势 |

冲突或高压主动对局占全局有效节点的约 35%--45%。每阶段至少有一个可预期的构筑调整窗口，保证养蛊总账是可经营的压力而非无解税收。

## 节点接触

地图节点不是简单的“敌人”或“事件”按钮。玩家可能遇到单个蛊师、蛊师队伍、商队护卫、山民、野兽、遗藏争夺者或势力使者。

节点通用流程：

```text
展示局势和玩家已知信息
  -> 玩家选择接触方式
  -> 局势、资源或关系变化
  -> 必要时进入冲突
  -> 结算收获、伤势、关系与后续影响
```

接触方式包括交涉、交易、欺骗、伪装、试探、调查、设局、伏击、直接战斗与撤退。每种方式必须改变状态，不能只改变文案：例如交涉会交易资源或关系，试探会获得信息，欺骗会降低戒心或制造误判，设局会消耗筹码换取冲突开局优势，撤退会保命但付出资源、关系、时间或路径代价。

所有关键状态变化写入不可变结构化事件日志。结局札记只可使用日志和玩家已知事实归因。

## 抽象状态战斗

战斗是面对一个或多个单位的主动回合制状态对局，而非战棋。玩家可见敌我伤势、真元、持续状态、已知蛊虫线索、敌方意图和局势压力。敌方意图可以是蓄力攻击、防御、逃跑、治疗、呼叫同伴或其他可读行动。

每轮基本节奏：

```text
公开敌方意图
  -> 玩家催发一只或连续多只蛊虫，也可交涉、设局或撤退
  -> 真元、蛊虫条件与效果结算
  -> 敌方行动结算；合法反应型蛊虫可在规则窗口插入
  -> 持续状态、伤势、冷却与局势更新
```

玩家能催发所有已养、已炼化且满足可见条件的蛊虫。合法限制只能来自真元、伤势、冷却、封禁、目标、局势和蛊虫自身条件，不得来自隐藏的战前可用蛊列表或界面栏位限制。

每只蛊虫必须表达至少以下规则：转数、真元或仙元类型及催发消耗、阶段养护需求、效果、用途、名称、简介、背景、炼制信息、价格区间、基础价值和来源审查。首发实际可用蛊虫为一至三转凡蛊，使用真元。

蛊虫用途至少覆盖攻伐、防御、辅助、移动和治疗。真元消耗、持续时间、条件、状态生成与状态利用应形成可以自然组合的规则空间。

## 自由杀招、传承与长期增益

自由杀招不是系统预设的技能或唯一正确组合。它是玩家把多只已养蛊虫按自选顺序、条件、目标和时机共同使用后形成的战术方案。系统只一致地结算各蛊虫和状态互动，玩家可自行给常用方案命名、记录参与蛊虫、建议顺序和备注，用于检索、复盘与快捷操作。个人杀招方案不额外赋予伤害、保证触发或绕过规则条件。

例如，玩家可用光源类蛊增强光剑类蛊的威能，再以移动类蛊调整追击节奏，并用召回类蛊形成二次压迫。玩家可命名该方案，但游戏不弹出“发现官方杀招”。

内置内容仍然存在，但不替代自由组合：

- 消耗类蛊虫可提供当前跑局内的一次性或有限次数长期变化，例如力量、真元、恢复或抗性。
- 改造类蛊虫可改变身体相关规则，例如流血、骨骼、防御或行动；必须有明确代价、边界或机会成本。
- 前辈传承提供已被验证的局部协同方向、受限加成或炼制信息，例如围绕某些标签的有效搭配，但不排除玩家发现其他有效方案。

杀招可作为残蛊方的灵感来源：玩家的多蛊方案、传承或炼道情报可以指向一个将多蛊作用固化为单蛊的炼制方向，但不是每个方案都必须有唯一单蛊答案。

## 用、炼、养与构筑经营

蛊师与蛊虫的核心关系是用、炼、养。蛊师没有世界观意义上的持蛊数量上限；实际限制来自真元、元石、养护、功能重叠和同阶适配，而不是固定四槽或五槽。

### 养蛊总账

第一、二阶段结束时，自动汇总全体已养蛊虫的养护需求，结算为一笔元石总账。界面常驻显示“下次养护：预计 X 元石”，并在获得、出售、换取或炼制蛊虫后立即刷新。

不逐只投喂、不要求逐项收集食料、不在普通节点频繁弹账单。只有元石不足以支付总账时，才进入明确经营选择：卖蛊、换蛊、炼蛊、请求势力援助、接受附带条件的交易，或放弃部分蛊虫。不得无代价拖欠。

### 买卖与交换

商队、寨市、势力、传承和特殊事件持续提供买蛊、卖蛊、换蛊和炼蛊机会。商队或特定势力可给出一换一、多换一、蛊虫加元石、蛊虫加情报或蛊虫加人情的报价。珍稀蛊优先通过限量交换、传承、高风险遭遇、势力回报与炼制获得，不以普通货币直售为主。

低转蛊应保留多重价值：杀招的一环、炼蛊输入、指定交换筹码、势力所需物或可出售资产，而不是在获得高转蛊后变成纯垃圾。

### 炼蛊

炼蛊是正式构筑成长路径，需在商队、传承、事件或适当炼蛊场景获得机会、材料、信息与风险。

- 合炼：多只蛊虫共同炼制。
- 升炼：低转蛊虫升级为高转蛊虫。
- 平炼：炼制前后转数不变，改变能力、用途或形态。
- 逆炼：高转蛊虫还原为低转蛊虫。

每个配方声明输入蛊虫、材料、输出、转数变化、前置条件、风险和失败后果。失败可直接毁掉输入蛊虫；高收益炼制不能只损失可忽略材料。

## 修为与资质门槛

战斗不提供可直接自动升级的经验条。冲突、交易、探索与势力活动提供元石、材料、信息、修行环境和机缘；突破只在明确的修行节点、传承环境、特殊机缘或安全窗口中发生，并消耗资源、承担风险。

固定主角的修为流程：

```text
一转初阶
  -> 通过修行机会、资源和条件冲二转
  -> 丙等资质上限为二转
  -> 获得当前跑局的提升资质内容
  -> 开放三转突破机会
```

三转不是每局保底，也不是杀敌次数奖励。它是高价值路线成果，会改变真元品阶、可用内容范围和构筑上限。提升资质的来源必须稀有、可追溯、带机会成本，并进入事件日志。

## 势力关系

首发有四个原创地方势力，每局随机激活其中二至三个。它们受商家城、古月、铁家等原著大势的商路、规矩或威慑影响，但不直接搬用原著人物、既有支系或历史结局。

势力关系贯穿整局，影响路线信息、商队货品与价格、交换资格、委托、援助、遗藏撤离和升仙外扰。玩家无法让所有势力满意。为控制单人开发工期，实施顺序先完成两势力闭环，再扩到四势力。

## 终局与局外

第三阶段收束到固定顺序：

```text
击败固定守关首领
  -> 夺取遗藏
  -> 成功撤离
  -> 携遗撤离通关
  -> 或主动进入不可逆升仙考验
```

守关首领必战。击败后仍要面对撤离，势力关系、伤势、真元、情报、构筑与资源均影响结果。携遗撤离已是完整通关。

玩家主动进入升仙考验后必须完成一次不可逆冲击。考验为约 5--8 分钟的多轮第一视角结算，不显示成功率、风险评级、三气缺口或上帝视角提示。玩家依靠当下已知信息、伤势、空窍与真元、蛊虫、遗藏异状、环境与势力痕迹决策。

结局包括：升仙成功、活着失败但遗藏尽失、三气失衡身死。结局札记只根据不可变事件日志和玩家已知事实说明结果。

局外只保留图鉴、挑战记录、已知信息、结局札记和新可选内容。不保留永久属性、额外元石、额外真元或强化开局。

## 首个可验收纵向切片

在量产内容前，先完成一个可反复手工游玩的短流程，证明每个系统都落在同一条因果链上：

```text
可见分叉路线选择
  -> 中立蛊师遭遇（可交涉、欺骗、直接战斗或撤退）
  -> 全量已养蛊虫的抽象状态战斗
  -> 收刮元石、材料或情报
  -> 商队买卖和一换一/多换一
  -> 炼蛊场景（成功转化或失败毁蛊）
  -> 修行节点冲击二转
  -> 第一阶段养蛊总账和资金不足的处理选择
```

该切片必须允许多条可见路线、至少两种不同构筑走向、可胜利与可失败、完整事件日志和中文玩家界面。通过手工验收与自动领域测试后，才扩展为三阶段、完整势力、遗藏守关和升仙终局。

## 敏捷交付节奏

第二版采用短周期纵向切片开发，不以“完成一大套架构”作为交付目标。每一轮只加入一段玩家可操作、可失败、可得到不同结果的完整流程，并在同一晚提供 Windows 手工验收入口。

每轮固定顺序：

```text
固定种子验收场景和可失败测试
  -> 最小领域规则
  -> 中文玩家界面与可见反馈
  -> 自动测试、启动检查、手工试玩
  -> 用户验收反馈
  -> 下一轮只修正或扩展已验证流程
```

首轮目标仅为“路线 -> 中立遭遇的多种处理 -> 战斗或替代结果 -> 战利品 -> 商队调整 -> 炼蛊或修行 -> 养蛊总账”的可运行闭环。未通过手工验收前，不提前量产三阶段地图、数十个事件、完整势力池、美术资产或升仙终局。

每轮结束必须报告：实际可玩的入口、固定种子、覆盖的选择、已知限制、测试命令和结果。对用户验收中发现的规则或 UI 问题，优先在下一轮修正，不以文档补充替代可玩修复。

## 技术与质量约束

- 使用 Godot 4.6.2、GDScript、JSON 数据表与 GUT 测试。
- 场景仅展示状态和提交命令；领域规则为可测试纯 GDScript，UI 不直接修改状态。
- 随机种子、地图、数值、战斗、蛊虫、NPC 状态、存档和结局均本地可复现。
- 所有内容数据区分 `canon`、`adaptation`、`original_game_content`，并附来源和审查状态。详见 `docs/lore/`。
- 不修改 `vendor/godot-open-rpg/`；其引入与审计仍作为独立 Task 1，不能被 V2 内容开发绕过。
- 不修改受保护资料目录：`分支：六卷精编版/`、`豆包/`、`旧稿归档_不采用/`、`肉鸽设计-原始数据/`。

## 验收标准

第二版不以“能启动”作为完成标准。任一阶段实现必须能说明并验证：

1. 玩家在路线、节点、战斗、交易、炼蛊、修行和总账中作出了什么可见选择。
2. 该选择改变了哪些结构化状态、后续节点或结局条件。
3. 至少一条替代路径是否真实存在，而不是不同文案通向相同结果。
4. 规则是否可通过固定种子和领域测试重现。
5. 玩家是否能在不看调试日志的情况下理解当前局势、可用行动、主要代价和实际结果。
