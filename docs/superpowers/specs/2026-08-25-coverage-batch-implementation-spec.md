## T13 保底基础动作（拳脚攻击 / 闪避）

### 规则（用户原文口径）

- 常驻、**零消耗**（无真元/气血/寿元）、**非卡牌**（不占手牌与牌组容量、不触发魂魄反噬、不参与一心多用计数）；
- 拳脚：固定基础物理伤害，每回合可自由使用；
- 闪避：固定基础闪避概率，规避敌方单次攻击；
- 流派增幅（力道）留待 T15 字段接入。

### 实现设计

| 文件 | 改动 |
| --- | --- |
| `scripts/domain/battle_resolver.gd` | `take_turn` 增加 `basic_attack` / `basic_dodge` 命令分支（在 `end_turn` 等之外）：拳脚 = 固定 1 点伤害（+T15 力道力量），敌人反应机制适用（直接打击触发已知反应，与普通直击同权）；闪避 = 按概率结算（见下）、致"本次敌方意图无效化"状态 |
| 闪避口径（已裁定 2026-08-25） | **速度判定**：当玩家的闪避速度数值 > 敌方攻击速度数值时，豁免该次伤害；无随机、可复现。玩家基础闪避速度 = 2（`cultivator.speed`），力道敏捷/肉身增幅后续加成；敌方意图新增 `speed` 字段（兽扑 0 / 石掌 1 / 弩箭 3 / 瘴气 4；legacy 同类） |
| 事件日志 | 各自 append_event：`battle_basic_attack` / `battle_basic_dodge`（含命中/闪避结果、回合）；闪避状态写入 battle flags（`dodging`，`_apply_enemy_intents` 读取） |
| `scripts/domain/action_preview_service.gd` | 战斗预览：拳脚/闪避作为常驻卡（`battle.basic.*`），显示"0 消耗""伤害 1""闪避概率 X%"；不依赖任何资源 |
| `scripts/presentation/battle_view.gd` | 手牌区下方常驻两个按钮（点击走 command 流，场景零裁决） |

### 测试（tests/unit/test_basic_actions.gd）

1. 真元 0、空手牌状态仍可出拳且 accepted；事件 reason 正确。
2. 拳脚造成 1 伤害；引爆已知反应（如石甲返击）与蛊卡直击同规则。
3. 拳脚不改变 `hand_version`、不触发魂魄反噬（soul 不变）。
4. 闪避（速度判定）：玩家闪避速度 > 敌方攻击速度 → 敌方意图伤害为 0 且 battle log 有 dodged 记录；≤ 敌方速度 → 伤害照常；状态单次消耗。
5. 闪避状态跨回合清除（只在闪避当回合生效）。
6. 闪避动作本身无消耗、可连续使用（每回合一次由行动经济天然限制）。

## T15 三流派框架（血道 / 气道 / 力道）

### 范围声明

流派是**新的核心构筑方向**：开局可选 3 选 1，卡牌效果/养成逻辑差异巨大。本批立**框架与数据契约**（可测试、可被后续卡牌数据填充）。**5 张初始蛊卡数据由用户提供**（已裁定）；我定义数据契约（`data/gu.json` school 字段、`data/schools.json` schema）并提供三流派初始卡 JSON 模板，用户填数后我接线激活开局池。

### 框架设计（草案）

1. 数据：`data/gu.json` 每蛊加 `"school": "blood"|"qi"|"force"`（现有 13 蛊按效果归派，新蛊必须带学校）；`data/schools.json` 定义流派描述、初始蛊列表（各流派 5 张开局蛊草案）、专属规则开关。
2. 开局：标题画面"选择流派"→ `run_state.school`（存档/读档随 run）；`new_run` 按流派注入初始蛊（现固定小光蛊）。
3. 力道：`cultivator.force_power`（永久力量加成）字段；永久增幅蛊用"体印式"一次性生效写 `force_imprints`（复用 `body_imprints` 模式，事件日志记录）；**拳脚伤害 = 1 + force_power**（接 T13 字段）；闪避概率随敏捷增幅（数据口）。
4. 血道：叠层计数 `blood_stacks`（战斗 dict 内）+ 层数无上限的叠层结算助手；效果数据由卡牌定义引用助手。
5. 气道：依赖"材料获取/材料卡"缺口——需先补覆盖批的"材料掉落 + 材料买卖 + 材料炼蛊"（§7 缺口）后接线：材料→临时卡 `materials` 转化助手。
6. 全局图鉴/黑市/恶名等既有系统对三流派透明。

### 测试（tests/unit/test_school_framework.gd）

1. 数据校验：所有蛊携带合法 school；schools.json 引用蛊存在且数量达标（初始蛊 ≥3）。
2. 开局选流派 → `run_state.school` 正确、初始蛊按流派注入（旧默认小光蛊保留为非流派通用备选）。
3. 力道：`force_power` 增长事件 + 拳脚伤害加成（T13 联动）。
4. 血道叠层助手：叠加/结算/上限无限制。
5. 气道材料卡助手：仅在有材料时可用、用后销毁（契约层）。
6. 存档/读档携带 school/force_power。
