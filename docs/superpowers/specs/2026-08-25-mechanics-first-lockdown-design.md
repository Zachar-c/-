# 机制先行锁死规格书：南疆卡牌肉鸽冒烟切片

> 日期：2026-08-25。状态：**生效基线**（同日两次用户裁决：一次采纳 §3.3 裁剪建议与 §3.4 优先级；二次对照两份世界观参考稿裁定五流派与哲学基调，见 §16）。
> 输入：通用 Roguelike 固化系统设计框架（杀戮尖塔/哈迪斯/死亡细胞等萃取）+《Roguelike 反例设计禁忌规范》（P0–P3 四级黑名单）。
> 地位：本文档是**机制权威基线**。《2026-08-21 冒烟版设计》降为参考；`AGENTS.md` 中已裁定的方向条目若与本文冲突，以本文为准并回写 `AGENTS.md`。
> 方法论裁定：**先锁死机制，再包世界观**。绝大多数翻车独立游戏的死因是先写宏大世界观、玩法适配不上，被迫删系统改逻辑砍特色。因此本文 Part 1 用主题无关术语锁死玩法，Part 2 才允许世界观上身，Part 3 对照正反两套规范给出差距审计。

## 0. 判定基准与文档纪律

- 优秀肉鸽唯一判定标准：玩家每一局的强弱，主要来自**本局随机获取与本局决策**，而非跨轮刷取、固定数值碾压或纯随机运气。
- 机制先行纪律：任何世界观内容必须挂在 Part 1 已锁定的机制槽位上；没有机制槽位的世界观设定不进入版本。
- 双规范约束：Part 1 每一条规则同时通过正面框架（八大强制模块）与反例黑名单（P0–P3）检验；冲突时以更严格者为准。
- 新功能准入四问（2026-08-25 十批输入确立的常设门槛，任何新蛊/新事件/新系统提案先过一遍）：①会把本局强力效果带到下一局吗？②会强迫玩家为了外部奖励违背本局 Build 吗？③支持回退或 SL 撤销代价吗？④会用跨局数值养成碾压本局随机与抉择吗？任一答案为「是」即否决。另两条底线：风险与代价必须对玩家可见，收益必须附带对应代价。
- 本文档只锁结构与规则，不锁具体平衡数值；平衡数值归数据表，改动不需修订本文，但不得违反本文的结构性条款。

## Part 1 纯机制规格（主题无关）

### 1. 轮回生命周期（Run 循环）

```
大厅(极简元界面, 跨局存档)
  → 开局构建(三选一流派 + 固定初始卡组 + 初始资源)
  → 一转…五转：每转 2–3 个候选节点中选 1–2 个推进 + 转末收敛突破节点(层Boss)
  → 五转末：冲仙窗口(终局Boss/终局判定)
  → 结局(成功 / 险成 / 失败求生)
  → 结算(统计 + Build复盘 + 解锁素材发放)
  → 返回大厅
```

- R1.1 单局 Run 内获得的卡牌、被动、元石、消耗品，在 Run 结束时**全部清零**。
- R1.2 大厅只保留：解锁进度、跨局图鉴、上一局结算回看。无叙事化主城。
- R1.3 **死亡必有正向收益**：胜利、险成、失败求生三种结局均按进度发放解锁素材；进度永不倒退【反例 4.3 否决项】。
- R1.4 单局目标时长 45–90 分钟，总有效节点 10–14 个（沿用旧基线预算）。
- R1.5 关闭游戏≠放弃本局：中途关闭自动保存 Run 状态，重进续玩；续玩只能向前推进，不可回退重roll任何已结算奖励【反例 P3 SL 禁令】。
- R1.6 只有主动放弃本局才结算为失败求生，发放解锁素材，不扣任何进度。
- R1.7 结局族：冲仙成功 / 险成 / 失败求生 / **蛊化坠落**（反噬累积失控，被自身蛊吞噬——非战斗死亡的另一种轮回终点，阈值可见可管理见 R9，解锁专属内容）/ **中途遁走**（隐藏逃离节点，收益低于通关、高于死亡，只带解锁素材不带任何组件）/ **真结局**（苛刻条件组合）。无论哪种结局，本局所有局内组件一律清空，只产出大厅永久进度。全部结局通用铁则：①**必须经玩家主动确认触发**——反噬/躁动等数值阈值只负责解锁选项（如「拥抱蛊力」抉择），最终以二次确认弹窗执行，禁止不经选择强制结束 Run；②非死亡结局分支需**本局行为与线索解锁**（全程压低躁动则蛊化分支不出现），不得每局无条件出现、不凭空弹出；③收益排序铁则：死亡/失败求生 ＜ 中途遁走 ＜ 蛊化坠落 ＜ 险成 ＜ 冲仙成功 ＜ 真结局——退路永远是保命选项，不是最高奖励路线。

### 2. 资源规则锁死

| 资源 | 归属 | 规则 | 清零时机 |
| --- | --- | --- | --- |
| 气血（生命） | 局内 | 最重要资源；回血手段稀缺，主要来自休整节点与治疗类组件 | Run 结束 |
| 真元（行动能量） | 局内 | 打出卡牌的费用；每回合重置为基准值，上限可被组件改变 | 每回合重置 |
| 元石 | 局内 | 唯一通用货币：买卡、买被动、移除、情报、服务；供给总量受控，商店不可买空 | Run 结束 |
| 魂魄（上限值） | 局内属性 | 派生战斗操作上限（每回合可催动卡牌数）与炼蛊投入上限；非线性曲线增长；超出安全上限催动触发魂魄反噬并扣减魂魄；**魂魄耗尽即死线之一**（必须可预见，见 R2.3） | Run 结束 |
| 局内材料 | 局内 | 地图掉落、敌人拆解与场景搜集所得；气道/炼道的核心战力载体，可直接转化为战斗效果、可投入炼蛊；气道享有地图材料保底 | Run 结束 |
| 寿元 | 局内代价媒介 | 不可逆消耗，用于特殊交易与禁忌收益的支付；消耗前必须预检明示，禁止静默致死 | Run 结束 |
| 修为 | 局内进度 | 转数门槛；达到门槛才解锁对应转数的地图与突破节点 | Run 结束 |
| 解锁素材 | **跨局唯一** | 只用于图鉴/组件池解锁，不能购买任何局内数值【反例 4.5】 | 保留 |

- R2.1 局内所有交易、强化、获取只能使用局内资源；局内强度绝不绑定跨局资源。
- R2.2 任何消耗寿元/气血的交易与反噬结算，执行前必须预检并显示明确文案。
- R2.3 三死线可视化：气血/寿元/魂魄临界值常驻高亮预警；任何死亡结算弹出精准死因（气血耗尽/寿元枯竭/魂魄耗尽），禁止模糊暴毙；魂道等流派的**明示主动透支**允许致死，但同样必须预检确认【反例 P3 信息不透明】。

### 3. 地图系统

- R3.1 结构：网状收敛图。每层展示 2–3 个候选节点，玩家选 1 个进入；每转末强制收敛到突破节点。禁止纯随机乱跑迷宫，也禁止纯线性无选择地图【反例 P3】。
- R3.2 节点类型池固定 7 种：普通战斗、精英战斗、宝箱/机缘、黑市（商店）、事件（问号）、休整、突破节点（层Boss）。五转末为冲仙窗口（终局）。
- R3.3 信息迷雾：当前层可选节点可见类型，下下层不可见；侦查类卡牌、情报商品、事件结果可揭示局部信息。不做一键开全图。
- R3.4 路线权衡铁则：每个候选节点必须有明确的风险/收益差异标注——高奖励=高危险，安逸=低回报【反例 5.1 否决虚假多选项】。
- R3.5 层数权重：低级组件前期高概率，强力核心组件中后期提升概率；前期不得出现毁灭级事件【反例 P3 权重混乱】。
- R3.6 节点一次性（2026-08-25 十九批输入）：地图节点一经通过即完成，不刷新、不重来；不存在重复刷怪或无限获取资源的途径。单局成长轴**唯一为修为/转数**（R2），以五转为天然上限封顶，**不另设平行经验等级系统**。

### 4. Build 组件四分类

| 分类 | 内容 | 约束 |
| --- | --- | --- |
| 角色基底 | 流派（5 选 1：血/气/力/魂/炼），自带专属机制、初始卡组、专属组件倾向 | 改变整局游玩逻辑，不只是数值差异 |
| 主动组件 | 卡牌（蛊）：战斗主要输出与工具手段 | 逐步获取，不许开局全拿 |
| 被动组件 | 常驻规则改变效果（框架中的"遗物层"，**本作最大待建缺口**） | 以触发/联动为主，多个被动可互相叠加产生 combo |
| 消耗品 | 一次性道具 | 只救急，不能主导 Build |

- R4.1 联动＞数值：核心组件池必须以条件联动触发为主，纯「攻+X/防+X」式组件占比不得超过 40%【反例 5.4】。
- R4.2 获取渠道至少四条：战后奖励三选一（权重池+保底）、黑市定向购买、炼蛊合成产出、事件授予。
- R4.3 改造渠道每局至少两条且全程可达：黑市移除/替换服务（价格递增）、休整节点移除负面、事件删除/重roll【反例 4.4 否决 Build 锁死】。
- R4.4 Build 分水岭：中期（约二至三转）凑齐 2–3 件联动组件后玩法质变；验收时必须能在实际对局中指出分水岭时刻。
- R4.5 稀有度四级：普通＜稀有＜史诗＜传说；传说一局自然获取 1–3 件并设软上限——每获取一只，后续同类出现概率递减，防多传说 Build 碾压全局。
- R4.6 组件池过滤：抽卡池按流派倾向 + 层数权重过滤，防止新增内容稀释 Key 组件概率【反例 6.1】；玩家所选流派的专属蛊在所有奖励 roll 中获得权重倾斜（不锁死，通用蛊仍可出现），杜绝「玩 A 流派整局刷不出 A 核心蛊」。反向饱和倾斜：当本局同流派核心组件已趋饱和，后续掉落适度提高对立流派权重以促成取舍——只调倾向不锁死，玩家仍可坚持特化（配合「偏执倾向」类契约）。
- R4.7 五流派机制锚点（2026-08-25 二次裁定：初版直接五流派；专属卡池与平衡数值归数据表）：
  - **血道**：以气血为核心博弈载体——自损爆发、敌方流血、掠夺续航；低阶蛊多卡堆叠，成型最快、血线容错最低。
  - **气道**：局内材料直接转化为瞬发战力，用完即耗，无固定牌组束缚；材料耗尽战力滑坡，配地图材料保底兜底。
  - **力道**：全流派最低真元消耗；永久肉身增益走递减曲线，蛊虫消耗后增益留存；兜底拳脚/闪避动作全额继承力道加成。
  - **魂道**：可主动超额释蛊触发魂魄反噬，并将反噬损耗转化为伤害/抽牌/增伤；唯一被设计为可明示透支至死的流派，操作上限与风险全流派第一。
  - **炼道**：唯一可在战斗内简易炼蛊（献祭/融合/重塑手牌）的流派；战斗内炼蛊只优化本局战力，不解锁全局图鉴。
- R4.8 元机制型印记：允许极少数修改底层规则的被动（调换生命规则、改变回合行动逻辑、改写奖励规则等）；**一局出现 ≤2 个**，超出即玩家理解成本灾难；它们是反噬补偿、事件奖励、精英专属奖励的顶级载体。
- R4.9 组件槽位有限：卡组、印记槽、消耗品栏各有上限；获取新组件经常伴随替换/放弃决策，不允许无限拾取。槽满时获取新组件必须弹出取舍弹窗（拾取并替换 / 直接放弃），**禁止无提示强制覆盖旧组件**。扩容仅可经事件或特殊奖励少量获得：设全局硬顶、本局有效、且通常附带代价（如「+1 蛊槽，但蛊躁动获取加快」）；不存在可无限堆叠的扩容道具。
- R4.10 组件信息全量前置：蛊卡 tooltip 固定格式——名称、品质标签、主效果、联动提示、释放代价、诅咒负面后果；所有数值写死（禁止「造成大量伤害」「一定概率」式模糊文案）；代价前置可见，不得藏在描述末尾；诅咒蛊强红色视觉警示（红边框/红标题），传说金边。数据表已声明的联动必须在 tooltip 写出，不做纯隐藏 combo。

### 5. 战斗规则

- R5.1 回合制：每回合玩家以真元打出卡牌，行动次数受魂魄派生上限约束；敌方按固定行为表行动。
- R5.2 敌人三级：
  - 普通敌人：输出平稳，奖励常规；
  - 精英敌人：高输出高奖励，**奖励必须附带代价**（附赠被动+随机反噬、高额元石但提升恶名等）【反例 5.2 否决白嫖】；
  - 突破节点/Boss：拥有专属机制与阶段变化，**禁止只堆血量伤害**【反例 5.5】。
- R5.3 撤离始终可用，但依地形、追击状态与敌方控制能力判定，并付出资源/伤势/恶名代价。
- R5.4 战斗不是唯一解：每个节点类型至少存在一条非战斗等效路径（交涉、情报、交易、伪装、撤离、恶名规避）。
- R5.5 情报链：侦查/事件产出弱点情报 → 对应敌人战斗中获得增伤，增伤走乘区。
- R5.6 敌人意图池：敌方从行为池行动且每回合**明示下回合意图**（攻击 X 伤害/获得增益/召唤/施诅咒等），玩家可预判而非猜拳；禁止纯「攻击→防御」循环与暗箱猜拳式 AI。行为权重随敌我状态动态调整（如自身残血抬升自爆/反噬类权重、玩家诅咒多抬升施毒权重），但意图展示永远在行动之前；意图必须包含具体数值与效果文字（如「准备释放蛊毒｜造成 12 伤害，施加中毒」），不允许只放图标让玩家猜。
- R5.7 敌人也有构筑：普通敌人 3–5 种行为；精英 6–8 种行为且自带 1 个专属敌方蛊（永久被动）；Boss 拥有独立行为阶段，按血量分段切换行为组，阶段切换可清除/新增战场状态（参考数值见 §16.3）。
- R5.8 环境击杀合法：敌人可被反噬、持续伤害、环境效应杀死；套路流与对拼输出同等正当。
- R5.9 强力行动必有后坐：玩家高威力蛊至少绑定两类释放代价——①精血代价（扣当前生命，护盾不可抵消）②自叠反噬/负面状态 ③疲劳封印（该蛊若干回合不可再用）；并附带下一回合受限类代价以防无限爆发循环。
- R5.10 敌人反制行为族：精英/Boss 至少具备一类反制——周期净化自身负面、针对玩家高频爆发的反噬反击、召唤改变战场、以自身血量换取强力蛊效；禁止玩家用单一控制套路无脑控死全场。
- R5.11 敌方高危行为冷却：毁灭性敌方动作设冷却计数器与权重上限，禁止连续重复释放。
- R5.12 敌我同源诅咒系统：敌方施加的诅咒蛊与玩家获得的诅咒组件同属一套状态系统、走相同解除渠道；诅咒体系敌我都可用，不只玩家专属。
- R5.13 状态三要素与统一叠法：每个状态记录剩余回合数、叠加层数、来源（玩家/敌方）；同类状态相遇时「叠加层数」或「刷新回合」二选一且全局统一，不得随机混用。
- R5.14 硬控上限：眩晕/禁锢类强控对精英/Boss 设最大生效回合（如 Boss 至多 1 回合），到期后获得短暂控制免疫；任何 Build 不允许无限控死 Boss。
- R5.15 伤害双通道：外部攻击伤害优先由护盾吸收；反噬、精血自损、诅咒扣血**绕过护盾直接扣生命**——反噬伤及本源，护盾挡不住，同时防止护盾解决一切问题。UI 层护盾与生命**分条展示**（护盾蓝条、生命红条），反噬扣血走生命条并给独立受击表现，杜绝「看不懂为什么扣血」。
- R5.16 封印只锁新开：蛊槽被封印时，已生效的被动蛊继续生效，仅禁止主动释放与新开启；禁止静默清除已挂载的被动。
- R5.17 死亡结算顺序写死：血量归零 → 先结算全部死亡遗言效果（自爆蛊、死亡蛊毒等）→ 再执行死亡 → 最后结算击杀奖励；顺序固化进引擎，杜绝遗言丢失类恶性 bug。
- R5.18 无限 combo 天花板：触发类效果设单回合硬上限；强力蛊使用后叠加【蛊躁动】，层数越高后续反噬越重；Boss 阶段切换可清除玩家身上无限叠加类 buff。给 combo 设天花板，不删除 combo。

### 6. 交互系统（非战斗路径）

- R6.1 NPC 三立场：中立/敌视/极度仇恨；高恶名必触发其一；极度仇恨禁止逃跑选项（高风险选择的代价）。
- R6.2 恶名是风险调节器而非纯惩罚：部分路径需要高恶名才能进入（威慑、黑市深水区），部分路径被高恶名关闭。
- R6.3 黑市防刷：同一市场二次访问价格上涨 +25%/次，封顶 +100%；卖家同向压价。NPC 交涉失败种子化翻转立场。
- R6.4 所有交涉、交易判定本地种子化可复现；文本生成（若有）不得触碰数值与状态。
- R6.5 经济供给硬上限与禁令：单局元石总产出控制在设定区间内，禁止事件/奖励无限刷钱买空商店；禁止「储存货币延迟释放」类组件；禁止局内贷款/负债机制。
- R6.6 温和通胀：越晚出现的商店物价小幅上涨，鼓励早期消费而非囤积到最后。
- R6.7 应急支付与非货币通道：事件与特定黑市摊位接受以气血/寿元/承受反噬/**销毁一只自身组件**替代元石支付，给穷局保留取舍路径（代价守恒的货币面）。
- R6.8 关键服务结构：移除、洗炼、定向购买稀有组件是黑市付费服务（休整节点移除作为第二渠道的既有裁定维持，受节点频度自然限制）；服务单次成本逐级递增且设单局次数上限（参考值：刷新 ≤3 次、移除 ≤2 次）；战斗掉落以基础组件与小额元石为主，防止经济形同虚设。商店界面必须显示服务的本局剩余可用次数与当前价格，通胀上浮以小字说明（如「层数提升，物价小幅上涨」）；「购买获得此蛊」与「付费屏蔽池子」是两个操作，文案不得混用。
- R6.9 产出风险挂钩：精英战斗与高代价事件给大额元石，普通战斗小额，纯安逸路线金钱收益偏低；高风险必须对应更高回报，大额元石奖励必附代价【反例 5.2】。
- R6.10 货币保底补额：若前几层总产出低于下限，后续战斗/宝箱小幅补额；允许贫富差距，禁止两极分化。

### 7. 事件系统（问号节点）

- R7.1 每个事件 2–3 个选项，全部是取舍，**不存在无代价最优解**；输出类型限定：获得组件/损失气血/损失元石/获得反噬/开启情报/开启隐藏路线。
- R7.2 事件池按层数权重管理；毁灭级事件不入前两层。
- R7.3 禁止无预警即死陷阱：任何致死可能必须在选项文案中明示【反例 P3】。
- R7.4 未选择的路线消失或转化为后果，不做无效摆设选项。
- R7.5 选项后果预览：事件每个选项标注预期风险与收益方向（如「获得稀有蛊，承受诅咒【蛊蚀】」），不做纯盲选；即死可能强制警示（承 R7.3）；事件界面提供侧边快捷查看自身气血/魂魄/元石/蛊虫，抉择时不必盲猜家底。

### 8. 休整节点

- R8.1 强制二选一（或多选一），不可全拿：回血 / 强化一张卡 / 移除一张卡或负面组件。
- R8.2 闭关型休整可挂载资质途径（洗髓换骨：一局一次，消耗寿元+元石，提升真元上限）；它属于局内构筑投资，不属于跨局成长。
- R8.3 关键成长奖励多选一（2026-08-25 十九批输入映射）：转数突破等成长节点的奖励一律**多选一**且功能向优先——克制幅度的基础属性提升 / 稀缺的蛊槽扩容 / 随机蛊（附躁动等代价）/ 元石与本局材料；禁止全部直接获取。基础属性增幅严格克制，**强度主体永远来自蛊构筑组合**，成长轴不得沦为数值碾压通道。

### 9. 反噬系统（诅咒层，新增）

- R9.1 获取途径：精英奖励附带、事件代价、黑市高回报交易、炼蛊盲盒失败。
- R9.2 效果必须干扰战斗/构筑逻辑（污染抽牌、费用上涨、禁用槽位、翻面惩罚等），不是单纯扣气血。
- R9.3 **必有解除渠道**（黑市移除、特定事件、特定卡牌），解除需付出明确代价；反噬是本局要处理的挑战，不是恶意折磨【反例 5.3】。
- R9.4 高收益必绑反噬：传说级被动、超额元石、禁忌交易的代价优先以反噬形式回收【反例 5.2】。
- R9.5 反噬时效压力：未解除的反噬/诅咒随层数推进逐步加重（软性放大早期问题），逼迫玩家在合适节点消费处理，而非无脑囤钱到最后。
- R9.6 诅咒准入边界：诅咒蛊不进入普通战斗与普通宝箱掉落池；只来自事件抉择、精英代价奖励、黑市高收益选项——**获取诅咒永远是玩家主动选择的结果，不得被动强制塞给**。

### 10. 炼蛊合成

- R10.1 三通道保留：定向（按配方）/ 组合（满足标签条件）/ 盲盒（随机结果）。
- R10.2 盲盒失败产出反噬或垃圾组件——它是反噬系统的自然入口之一。
- R10.3 配方属于跨局图鉴：已解锁配方后续对局可见、可炼（2026-08-25 已裁定豁免）。
- R10.4 炼蛊产出走组件稀有度体系；传说级产物一局仍限 1–3 件总盘。
- R10.5 战斗内简易炼蛊为炼道专属；其产物只存在于本场战斗/本局，不触发跨局图鉴解锁（防止对局行为泄漏为永久进度）。
- R10.6 拆解（2026-08-25 十八批输入）：多余蛊可在**炼蛊台节点或特定事件节点**拆解为本局材料——被拆解的蛊直接消失，换取少量材料。拆解是取舍行为而非资源循环，不存在无代价无限刷材料的组合；材料仅限本局使用、不可跨局。

### 11. 永久成长（大厅解锁）

- R11.1 只做解锁池：新卡入池、新配方、新敌人、新事件、新流派变体。解锁扩大可能性，不增加开局数值【反例 4.1】。
- R11.2 未来若引入任何永久数值加成，硬性上限：对局难度影响占比 ≤15%，且默认关闭。
- R11.3 关键内容解锁肝度受控：单条解锁内容的期望获取次数不超过 3 局正常进度【反例 6.4】。
- R11.4 禁止存档读档重复刷奖励：读档只能重放已保存事件得到相同状态【反例 P3 SL 禁令】。
- R11.5 传承三式边界（2026-08-25 三批采纳、十一批收紧、十四批补强）：允许①记忆碎片——**必须经开局大厅契约主动开启（如「轮回感应」，默认关闭）**后，本局商店小幅提升往期高频组件的出现权重，只是概率不是直给，Run 结束失效；**概率类传承契约必须附带对等负面代价**（如【轮回洞察】：高频蛊掉落权重上升、诅咒蛊出现率同步上升），收益风险绑定；②残影事件——事件房间遭遇上一轮的自己，残影只复用上局蛊虫组合与战术作为 AI 行为与演出，**属性按本局难度重新缩放、绝不继承上一局数值**；战胜或交易获得一次性局内增益；③知识解锁——重复遭遇解锁叙事文本/蛊方笔记，零强度。红线：传承只碰概率、叙事、一次性效果，严禁跨轮带走任何局内组件；禁止打完一局自动给下一局加成而玩家无法关闭。
- R11.6 传承不磨平代价（2026-08-25 十四批输入）：轮回积累的一切内容**不得永久降低契约、诅咒、反噬的负面强度**——代价体系恒定，「力量必有反噬」的主题不可被传承侵蚀。大厅存档只保存已解锁手记、已解锁契约、轮回总统计三项，**绝不持久化上一局 Build 与本局临时权重**——上一局构筑数据仅用于残影事件一次性生成，用后即弃、不入档。轮回统计为纯展示记录，零玩法加成。

### 12. 结算系统

- R12.1 无论胜败：展示本局统计、Build 构成复盘、路线图与精准死因可视化、修行札记归因（只读不可变事件日志与玩家已知事实）、发放解锁素材。
- R12.2 结算素材与剩余货币脱钩：解锁素材只按进度里程碑计算（推进转数、击败精英/突破节点、完成特殊事件、达成特殊条件），**绝不按剩余元石折算**——防止玩家刻意囤钱换进度，扭曲全部消费决策。
- R12.2 结算后返回大厅，立即具备开始下一局的完整入口。

### 13. 可控随机三件套（保底范式）

- R13.1 分层权重（R3.5/R4.6）+ 稀有保底：连续 3 次**冒险掉落**未出稀有及以上，下一次必出稀有及以上；拿到稀有+即清零计数，轮回结束重置。保底只抬品质下限、**不指名具体蛊**，禁止保底直给传说——保底补偿坏运气，不消解高期待。商店购买不推进也不消耗保底计数（保底是冒险的补偿，不能靠消费刷出来）。精英与突破节点必掉史诗及以上。
- R13.2 定向补救渠道：黑市可定向购买指定类别组件；事件提供定向取舍。
- R13.3 垃圾兜底：任意烂开局都存在可行的移除/替换路径（R4.3），不允许"天崩坐牢局"无法翻盘【反例 4.2】。
- R13.4 池排除权：黑市/休整可付费将指定组件**临时移出本局奖励池**（本局有效，轮回结束重置）；「移除身上的蛊」（只删身上这只，不影响后续 roll）与「池排除」（本局不再刷出）是两个操作，UI 文案必须明确区分。
- R13.5 奖励来源隔离：普通战斗池以普通+少量稀有为主；精英/Boss 奖励池提高史诗/传说权重；商店池含本局流派专属蛊；事件池允许混入诅咒蛊。同一蛊在不同来源权重不同，拉开风险收益差。
- R13.6 池工程边界：①未在大厅解锁的内容绝不进入本局随机池；②过滤/排除后池为空时自动回退基础通用池，不允许程序卡死；③同一次奖励弹窗内不出现重复组件；④真结局/隐藏蛊走独立触发池——不混入普通奖励池、不可被运气 roll 出。

### 14. 数值底层范式

- R14.1 伤害与增益计算倍率乘区优先，简单加法为辅；乘区层数设上限防爆炸。
- R14.2 气血是最重要资源，回血稀缺；修为门槛制造阶段压力。
- R14.3 平衡验收要求：五个流派均能以正常决策通关标准难度；不允许只有一套 Meta 可通关【反例 6.2】。
- R14.4 动态危险等级（力量反哺世界）：本局获取超额强力组件后，后续节点提高精英/诅咒事件权重——你越强，世界越危险；**必须 UI 明示提示（如「蛊力躁动，周遭危险提升」），禁止暗地加强导致莫名暴毙**。危险等级仅本局有效，绝不跨局携带。
- R14.5 动态难度自适应总则（2026-08-25 十三批输入）：分两层——**进度驱动**（层数推进改变敌人池组合与地图结构，必做，由 R3.5/R4.6 承载）与**本局状态驱动**（依当前气血比例、构筑强度、元石存量、躁动等级、近几场损耗调整后续内容，谨慎启用）。判断输入**只读本局 Run 内部数据，严禁读取跨局胜率/通关次数**。手段优先级：换敌人种类与行为池 ＞ 调地图节点权重 ＞ 调奖励与商店供给 ＞ 调经济产出；数值乘算只作最后兜底且倍率限制在很小区间【反例 5.5】。
- R14.6 自适应硬边界：①任何触发必须生成**全局元机制标记**（如【险象】/【衰运】）写入 `RunData.meta_rules`，顶部常驻图标 + Tooltip 写明改动内容 + 触发弹窗提示，并与玩家自选契约在 UI 上分区展示、不得混淆；②同类互斥，同时至多存在一条系统自适应标记（新替换旧），禁止无限叠加；③设压力阈值上限——即使处于高风险标记，休息点与补救事件仍保持生成概率，不允许把本局逼入无解死局；④增加风险而非废除 Build：可以多刷精英，但不刷完全克制玩家套路的敌人；⑤只修改概率与生成权重，**绝不直接赠送蛊虫/血量等战力道具**，救局手段留给事件抉择与黑市；⑥大厅设置提供「关闭本局状态自适应」开关（关闭后仅执行固定进度难度）；⑦Boss 战内局部自适应（按玩家蛊组合切换招式）仅限本场战斗，UI 提示「Boss 感知你的蛊力，招式发生变化」，战斗结束立即清除、不扩散到地图层；⑧结算页复盘展示本局触发过的自适应标记，调试面板暴露触发条件与评估分数。系统侧自适应标记属于元机制载体，但**不计入 R4.8 玩家元机制 ≤2 的上限**。

### 15. 可选扩展模块（按需接入，缺省不做）

| 模块 | 优先级 | 说明 |

契约系统补充约束（2026-08-25 十五批输入；契约=P2 模块，实装前按此锁死）：

1. 契约是**开局全局规则修改器**——大厅选好再开 Run；局内元机制则是中途经事件/Boss/自适应获得。两者统一注入 `RunData.meta_rules` 执行，UI 以【契约】标签（蓝系图标）与【本局异变】标签（黄红系图标）严格区分。
2. 每条契约必须**收益与对等代价成对存在**，不存在纯正向契约（自愿「自苦」型负面契约除外：无奖励加成的纯自我挑战）。
3. 回报形态锁定为**大厅解锁素材倍率**——代价越高倍率越高；绝不在本局赠送蛊虫/元石/生命。
4. 优先改写池子、战斗公式、地图生成（如「命运盲盒」关保底、「共蚀之约」反噬共担、「险途」增精英减休整）；数值乘算型契约只作少量兜底。
5. 同时启用数量软上限 5–6 条；逻辑冲突的契约在 `contracts.json` 互斥 ID 列表中声明，不可同选。
6. 普通清除手段（解诅咒蛊等）**不可撤销契约效果**；唯一例外是极罕见事件付出巨大代价放弃单条契约，Tooltip 写明「普通清除无效」。
7. 解锁条件绑定结局/特殊事件/手记收集，禁止按轮回次数解锁；解锁状态存大厅存档，效果仅当前 Run 生效、结束清空。

包装纪律：

1. 世界观只解释、美化 Part 1 已锁定机制，**不新增机制**；
