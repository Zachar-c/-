## WORLD_POSITION

> **《问真》不是一个修炼者寻找力量的世界，而是一个人类通过理解、培育、组合和驾驭具有规则能力的生命，将自身与世界共同改造的蛊道文明。**

核心区别：

普通修仙：

```text
人 → 修炼 → 获得力量
```

《问真》：

```text
人
↓
发现规则生命（蛊）
↓
理解其规律
↓
培育、炼化、组合
↓
形成新的规则能力
↓
改变自身、社会与世界
```

因此视觉核心不是：

> “一个人有多强”。

而是：

> “一个生命如何成为一条道路”。

## CANDIDATES

### 方案一：东方规则炼成世界

#### 核心命题

> 将蛊表现为世界中的“规则器官”，强调炼化、组合和成长过程。

视觉预算主要投入：

```diff
规则可视化
+
能力结构
+
炼成过程
```

不是展示“神秘生物”，而是展示：

> “为什么这个蛊可以产生这种力量。”

#### HARD 适配

高度适配。

原因：

HARD 对象不会被美化覆盖，而被强化理解。

例如：

月光蛊：

不是：

> “漂亮月系少女”

而是：

> “弯月蓝晶生命体，其结构天然产生月刃规则”。

#### SOFT / OPEN 用法

主要利用：

SOFT：

- 材质重构；
- 内部结构；
- 灵气循环；
- 生命组织。

OPEN：

- 微观结构；
- 规则纹理；
- 能量循环。

视觉语言：

```diff
蛊
=
生命
+
规则
+
器官
```

#### 拟人化与角色化

限制较高。

主题层允许：

- 化形；
- 投影；
- 象征人格。

但是核心价值不是角色。

角色化必须回答：

> “为什么这个规则生命会形成这个人格。”

#### 玩法连接

非常强。

天然支持：

##### 单蛊

展示：

```text
蛊本体
↓
能力
↓
代价
```

##### 炼蛊

视觉表现：

```text
多个规则生命
↓
融合
↓
新规则诞生
```

##### 杀招

表现为：

```text
多个蛊
+
组合关系
=
临时规则系统
```

##### 蛊屋

表现：

```text
大量规则固定化
=
永久规则建筑
```

#### MVP 验证

月光蛊：

验证：

```text
一个小生命
是否能让玩家理解：
它为什么能释放月刃
```

#### 风险

风险：

商业传播上可能偏理性。

玩家第一眼可能认为：

> “这是一个复杂系统游戏”。

而不是：

> “我想收藏它”。

### 方案二：超凡生态收藏世界

#### 核心命题

> 将蛊表现为拥有独特生命属性的超凡生命收藏体系。

视觉预算主要投入：

```diff
生命感
+
收藏价值
+
个体魅力
```

核心问题：

> “如果这个世界真的存在蛊，人为什么想拥有它？”

#### HARD 适配

中高。

保留：

- 身份；
- 能力来源；
- 标志结构。

但允许更多：

- 生物设计；
- 材质设计；
- 情感表达。

#### SOFT / OPEN 用法

大量利用：

OPEN：

- 未描述蛊；
- 概念蛊；
- 高阶蛊。

SOFT：

重新解释：

- 外形；
- 生态；
- 成长阶段。

视觉语言：

```diff
蛊
=
生命收藏品
+
伙伴
+
力量来源
```

#### 拟人化与角色化

空间最大。

主题层天然成立：

例如：

月光蛊：

本体：

```text
蓝色弯月晶体生命
```

主题：

```text
月之精灵人格化
```

但必须保持：

月光来源。

#### 玩法连接

强。

尤其适合：

##### 收集

```text
发现蛊
↓
收藏
↓
培养
↓
进化
```

##### 商业化

优势明显：

主题皮肤：

- 人格化；
- 收藏；
- 稀有版本。

##### 组合

仍然可以：

```text
蛊A
+
蛊B
=
新能力
```

但是视觉重点偏向：

> “拥有”。

#### MVP 验证

月光蛊主题双层：

测试：

```text
本体：
蓝晶弯月生命

主题：
月之人格化形态
```

观察：

玩家是否理解：

> “这是同一个蛊的不同表达。”

#### 风险

风险：

容易接近：

- 二游角色收藏；
- 普通宠物系统。

必须强化：

> “蛊不是宠物，而是规则生命。”

### 方案三：蛊道文明模拟世界

#### 核心命题

> 将蛊作为文明发展的基础单位，人类社会围绕蛊建立制度、商业和战争体系。

视觉预算：

```diff
个人
+
组织
+
社会
+
文明演化
```

#### HARD 适配

最高。

因为重点不是外观，而是：

世界运行逻辑。

#### SOFT / OPEN 用法

利用：

OPEN：

- 城市；
- 制度；
- 产业；
- 商业。

SOFT：

- 五域文化；
- 社会结构；
- 建筑体系。

视觉语言：

```text
蛊
↓
产业
↓
社会
↓
文明
```

#### 拟人化与角色化

较低。

角色不是重点。

重点：

- 炼师；
- 商队；
- 家族；
- 宗门；
- 城池。

#### 玩法连接

最强。

可以支持：

```text
个人成长
↓
宗门建设
↓
势力竞争
↓
世界改变
```

#### MVP 验证

一个小型：

> “蛊坊”

展示：

```text
采集
↓
炼蛊
↓
交易
↓
战斗
```

#### 风险

最大风险：

范围膨胀。

容易从 roguelike：

变成：

文明模拟游戏。

## RECOMMENDATION

### 推荐：方案一 + 方案二融合

即：

> **规则生命收藏世界**

一句话：

> 《问真》中的蛊既是可以被收藏和喜爱的生命，也是承载世界规则的超凡器官。

原因：

方案一解决：

为什么《问真》不是普通二游。

保证：

```text
蛊 ≠ 角色皮肤
蛊 = 规则载体
```

方案二解决：

为什么玩家愿意长期投入。

提供：

```diff
收藏
+
人格化主题
+
情感连接
```

二者不是互斥。

关系：

```text
本体层：
规则炼成世界

主题层：
超凡收藏世界
```

刚好对应已经批准的双层体系。

方案三作为长期扩展方向：

不是视觉母方向。

而是：

未来世界系统扩展。

主题皮肤是否作为长期内容：

```text

主题：
玩家收藏表达
```

### 3. 文明层范围

确认：

五域、宗门、商贸、势力是否：

A.

作为视觉背景支撑

还是

B.

作为核心玩法扩展

## DO_NOT_ASSUME

L1 / L2 不应自行决定：

- 最终画风；
- 是否二次元化；
- 是否全部蛊人格化；
- 具体角色比例；
- 商业皮肤数量；
- UI 形式；
- 美术生产规模。

这些必须在方向冻结后进入下一阶段。

```diff
《问真》

+
超凡收藏世界（玩家情感）
+
蛊道文明模拟（未来扩展）
```

