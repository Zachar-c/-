## 1. 设计简报

**目标**：以 Slay the Spire 的界面信息架构为骨架，套入《蛊路求生》的南疆仙侠水墨质感，建立「信息清晰、质感统一、肉鸽可读」的完整视觉系统，覆盖上表 22 个界面与全部公共控件。

**不做的边界**：
- 领域层 `scripts/domain/*`、`data/*.json`、存档格式一律不动；UI 只读 state、仅发 command。
- 不引入需商业化付费许可的美术资产；新增视觉尽量程序化 / 现有贴图派生。
- 不改变 §16.5 / §16.6 已锁定规则，本设计只是视觉表达。

**核心设计判断**：现有 UI「功能正确、视觉朴素」——主流程五屏为纵向 VBox 堆叠，且黑市/炼蛊/图鉴/设置/结算六要素等大量界面尚未成屏。StS 的价值不在「好看」，而在**空间分区 + 视觉符号把状态与决策压到一眼可读**。本设计先建**界面全景**（谁在哪、从哪进），再统一**视觉语法**（颜色语义、分区、符号系统），避免各界面各自为政。

## 2. 参考分析与设计语言

### 2.1 StS 三屏设计语言提炼（来自用户参考图）

| 屏幕 | 信息架构 | 视觉语法 | 对肉鸽的贡献 |
| --- | --- | --- | --- |
| 主菜单 | 全屏场景插画底，标题居中，菜单纵向，左上版本角标 | 低饱和暗调叙事背景，前景信息极简 | 氛围即世界观，菜单零干扰 |
| 战斗 | 顶 HUD → 中战场（左我右敌）→ 底操作（能量+手牌+结束） | 三区严格分层；意图符文+数值悬头顶；手牌横向展开 | 意图可视化=决策前置 |
| 地图 | 中央分层节点网络 + 右侧图例 | 羊皮纸质感；节点图标化；三态区分 | 路线即策略 |

### 2.2 本作融合定位与全局视觉语法

**StS 信息架构 × 南疆仙侠水墨质感**。四条全局语法（所有界面强制遵守）：

1. **分区即语法**：状态（顶）→ 内容（中）→ 操作（底），永不混区。
2. **符号即信息**：意图符文、节点图标、资源图标、风险徽章、结局徽章全部图形化，文字只作补充。
3. **暗底亮文、克制动效**：墨青夜色底，月光银/蛊虫青白第二光源，暖橙烛火点缀；动效只做引导。
4. **颜色语义全局锁死**（见 §3.1）：危险永远红、正向永远玉、资源永远金、契约蓝、异变黄红、死亡线血锈。

### 3.2 字体与字号层级

> 字体资产缺口：主题未绑定中文字体（Godot 默认中文为 fallback）。标题建议引入可商用楷体/宋体（思源宋体 SIL OFL）；正文用系统中文回退。字体资产落地单列待办，不阻塞布局。

| 层级 | 字号 | 颜色 | 场景 |
| --- | --- | --- | --- |
| H1 屏标题 | 40–48 | `GOLD` | 大厅题字、结算标题 |
| H2 屏内标题 | 24–28 | `GOLD` | 地图「南疆行程」、黑市「黑市」 |
| H3 面板标题 | 20 | `BONE` | 各面板标题 |
| 正文 | 18（主题默认） | `BONE` | 卡牌效果、事件正文 |
| 次要 | 14–16 | `BONE_DIM` | 说明、图例、footer、保底暗示 |
| HUD 数值 | 20–22 加粗 | 随资源色 | 顶栏资源 |

### 3.3 间距 / 圆角 / 描边 / 阴影

- 间距 4pt 网格：4 / 8 / 12 / 16 / 24 / 32。
- 面板圆角 6px、卡牌圆角 10px（RUI 主题统一）。
- 描边：面板 1px `BG_RAISED` 亮边 + 墨色投影；选中态 `JADE_BRIGHT`/`GOLD` 描边 2px。
- 阴影：悬浮卡片投影 8px / 4px 偏移。

### 3.4 动效预算（克制）

- 界面切换：淡入 + 轻滑 120–180ms；死亡返回大厅加载尽量短（§16.5）。
- 卡牌悬停：上浮 6px + 描边高亮 100ms；Tooltip / 确认框淡入 / 缩放 100ms。
- HUD 数值变动：轻微脉冲一次；禁止常驻循环动画。
- 可选跳过：杀招动画 / 死亡演出一键跳过（R5.22、§16.5）。
