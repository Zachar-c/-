# 《問眞》首版中文单语界面设计（前称《蛊路求生》/旧名 Nanjiang Smoke）

> 日期：2026-08-22
> 状态：已归档
> 范围：首版中文单语展示层设计；保留用于历史实现追踪。
> 权威基线：[机制先行锁死规格书](./2026-08-25-mechanics-first-lockdown-design.md)
> 替代关系：现行品牌与 UI 视觉口径由《問眞》极简 UI 重设计规格取代。


## 目标

首版只向玩家呈现中文文本。地图节点、节点类型、遭遇行动、蛊虫、传承杀招、敌手、已知情报、行动结果和修行札记都不得直接显示内部 ASCII 标识符。调试窗口标题 `Nanjiang Smoke (DEBUG)` 保持不变。

## 边界

- 仅修改玩家可见的运行时文本和离线对话模板。
- GDScript 标识符、JSON 键、节点 ID、存档内容、事件日志、测试名称和提交信息继续使用 ASCII。
- 不修改 `vendor/godot-open-rpg/`，不加入语言切换器或多语言资源管线。
- 保持既有确定性规则、事件日志和存档格式不变。

## 架构

新增 `scripts/presentation/display_text.gd`，作为显示层唯一的内部标识符到中文文本的映射点。它提供节点、节点类型、行动、蛊虫、传承、敌手、已知事实、关系反应、结局、交锋结果和札记文本的静态函数。未知标识符按类别显示中文兜底文本，绝不回显原始 ID。

`MapView`、`EncounterView`、`BattleView` 和 `EndingView` 只在渲染时调用该映射。命令仍提交原始 ASCII ID；`RunController`、`Resolver`、`BattleResolver`、`RunState` 和存档仓库不读取或保存中文显示文案。离线对话模板本身改为中文，因为其 `text` 会直接渲染给玩家。

## 呈现规则

- 地图展示“序号 节点中文名 [节点类型中文名]”；未发现节点继续显示“未明地带”。
- 遭遇页展示中文节点名、中文已知情报和中文行动按钮。结果改为简短中文摘要，不能序列化或打印原始 Dictionary。
- 战斗页展示中文敌手名、蛊虫名和传承杀招名。
- 结局页把札记标题、札记正文和可见事实全部渲染为中文。
- 无法预期的内部值使用“未知地点”“未知类型”“未知行动”“未知情报”或“未知结果”等中文兜底文本。

## 验收

1. 固定种子 `101` 的地图没有裸露的节点 ID 或类型 ID。
2. 进入商队遭遇后，节点名、行动和离线对话均为中文；结果区域不包含 `{`、`}` 或内部键。
3. 进入交锋后，敌手、蛊虫和传承杀招为中文。
4. 结局与修行札记为中文，且不突破玩家已知事实边界。
5. 全部单元测试、集成测试和无头启动检查通过；调试窗口标题不改动。
