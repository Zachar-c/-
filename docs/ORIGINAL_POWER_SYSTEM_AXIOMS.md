## 1. 转数到底约束什么

转数 **不是** 装备等级。禁止默认「二转 > 一转」「高转自动替换低转」。

转数同时约束：

| 约束 | 含义 |
| --- | --- |
| 力量层级 | 效果预算与能力量级所在档 |
| 使用门槛 | 低转真元**催不动**高转蛊（质量门禁） |
| 资源层级 | 真元容量/质量、可维持的循环规模 |
| 修为承载 | 空窍/境界能同时运行多少手段与多复杂的杀招 |

同转内部允许巨大价值差：垃圾 / 普通 / 优秀 / 极品 / 特殊机制蛊。

**允许真实存在：优秀一转蛊 > 垃圾二转蛊。** 优秀低转蛊可长期作功能件、杀招组件、特殊规则组件。

## 2. 蛊虫价值为什么不与转数等价

必须分三层，永不合并成一个数字：

```text
本体能力     —— 这只蛊单独做什么
构筑价值     —— 在某杀招/循环里是否不可替代
环境价值     —— 当前敌人、资源、路线下值不值得拿
```

- 单独很弱 + 某杀招核心 = 极高实际价值  
- 纸面极强 + 吃不到资源/进不了杀招 = 当前不值得拿  

禁止用 `priceGu()` 回答「这只蛊最终值多少」。它最多回答：**基础效果量级是否异常**。

## 3. 道如何决定资源与战斗逻辑

道 **不是** 伤害染色。每道必须先答「它依靠什么运行？」再设计技能。

| 道 | 运行资本 | 节奏/风险 |
| --- | --- | --- |
| 血道 | 血液 / 气血 / 伤势 | 以伤换力；强收益伴随身体代价 |
| 智道 | 念头 / 推演 / 信息 | 改行动与决策优势；念头不足、思维干扰是风险 |
| 魂道 | 魂魄状态 | 控制与灵魂攻击；魂伤难恢复 |
| 力道 | 肉身 / 力气 / 承伤 | 低外部资源依赖；身体即资本 |
| （后续各道） | 各自资源/状态/发动条件/收益结构 | **先定运行逻辑，再写技能** |

禁止：火道=火伤、血道=红伤、智道=蓝控。

## 4. 蛊虫与杀招的关系

禁止：蛊虫=技能，杀招=更大的技能。

正确模型：

```text
蛊虫 = 功能元件

杀招 = 核心蛊 + 辅助蛊 + 发动顺序 + 状态条件
     + 资源需求 + 规则关系 + 失败风险 + （泄密/被破解）
```

杀招成长 = 换件 / 加减件 / 换核心 / 调顺序 / 降成本 / 换资源类型 / 改触发 / 改副作用 / 改效果结构。

禁止杀招成长退化为 `Lv1→Lv2 → +30% 伤害`。

（原作已核验：杀招层级由**配方蛊**决定，可跨转；改良是生命周期常态。）

## 5. 修为如何改变力量承载能力

修为 **首先** 扩大「可承载力量」，不是倍率轴。

优先体现：

- 真元容量 / 质量  
- 可催动蛊虫层级  
- 复杂杀招承载  
- 资源循环规模与持续作战  
- 可同时维持的手段数  

「境界更高」= **能运行过去无法运行的力量体系**，而不是「所有技能伤害 ×2」。

---

## 6. 玩家为什么需要不断淘汰 / 添加 / 替换蛊虫

长期循环：

```text
获得新蛊 → 判断是否适配 → 入体系 → 淘汰旧蛊
→ 出售 / 炼化 / 喂养 / 作材料 → 修改杀招
→ 新资源循环或战斗手段 → 修为提升
→ 承载更高转蛊与更复杂杀招 → 继续重构
```

成长必须同时是：数值 + 手段 + 构筑复杂度 + 资源管理 + 针对不同敌人的解法。

禁止退化成：攻击越来越高、HP 越来越多、技能数字越来越大。

## 7. 为什么真正平衡单位是构筑路线

平衡单位优先：

```text
成熟构筑 / 路线 / 战斗体系
```

不是「每只蛊必须和同转其他蛊公平」。

允许垃圾蛊真的垃圾、极品蛊真的极品。必须避免的是：

> 某一条完整路线在绝大多数情境下全面支配所有路线。

正确问题：成型血道 / 月道 / 力道是否各有真实优势、缺陷与适用情境？  
错误问题：血道蛊 A 与月道蛊 B 是否都值 100 PP？

## 8. Budget / PP 的权限边界

Rank Budget、Effect PP、priceGu、kitDpr、encounter budget =

> **数值工程校验工具**（报警器，不是法律）。

**负责发现**：异常超模、明显低模、无限资源、不合理 DPR、敌人 HP 数学错误、战斗时长/资源曲线异常。

**不负责决定**：是否优秀、是否该选、是否该淘汰、是否与同转「公平」。

禁止逻辑：

```text
超过同转标准预算 → 必须削弱
```

必须再问：为何超？是否稀有极品？使用条件？资源限制？是否杀招依赖？是否只是局部强？

## 9. 升仙为什么是凡人阶段力量体系的总检验

升仙不是资料片，而是对整个凡人力量体系的**总验收**：

```text
低转 → 蛊与初级杀招 → 替换与推演 → 主修流派与资源结构
→ 修为提升承载更高转 → 杀招复杂化、手段丰富
→ 应对更复杂敌人 → 五转巅峰
→ 为升仙备资源与体系 → 碎窍 → 天地人三气
→ 渡劫 → 平衡三气 → 蛊仙
```

凡人阶段若只有「数字变大」，升仙会失去意义。当前 Web MVP 只验证最小段：

```text
获得 / 交换蛊 → 改变构筑 → 改变解决敌人的方法
```

**现在不实现升仙**；但当前规则不得堵死这条路。

## 附录 · 直接 REJECT 的提议形状

```text
“为了平衡，同转蛊的综合价值应控制在 ±10%。”
```

→ **REJECT**。理由：消灭品质差异与识货能力、消灭低转神蛊与高转垃圾蛊、削弱淘汰替换，最终退化为装备等级系统。

改问：为何强/弱？要什么构筑？耗什么资源？何时值得留/该淘汰？是否破坏**路线**竞争？
