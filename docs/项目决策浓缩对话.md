# 项目决策浓缩对话

> 用途：这是项目交接用的结论摘要，不是逐字聊天记录。完整规则以《南疆凡人修行肉鸽：45--90 分钟冒烟版设计》为准。

## 这是什么游戏

**问：为什么不直接做方源剧情？**

答：方源的既定故事更适合作为后续剧情模式。本项目的核心是让玩家每局随机经历一名蛊界人士的修行人生，感受原著中资源、情报、人情、风险和强弱差距共同决定命运的世界。首版为了验证玩法，暂不随机身份，而是固定为一名南疆新开窍的散修。

**问：怎样既忠于原著又有游戏自己的特色？**

答：不把修行简化成连续战斗。战斗、交易、试探、伪装、设局、借势、撤离和投降都应是玩家能主动选择的手段；未选择的节点会消失或转化为后果。原著资料用来提炼物品关系、地域风土与事件因果，而不是复刻青茅山剧情。

## 第一版做什么

**问：首版的范围多大？**

答：只做南疆，单机，45--90 分钟，10--14 个有效节点。一局从一转凡人起步，经过生存、构筑、关系、布局和升仙筹备，终点是第一次冲击蛊仙。结局有成功、险成、失败求生三种；失败求生必须有尊严，而不是简单的失败画面。

**问：为什么不先做五域两天和全随机人生？**

答：它们是最终方向，但会同时放大内容、数值、事件和测试成本。首版先以南疆验证核心循环；之后再依接口扩展北原、东海、中洲、多身份、随机资质/家世/本命蛊与更长的关系链。

**问：小光蛊在首版里是什么？**

答：固定起始蛊。它既能探路和解除部分迷雾，也可用于交涉、伪装、战斗或脱身，不是强制教学工具。首版最多四个已装备蛊槽，总蛊池为小光蛊加八种可获得凡蛊。

## 数值、蛊虫与杀招

**问：凡人阶段保留哪些资源？**

答：持久的数值资源只保留元石和修为；行动内使用真元。伤势、寿元债、关系账、证据/线索、追击、玩家已知事实、升仙准备和肉身印记是有意义状态，但不做材料背包膨胀。食料、养蛊等复杂循环不进入当前确认的精简方向；疗伤依赖装备的治疗蛊或事件效果，并应占用构筑位置。

**问：为什么首版没有凡人道痕或泛化的“流派感悟”？**

答：原著中道痕和境界的巨大差距主要在升仙后才成为核心。凡人阶段差异更适合体现为特殊体质或特殊蛊带来的肉身印记，例如铁骨、冰肌、三更等，并且每种都要有明确收益和代价。它们属于后续可加入的有限内容，而不是无穷叠加的百分比词条。

**问：玩家是否需要照着预设杀招玩？**

答：不需要。蛊虫自身必须有清晰数值和联动机制，玩家通过实际使用发现搭配，并可自行命名自己的打法。首版只保留少量原著风格的“传承杀招”：满足特定蛊虫条件即可施放，并享受特殊效果；它们用于展示一种可理解的搭配范例，不覆盖玩家的自由构筑。能力标签只能校验条件、驱动节点反应和支持已设计配方，不能自动生成难以解释的杀招。

## 地图、战斗与人情

**问：为何采用《杀戮尖塔》式节点地图？**

答：它能用低内容成本做出路线取舍。地图后续节点处于迷雾中，小光蛊、情报、关系帮助和侦查可以揭露局部信息。每一层代表数月到数年的修行阶段；少数紧急事件可以在节点内部使用数日倒计时，不与宏观时间混淆。

**问：交涉如何避免变成“敌人低血量就能劝降”？**

答：关键 NPC 有本地维护的目标、底线、恐惧、原则、意志、知情范围、利益、退路、阵营、援军和对重伤的反应。劝降或谈判必须同时满足利益、证据、退路、实力、援军和意志等条件；意志坚定的敌人受伤也可能拒绝。

## LLM 怎么用

**问：为什么需要 LLM，又为何不能全局使用？**

答：LLM 只为受限交涉增加人物口吻和小范围随机反应，避免模板话术完全固定。资源、地图、战斗、NPC 真正状态、判定、存档和结局都由本地规则驱动。关键事件允许 2--4 次行动标签，但普通事件最多一次 LLM 调用，商队纠纷和机缘争夺最多两次；离线、超时或返回不合法时立即使用模板继续游戏。

## 实施与当前状态

**问：为什么选 GDQuest Open RPG？**

答：它是 MIT 许可的 Godot RPG 底座，计划在审计后仅通过适配器复用少量通用战斗、物品或 UI 组件。南疆规则、蛊虫、节点、社交、升仙、日志和数据表均由本项目独立实现，不能混进或直接改写上游代码。

**问：下一步是什么？**

答：完成实施计划 Task 1：以固定提交引入并审计 GDQuest Open RPG、保留许可证和第三方说明，然后再建立隔离的 Godot 入口、领域规则、数据表和测试。此前拉取上游仓库中断，因此当前远端没有已完成的 GDQuest 底座。
