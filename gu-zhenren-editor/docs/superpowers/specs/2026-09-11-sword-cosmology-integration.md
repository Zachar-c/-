## 1. 蛊虫 —— 剑道蛊是"锋锐碎片"，不是数值载体

**分类**（实测）：40 只 = attack **15** / defense 5 / movement 5 / healing 5 / recon 5 / logistics 5；
rank 1:11 / 2:9 / 3:8 / 4:5 / 5:7；`attack` 是唯一在数量上被刻意加权的 role。

**定位**：按本体链（`gu-ontology.md`），蛊＝**天地真精 / 大道法则碎片的聚合体**。
所以剑道蛊不是"攻击道具"，而是**携带锋锐性质法则的碎片**——这决定了它的强度应来自**碎片规模（转数）**
与**同源碎片的共鸣**，而不是来自数值表。

**原文对剑道蛊的定性（原句）**：
- 「但天资卓绝，独自一人**开创剑道蛊虫**，纵横五域，无人可敌」
- 「一身**剑道蛊虫，更是别出机枢，另辟蹊径**，威力绝伦」← **剑道蛊的特征是"结构独特"，不是"数值高"**

⇒ **设计含义**：剑道蛊的差异应当体现在**行为结构**（式）上，而非单纯加伤害。这正是「式」设计的原文依据。

**相互作用**：同源碎片之间通过 `support_school` 产生**共鸣**（见 §2）。`v1_battle_resolver.gd:385-386` 只给
**本回合后续**同流派蛊加成 ⇒ **蛊的出手顺序本身就是战术**。

**⚠️ 现状缺口**：recon 5 + logistics 5 = **10 只（25%）在战斗里零数值效果**
（`status` 只有 `marked`/`bound` 且都不参与伤害，见任务书 §0-F2）。**这不是剑道的问题，是全流派的结构性空洞**。

## 2. 道痕 —— 剑意的来源，也是剑道的代价来源

### 2.1 剑道道痕的原文定性（38 次出现，语义明确）

| 属性 | 原句 |
|---|---|
| **侵蚀性** | 「剑光造成的创伤，非常麻烦，**剑道道痕似乎有侵蚀性**」 |
| **会持续侵袭** | 「若是任由**剑道道痕侵袭**下去，势必会酿造成更为惨重的损失」 |
| **毁蛊** | 「为了防止**剑道道痕的侵蚀，毁掉更多的蛊虫**，他们夜以继日……展开修复」 |
| **隔绝他道** | 「残留的剑道道痕横霸于此，**隔绝了水道道痕**」（**道痕排斥的实例**） |
| **可留存** | 「一身**剑道道痕，都未消损**」 |

⇒ **剑道道痕是"攻击性 + 侵蚀性"的道痕**：它伤敌人，也**伤蛊虫**，还**排斥别的道**。
这三条给了剑道三层代价，是设计的内在依据，而不是我们拍脑袋加的。

### 2.2 关键澄清：「剑意」是原文词，但"层数"是我们的机制化

- **原文：剑意 4 次**（低频但有）：「可以催发出**大量的剑意**」「一道犀利至极的庞大**剑意**，直冲而上」
  「运用这些**剑意**冲刷意志海洋」「散发森森**剑意**」
  ⇒ 原文语义偏**"锋锐的气势/精神具现"**，**没有层数规则**。
- **我们的「剑意 = 层数资源，每层 +1」是机制化产物，不是原文设定。** 必须这样标注，否则会像"炸炉"一样
  被后人误当原文。

### 2.3 ⭐ 定量锚点：道痕增幅是"百分比、小幅度、靠量堆"

原文给出比例（**这是本次最有价值的数值发现**）：

> 「**两百多道道痕，便能增幅两成的威能**」⇒ 约 **200 道 ≈ +20%**，即 **1 道 ≈ 0.1%**

配套原句：「历代的智道蛊仙继承者们，身上都有智道道痕，**增幅着星念仙蛊的效果**」；
「被大力真武体身上的**大量力道道痕增幅**之后，威力居然攀升到了这种地步」（**凡道杀招也会被道痕增幅**）；
「仙蛊在福地中作战，威能效用会受到**福地道痕的增幅和削弱**」。

⇒ **两条结论**：
1. 原文的"道痕增幅"是**长线、小幅度、靠数量堆**的量变（几百道换两成）。
2. 因此 **局内 5 层剑意（+1/层）绝不等同于原文的道痕增幅**——它是**吸收其方向、另定其量级**的机制化产物。
   若要忠实原文比例，5 层 ≈ 0.5%，玩家无感。

**分层处理（这是整合的关键判断）**：
| 层 | 机制 | 量级 | 归属 |
|---|---|---|---|
| **局内短乘数** | **剑意**（5 层，+1/层） | 大幅、快节奏 | 本次落地（T2/T8） |
| **长线积累** | 真正的"道痕层数"（百分比增幅） | 小幅度、靠量堆 | 接 `body_imprints`（T10），与剑意**分开** |

⇒ **不要把两者合并**：合并会让剑意要么无感（贴原文比例），要么失真（把 200 道的语义塞进 5 层）。

### 2.4 相互作用闭环（这条闭合了"变强→付代价"）

```
蛊（锋锐碎片）──共鸣──▶ 剑意（局内乘数）
     │                        │
     │使用高阶剑蛊             │兑现
     ▼                        ▼
  侵蚀（伤己）──────────▶ 道痕伤势
                              │ 污染光膜窍壁
                              ▼
                        资质下降 ──▶ 真元上限下降 ──▶ 段数上限下降（自己的 build 被削弱）
```
**这条闭环是剑道"高风险高爆发"定位的世界观依据**：越依赖剑道，越会被剑道反噬；
且反噬的终局不是掉血，而是**削弱你继续用剑的能力**——比单纯扣血更有主题性。

## 3. 流派 —— 剑道的定位有原文背书，且不许做克制网

### 3.1 ⭐ 原文给出了"战力最强五大流派"的官方名单

> 「**金道、炎道、雷道、剑道、血道，这五大流派，是公认的战力最强的五大流派**」

配套：「**薄青走的剑道，战力最强**」「折剑沉沙……是说**剑道第一人**的薄青」「**亚仙尊**薄青」；
「不过**剑道攻伐强大**，又事关历史上的传奇人物"亚仙尊"薄青」。

⇒ 剑道"攻伐第一"**不是我们的设定，是原文公认**。
⇒ **顺带一个流派补充的优先级依据**：五大里的 **雷道（我们零覆盖待补）** 应优先于其它候选补上——
它不是冷门分支，是原文公认最强五分之一。

### 3.2 关系原则（红线）

原文中**唯一一条有直接依据的"道与道的对立轴"是天道↔人道**（「诸多流派当中，**人道是最能应付天道的流派**」）。
其余各道（含剑道）都是**并列独立体系**。

⇒ **剑道不得与任何流派构成克制关系**。剑道的差异化只能落在三处（规格 §2.3 允许）：
**① 己方资源循环 ② 结算方式 ③ 代价结构**。这三处正好对应 §2.4 的闭环。

### 3.3 差异化的正确表述

| 维度 | 剑道的答案 | 依据 |
|---|---|---|
| 强度来源 | 自己身上的剑意（**自给自足**，不是队友给的） | `support_school` 自用语义（§0-F4） |
| 节奏 | 快（起势→出剑→收势） | 支援链的出手顺序 |
| 代价 | **侵蚀（伤己 + 毁蛊 + 降资质）** | §2.1 三条原句 |
| 峰值/短板 | 峰值最高、脆、怕护盾 | 设计 §8 矩阵 |

> 与光道的对照仍是**同一机制的相反用法**：光道 `small_light_gu` 用 `support_school:"light"` **供给队友**；
> 剑道把它用于**给自己铺势**。机制同源、体验相反——这是零成本的差异化。

## 4. 天道 —— 剑道不与它对立，但代价哲学与它同构

**分类与定位**：天道 = **宿命 + 规则 + 平衡律**（「宿命蛊归属于天道」「**损有余补不足**」）。
它是**世界生灭级**概念（天道道痕「化为一个个的新生世界」），五转内已整体降级/裁剪。

**相互作用（三条，两条是"不许做"）**：
1. ❌ **剑道不能"斩断宿命"**。原文只给了**人道**这条对立轴；让剑道克制天道是凭空造设定。
2. ❌ **不做"对天道 +X%"**（规格 §2.3 全局克制红线）。
3. ✅ **剑道的代价结构与天道平衡律同构**——「**损有余补不足**」：剑意越强，侵蚀越重。
   这是**叙事层的统一**（不是机制耦合）：剑道的强不是免费的，恰好呼应天道律。
   ⇒ 可在剑道蛊/杀招的文案里用这个母题，**但不要做成天道数值机制**。

**五转内天道的可玩残留**（供参考，不属剑道任务）：宿命类 fact、寿元债、灾劫（已裁至层内风险）。

## 5. 人道 —— 剑是技，人是愿；只借形式，不借能力

**分类与定位**：人道 = **人心人性与情感愿念**；唯一有直接定位句的一道（「**最能应付天道**」）；
载体《人祖传》（「记载着**人祖的人道真传**……堪称**蛊师世界的第一真传**」）。

**相互作用**：

| 维度 | 人道 | 剑道 | 整合结论 |
|---|---|---|---|
| 内核 | **愿**（以情克命、以愿逆天） | **技**（以技破势） | 二者是**平行的两条道**，不是同一条 |
| 强度来源 | 心念/情感 | 技艺积累（剑意） | ✅ **剑道的乘数只能来自"技"，不能来自"决心"** ——所以剑道**不该有意志力类机制** |
| 对天道 | 正面对抗 | 无轴 | ❌ 剑道不得借人道的"克命"能力 |
| 载体形式 | 《人祖传》= 真传 | **薄青 / 折剑沉沙 = 剑道传承** | ✅ **可借"真传"这个形式**：剑道的传承渠道挂在人物上 |

**⭐ 这里有一条可用的对应**：人道用《人祖传》作真传载体，剑道在原文里有**人物级传承**
（「折剑沉沙……**剑道第一人**的薄青」「**亚仙尊**薄青」「独自一人**开创剑道蛊虫**」）。
⇒ **剑道杀招/蛊的传承渠道，可挂在"薄青一脉"这一段叙事上**——这与人道的《人祖传》是同一结构，
既补了剑道的获取路径（杀招 P5），又不动人道系统的任何机制。

**⚠️ 不得做**：剑道获得"以愿改命""情绪加成"之类机制——那是在偷人道的定义，会让两道同质。

## 6. 杀招 —— 剑意的兑现器，且"多段"有现成宿主

**分类与定位**：原文定义「**仙道杀招是将数种道痕集合在一起**」⇒ 杀招是**道痕的集合**，比蛊高一级。
对我们的五转范围，可玩形态是**凡道杀招**（190 次那一类）。

**相互作用（三条，其中一条解开了原设计的死结）**：

1. **⭐ `steps` 序列 = "多段"的合法宿主。**
   原设计把"多段/剑气"判为 **P2 引擎扩展**（需新 effect）。但杀招的设计（`kill-move-design.md`）
   本来就包含 **`steps` 有序步骤 + 逐步结算**——**多段不需要新 effect，只需要杀招的步骤序列**。
   ⇒ **修正**：多段从"要造新引擎"降级为"等杀招 P3 落地"，**省掉一整个 P2 项**。
   （注：当前 `kill_moves` 用的是 `recipe` 一次性结算；`steps` 属 P3，仍需引擎改动但**复用既有规划**。）
2. **剑道杀招实例（原文）**：「薄青又催动**仙道杀招一剑纵横**，此招的**核心仙蛊之一，就是这只剑遁仙蛊**」
   ⇒ 剑道杀招的命名与结构可参照「一剑纵横」：**核心仙蛊 + 配套蛊**，对应我们的 `recipe`。
3. **生命周期四段**（`kill-move-semantics.md`）：独创（有署名定价权）→ **改良（最高频，共现 438）** →
   **泄密**（用一次就被研究）→ 被克制。剑道杀招同样适用：**剑道招式的秘密会被敌人学会**，
   所以「同一招重复用」不是无代价的（`reveals` 字段已存在，逻辑待接）。

**对应关系**：
| 设计要素 | 剑道形态 | 归属 |
|---|---|---|
| `recipe`（当前） | 多只剑道蛊的组合（吃相互支援） | ✅ 已有（双锋引） |
| 命名按「式」 | 暴雨式 / 重剑式 / 剑阵式 | T9 |
| `steps` 逐步结算 | **多段**的实现 | P3（复用既有规划） |
| `reveals` | 出招即泄密 | 待接 |
| 改良 / 传承 | 薄青一脉 · 折剑沉沙 | P5 |

## 7. 元石 —— 剑道的瓶颈，也是剑道的加速器

**分类与定位**：元石**不只是货币**——原文「**凝聚着天然真元，可以被蛊师吸收**」，
且「**用元石补充真元**」是它的日常用途；它会「随着石内天然真元不断损耗，**体型也会不断缩小**」。

**剑道视角的三重作用**：

| 作用 | 说明 | 落点 |
|---|---|---|
| **瓶颈** | 剑道蛊成本偏高（快攻=高消耗），元石是"每回合能出几剑"的直接约束 | 数据层（T6 成本分档） |
| **加速器** | **花元石补真元** ⇒ 支撑多段爆发。这是原文元石第二职能的落地 | 接 `aptitude_recovery_multiplier` 钩子（T13） |
| **节奏压力** | 元石**会缩水** + 原文「**元石是拿来用的**，像个守财奴积蓄元石，干嘛成为蛊师呢」⇒ 天然反对囤积 | 与"资源紧张"设计同向 |

⇒ **整合结论**：剑道的"快"不能是免费的——**它的燃料是元石**。这让剑道的爆发有了**经济代价**，
而不是单纯的真元数值问题。三 build 的差别也因此有了经济含义：
暴雨式（多段）烧元石最多，重剑式（单发）烧得少但吃寿元，剑阵式（持续）占用持续成本。

**⚠️ 不新增货币、不引入仙元石**（仙级已裁）。

## 8. 资质 —— 决定剑道能走哪条 build 的硬上限（最被低估的一条）

**分类与定位**：资质**不是根属性，而是"元海占空窍比例"的派生读数**（丁 2–3成 / 丙 4–5成 / 乙 6–7成 / 甲 8–10成），
经 `真元上限` 决定**可修到的最高转数**。我们的 `essence_max = essence_base(10) × aptitude_factor × cultivation_factor`
就是这条链的抽象。

**剑道视角（这是把资质与流派真正咬合的地方）**：

```
资质 → 真元上限 → 每回合可支付的真元 → 每回合能出几只剑蛊 → 能走哪条 build
```

| 资质 | 真元上限（我们） | 剑道可走的路线 | 理由 |
|---|---|---|---|
| 丁 | 最低 | **重剑式**（单发、低真元、高寿元代价） | 只够一次兑现 |
| 丙（默认） | 低 | 重剑式 / 低配暴雨 | — |
| 乙 | 中 | 暴雨式（多段）开始成立 | 支付得起多只 |
| 甲 | 高 | 暴雨式 / 剑阵式 | 真元不再是瓶颈 |

⇒ **剑道的三条 build 天然按资质分层**：这不是平衡问题，而是**世界观的正确投影**
（低资质者只能走"少而重"的路）。**剑道因此不需要额外的 build 解锁机制**——资质就是门槛。

**闭环**（与 §2.4 接上）：侵蚀 → 道痕伤势 → 污染光膜 → **降资质** ⇒ **自己的 build 被自己的道反噬削弱**。

**对应关系**：
- ❌ 不改资质公式、不新增资质档位（那是 §0 清单里的"补充流派"，不是这里）
- ✅ 剑道数据里**用真元成本表达对资质的依赖**：暴雨式蛊高 `true_qi_cost`、重剑式低 `true_qi_cost` 但带 `life_cost`
- ✅ 侵蚀降资质走**已设计的 M3 道痕伤势**（`body_imprints` + `curse` 通道），不新造系统

## 9. 整合思路：四条贯通线（把八个概念串成一个体系）

```
① 剑意线（强度）   蛊 ─共鸣→ 道痕 ─机制化→ 剑意 ─兑现→ 杀招(steps=多段)
                                             ↑
② 侵蚀线（代价）   剑意越高 → 侵蚀越重 → 道痕伤势 → 污染光膜 → 降资质 → 削弱本 build
③ 经济线（燃料）   元石 ─补真元→ 真元上限 ←决定─ 资质 ；段数 ←真元─ 出手次数
④ 对抗线（社会）   杀招 ─使用→ 泄密 → 被研究 → 被克制 ─驱动→ 改良 ─传承→ 薄青一脉
```

**这四条线的意义**：它们让八个概念**互相咬合而不是并列罗列**——
剑意（②的来源）、资质（②的终点）、元石（③的燃料）、杀招（①的出口与④的主体）、
道痕（①的源与②的载体）、蛊（①的碎片）、流派（①在体系中的位置）、天道人道（价值判断的坐标）。

## 13. 一句话总结

**剑道是一个"把代价存在自己身上"的流派**：它的强度来自**同源道痕的共鸣**（机制化为剑意），
它的燃料来自**元石**（可补真元），它的上限被**资质**（真元上限）锁死，它的出口是**杀招**（steps 即多段），
它的终局风险是**侵蚀 → 道痕伤势 → 降资质**（自己削弱自己）。
它与**天道**同构（损有余补不足）却不对立，与**人道**平行（技 vs 愿）却不重叠，
在**流派**体系中占"攻伐第一"（原文公认五大之一），且**不与任何流派构成克制关系**。
