## 2. 全局视觉基调（约束所有后续生成）

南疆仙侠生存肉鸽，中国古典工笔/水墨质感；暗调低饱和：墨青夜色（deep teal night）+ 墨黑，
月光银/蛊虫青白微光为第二光源，暖橙烛火点缀，血锈暗红仅用在伤势与危险意象；
宣纸米黄承载文字与图标底（圆形深墨底+米黄环，参考 #5-13 的图标样式统一）；无 Q 版、无赛博。
所有蛊图表征必须与 `DisplayText.gu()` 中文名一一对应，禁止出现数据中不存在的蛊名。

## 3. 战斗页约束（vs 当前 BattleView）

| 区域 | 约束 | 裁决 |
| --- | --- | --- |
| 顶部 HUD | 4 格：真元、元石、寿元、魂魄 | 参考图"寿元 x2"系生成重复，否掉；伤势/材料/情报/遗物不占战斗顶部 |
| 血量 | 主角区旁生命条 | 复用 GDQuest 生命条贴图（已购入 `assets/theme/bar/`） |
| 行动卡主卡 | 蛊名（左竖排卷标）+ 蛊名大字 + 真元代价 + 风险徽章 + 首条已知风险一句 | **删除"成功率"**：战斗无百分比判定，成功率字段仅野外/炼制卡存在；ActionCardRow 按"有字段才显示"自然隐藏 |
| 风险徽章 | 低/中/高 | 展示层派生：`known_risk` 0 条=低、1-2=中、3+=高；不改数据模型，确定性由卡数据决定 |
| 卡片详情 | 收益/未知/受阻/途径 | **保留**在主卡下方详情区（信息透明是本作核心，不得砍），样式按竹简三段式 |
| 翻页箭头 | 本参考两侧箭头 | **不实现**：当前手牌 ≤6 无翻页需求；将来手牌扩充时再引入分页 |
| 敌区 | 图标敌（图鉴圆风）+ 敌名 + 意图符文 + 血条 | 敌群大图裁作战斗页半透明氛围背景，不作单元美术；敌人单体图标待补（需实体敌索引：兽群/贪利散修/势力护卫/精英） |
