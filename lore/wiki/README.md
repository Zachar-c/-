# 问真·《蛊真人》知识库

这是《蛊真人》蒸馏的第一版知识层：人和 AI 都能从这里进入结构化的世界知识，并在需要时回查原文。

目标是将《蛊真人》全书知识蒸馏为人和 AI 都能长期使用的知识层：平时优先读 Wiki，遇到缺口、冲突或争议再回查少量原文。首先服务理解全书，再服务游戏、同人、数值、美术和剧情等下游；知识不因当前《问真》未使用而舍弃。原文仍是最终事实来源，Wiki 必须保留条件、限制、例外、人物状态、事件因果和证据边界。

## 使用方式

1. 人类浏览入口为[网站窗口](web/README.md)，按人物、蛊虫、事件、世界、流派、规则与主题分类；总表、关系与资料另列。也可先读 [`index.md`](index.md)——那里给出「五条阅读路径」（访客 / 剧情读者 / 同人作者 / 研究者 / 开发）与分类入口的人话说明。
2. 按阅读路径或分类索引进入人物、蛊虫、事件、世界规则、规则命题或主题页。
3. 页面没有回答问题时，用 `rg` 回查现有原文和读书笔记。
4. 确认后的结论写回对应 Wiki 页面，并保留章节或行号来源。

原文来源状态与 EPUB 迁移验收材料见 [`source/README.md`](source/README.md)。现以 `source/蛊真人-epub-canon.txt` 为正文真源；旧 E-ID 和行号保留作历史回查。全量 E-ID 定位及未决状态见 `lore/wiki/source/eid-migration-decisions.tsv`，运行时使用的子集见 `lore/runtime/evidence-locators.json`；旧裸行号可查 `lore/wiki/source/old-line-to-epub-map.tsv`。当前接入状态、待 L1 裁决的口径项（迁移窗口放宽、pack 状态行白名单、正文站点残留）与产物同步缺陷见 [`2026-09-30-epub-canon-l1-review-pack.md`](2026-09-30-epub-canon-l1-review-pack.md)。

```powershell
rg -n "关键词" "source\蛊真人-epub-canon.txt"
rg -n "关键词" "game\分支：六卷精编版\读书笔记"
```

## 来源优先级

1. `source/蛊真人-epub-canon.txt`
2. `source/《人祖传》.txt`
3. `game/docs/lore/canon-index.md`
4. 现有读书笔记和记忆库
5. 游戏设计、重写方案和分析文字

Wiki 页面中的“原著明确内容”须由原文核验支持；命题登记表提供证据入口，读书笔记和记忆转述未经原文核验只能进入“资料整理”。人物观点、未知、分析、项目裁定与游戏改编分开标明；游戏改编和重写决定不得伪装成原著事实。

## 工程边界

- 不复制整部原文到新目录。
- 不新增 SQLite、向量数据库、知识图谱、任务队列或自研 RAG。
- 不修改游戏运行时代码和现有 `lore_engine`。
- 复用[现有网站](web/README.md)、Markdown、少量元数据与构建脚本；不为目录漂亮批量迁移或重写页面。

“暂时没有整理”不等于“原著不存在”。不确定的内容写入“待核对”，不要凭印象补全。

验收关注重要知识能否找到、条件与时序是否保留、AI 是否能靠 Wiki 正确理解问题及何时需要回查原文。页面数、实体数、状态行数和章节覆盖统计只能辅助定位，不能证明知识完整或成熟。
