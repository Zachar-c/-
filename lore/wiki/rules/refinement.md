# 炼蛊术语体系

炼、养、用是蛊师修行的三件并列事；本页收录"炼"下的术语分类学（REF-001…012）与高价值规则簇：失败机理与归因、材料道痕边界、本命蛊规则、仙蛊转数上限、纠错还原装置、杀招同构（REF-013…022）。每条主张带证据与禁止误读；主键暂用 REF-\*（CAN-\* 登记受 `game/` 冻结限制，同 [灾劫体系](tribulation.md) 页尾说明）。

## 分析与解读

以下为跨事实归纳的分析层模型，不是原著明文；引用时须声明为分析：

- **炼蛊=形成新的稳定结构**（已证实方向）：蛊虫是大道碎片、蛊材是道痕聚集，炼蛊的核心不是简单混合材料，而是让多种道痕/大道碎片形成新的稳定结构——失败机理（REF-014 道痕交融不可控）、残方论（REF-021"融汇成一体"）、成功道痕作用点（REF-014）三线互证。核心原文句"蛊虫是大道碎片，蛊材则是道痕聚集"（E:V6-401146）为叙事中角色（鲁桐兰）陈述、方源独立复述（E:V5-290910），两处独立来源。
- **蛊方=工艺路线**（已证实方向）：同一目标蛊可存在多条炼制路线（REF-018 五窍火塔蛊：逐级递进 vs 改良跳步；REF-008 改良蛊方减步骤；REF-004/005/007/008 合炼/逆炼/平炼/升炼各有方向），路线选择改变时间、材料、风险与失败代价。
- **失败不是纯随机骰子**（已证实方向）：主要失败源=仙材道痕交融的细微处无法人为操纵（REF-014），叠加工序/环境/时机/随机环节（REF-015）与反噬代价（REF-016）；"同一个蛊方材料齐全仍失败"由此可解释，不再只留下"成功率很低"。
- **边界与反例**：浓缩/改良路线受工序约束（REF-018 禁止误读）；威能未必更强、可改性下降（KM-013/KM-018）；同一炼制目标在原文同段先后作"星念/变化/变形仙蛊"三名并见（E:V4-177866 语境），引用时注明不逐一拆分。
- **下游提示（非数值，L6 细则在 Wiki 之外）**：蛊方不应天然建模为唯一 A+B=C；炼蛊失败未来应允许产生可归因原因而非纯 RNG；高炼道境界首先意味着能看见更多工艺信息、改良蛊方（REF-009/018），而不只是成功率加成；部分蛊存在天然升转上限（REF-020）。

## 待核对

- "正炼"无独立定义段（仅与逆炼对举），其确切语义（按秘方顺向炼制？）待回原文确认。
- 升炼与合炼的边界：合炼是"低阶→高阶"的组合炼制，升炼是"跨层级提升"——两术语在低阶合炼场景下是否重叠，原文未明确。
- 平炼的完整适用条件（为何只有特定蛊虫可平炼）未核验。
- 修复是否也分单/合/正/逆维度，未核验。
- 天庭"成功道痕"不属于炼蛊术语（见[道痕体系](dao-marks.md) DM-007），本页不收。
- "大势力以奴隶/毛民立零件本命蛊承担高风险炼制"无直接原文（本命蛊×奴隶/毛民 全文 0 命中），保持 UNKNOWN；不得写成方源石巢实际机制。
- REF-014 道痕交融机理目前只有方源单源体悟（E:V4-177866），无第二独立来源或叙事者定论；成功道痕机理见 DM-007。
- "昼锚仙蛊"全书 0 命中，与四元方悔血炼池无关（REF-022），不收录。
