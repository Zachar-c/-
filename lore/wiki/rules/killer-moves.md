# 杀招连招并招体系

杀招是多蛊组合的用法沉淀，是蛊虫能力的放大器与代价放大器。本页为规则页（v2.1 冻结版）：KM-\* 主键（CAN-\* 登记受 `game/` 冻结限制，同 [灾劫体系](tribulation.md) 页尾说明），每条主张带证据与禁止误读。

## 规则表

| ID | 规则 | 证据 | 禁止误读 |
|---|---|---|---|
| KM-001 | 定义："杀招，就是蛊虫的绝妙搭配。" | E:V3-099762 | 搭配是必要条件，不是充分条件——组合必有代价（KM-003） |
| KM-002 | 构成：杀招由多只蛊虫按方案组成，存在"必要蛊虫"（春星雨必须含星芽蛊）；可以凡蛊为主体（轻虚蝠翼由众多凡蛊组成） | E:V4-124430、E:V4-125528 | 凡蛊可组成杀招但不等于仙道杀招——仙道杀招以仙蛊为核心（首现于蛊仙语境，E:V5-311102 同段语境） |
| KM-003 | 代价与缺陷：威力惊人则真元消耗巨大、必有缺陷；后遗症不可避免、只分严重微弱（六臂天尸王例：完善后威力翻番、时长一炷香、无法再改进，过多使用有变僵尸之忧） | E:V4-098114、E:V3-106762–106772 | "必有弊端"是全称规则；完善只能缓解不能根除 |
| KM-004 | 仙道杀招起源：最早的仙道杀招是蛊仙们参照荒兽身上的道痕、模仿摸索发展出来的 | E:V5-311102 | 起源考据不等于当世仍需参照荒兽才能创招 |
| KM-005 | 距离限制：仙道杀招与蛊仙之间的联系有距离限制，超过限制仙道杀招往往分崩离析 | E:V5-321490 | 限制值未给出，不得虚构数字 |
| KM-006 | 蛊屋：蛊屋本质是杀招、只是形式固定（八十八角真阳楼、近水楼台之功用单蛊提供不了） | E:V3-105514 | 蛊屋是固定化杀招子类，不是独立于杀招的体系 |
| KM-007 | 战场杀招：建立需要刻印道痕改造环境；仙窍中通常不能铺设——临时刻印与仙窍自身道痕冲突并造成伤害 | E:V5-158566、E:V5-194608 | 机制细节见 [道痕体系](dao-marks.md) DM-009；战场杀招可师承（乐土仙尊最擅长战场杀招、玉露仙子承精髓并推陈出新，E:V4-149132） |
| KM-008 | 获取路径·传承：杀招可经遗藏/传承获取（斗志昂扬出自紫山真君遗藏传承） | E:V5-261746 | 传承获取的杀招仍受通用代价规则约束 |
| KM-009 | 获取路径·自创：自创杀招是蛊仙常规进阶现象（星罗小新以寒纱+六九星尘为基石自创；洪易极其擅长自创；叶凡自创才情受族 judged） | E:V4-124314、E:V4-125320、E:V5-286120 | 自创常带一大弊端（身体力行杀招只能直线前进、方向不可更改，E:V5-196196） |
| KM-010 | 连招：两种以上仙道杀招先后爆发，产生威力提升或效果共鸣；有顺序与时间窗口（愤怒小鸟+火囚例：超时或先催火囚则威力大减且易躲）；原理为临时道痕残留（炎道道痕为火囚垫基）；能设想者须大宗师境界；支撑时间有限（焚天魔女连招不十呼吸即近崩解） | E:V4-171840–171874 | 连招≠并招；道痕残留机制见 [道痕体系](dao-marks.md) |
| KM-011 | 并招：仙道杀招著名技巧之一——两个杀招并为一招，非简单叠加（上古剑蛟变并万我成万蛟，经七转巅峰道痕增幅登顶七转杀招极限）；失败代价沉重（自由残缺变三核心并招，失败轻则重伤重则死亡） | E:V5-266794–266830、E:V5-365072 | 并招与连招术语不得互换（一为合并、一为先后） |
| KM-012 | 与道痕/真元的联动：杀招威力惊人则真元消耗巨大；连招依赖临时道痕残留、并招受道痕增幅——道痕规则见 [道痕体系](dao-marks.md) DM-010、灾劫道痕收益见 [灾劫体系](tribulation.md) TRIB-011 | E:V4-098114、E:V4-171858、E:V5-266796 | 跨页引用，不重复记数字 |

## 待核对

- 仙道杀招距离限制的具体数值与流派差异未核验。
- 连招的"临时道痕残留"时长量化、并招的前置境界，均只有个案（同 [蛊的饲养与炼化](../world/gu-care-and-refinement.md) 待核对）。
- 凡蛊杀招与仙道杀招的正式分界表述未核验（本页仅记录语境差异）。
