# 流派境界五级

流派境界是蛊师/蛊仙对某一大道的理解深度，与修为（转数）解耦、与道痕（沉淀）相邻。本页为规则页（v2.1 冻结版）：PR-\* 主键（CAN-\* 登记受 `game/` 冻结限制，同 [灾劫体系](tribulation.md) 页尾说明）。本页恢复原 T1 延期考证（L0 指令）。

## 真意与本页的关系

- 真意（狂蛮真意、炼道真意、智慧之光等）是境界提升的加速资源；其来源（尊者遗留/自悟）与保真度决定提升幅度（PR-004、PR-006）。
- 真意定义：真意其实就是一种意志；智道有三元要素，讲究念、意、情——真意便是三元中的"意"（此外还有假意、特意、故意、刻意、敌意、战意等），是当中最具价值、最引人入胜，连蛊修尊者都要追逐不休的（E:V5-289122–289126）。
- 狂蛮真意实例：北部大冰原乃狂蛮魔尊一力打造、蕴藏狂蛮真意；蛊师在北部大冰原升仙力道就会勾动出狂蛮真意，得此真意便能引得变化道或力道的境界凭空上涨（E:V5-289124–289126）。
- "真意往往意味着的，就是境界飙升"；梦境中蕴藏真意、探索成功得灌输即直接提升境界——机制与上限见 [梦道机制](dream-path.md) DRM-013、PR-015。
- 真意与道痕、境界三者的完整因果（谁决定谁）未核验；现行记录只支持"真意→境界""灾劫→道痕"两段（见 [道痕体系](dao-marks.md)、[灾劫体系](tribulation.md)）。
