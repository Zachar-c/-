# 道痕体系

道痕是蛊仙力量的沉淀形态：既是身躯构成（仙体），也是环境属性（福地道痕），还是攻击手段（刻印敌体）。本页为规则页（v2.1 冻结版）：DM-\* 主键暂代 CAN-\*（受 `game/` 冻结限制，见 [灾劫体系](tribulation.md) 页尾同款说明），每条主张带证据与禁止误读。

## 规则表

| ID | 规则 | 证据 | 禁止误读 |
|---|---|---|---|
| DM-001 | 本质定义：蛊仙修行即培养仙窍，"何谓仙体？说通透一点，无非就是身上刻印了道痕！"——仙体与凡人躯体的本质差异就是道痕刻印 | E:V4-149574、E:V4-149598 | 道痕是身躯构成的一部分，不是可摘戴的装备 |
| DM-002 | 境界评价：道痕越多越亲近天地、亲近大道法则；评论蛊仙修为冠以"一次天劫、二次天劫"等渡劫次数标准 | E:V4-138686–138688 | 渡劫次数是评价口径，不是道痕的唯一来历（见 DM-003…009） |
| DM-003 | 取得·渡劫：每一次渡劫成功，蛊仙身躯增加本道道痕 | E:V4-138684 | 只增"本道"道痕，不是任意流派 |
| DM-004 | 取得·吞食剥夺：吃力仙蛊的效用是让蛊仙吞食含纯粹力道道痕的仙材或荒兽血肉，剥夺其天然道痕增添到自身（巨角羊、象腿骨实例） | E:V4-152010、E:V4-161138、E:V4-142182 | 剥夺对象是"天然道痕"的仙材/荒兽，不是其他蛊仙（那条走 DM-005） |
| DM-005 | 取得·击杀吞并：斩杀其他蛊仙可吞并其一身道痕，收获可观；对比之下仙窍吞并条件苛刻麻烦得多 | E:V5-200050、E:V5-208970 | 杀四位蛊仙是方源 Run 1 个案计数；"吞并道痕"与"吞并仙窍"是两件事 |
| DM-006 | 取得·仙蛊刻印：兽力仙蛊（如铁冠鹰力蛊）可在身上刻印部分道痕，但与人体结构不完美适配、数目稀少、效果不大 | E:V4-138706–138712 | 刻印道痕"并不完美适合肉身"——外源道痕有适配折损 |
| DM-007 | 取得·成功道痕：炼蛊大会前六名各奖励六道成功道痕，当场直接印刻身上、外人根本无法抢夺；成功道痕无法夺取和转移——天庭多次努力无一次成功 | E:V4-153812、E:V4-155840 | "不可夺取转移"是成功道痕特有属性，不外推到天然道痕 |
| DM-008 | 取得·杀招刻印（攻击性）：剑痕索命永久耗费剑道仙蛊中的道痕、刻印到目标身上；刻印的剑道道痕自寻目标弱点持续攻击 | E:V5-194498–194500 | 刻印到敌体的道痕是持续伤害源，且以永久消耗己方仙蛊道痕为代价 |
| DM-009 | 取得·环境刻印：战场杀招建立需要刻印道痕改造环境；仙窍中通常不能铺设战场杀招——临时刻印会与仙窍自身道痕冲突并造成伤害 | E:V4-158566、E:V5-194608 | 仙窍内外是两套刻印环境，规则相反 |
| DM-010 | 作用·增幅与冲突：道痕越多，使用相应流派仙蛊引发更深共鸣——同流派增幅（力道仙蛊十成→十二三成）；异流派冲突（力道道痕 vs 浪迹天涯水道，十成→七八成） | E:V4-138690–138692 | 增幅/冲突幅度是个案数字，不是通用倍率表 |
| DM-011 | 作用·环境反哺：灾劫新增道痕改良天地、孕育更有价值的事物（泥沼蟹土道改善土地承载；血毒棠血道养出血镰草、赤斧花）；道痕决定适生条件（宙道↔光阴支流、宇道↔空间承载、奴道↔养狐驭兽） | E:V4-150406、E:V4-149584 | 食物链补入（血纹兔/狐）当时是经营预期，不是已发生事实 |
| DM-012 | 作用·反制入侵：蛊仙入侵福地也受道痕反制；福地道痕越多、反制越强（蛊仙有仙体，与凡人本质不同） | E:V4-149598 | 反制强度与福地道痕量正相关，不代表入侵必然失败 |
| DM-013 | 丢失与清空：抢夺仙蛊屋可令福地道痕锐减、损失惨重（秦百胜夺炼炉仙蛊屋例）；炼成血神子时被刻印的智道道痕会被清除清空、只余最纯粹血道道痕（方正例） | E:V4-161550、E:V5-196832 | 道痕可丢失/清空，但两者机制不同（载体转移 vs 炼化清除） |
| DM-014 | 特例·多道痕容纳：狂蛮魔尊吞吃太古荒兽、体内形成荒兽图腾，将无数道痕容纳于一身、随时变化形态 | E:V4-131612 | 传奇个案，不构成通用多道痕共存规则 |
| DM-015 | 特例·万劫加身：以宇道、毒道、气道、木道多种道痕刻印其身，可破坏其魂道道痕——多系刻印是重创魔尊幽魂的手段 | E:V4-187078 | 这是针对性多系刻印的攻击用法；道痕间的一般克制关系未系统核验 |

## 连招/并招衔接

- 仙道连招的原理为临时道痕残留（炎道道痕为火囚垫基、超时失效）——E:V4-171840–171874，个案记录见[蛊的饲养与炼化](../world/gu-care-and-refinement.md)。
- 并招非简单叠加：上古剑蛟变并万我成万蛟、经七转巅峰道痕增幅登顶七转杀招极限——E:V5-266794–266830。

## 待核对

- 道痕的计量单位与总量概念（"三十道不败道痕""一身道痕"）只有个案数字，全体系计量学未建立；不败道痕稀缺性（天庭攻略福地数千年仅提取三十道、传承满额三十六道，E:V4-153504）待归档为独立条目。
- 道痕与五转以下凡蛊师的关系（凡人无道痕、蛊师是否有微量道痕）未核验。
- 道痕组合的完整相克表、吞并道痕的流派覆盖边界（是否只能吞同流派）、以及"无数道痕容纳"的实现条件，均未核验。
- TRIB 联动：灾劫周期与道痕收益的对应关系见[灾劫体系](tribulation.md) TRIB-011；两页的口径冲突登记相互独立。
