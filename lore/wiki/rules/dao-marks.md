# 道痕体系

道痕是蛊仙力量的沉淀形态：既是身躯构成（仙体），也是环境属性（福地道痕），还是攻击手段（刻印敌体）。本页为规则页（v2.1 冻结版）：DM-\* 主键暂代 CAN-\*（受 `game/` 冻结限制，见 [灾劫体系](tribulation.md) 页尾同款说明），每条主张带证据与禁止误读。

## 规则表

| ID | 规则 | 证据 | 禁止误读 |
|---|---|---|---|
| DM-001 | 本质定义：蛊仙修行即培养仙窍，"何谓仙体？说通透一点，无非就是身上刻印了道痕！"——仙体与凡人躯体的本质差异就是道痕刻印 | E:V4-149574、E:V4-149598 | 道痕是身躯构成的一部分，不是可摘戴的装备 |
| DM-002 | 境界评价：道痕越多越亲近天地、亲近大道法则；评论蛊仙修为冠以"一次天劫、二次天劫"等渡劫次数标准 | E:V4-138686–138688 | 渡劫次数是评价口径，不是道痕的唯一来历（见 DM-003…009） |
| DM-003 | 取得·渡劫：每一次渡劫成功，蛊仙身躯增加本道道痕（渡劫增道痕是蛊仙修行常识）；增益可被仙蛊放大——因祸得福仙蛊使渡劫成功后身上道痕在原基础上再增加一倍有余，一次渡劫的收获相当于旁人两次渡劫的成果 | E:V4-138684、E:V4-139204–139208 | 只增"本道"道痕，不是任意流派；"一倍有余"是因祸得福仙蛊个案效果，不是渡劫默认收益 |
| DM-004 | 取得·吞食剥夺：吃力仙蛊的效用是让蛊仙吞食含纯粹力道道痕的仙材或荒兽血肉，剥夺其天然道痕增添到自身（巨角羊、象腿骨实例） | E:V4-152010、E:V4-161138、E:V4-142182 | 剥夺对象是"天然道痕"的仙材/荒兽，不是其他蛊仙（那条走 DM-005） |

| DM-006 | 取得·仙蛊刻印：兽力仙蛊（如铁冠鹰力蛊）可在身上刻印部分道痕，但与人体结构不完美适配、数目稀少、效果不大 | E:V4-138706–138712 | 刻印道痕"并不完美适合肉身"——外源道痕有适配折损 |
| DM-007 | 取得·成功道痕：炼蛊大会的奖励**共六道**成功道痕（不败传承每次积满共三十六道，天庭提前取走三十道，"还剩下六道道痕，只能留给那些参加大会的比试之人"），**前六名各得一道**，当场直接印刻身上、外人根本无法抢夺；成功道痕无法夺取和转移——天庭多次努力无一次成功。**调和注**：E:V4-153812 字面作"前六名，将会被奖励六道成功道痕"，可被误读作"各六道"；据 E:V4-153504（余六道）与 E:V4-155836（方源获第二名实得"一道"）核定总数为六道、前六名各一道，原"各六道"表述作废 | E:V4-153504、E:V4-153812、E:V4-155836、E:V4-155840、E:V4-153816（153814–153816） | "不可夺取转移"是成功道痕特有属性，不外推到天然道痕；成功道痕只排除炼制过程中的失败概率，并非"肯定成功"；数目须读作"共六道、各一道"，不得读作"前六名各六道" |
| DM-008 | 取得·杀招刻印（攻击性）：剑痕索命永久耗费剑道仙蛊中的道痕、刻印到目标身上；刻印的剑道道痕自寻目标弱点持续攻击 | E:V5-194498–194500 | 刻印到敌体的道痕是持续伤害源，且以永久消耗己方仙蛊道痕为代价 |
| DM-009 | 取得·环境刻印：战场杀招建立需要刻印道痕改造环境；仙窍中通常不能铺设战场杀招——临时刻印会与仙窍自身道痕冲突并造成伤害 | E:V4-158566、E:V5-194608 | 仙窍内外是两套刻印环境，规则相反 |
| DM-010 | 作用·增幅与冲突：道痕越多，使用相应流派仙蛊引发更深共鸣——同流派增幅（力道仙蛊十成→十二三成）；异流派冲突（力道道痕 vs 浪迹天涯水道，十成→七八成） | E:V4-138690–138692 | 增幅/冲突幅度是个案数字，不是通用倍率表 |
| DM-011 | 作用·环境反哺：灾劫新增道痕改良天地、孕育更有价值的事物（泥沼蟹土道改善土地承载；血毒棠血道养出血镰草、赤斧花）；道痕决定适生条件（宙道↔光阴支流、宇道↔空间承载、奴道↔养狐驭兽；福地功用实例见 DM-020） | E:V4-150406、E:V4-149584 | 食物链补入（血纹兔/狐）当时是经营预期，不是已发生事实 |
| DM-012 | 作用·反制入侵：蛊仙入侵福地也受道痕反制；福地道痕越多、反制越强（蛊仙有仙体，与凡人本质不同）；反向同样成立——蛊仙身上的道痕越多，福地的压制就越少 | E:V4-149598 | 反制强度与道痕量双向正相关，不代表入侵必然失败；三层压制机制（凡蛊/仙蛊/蛊仙）见 DM-019 |
| DM-013 | 丢失与清空：抢夺仙蛊屋可令福地道痕锐减、损失惨重（秦百胜夺炼炉仙蛊屋例）；炼成血神子时被刻印的智道道痕会被清除清空、只余最纯粹血道道痕（方正例） | E:V4-161550、E:V5-196832 | 道痕可丢失/清空，但两者机制不同（载体转移 vs 炼化清除） |

| DM-015 | 特例·万劫加身：以宇道、毒道、气道、木道多种道痕刻印其身，可破坏其魂道道痕——多系刻印是重创魔尊幽魂的手段 | E:V4-187078 | 这是针对性多系刻印的攻击用法；道痕间的一般克制关系未系统核验 |

| DM-017 | 蛊材承载道痕：魂兽体内魂核凝结大量魂道道痕、是上佳蛊材；凡级蛊材内蕴残破土道道痕（草木汲取后绝大多数消散）；蛊材道痕受环境道痕构成影响发展——梦道蛊材在土道主导环境受压制、在梦道主导环境优良发展；总纲："蛊虫是大道碎片，蛊材则是道痕聚集"（鲁桐兰语）；高明炼道大能甚至考究每一分蛊材上的道痕数目 | E:V5-192166、E:V5-213594、E:V6-398220、E:V6-398224、E:V6-401146、E:V5-228940 | 材料层替代规则与边界归 [炼蛊术语体系](refinement.md) REF-019，本页只记载体事实；"承载"不等于材料可任意当蛊虫用 |

| DM-021 | 变化道残留处理：变化道蛊仙每次只变一种猛兽、身躯的道痕只有一种；变化之后会用相应的蛊虫冲刷身体、将残留的道痕印记洗干净，方能变化做具备另一种道痕的猛兽（黑楼兰语）；两种道痕混杂犹如蛊师时期兼修两道 | E:V4-131610 | 这是常规变化道手段（说话人：黑楼兰 `对话\|已核`）；狂蛮魔尊吞吃太古荒兽容纳无数道痕是特例（DM-014），不得混同 |

## 连招/并招衔接

- 仙道连招的原理为临时道痕残留（炎道道痕为火囚垫基、超时失效）——E:V4-171840–171874，个案记录见[蛊的饲养与炼化](../world/gu-care-and-refinement.md)。
- 并招非简单叠加：上古剑蛟变并万我成万蛟、经七转巅峰道痕增幅登顶七转杀招极限——E:V5-266794–266830。

## 待核对

- 道痕的计量单位与总量概念（"三十道不败道痕""一身道痕"）只有个案数字，全体系计量学未建立；不败道痕稀缺性（天庭攻略福地数千年仅提取三十道、传承满额三十六道，E:V4-153504）待归档为独立条目。
- 道痕与五转以下凡蛊师的关系（凡人无道痕、蛊师是否有微量道痕）未核验。
- 道痕组合的完整相克表、以及"无数道痕容纳"的实现条件，均未核验。（吞并道痕的流派覆盖边界已结：唯有斩杀相同流派才能吸收、至尊仙体例外，见 DM-005；2026-09-25 RULES 基准回归批补验。）
- 道痕"怎样排列才算符合规则"无系统表述——DM-016 只证明排列/分布与能力相关（个案：上极天鹰、大阵、仙招），排列方式的分类学与可控操作手段未核验。
- TRIB 联动：灾劫周期与道痕收益的对应关系见[灾劫体系](tribulation.md) TRIB-011；两页的口径冲突登记相互独立。
