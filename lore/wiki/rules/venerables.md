# 尊者体系

尊者是天地最强者的称号层。本页为规则页（v2.1 冻结版）：VEN-\* 主键（CAN-\* 登记受 `game/` 冻结限制，同 [灾劫体系](tribulation.md) 页尾说明）。本页收口 [流派境界五级](path-realms.md) PR-011 的尊者资格链问题。

## 规则表

| ID | 规则 | 证据 | 禁止误读 |
|---|---|---|---|
| VEN-001 | 必要条件：世人公认十大尊者，都是无上大宗师；"每一个尊者都有无上大宗师的境界，这是世人公认的事情" | E:V5-281112、E:V5-337214 | 无上大宗师是必要条件不是充分条件——炼道三老（长毛老祖、天难老怪、空绝老仙）是无上大宗师但不在十大尊者之列 |
| VEN-002 | 准无上大宗师（权威定义）：对某流派的认知已达到天地的极限、碰触到那层天花板，几乎穷尽了此流派的所有奥秘，"但还差一些边角，没有踏足" | E:V6-396090 | 这是全书对该层级最完整的定义段，优先于各处简称 |
| VEN-003 | 无上大宗师（权威定义）：不仅完全洞悉流派的全部奥妙，还能推陈出新——此层次的每次进步都是前无古人的创举，是对整个流派上限的提高 | E:V6-396092 | 无上大宗师的含金量会随流派整体进步而稀释（见 VEN-005） |
| VEN-004 | 境界贬值机制：尊者消逝后流派继续发展，其旧的无上大宗师境界会"放在今天早已经不是了"（星宿仙尊智道例：三百万年前的无上大宗师，今天已不算数） | E:V6-396084–396096 | 境界贬值只发生在死后停滞者身上；活着并持续精进者不受此限 |
| VEN-005 | 道主：进入元境，方能令境界重回无上大宗师并"成为道主"；道主"很可能关乎尊者无敌的秘密" | E:V6-396100、396104 | 元境位于疯魔窟最底层之说出自陆畏因一面之词，方源未直接验证 |
| VEN-006 | 成尊四条件（证据分级拼装，2026-09-25 逐段重读收口）：**明文之一=突破天道封锁**（"成尊的四个条件当中，就有一条要突破天道封锁"），杠杆="除了运道，就是人道"（400914），机制=传承流传越广、修行者越多越强、天道制衡付出越多、关键时刻封锁力下降（400906–400910）；**渡过三次万劫**[推断]——叙述者明文"渡过三次万劫的，只有十位，即十大尊者"（E:V4-184790），方源推断口径"理论上渡过三次万劫后就能晋升成尊、道痕平均约三十万"（E:V5-337540–337542，[信念\|已核]），但方源本人一次万劫未渡仍成尊（E:V6-395812、422102，借至尊仙窍取巧跨万劫 395810）——存在替代满足路径；**主修流派成就无上大宗师**[推断]——十大尊者皆无上大宗师（E:V5-281112），方源自述"要成为真正的无上大宗师，欠缺的就是这些东西"（E:V6-396260）、定策先炼道成尊（396422–396424）；**第四条件[未决]**：原文无明文，候选=道痕底蕴（337542 三十万口径，系渡劫积累相关量[推断]）、元境/道主（396100，更近"尊者无敌之秘"[推断]） | E:V6-400904、E:V6-400914、E:V4-184790、E:V5-337542、E:V5-281112、E:V6-396260 | 四条件由陆畏因口述，揭示发生在页外（395676 发问后叙事切走、396104"全部获悉"），净本从未集中列出——除明文之一外均为拼装推断，不得当作原文枚举引用；渡三次万劫非充分（人族有渡尽灾劫仍不成尊者，E:V5-342642）；无上大宗师非充分（炼道三老反例，VEN-001） |
| VEN-007 | 尊者关卡与重生：宿命蛊在时不能重生复活；尊者几乎都留下了重生手段，宿命蛊一毁即可发动；越强的蛊仙重生越麻烦、代价越大，"稍有不慎，即便复活，也没有之前的实力" | E:V6-396006–396014 | 重生后"再无尊者关卡，可以一路上升回到九转修为"——尊者关卡拦的是生前路径 |
| VEN-008 | 尊者竞争：尊者立场阵营不同、相互谋算拆台；越后面出世的尊者越有利——整个蛊修世界不断进步（远古流派仅四五道、当代主修至少二十道）；故有尊者扣着流派真传不传播（画道被元莲私藏仍是巅峰、巨阳扣运道真传） | E:V6-396016–396054 | 大趋势不绝对：元莲早于幽魂仍坑了幽魂（神帝城与青仇例） |
| VEN-009 | 天道制衡：天道讲究平衡，一直在压制蛊仙、尊者；掌控灾劫、控制寿蛊；传承流传越广、修行者越多越强，天道制衡要付出更多力量 | E:V6-400904–400906、E:V6-405586 | 天道制衡与灾劫体系的关系见 [灾劫体系](tribulation.md) TRIB-007（天意须守天道平衡） |
| VEN-010 | 天道哲学："天道无情，天之道，在于损有余而补不足。所以万物平……" | E:V5-188126 | 这是角色引述的天道观（老庄表述），不是叙事者的形上学定论 |
| VEN-011 | 层级序列：亚仙尊（距尊者层次最近）→ 尊者"乃天地最强，是天地间的极限"；尊者间差距一丝一毫即可决定交锋结果 | E:V6-421160、396180 | 亚仙尊不是官方称号层级，是实力圈层描述 |
| VEN-012 | 转修与代价：乐土仙尊转修天道、重生后未重拾尊者修为——"这就是代价"；若成为极其特殊的天道尊者，实力将一跃为天下第一 | E:V6-418814、421900–421902 | 天道尊者是晚近变局中的特例路径，历史上无先例记录 |
| VEN-013 | 天道仿效：天道甚至仿效尊者手段（盗天魔尊的无相手例）；灾劫涵盖各流派、种类繁多芜杂 | E:V6-380704、387670 | 天道仿效仅此一例记录，机制未核验 |
| VEN-014 | 尊者与天道道痕：尊者级才能炼化大量天道道痕（幽魂全盛期自评亦称艰难）；方源非尊者、对天道道痕了解有限 | E:V6-374408–374410 | 炼化天道道痕的完整流程（天意纠缠→天人感应→天工人代）见 395918–395926 行，属个案操作记录 |
| VEN-015 | 元境终局：元境后来被灭（"眼下元境已灭"）——经元境重登无上大宗师成为道主的路径一度断绝；未成尊者者（方源）"一日不成尊，哪怕道痕再多，也只是亚仙尊" | E:V6-419732–419734 | 道主路径断绝不等于永久不可能——元境是否可重建、有无替代路径未核验 |

## 待核对

- 成尊四条件逐段重读已收口（2026-09-25）：弧内（393990–396520）成尊/万劫/天道封锁/无上大宗师/道主关键词穷尽扫描完毕，确认净本无集中枚举——拼装结果见 VEN-006（明文之一+两个[推断]条件+第四条件未决）。残余开放点：第四条件的原文身份、方源成尊（422102）实际满足路径的完整回溯（疯魔窟之争某刻悄然成尊，双尊亦惑 422124–422126）。
- 道主与元境的完整机制（元境是什么、如何进入、道主权柄）只有陆畏因转述一方之言。
- 十大尊者的完整名单在本书正文中的集中表述待查（各尊者散见各弧）。
- 尊者与天道道痕、尊者与运道（察运）的完整关系未系统核验。
