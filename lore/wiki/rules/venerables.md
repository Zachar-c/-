# 尊者体系

尊者是天地最强者的称号层。本页为规则页（v2.1 冻结版）：VEN-\* 主键（CAN-\* 登记受 `game/` 冻结限制，同 [灾劫体系](tribulation.md) 页尾说明）。本页收口 [流派境界五级](path-realms.md) PR-011 的尊者资格链问题。

## 规则表

| ID | 规则 | 证据 | 禁止误读 |
|---|---|---|---|
| VEN-001 | 必要条件：世人公认十大尊者，都是无上大宗师；"每一个尊者都有无上大宗师的境界，这是世人公认的事情" | E:V5-281112、E:V5-337214 | 无上大宗师是必要条件不是充分条件——炼道三老（长毛老祖、天难老怪、空绝老仙）是无上大宗师但不在十大尊者之列 |
| VEN-002 | 准无上大宗师（权威定义）：对某流派的认知已达到天地的极限、碰触到那层天花板，几乎穷尽了此流派的所有奥秘，"但还差一些边角，没有踏足" | E:V5-396090 | 这是全书对该层级最完整的定义段，优先于各处简称 |
| VEN-003 | 无上大宗师（权威定义）：不仅完全洞悉流派的全部奥妙，还能推陈出新——此层次的每次进步都是前无古人的创举，是对整个流派上限的提高 | E:V5-396092 | 无上大宗师的含金量会随流派整体进步而稀释（见 VEN-005） |
| VEN-004 | 境界贬值机制：尊者消逝后流派继续发展，其旧的无上大宗师境界会"放在今天早已经不是了"（星宿仙尊智道例：三百万年前的无上大宗师，今天已不算数） | E:V5-396084–396096 | 境界贬值只发生在死后停滞者身上；活着并持续精进者不受此限 |
| VEN-005 | 道主：进入元境，方能令境界重回无上大宗师并"成为道主"；道主"很可能关乎尊者无敌的秘密" | E:V5-396100、396104 | 元境位于疯魔窟最底层之说出自陆畏因一面之词，方源未直接验证 |
| VEN-006 | 成尊四条件：第 119 节《成尊的四个条件》专述；其中一条为突破天道封锁；其余条件在净本中散落未集齐 | E:V5-395790（节题）、E:V5-400904 | 四条件的完整官方枚举未在净本中集中出现，不得虚构补全 |
| VEN-007 | 尊者关卡与重生：宿命蛊在时不能重生复活；尊者几乎都留下了重生手段，宿命蛊一毁即可发动；越强的蛊仙重生越麻烦、代价越大，"稍有不慎，即便复活，也没有之前的实力" | E:V5-396006–396014 | 重生后"再无尊者关卡，可以一路上升回到九转修为"——尊者关卡拦的是生前路径 |
| VEN-008 | 尊者竞争：尊者立场阵营不同、相互谋算拆台；越后面出世的尊者越有利——整个蛊修世界不断进步（远古流派仅四五道、当代主修至少二十道）；故有尊者扣着流派真传不传播（画道被元莲私藏仍是巅峰、巨阳扣运道真传） | E:V5-396016–396054 | 大趋势不绝对：元莲早于幽魂仍坑了幽魂（神帝城与青仇例） |
| VEN-009 | 天道制衡：天道讲究平衡，一直在压制蛊仙、尊者；掌控灾劫、控制寿蛊；传承流传越广、修行者越多越强，天道制衡要付出更多力量 | E:V5-400904–400906、E:V5-405586 | 天道制衡与灾劫体系的关系见 [灾劫体系](tribulation.md) TRIB-007（天意须守天道平衡） |
| VEN-010 | 天道哲学："天道无情，天之道，在于损有余而补不足。所以万物平……" | E:V5-188126 | 这是角色引述的天道观（老庄表述），不是叙事者的形上学定论 |
| VEN-011 | 层级序列：亚仙尊（距尊者层次最近）→ 尊者"乃天地最强，是天地间的极限"；尊者间差距一丝一毫即可决定交锋结果 | E:V5-421160、396180 | 亚仙尊不是官方称号层级，是实力圈层描述 |
| VEN-012 | 转修与代价：乐土仙尊转修天道、重生后未重拾尊者修为——"这就是代价"；若成为极其特殊的天道尊者，实力将一跃为天下第一 | E:V5-418814、421900–421902 | 天道尊者是晚近变局中的特例路径，历史上无先例记录 |
| VEN-013 | 天道仿效：天道甚至仿效尊者手段（盗天魔尊的无相手例）；灾劫涵盖各流派、种类繁多芜杂 | E:V5-380704、387670 | 天道仿效仅此一例记录，机制未核验 |
| VEN-014 | 尊者与天道道痕：尊者级才能炼化大量天道道痕（幽魂全盛期自评亦称艰难）；方源非尊者、对天道道痕了解有限 | E:V5-374408–374410 | 炼化天道道痕的完整流程（天意纠缠→天人感应→天工人代）见 395918–395926 行，属个案操作记录 |
| VEN-015 | 元境终局：元境后来被灭（"眼下元境已灭"）——经元境重登无上大宗师成为道主的路径一度断绝；未成尊者者（方源）"一日不成尊，哪怕道痕再多，也只是亚仙尊" | E:V5-419732–419734 | 道主路径断绝不等于永久不可能——元境是否可重建、有无替代路径未核验 |

## 待核对

- 成尊四条件的完整枚举未在净本集中出现（第 119 节以万劫战为主、条件散落弧内多处），须按弧逐段重读集齐。
- 道主与元境的完整机制（元境是什么、如何进入、道主权柄）只有陆畏因转述一方之言。
- 十大尊者的完整名单在本书正文中的集中表述待查（各尊者散见各弧）。
- 尊者与天道道痕、尊者与运道（察运）的完整关系未系统核验。
