# 仙蛊唯一性

这里是唯一性规则的主要落点。[蛊虫关系](../gu/gu-relations.md#五同种唯一性)负责连接具体蛊与炼蛊流程，不另维护一份规则。仙蛊的具体能力、持有人与转数变化仍以对应实体页为准。

## 原著明确内容

| 规则 | 适用条件与结果 | 证据与边界 |
|---|---|---|
| IU-001 同种仙蛊唯一 | 蛊达到六转及以上，同种在天地中同时只存在一只；现存同种未消失时，另行炼出相同仙蛊必失败。这里限制的是同一种，不是所有仙蛊合计只有一只。 | EPUB `chapter_0188` `para_006`：“只有前一只死了，才能有成功的可能性。否则百分百失败。”；历史锚 `E:V1-032214` |
| IU-002 唯一性的世界范围 | 春秋蝉达到六转后，大世界与小世界都适用唯一性，不能靠把现存蛊藏入小世界来避开规则。 | EPUB `chapter_0347` `para_045`：“不管是大世界还是小世界，都只有唯一的一只。”；历史锚 `E:V2-064426` |
| IU-003 转化可以使原种不再存在 | 神游蛊转化为定仙游后，原神游蛊不复存在，允许新的神游蛊出现。释放的是原种的存在限制；不等于可以复制已经存在的定仙游。 | EPUB `chapter_0412` `para_065`：“神游蛊转化为定仙游蛊，已经不复存在了。”；同段继续说明允许新神游蛊出现 |
| IU-004 名称不能按仙蛊转数拆成独立种 | 仙蛊六转后向上晋升，名字不变。察运仙蛊已在秦百胜手中时，方源即便得到七转残方也不能再炼出察运仙蛊。 | EPUB `chapter_0464` `para_010`：“六转之后往上晋升，名字并不会更变。”；`chapter_0761` `para_067` 是方源收手的判断与行动，不是完整物种分类标准 |
| IU-005 凡蛊不套用六转唯一门槛 | 和稀泥蛊一、二转数量多，三、四转常见，五转少见，六转只有一只。五转推杯换盏蛊以两只一套运作，不是仙蛊唯一性的反例。 | EPUB `chapter_0426` `para_016`；`chapter_0435` `para_041`–`para_042`。历史锚 `E:V3-078694`、`E:V3-080252`、`E:V3-080310`、`E:V3-080312` |
| IU-006 唯一不等于可无限使用 | 六转和稀泥仙蛊只能用一次；方源因此不把它选作本命蛊，避免消耗后自身受到牵连。 | EPUB `chapter_0426` `para_016`、`chapter_0495` `para_018`。本命绑定的完整规则仍见[炼蛊术语体系](refinement.md)与[蛊虫关系·本命](../gu/gu-relations.md#六本命蛊--蛊师) |
| IU-007 唯一不等于仙蛊种类稀少 | 原著区分“仙蛊唯一”与种类众多；年蛊升到六转后也变为世间唯一。 | EPUB `chapter_1140` `para_033`。历史补充锚 `E:V5-209566`、`E:V6-405756`；前者已核本章，后者保留为旧源回查，不拿旧锚单独增加本页结论 |

### 炼制决策如何使用这条规则

先识别要炼的是哪一种仙蛊，再核实该种是否仍存在：现存同种会阻止另炼；不存在只解除这一阻碍，并不保证蛊方、材料、手法和其他条件已经齐备。`chapter_0188` `para_006` 的“才有成功的可能性”不能改写为“旧蛊死后必定成功”。

转化与升炼也要分开：神游变成定仙游是原种不再存在的明文实例；同名仙蛊六转升到更高转数，不能仅凭转数差异当作一种全新的蛊。前述两种操作不要共用“都增加一只”的理解。

## 分析与解读

唯一性让炼蛊决策依赖世界中已经存在的对象状态，而不只是持有一份蛊方。神游转化的例子说明，调查“现存同种”时还要检查其是否已经变成另一种蛊。这是上述事实的归纳，不额外设定一个原著没有命名的规则系统。

## 待核对

- 相近命名、残缺形态、分体与异变时如何判定“同种”，本页尚未穷举；不能用名称相似度自动归一。
- 升炼失败、逆炼、毁灭与复生的各种路线是否改变种类，以及每条路线的名额释放时点，须逐案核原文。
- 本页不据唯一性推断仙蛊的交易价格、饲养需求或持有者当前生死；这些是其他事实。
