# 主题与《人祖传》

> 给想知道「这本书在争什么」的人：从《人祖传》寓言进入主题冲突。主题页是分析视角，**不是规则源**。

## 怎么用本页

1. **第一次接触本库的主题层** → 走下面「从《人祖传》读起」的推荐顺序。
2. **写同人、怕误读** → 直接看「写同人」阅读路径：动机 → 时代 → 限制 → 禁止误读。
3. **要硬设定 / 机制** → 本目录答不了，去[规则页索引](../rules/index.md)与[世界规则](../world/index.md)。
4. 铁律：**寓言 ≠ 硬规则**；**某人认为 X ≠ 世界规则 X**。主题页引用寓言或角色台词时只作互文线索，不得升格成世界机制。

## 从《人祖传》读起（推荐路径）

按「先看寓言骨架，再按冲突下钻」走一遍，大约能建立全书主题地图：

1. [《人祖传》](ren-zu-zhuan.md) —— 世界内神话寓言的 38 节主题索引 + 寓言-剧情互文锚点，全库主题总入口
2. [永生](immortality.md) —— 第一母题：方源与诸尊共同在追什么，以及无极「永生从来就不存在」的失败判词
3. [宿命](fate.md) → [自由](freedom.md) —— 全书最核心的一对张力：被安排的路 vs 自己选的路（注意宿命蛊/天意/命运蛊不是同一实体）
4. [坚持](persistence.md) —— 认准方向的前提下持续付代价、允许换方法；对应「小人的坚持」等寓言
5. [实力与利益](power-and-interest.md) —— 世界的显性运行伦理（唯有实力 / 以利为先 / 组织牺牲论），用来解释剧情里「证据与善意为什么让位」
6. [哲学思考](philosophy.md) —— 四组命题轴总表（自由 vs 宿命 / 思想自由 / 态度自由 / 人道与个体），要对照原文锚点或写争议段落时用
