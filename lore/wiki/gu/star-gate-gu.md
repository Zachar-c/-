# 星门蛊

星门蛊是五转、成对使用的凡蛊，能借黑天力量跨越五域界壁。它不是定仙游的替代品：星门依赖星光和仙元，耗能很重，对运输对象的道痕与品阶有严格限制。方源曾靠它往返狐仙福地与琅琊福地；一只被大同风幕毁坏后，他失去自行返回北原的能力，后来再从琅琊地灵处取得另一只。

## 原著明确内容

- [叙事|已核] 方源掌握星门蛊秘方，但材料稀缺，涉及上古蛊虫；最初估计百次未必能炼成一次。`chapter_0460` para_067–068（“一百次未必能有一次炼成”）
- [对话|已核] 琅琊地灵判断星门蛊可借黑天力量跨域传输，能与洞地蛊、通天蛊相提并论；炼制失败率低，可增辅料提高成功率，并以星萤供应星光，便可不受昼夜限制。`chapter_0463` para_065、071、075（说话人：琅琊地灵）
- [叙事|已核] 方源选择消耗一次炼蛊机会，请地灵炼星门蛊；地灵后来炼成一对蓝宝石状蛊虫，正文确认此蛊为五转。`chapter_0465` para_005–009、`chapter_0466` para_014–015、`chapter_0465` para_044
- [叙事|已核] 方源把一只星门蛊送进狐仙福地时，用推杯换盏蛊搬运；因星门蛊是凡蛊而可被该方法承载，但推杯换盏蛊因此严重受损。`chapter_0466` para_055–057
- [叙事|已核] 星门蛊不分子母；一对两端都须催动。五转巅峰蛊师的真元支撑不足三个呼吸，仙元才能长久催动。成门还需大量星光。`chapter_0467` para_006–007（“星门蛊不分子母”）
- [叙事|已核] 狐仙福地缺少天然星光，只能以星萤蛊供给；初次催动死去三十二只，此后维持星门平均每三个呼吸又死一只，方源因此叫停。`chapter_0467` para_007、010、012（“平均三个呼吸的时间”）
- [叙事|已核] 星门蛊是凡蛊，不能承担仙蛊之威；方源把九转智慧蛊收入死窍后才通过星门，仍称死窍承载能力有限、不能长时间停留。`chapter_0652` para_045–046
- [叙事|已核] 一只星门蛊被大同风幕毁掉后，方源手中只剩另一只，无法独自返回北原。`chapter_0657` para_005–006、`chapter_0659` para_069（“已经无法独自回去北原”）
- [叙事|已核] 琅琊地灵从方源处取得星门蛊蛊方，炼出第一对给方源，后来又炼一对自存。之后地灵借出自己一只，方源再往返琅琊福地取回。`chapter_0666` para_036–039、`chapter_0667` para_023、036–045
- [叙事|已核] 方源把推杯换盏蛊和星门蛊交给太白云生，让他保持联络；太白云生收下后使用星门蛊离开。`chapter_0674` para_020、023
- [叙事|已核] 星门蛊是凡蛊，仙窍道痕须少才可能运送；只有六转垫底或仅渡过数次灾劫的六转蛊仙可使用，运输仙材、仙蛊和高转蛊仙均有明显限制。`chapter_1087` para_061–066、070（“蛊仙身上的道痕，必须很少”）

## 资料整理

- 总表二期把星门蛊列为通信蛊，并记录方源以秘方换取神念蛊、通天蛊的经历。本页只记录星门蛊实体与其成对运作条件，不重复另外两蛊的机制。
- 方源保存并控制星门蛊蛊方，避免它流入宝黄天；星门的隐蔽性和可销毁一端，是其行动价值的一部分。`chapter_0667` para_021、028

## 分析与解读

- 星门蛊解决的是跨域通行与两地往返，效果依赖“成对端点＋星光＋仙元”同时具备；一端丢失或损坏就会失去完整通路。
- 它的跨域能力不等于普遍运输能力：凡蛊品阶、道痕承载和星光来源共同限制可运对象与持续时间。

## 待核对

- 本页确认了配对、星光、仙元、道痕和品阶限制；没有穷尽所有洞天福地、阵法或黑天环境对星门的影响。
- 原文只称早期配方百次未必成功、添加辅料可提高成功率；没有给出一套通用准确成功率或各材料数量。
- 星门蛊的通常喂养、休眠和自毁成本未在本批证据中给出；仅记录被毁的一只和毁损的搬运蛊。

## 机制条件、代价与限制

- **品阶与配对**：五转凡蛊，成对且不分子母（`chapter_0465` para_044、`chapter_0467` para_006）。
- **发动条件**：借黑天星辰之力；夜间可牵引星光，星萤能在任何时刻提供星光（`chapter_0463` para_065、071、075）。
- **真元/仙元成本**：五转巅峰真元只能支撑不足三个呼吸；仙元可使通路长久维持（`chapter_0467` para_006）。
- **星光代价**：狐仙福地以星萤供光，初次消耗三十二只，之后平均每三息死亡一只；方源停止催动（`chapter_0467` para_007、010、012）。
- **运送限制**：星门蛊自身不能承载仙蛊；蛊仙须道痕少，原文给出低阶六转为可用范围，且死窍运九转智慧蛊也只能短时间通过（`chapter_0652` para_045–046、`chapter_1087` para_064–066）。
- **损坏后果**：一对中任一端被毁，另一端不能独自构成往返通路（`chapter_0657` para_005–006）。
- **持有状态**：第一对为方源借炼蛊机会取得；随后有端点遭大同风幕损毁；琅琊地灵另存的一对让方源补回一端，后来星门蛊被交给太白云生使用（`chapter_0466` para_014–015、`chapter_0657` para_006、`chapter_0666` para_039、`chapter_0674` para_020、023）。
