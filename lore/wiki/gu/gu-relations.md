# 蛊虫关系

蛊虫之间的六类关系总览页：**合炼（低→高）、逆炼（高→低）、平炼/升炼（同级/跨级）、同种唯一与排行、本命（蛊↔蛊师）、替代与协同**，另附交易/传承与仙蛊屋核心关系。本页是导航与关系索引：明细与证据落点在各自蛊页与规则页，本页只收录已核关系对；**所有关系均标注证据或「笔记层」/「待核对」**，不得把笔记层当已核事实。

## 关系类型总览

| 关系类型 | 一句话定义 | 规则锚点 |
|---|---|---|
| 合炼 | 低阶蛊按秘方晋升高阶，须秘方、有些蛊不能合炼 | [炼蛊术语体系](../rules/refinement.md) REF-004；[蛊的饲养与炼化](../world/gu-care-and-refinement.md) |
| 逆炼 | 高阶蛊降回成分蛊（幡然蛊例） | REF-005/REF-029 |
| 平炼 / 升炼 | 同级提升年份 / 跨级提升转数 | REF-007/REF-008/REF-028 |
| 同种唯一与排行 | 同一种仙蛊天地间只存一只；奇蛊/仙蛊排行 | [春秋蝉](spring-autumn-cicada.md)、[方源](../characters/fang-yuan.md) ST-FANGYUAN-57 |

| 替代与协同 | 流派一致可相互取代、喂养替代上限、协同辅助 | REF-019；[蛊的饲养与炼化](../world/gu-care-and-refinement.md) |

## 替代与协同

### 方源力道蛊组的已核协同

这里记录原著关系，不记录游戏卡牌数值。方源本人提出以全力以赴蛊为核心、自力更生蛊和苦力蛊为支点的搭配计划 `[对话|已核]`（说话人：方源；E:V2-052510）。

| 关系 | 原著事实与边界 | 证据 |
|---|---|---|
| 肉身承载 → 兽力 | 铁骨为消耗型改骨，钢筋须连续使用才形成效果；方源后来达到八种兽力虚影的肉身极限。兽力虚影是体内的力量道纹，本身不耗真元。不能把八影断言成八只同转蛊。 | [叙事|已核] E:V2-053020、E:V2-058964、E:V2-053862、E:V2-053720 |
| 全力以赴 × 苦力 | 全力以赴蛊较早时一次仅催出一种兽力；受伤并催用四转苦力蛊后，该战例同时打出三种。苦力随伤痛提高力量，但有上限。 | [叙事|已核] E:V2-053012、E:V2-059288、E:V2-059292–59298 |
| 兽力 → 位移 | 直撞蛊无阻碍时冲五十步，力量越强、突破效果越好；横冲蛊为横向版本。距离不是随力量无上限增长。 | [叙事|已核] E:V2-052976–52992 |
| 兽力 → 治疗 | 三转自力更生蛊主动催用须真元；其疗效随使用者力量增强，并非随受伤严重程度直接增强。 | [叙事|已核] E:V2-053792、E:V2-053802 |
| 兽力 → 远程 | 三转力气蛊使虚影附着于力之气，才可离体攻击；八影同出高耗真元，实战还须分摊移动、防御与全力以赴的消耗。 | [叙事|已核] E:V2-059728–59744、E:V2-059764–59772 |

关系归纳：这是一套复用兽力存量的攻、防、机动、恢复和射程网络，不是每只蛊独立输出的加法。此句为分析，不等于原著给出了游戏蛊位或伤害公式。设计层的建模见[力道蛊组研究](../../../docs/design/rank1-9-model/strength-build-study.md)。
