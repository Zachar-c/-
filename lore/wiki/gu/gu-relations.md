# 蛊虫关系

蛊虫之间六类关系的总纲页：**合炼（低→高）、逆炼（高→低）、平炼/升炼（同级/跨级）、同种唯一、本命（蛊↔蛊师）、替代与协同**。它是游戏侧 `game/data/refinement_recipes.json`（145,382 B、469 条配方）的**知识底座**：每条关系规则都附原文实例（蛊A＋蛊B→产物C，带 E-ID），并明确标注哪些规则能直接映射到配方 schema、哪些属改编缺口。

## 一、合炼（低 → 高）

- **原著事实** [已确认]
  - 定义（两种口径并存，见 §术语冲突）：早期把「炼」分为单炼与合炼——「然而这个，只是单炼。单炼之外，还有更重要的合炼。」（E:V1-015728）；合炼是「合并成一只更高级数的蛊虫。这是生命的进化和升华。」（E:V1-015730）。后期改以方向定义——「合炼，是将低转的蛊虫晋升为高转。逆炼却恰恰相反。」（E:V2-037032），与起点「其中炼蛊，大致分为合炼，逆炼两大方面」（E:V2-037030）互为呼应。
  - 秘方约束：「要合炼就得知道秘方。有些蛊虫之间，是不能合炼的。」秘方由先祖在「数不清的失败后」总结而来（E:V1-015734）。全族对月光蛊研究最深、「已经掌握了两个五转秘方」（E:V1-015734）。
  - 机制：合炼的要害是意识融合——「合炼蛊虫最重要的，就是一心多用，意识融合」（E:V1-015744）；过程为两只蛊虫意识融入同一白色光团、再「将元石投入光团当中」，元石化纯净天然真元补入（E:V1-017042）。
  - 转数关系（只有实例，无通用公式）：一转＋一转→二转——月光蛊＋两只小光蛊→月芒蛊（E:V1-017148）；白豕蛊＋玉皮蛊→白玉蛊（E:V1-009986）。逐级＋1——黑豕蛊＋青丝蛊→二转黑鬃蛊→三转钢鬃蛊（E:V1-009984）；白豕蛊＋玉皮蛊→二转白玉蛊→三转天蓬蛊（E:V1-009986）。二转＋?→三转——二转月芒蛊＋血气蛊→三转血月蛊（E:V1-026840）。三转→四转→五转——木魅蛊＋百年寿蛊→四转百年木魅，再＋千年寿蛊→五转千年木魅（E:V1-021016）。四转×3→五转——四转金杯银盏蛊＋四转旁推侧引蛊＋四转移步换形蛊→五转推杯换盏蛊（E:V3-078796）。五转→六转——「要合炼出六转的春秋蝉，需要的都是五转的蛊虫」（E:V1-017170）。层层升炼——恶念蛊「需要从一转到二转，二转到三转，如此层层升炼，却无一蹴而就的蛊方」（E:V4-135028）。逐级递进——火塔系列单窍火炭蛊→双窍火炉蛊→三窍火屋蛊→四窍火楼蛊→五窍火塔蛊（E:V4-154990、E:V4-154994）。同底分叉——月光蛊可分别合炼为月芒蛊（E:V1-017156）、月痕蛊（另一条，殊途同归，E:V1-026760）、月旋蛊（E:V1-017158）、月霓裳（E:V1-017160）。
- **合理推导** [合理推导]
  - 依据：上述实例的转数配对（12348? 见上）＋方向定义（37032）。结论：合炼/升炼产物的转数**看起来≈参与材料中的最高转数＋1**（一转＋一转→二转、五转→六转、每一步各＋1），但原文**未给**「几转＋几转＝几转」的通用公式，不得据此推出可跳级。方向（低→高）是明文，步长（＋1）是归纳。
  - 不确定性：同一对材料是否可能产出不同转数的产物、材料转数不齐时以谁为准，原文未给 → `待取证`。
- **《问真》设计意义**
  - **可直接映射**：合炼＝`refinement_recipes.json` 的 `kind:"fixed"`——`input_gu_ids[]` → `output_gu_id`（例：`moonlight_glow`、`white_jade_basic`、`moon_ray_forged`，共 15 条 fixed）。「有些蛊虫之间不能合炼」＝配方表中无对应 `input_gu_ids` 条目，天然可表达。
  - **可映射但需 UI**：「同底分叉」（月光蛊四条路线）＝多条 fixed 共享部分输入、输出不同；schema 能承载，但同一对输入指向多个产物时须让玩家选路线。
  - **改编留白**：`kind:"promotion"`（76 条）已把「跨 definition 定向晋升、每步 ＋1 转、换蛊名、有 `materials`/`stone_cost`/`input_min_rank` 成本」建成一层，与原著「逐级递进」（火塔）一致；但原著并未把「几转＋几转＝几转」写进数据层——这属于合理的改编留白，不是遗漏。

## 二、合炼的代价、失败与秘方制度

- **原著事实** [已确认]
  - 失败代价：「根据合炼秘方的不同，蛊虫会因此受伤，运气差的时候。蛊虫会直接死亡。」（E:V1-017062）。
  - 非百分百：「合炼蛊虫，并非是百分百成功率。合炼越高端的蛊虫，成功率就越低。方源前世合炼春秋蝉，成功率不到百分之一」（E:V1-017168）；六转「成功率更是降到百分之一」（E:V1-020078）。早文亦言「有五转的秘方，并不意味着一定就能炼成五转的蛊虫」（E:V1-017162）。
  - 失败个案（方源合炼月芒蛊）：元石全消、光团猛爆、三只蛊虫弹射四散，「合炼月芒蛊失败了！」（E:V1-017052）；一只小光蛊「开始渐渐地消散在空气中」，几个呼吸后彻底消散（E:V1-017058）；幸存两蛊「表面，都有些黯淡无光」（E:V1-017070）；受伤后「蛊虫一旦受伤，合炼成功的概率就要下降」（E:V1-017072），须等其恢复，「至少三天后，才能再次进行合炼」（E:V1-017074）。
  - 成功率的影响因素：蛊虫使用越久成功率越大（E:V1-015912）；辅材可加成——「雪獠牙的添加，如同画龙点睛，能将成功率骤然提升两成」（E:V1-015916）。
  - 秘方制度：炼制秘方只掌握在少数家老和历代族长手中（E:V1-015920）；五转及以上秘方秘藏，「不到将死之时，是绝不会传授出去的」（E:V1-015922）。
  - 元石消耗：合炼要烧元石——「每一次合炼蛊虫都是一笔不菲的费用」（E:V1-014916）；合炼九眼酒虫历时三天、耗近二十万元石（E:V2-060702、E:V2-060708）。
- **合理推导** [合理推导]
  - 三方记账（按 L0 纪律）：**支付方**＝发起合炼的蛊师（支付元石＋辅材＋蛊虫本体风险）；**受益方**＝成功时该蛊师（获得更高转产物）；**支付时点**＝炼制过程（元石逐块投入，17042）与失败当下（蛊虫死伤、辅材作废，17058、17062）。
  - 结论：风险量级随转数上升而不可逆——低阶可承受（「小光蛊死掉一只，还可以去商铺购买。容易补充」，E:V1-017068），高阶不可逆（前世春秋蝉失败时「蛊虫就全死光了」，17168）。失败还带**冷却**（至少三天，17074）与**成功率惩罚**（受伤后下降，17072）。
  - 不确定性：各路线成功率、单次元石量、三天冷却是否随转数变化，原文多未给。按 L0 纪律拆条：**机制 [已确认]**（失败会伤蛊乃至亡蛊、受伤与失败会降低后续成功率、失败后有恢复期）；**具体数值 [待取证]**（各路线成功率百分比、冷却时长与转数的关系）。
- **《问真》设计意义**
  - 可采用规则：失败分支＋恢复期＋成功率惩罚可组合成配方的前置/风险层。`refinement_recipes.json` 已有 `kind:"free_mix"`（1 条，id＝`free_mix`）用 outcomes/weights/risk_hints 表达「无秘方自由混合」的失败分支，可借其形态表达有秘方合炼的失败。
  - **改编缺口**：`fixed`/`promotion` 配方只有 `stone_cost`/`materials` 成本字段，**无失败概率、无失败惩罚、无冷却字段**；原著「伤蛊/亡蛊＋三天冷却＋受伤降成功率」在数据层缺位。把"成功率"写成常量还是分路线概率表，须由设计层决定，本页不替它选值。

## 三、逆炼（高 → 低）

- **原著事实** [已确认]
  - 定义：「合炼是将低阶蛊虫，晋升为高阶。逆炼则是将高阶蛊虫，降为低阶。」（E:V1-026908）「一升一降之间，因为过程不同，得到的也许就是全新的蛊虫。」（E:V1-026910）
  - 器具条件：幡然蛊「针对蛊虫，能将二转的蛊虫分解成一转」（E:V1-018464）；例——「方源的白玉蛊，若用幡然蛊分解之后，就会重新化为白豕蛊和玉皮蛊」（E:V1-018466），「这个过程。被称之为逆炼」（E:V1-018468）。逆炼条件苛刻，「要求很多，我现在还达不到」（E:V2-037028，`[对话|已核]`，说话人：方源）。
  - 产物取决于器具（关键）：逆炼四味酒虫方法有多种——用浪子蛊「就能得到两只一转酒虫」；用幡然蛊「只能得到一只酒虫」；「用化蝶蛊的话，则会得到幽气蝶」；「用莫测蛊的话，得到的蛊虫就不定了，甚至有可能会是一种全新的蛊虫」（E:V2-037034）。
  - 逆炼造物：月光蛊「并非是天然蛊虫，而是一代族长逆炼而得的」（E:V1-026912）；家族特有的蛊多由此而来——「这些蛊虫，不是稀有的天然蛊虫，就是逆炼出来的全新物种」（E:V1-026916），三家族的标志蛊「皆是如此情形」（E:V1-026920）。
  - 秘方价值与保管：逆炼月光蛊的秘方「价值甚至能超过很多四转、五转的秘方」（E:V1-026926），由族长亲自保管、另有一位最忠心家老秘密知晓（E:V1-026928）。
- **合理推导** [合理推导]
  - 依据：718466（幡然→成分蛊）＋37034（四种器具四种结果）＋26912（逆炼可造全新物种）。结论：「产物能否拆回原料」**不是必然**，而取决于所用逆炼器具——幡然蛊→成分蛊（白玉蛊→白豕蛊＋玉皮蛊；四味酒虫→一只酒虫）、浪子蛊→两只酒虫（近乎完整还原）、化蝶蛊→换成幽气蝶（不同产物）、莫测蛊→不定甚至全新。因此逆炼≠简单回滚。
  - 不确定性：逆炼是否也像合炼一样有失败率与冷却；器具（幡然/浪子/化蝶/莫测）各自的转数门槛与获取方式，原文未给 → `待取证`。
- **《问真》设计意义**
  - **改编缺口（本页最重要的一条）**：`refinement_recipes.json` 现只有 `fixed`/`advance`/`promotion`/`free_mix` 四类，**没有"高→低"的逆操作 kind**。逆炼在数据层完全缺位。
  - 可采用规则：把逆炼建成一条独立配方（如 `reverse_of` 引用正向配方，或新增 `kind:"reverse"`），并保留「不同器具→不同产物」的分叉（幡然/浪子/化蝶/莫测四路），这比"逆炼＝撤销合成"更贴原著；`fixed` 的 `input_gu_ids`/`output_gu_id` 只需颠倒即可表达最简一路（幡然蛊）。
  - 张力：逆炼秘方「价值超过四转、五转秘方」（26926）说明反向知识比正向更稀缺——可作为"逆向工程"式玩法，而非免费撤销。

## 四、平炼与升炼

- **原著事实** [已确认]
  - 平炼定义：「蛊仙消耗仙材，可以对一只年蛊，进行不断的平炼。」（E:V5-209556）
  - 主流与罕见：「升炼、逆炼是炼道的主流，平炼比较罕见。」（E:V5-209558）「能够平炼的蛊虫。也比较罕见。」（E:V5-209560）
  - 年蛊实例：年蛊升到六转即成仙蛊、「世间唯一」，六转年蛊最少十年（E:V5-209566）；十年的仙级年蛊「可以用其他仙材加以平炼」，炼成二十年蛊、三十八年蛊等，**最高九十九年蛊**（E:V5-209568）；「百年蛊就是七转程度，要从十年蛊炼成百年蛊，那就不是平炼，而是升炼」（E:V5-209570）；而「升炼的难度和失败概率，是平炼的数十倍，甚至上百倍」（E:V5-209572）。「它会根据蛊仙使用的次数和量，不断削减年份」（E:V5-209580），「严格来讲，年蛊是一种消耗性的仙蛊」（E:V5-209584）。
  - 升炼实例：恶念蛊「需要从一转到二转，二转到三转，如此层层升炼，却无一蹴而就的蛊方」，成功率不高、耗材巨大（E:V4-135028）；江山如故仙蛊「已经成功将它升炼到了八转」（E:V6-405748），「八转就是江山如故仙蛊的极限了」（E:V6-405750）。
  - 升炼极限：「绝大多数的仙蛊的极限，就是八转。升上八转之后，就走到头了，再不能提升转数。」（E:V6-405752）「真正能够升上九转的仙蛊只占相当小的一部分。」（E:V6-405758）
- **合理推导** [合理推导]
  - 依据：209568/209570 的对照（同层级反复提年份＝平炼，跨层级＝升炼）＋209572 的风险倍数。结论：平炼与升炼的**区别是"跨不跨层级"**——同层级内反复提升品质（十年→九十九年）为平炼，跨层级（十年→百年/七转）为升炼，且风险差数十至上百倍。
  - 不确定性：原文未给"层级"的精确定义；低阶场景里「合炼（低→高）」与「升炼（跨层级）」是否重叠、「升炼」能否单蛊完成（恶念蛊是多只凡蛊分别层层升炼），原文未明确 → 属 `存在冲突`，见下。
- **《问真》设计意义**
  - **可直接映射**：升炼＝`kind:"advance"`（377 条）——同一只蛊 id 进、同一只蛊 id 出，提升转数/品质，正是"单蛊上行"的形态；恶念蛊「层层升炼」＝连续多条 advance 的链。
  - **改编缺口**：平炼**无字段**——schema 没有"年份/同层级品质等级"维度；年蛊那类"同级反复炼制提年份"（十年→九十九年）需要另立字段（如独立 `grade`/`polish_level`），不能塞进现 rank。
  - 极限：`advance` 链到顶即"无下一条条目"，可表达"八转封顶"，但 schema 无显式上限字段，属改编留白。

## 五、同种唯一性

- **原著事实** [已确认]
  - 门槛规则：「况且，蛊虫一达到六转及以上级数，都是天下唯一，仅有一只。旁人若要合炼出来，只有前一只死了，才能有成功的可能性。否则百分百失败。」（E:V1-032214）
  - 世界范围：「春秋蝉是六转蛊，蛊虫到达六转，不管是大世界还是小世界，都只有唯一的一只。」（E:V2-064426）
  - 仙蛊口径：「仙蛊是有很多的，虽然仙蛊唯一，但种类方面可以说应有尽有。」（E:V6-405756）；年蛊「上升到六转，就成为仙蛊，世间唯一」（E:V5-209566）。
  - 骤然门槛的实例（和稀泥蛊）：一二转非常多、三四转常见、五转稀少，「到了六转，全天下就只有一只了，并且和稀泥仙蛊只能用一次」（E:V3-078694）。
  - 边界（非六转可多只）：推杯换盏蛊「并非只有一只，而是两只」（E:V3-080310），「这两只蛊一只上金下银杯，一只上银下金盏。两只组成一套，才是完整的推杯换盏蛊」（E:V3-080312），而它是五转蛊（E:V3-080252）。故"多只并存"出现在五转及以下，不构成六转唯一性的反例。
- **合理推导** [合理推导]
  - 依据：32214＋78694（和稀泥从"非常多"到"只有一只"发生在六转）＋405756（仙蛊唯一但种类应有尽有）。结论：唯一性是**转数门槛（六转及以上）**的属性，"前一只死了才能再合炼"意味着它是**全局名额**，不是"每份配方限做一次"——属世界状态。
  - 不确定性：「前一只死了」之外，转化/消亡是否也释放名额，原文未明确 → `待取证`。
- **《问真》设计意义**
  - **改编缺口**：`refinement_recipes.json` **无唯一性约束字段**。"同种仙蛊全球只存一只""名额被占则百分百失败"必须在运行时/世界状态层实现，不能只在配方层限次——否则丢掉"全球名额"这条世界规则。
  - 可采用规则：把"六转及以上"设为一个可配置的全局门槛；`advance` 链跨过该门槛时触发唯一性检查；"种类应有尽有"说明唯一性约束的是"每一种"，不是"仙蛊总数"。

## 六、本命（蛊 ↔ 蛊师）

- **原著事实** [已确认]
  - 定义：「而蛊师炼化的第一只蛊虫，意义重大，称之为本命蛊，性命交修。一旦灭亡，蛊师必定遭受重创。」（E:V1-001480）；「本命蛊和蛊师之间的关系，最为密切」（E:V3-090860），「不管哪一方受到重创，另一方也会受到牵连」（E:V3-090862）；被擒即等于被捏住把柄（E:V3-117690）。
  - 最大收益（对合炼/升炼）：本命蛊「有一个其他蛊虫，都无法企及的最大优点，那便是炼蛊失败之后，哪怕反噬再严重，也能保留下原有的蛊虫」（E:V3-090864）；合炼「不管合炼的结果，是失败还是成功。蛊师的本命蛊是不会死亡的，最多不过受伤罢了」（E:V1-017186），失败后「至多也只是奄奄一息」（E:V1-017192）；升炼「即便失败无数次，本命蛊都会保存下来，并不会毁灭」（E:V5-329114），「就算失败，本命蛊也不会损毁」（E:V5-277406）。
  - 豁免边界：与它同炼的其他蛊「仍会有死伤的可能」（E:V1-017194）；若炼蛊失败致蛊仙身死，「本命蛊基本上也会毁掉」（E:V5-277410）。
  - 绑定代价（更换）：本命蛊「一旦形成，便难以更改」（E:V3-090868）；要换须「将原有的本命蛊毁去」（E:V3-090872），「但这种行为极其危险」（E:V3-090874），「本命蛊一旦毁去，蛊师将遭受巨大牵连。轻则重创，重则死亡」（E:V3-090876）。
  - 第二本命与升仙：第二空窍带来「一次可以选择第二本命蛊的机会」（E:V3-090880）；全力以赴蛊成为第二本命后，「方源就再不用担心炼蛊失败后，失去这只宝贵的蛊虫了」（E:V3-090906）；多出一个仙窍「最大的作用就是有一个本命蛊的名额」（E:V5-277404）。「如果升仙顺利，理想情况下本命蛊还会提升转数，成为七转！」（E:V6-432814）。
  - 非本命的风险对照（商家建议）：「它却不是你的本命蛊，合炼是有危险的，万一全力以赴蛊在合炼的过程中毁灭了，你的整套蛊虫就要面临崩溃的危险」（E:V2-052480，`[对话|已核]`，说话人：商家顾问）。
- **合理推导** [合理推导]
  - 三方记账（按 L0 纪律）：**支付方**＝蛊师本人（首次炼化即绑定；更换时以"毁原蛊＋自身重创甚至死亡"支付）；**受益方**＝蛊师（合炼/升炼失败时蛊虫本体不灭、成果可累积）；**支付时点**＝绑定时（首蛊炼化 1480；第二空窍/仙窍开设 90880、277404）、代价支付于**更换当下**（毁蛊，90872–90876）与**合炼/升炼失败时**（宿主反噬，但蛊不灭）、升仙成功时生效提转（432814）。
  - 结论：本命蛊把"失败即清零"改写成"失败可累积"，是一份**风险保险**——保额是"蛊不灭"，免赔额是"宿主反噬＋同炼其他蛊的死伤"。
  - 不确定性：本命蛊占几个蛊位、第二本命是否与首蛊同转、升仙提转的触发条件，原文未给 → `待取证`。
- **《问真》设计意义**
  - **改编缺口**：schema **无本命字段**。本命是"蛊↔蛊师"的绑定状态，`advance`/`fixed` 只描述合成、不描述"哪些蛊在失败时受保护"。
  - 可采用规则：把"本命蛊失败时保留本体、同炼其他蛊仍会死伤"建成一条运行时保护规则；"第二本命＝多一个保险名额"可直接映射为可成长的保险槽。不要把它写成数值减伤——原文的保额是"蛊本身不灭"，不是"伤害打折"。

## 七、替代与协同

- **原著事实** [已确认]
  - 流派一致可取代：「仙蛊是大道碎片，蛊材则是道痕累积，只要流派一致，它们就能相互取代。」（E:V5-290910）同一命题的另一表述：「蛊虫是大道碎片，蛊材则是道痕聚集」（E:V6-401146）。
  - 流派不合的后果：「因为流派不合，不仅会因为道痕冲突，效果削减，而且也不利于豢养」（E:V5-198856）。
  - 喂养替代上限：「最多只能替代百分之四十的仙蛊食材，超过这个数目，喂养仙蛊再多的量，也没有效果了。」（E:V5-273142）
  - 凡蛊替代仙蛊：「如果要用恶念凡蛊，来替代乐山乐意仙蛊的话，那么前者的数量就必须很庞大」（E:V4-135020）；「这两千只以上的恶念蛊，都必须是五转」（E:V4-135024）；一转到五转的恶念蛊「效用相同。只是一次产生的念头数量不同，消耗的真元多寡也有巨大差距」（E:V4-135026）。
  - 协同·辅助蛊增幅（小光蛊×月光蛊）：「此蛊主要是配合月光蛊使用，是月光蛊最常见的一种辅助蛊虫」（E:V1-009710）；「用此蛊辅助月光蛊，能令月刃攻击更强」（E:V1-009774）；「加上了小光蛊的辅助之后，这片月刃整个体积扩大了一倍，攻击力也扩大了一倍」（E:V1-010940）；但两只小光增幅**不叠加**，合炼后的月芒攻击力另为月光三倍（E:V1-017148）。
  - 协同·肉身复合（冰肌蛊＋玉骨蛊）：「玉骨蛊和冰肌蛊用来搭配使用，效果最佳」（E:V2-039728）；「两者效果相互影响，有叠加之效用」（E:V2-039730）。
  - 协同·形态增幅（木魅蛊）：青书以树精身份催动时，「青藤蛊、松针蛊以及生机叶，都传来欣欣向荣之意」，这些木行蛊「威力也将得到增幅」（E:V1-023856）；代价是无节制使用木魅会变成死树人（E:V1-023862）。
  - 协同·部件蛊沟通（双仙蛊杀招）：坚持仙蛊与挽澜仙蛊「不能融汇一体，显然是那些水道凡蛊数量和种类不到位」，「这些凡蛊就是在两只仙蛊中间，起着沟通和融洽的巨大作用」（E:V5-240294）。
  - 一蛊一能：「任何一个蛊虫。都只有一个能力。」（E:V1-016906）；合炼后的新蛊「常常只能留取一只蛊虫的能力，并加以强化」——如白玉蛊保留并强化玉皮蛊的防御，同时丧失白豕蛊增力的效果（E:V1-016910）。
- **合理推导** [合理推导]
  - 依据：290910（定性：流派一致即可取代）＋273142（定量：40% 上限）＋135024（规模：两千只五转）。结论："替代"有两条互不相同的口径——**流派一致即可取代**是定性许可，**40% 上限**是具体仙材（橙黄浆水）的效果天花板，二者不可混为一谈，且 40% 不是所有替代的通用上限。
  - 「协同」有两种方向：辅助蛊**增幅**（小光→月刃，10940）与部件蛊**沟通/融洽**（水道凡蛊让两只不能直接兼容的仙蛊协同，240294）；前者是能力叠加、受"不叠加"规则约束（17148），后者是让核心协同工作，性质不同。
  - 不确定性：40% 是否为通用规则、两千只五转之外是否还有更低门槛的替代路径，原文未给 → `待取证`。
- **《问真》设计意义**
  - **可直接映射**：`inputs[{school,rank,count}]` 用"流派＋转数＋数量"而非固定 id，正是"流派一致可相互取代"的数据形态（现有 87 条配方使用该形态）。这也可表达"替代"——同 school/rank 的蛊可互换。
  - **改编缺口**：`inputs` 只有 school/rank/count，**无"40% 上限""两千只五转"这类量与规模约束字段**；"辅助蛊增幅""部件蛊沟通"在图谱/配方层都无表达。
  - 一蛊一能（REF-031）：`output_gu_id` 单产物天然符合"只有一个能力"，但 schema **无"继承/丧失哪只能力"字段**——白玉蛊"保留防御、丧失增力"这类规则目前只能写进文本，属改编留白。

## 九、关系规则 → `refinement_recipes.json` schema 映射

Schema 现状（只读核对）：`kind` 共四类——`advance` 377、`promotion` 76、`fixed` 15、`free_mix` 1，合计 469 条；另有 `caravan_offers` 4 条、`retired` 5 条；87 条配方使用 `inputs[{school,rank,count}]`。

| 原著关系 | schema 可否表达 | 对应形态 / 缺口 |
|---|---|---|
| 合炼（多蛊→高级蛊，有秘方） | **可直接映射** | `kind:"fixed"`：`input_gu_ids[]`→`output_gu_id`；无秘方＝无条目 |
| 合炼·同底分叉（月光蛊多路线） | **可映射（需 UI）** | 多条 fixed 共享输入、不同输出 |
| 升炼（单蛊跨转提升） | **可直接映射** | `kind:"advance"`：同 id 进出、提升转数 |
| 定向晋升（换名、每步＋1 转、有成本） | **可映射** | `kind:"promotion"`：`materials`/`stone_cost`/`input_min_rank` |
| 无秘方自由混合（含失败分支） | **可映射** | `kind:"free_mix"`：outcomes/weights/risk_hints |
| 流派一致可相互取代 | **可直接映射** | `inputs[{school,rank,count}]` |
| 逆炼（高→低 / 成分蛊 / 换产物） | **缺口** | 无 `reverse` kind；建议新增 `kind:"reverse"` 或 `reverse_of` |
| 平炼（同层级反复提年份/品质） | **缺口** | schema 无年份/同层级质量维度（建议另立 `grade`/`polish_level`） |
| 同种唯一（六转及以上全球一只） | **缺口** | 无唯一性约束字段；须置于世界状态层 |
| 本命（失败保护/绑定代价/第二本命） | **缺口** | 无字段；属"蛊↔蛊师"状态层 |
| 失败代价（伤蛊/亡蛊/冷却/降成功率） | **部分缺口** | 仅 `free_mix` 的 outcomes 可借形；`fixed`/`promotion` 无风险字段 |
| 一蛊一能（产物只留一个能力） | **部分缺口** | `output_gu_id` 单产物符合，但无"继承/丧失哪只能力"字段 |
| 替代的量与规模约束（40%、两千只五转） | **缺口** | `inputs` 只有 school/rank/count，无量与规模字段 |

**结论（供设计层裁决，本页不替它选值）**：合炼/升炼/流派替代三条主线已在 schema 内；**逆炼、平炼、同种唯一、本命四项属系统性缺口**，需要新字段或运行时规则，而不是靠现有字段拼凑。

- [存在冲突] 「合炼」与「升炼」的边界在不同卷被不同口径使用：口径A（早期二分）——炼蛊分「合炼、逆炼两大方面」，「合炼，是将低转的蛊虫晋升为高转」（37030、37032）；口径B（多蛊合一）——「将不同的多种蛊虫，合并成一只更高级数的蛊虫」（15730）；口径C（后期三分为主）——「升炼、逆炼是炼道的主流，平炼比较罕见」（209558），此处由「升炼」承担"低→高"，火塔系列则称"逐级递进"而不称合炼（154994）。**当前状态**：同一"低转→高转"操作在不同卷分别被称"合炼/升炼"，原文未给清晰分界，不强行统一；本页"合炼"用作"多蛊合一/低→高"统称，"升炼"用作"跨层级提升"，分歧保留待 L1 裁决。
- [待取证] 合炼/升炼产物的**通用转数公式**：原著只有实例（一转＋一转→二转、五转→六转、每步＋1），未给"几转＋几转＝几转"。**机制 [已确认]**（低→高、逐级）；**具体数值 [待取证]**（是否存在跳级、材料转数不齐时以谁为准）。
- [待取证] 各条合炼路线**成功率**与**失败冷却**（原文只有"不到百分之一""至少三天"等个案与量级词，未给分路线数值）。
- [待取证] 逆炼是否也有失败率与冷却、四种逆炼器具（浪子/幡然/化蝶/莫测）的转数门槛与获取方式。
- [待取证] 「只有前一只死了，才能有成功的可能性」（E:V1-032214）之外，转化/消亡是否也释放六转唯一性名额。
- [待取证] 喂养替代 40% 是**橙黄浆水的个案上限**还是**通用规则**（273142 语境为该仙材，未言通用）。
- [待核对] §十中 `EVT-FMK-066`（天妒仙蛊）、`EVT-FMK-124`（兜风蛊）、`ST-FANGYUAN-39`（坚持仙蛊河主）、仙蛊排行的其余细节：延用上一版整理，本轮未逐行复核。
- [待核对] 上一版曾把"同一种仙蛊天地间只存一只"标为"wiki 尚无已核条目"——**本轮已锚定**（E:V1-032214、E:V2-064426、E:V3-078694、E:V5-209566、E:V6-405756），改判 `已确认`。
- [待核对] 上一版附录曾把"凡蛊替代仙蛊"锚在 E:V6-401146（该行实为"蛊虫是大道碎片/道痕聚集"）——**本轮修正**：恶念蛊替代乐山乐意仙蛊的实例锚点应为 E:V4-135020–135024；E:V6-401146 只支持"流派一致可取代"。
