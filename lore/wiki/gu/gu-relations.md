# 蛊虫关系

蛊虫之间的六类关系总览页：**合炼（低→高）、逆炼（高→低）、平炼/升炼（同级/跨级）、同种唯一与排行、本命（蛊↔蛊师）、替代与协同**，另附交易/传承与仙蛊屋核心关系。本页是导航与关系索引：明细与证据落点在各自蛊页与规则页，本页只收录已核关系对；**所有关系均标注证据或「笔记层」/「待核对」**，不得把笔记层当已核事实。

## 关系类型总览

| 关系类型 | 一句话定义 | 规则锚点 |
|---|---|---|
| 合炼 | 低阶蛊按秘方晋升高阶，须秘方、有些蛊不能合炼 | [炼蛊术语体系](../rules/refinement.md) REF-004；[蛊的饲养与炼化](../world/gu-care-and-refinement.md) |
| 逆炼 | 高阶蛊降回成分蛊（幡然蛊例） | REF-005/REF-029 |
| 平炼 / 升炼 | 同级提升年份 / 跨级提升转数 | REF-007/REF-008/REF-028 |
| 同种唯一与排行 | 同一种仙蛊天地间只存一只；奇蛊/仙蛊排行 | [春秋蝉](spring-autumn-cicada.md)、[方源](../characters/fang-yuan.md) ST-FANGYUAN-57 |
| 本命 | 本命蛊与蛊师性命交修，可立第二本命对冲 | REF-017 |
| 替代与协同 | 流派一致可相互取代、喂养替代上限、协同辅助 | REF-019；[蛊的饲养与炼化](../world/gu-care-and-refinement.md) |
