# 招灾蛊

运道流派的**七转仙蛊**，机制方向与全书绝大多数蛊虫相反：它不把伤害打出去，而是把天地层面的灾劫**拉向自己**。「这招灾蛊，品级高达七转，比方源如今的春秋蝉还要高一个档次」`E:V3-104130`。原文对它的第一反应不是赞叹，而是疑问——「这样的仙蛊，谁敢用？」`E:V3-104136`。

本页为 2026-09-28 A 线正式 20 页恢复批**新建页**。所有引文回根原文 `source/蛊真人-clean.txt` 逐行复核，行号即 `E:V{段}-{6位行号}`；正文按"原著事实／合理推导／《问真》设计意义"三层组织。游戏侧 `luck_atk_1_03_gu` 与 `heaven_atk_1_12_gu` 的重名关系单独登记于主题六与《待核对》，不与原著本尊做 1:1 合并。

## 主题档案

### 一、身份与品阶：七转运道仙蛊，比春秋蝉高一档

#### 原著事实

- **品级明文七转**：「这招灾蛊，品级高达七转，比方源如今的春秋蝉还要高一个档次」`E:V3-104130`。
- **与春秋蝉的档次差被反复确认**：「此蛊高达七转，经过朱红巨碗的孕养，此刻已经彻底成形」`E:V3-104500`；方源自述「如今靠着重生的优势，年纪还未过百，就获得了招灾蛊，比春秋蝉还要更高一转」`E:V3-104510`。
- **名录口径**：全书七转仙蛊清单里列有「七转仙蛊换魂蛊、剑眉蛊、浪剑蛊、剑遁蛊、招灾蛊」`E:V5-199798`。
- **道属明文**：「但如今，方源手握的招灾蛊，就隶属运道」`E:V3-104522`；「排难蛊、招灾蛊，这就是运道流派的蛊虫」`E:V3-104524`。
- **外观**：「蚕茧已经破开，招灾蛊已经彻底成形。它形如蚕茧，浑身灰白，只有小拇指大小，在水里载沉载浮」`E:V3-104238`；成形后另一处作「它有小拇指般大小，通体灰白，十分精致袖珍，如同蚕蛹」`E:V3-104502`。

#### 合理推导

- **依据**：`E:V3-104130`（七转）＋`E:V3-104500`（高达七转）＋`E:V5-199798`（七转名录）；**结论**：招灾蛊的七转是**逐字明文**，不是旁证推出来的，本页可按 `[已确认]` 记；**不确定性**：原文未说明七转之内是否还有品阶高低之分（同一转数不同个体是否强度不同）。
- **依据**：`E:V3-104522`、`E:V3-104524`；**结论**：招灾蛊是**运道流派的样本证据**——方源据它确认「传说中的运道流派，是的确有的」`E:V3-104516`；**不确定性**：运道在书中另有鸿运齐天蛊（`E:V3-111120`）、连运仙蛊等，本页不据此绘制运道全谱。

#### 《问真》设计意义

- 蛊的品级与蛊的**作用方向**在这里是解耦的：七转只说明它层级高，不说明它能打。设计上宜给"非战斗高转蛊"留出独立价值位，而不是让转数自动等于伤害。
- 转数公开可读（`E:V5-199798` 一类名录在原著里反复出现），支持把"原著名录"做成可查阅的世界内资料，而不是隐藏面板数值。

### 二、核心机制：把地灾天劫从原目标勾连到自己身上

#### 原著事实

- **机制逐字**：「招灾蛊能够替蛊仙招灾引难，将地灾天劫脱离原来的目标，勾连到自己的身上」`E:V3-104132`。
- **效用被原作者定性为"极端奇妙"**：「效用极端奇妙，居然是涉及地灾天劫」`E:V3-104130`。
- **施术者视角的恐怖感**：「用招灾蛊吸引来这些天劫地灾，这不纯粹自己找死么？」`E:V3-104138`。
- **与排难蛊的成对关系**：「它和排难蛊可谓一体两面，一个招灾，一个排难」`E:V3-104248`。
- **正反两用的自述**：「灾劫虽强，但只要自身过硬，能够撑住，那么用来陷害他人却是别有妙用」`E:V3-104246`。
- **机制 [已确认] / 具体数值 [待取证]（拆条）**：机制＝把地灾天劫从原目标转移到持蛊者身上，`[已确认]`（`E:V3-104132`）；具体数值＝催动一次的仙元消耗、单次可转移灾劫的量级上限、转移的作用距离，原文均未给出，故另列 `[待取证]`（见《待核对》），**不得据机制成立反推数值**。

#### 合理推导

- **依据**：`E:V3-104132` 的"脱离原来的目标"＋"勾连到自己的身上"；**结论**：招灾蛊是一个**灾劫转移件**而非灾劫制造件——它改变的是"谁承担"，不是"有没有"；**不确定性**：转移是否有距离、目标锁定方式、能否转移非地灾天劫类的伤害，原文四句之内均未交代。
- **依据**：`E:V3-104246`＋`E:V3-104248`；**结论**：使用者的收益来自**选择谁挨灾**（把灾引到自身再转嫁／以自身为筹码），而不是来自蛊本身的输出；**不确定性**："用来陷害他人"原文未给任何一次成功战例，属可能性陈述而非已实现记录。

#### 《问真》设计意义

- 这是一个干净的**责任转移机制**：同一枚蛊可作自保（把灾引走）、可作攻伐（把灾引向对手），其强度完全取决于"谁能扛住"。做成系统时，价值锚点应放在承受能力与时机，而不是伤害数字。
- "排难蛊／招灾蛊一体两面"提供了天然的**配套件设计**：一体两面的两枚蛊分属不同持有者时，能直接生成合作与背叛的叙事张力。

### 三、代价与收服条件：自我牺牲之蛊

#### 原著事实

- **性质定性**：「招灾蛊乃是货真价实的自我牺牲之蛊，墨瑶用之舍己为人」`E:V3-104240`。
- **收服条件明文**：「要收服招灾蛊，需要一定的条件。虽然不计仙凡身份，但却需要有缘人有一颗自我牺牲的心」`E:V3-104254`。
- **不满足条件的后果**：「如果没有这颗心的话，强行收服，轻则导致仙蛊反噬，重则仙蛊自毁」`E:V3-104256`（该句后半另有"殃及人身性命"之意，原文此处含清洗讹字，本页不逐字复录被破坏处）。
- **实际收服过程顺利**：「汲取着他的气息，招灾蛊身上光辉一闪，旋即便成为方源之物」`E:V3-104468`；「整个过程顺利无比，没有丝毫震荡和反噬」`E:V3-104468`。
- **使用者的自我定位**：招灾蛊"是主动牺牲自己，引动天灾地劫加身"，而方源「坚信，蛊师用蛊存乎一心」`E:V3-104512`。

#### 合理推导

- **依据**：`E:V3-104254`＋`E:V3-104256`；**结论**：招灾蛊的门槛是**持有者的心理条件**，不是修为或血脉；支付方＝**收服者本人**（押上"肯自我牺牲"这一人格条件），支付时点＝**收服瞬间**，受益方＝**被招灾蛊服务的那个人（常常不是蛊的持有者）**——墨瑶即为薄青承担灾劫（`E:V3-104222`）；**不确定性**：原文没有给出"自我牺牲的心"的判定方式（由蛊判定、由人自证，还是由行为体现），也未说明判定失败是立刻生效还是延迟。
- **依据**：`E:V3-104240`＋`E:V3-104222`；**结论**：招灾蛊的受益方与支付方**系统性分离**，这是它区别于"自用型蛊虫"的核心特征；**可能反例**：方源是反例候选——他收服顺利却不承认自己有为他人牺牲之心（`E:V3-104512` 的表述落在"用蛊存乎一心"上），原文未解释这一顺利收服的判定依据。

#### 《问真》设计意义

- **可采规则（人格门槛）**：把"获得条件"从数值门槛换成**角色行为史条件**（是否做过自我牺牲类选择），比"等级≥N"更能承载叙事，也天然形成隐藏条件。
- **可采规则（受益方≠支付方）**：这类蛊适合做"我付代价、你受益"的道具，可支撑保护、代偿、赎罪一类关系型玩法。

### 四、炼制与来源：墨瑶、排难蛊与八十八角真阳楼的伟力回流

#### 原著事实

- **炼制者与原理**：招灾蛊「乃是炼道宗师墨瑶，通过八十八角真阳楼中的排难蛊感应，炼制而成的仙蛊」`E:V3-104522`。
- **获准进入的手段（概括）**：王庭福地与八十八角真阳楼共生，每十年引来天灾地劫，需敞开一丝缝隙配合排难蛊排遣；墨瑶便借这丝缝隙逆向进入福地（`E:V3-104182`、`E:V3-104184`、`E:V3-104186`）。
- **关键节点**：「冒着惊醒巨阳意志的危险，将小塔楼摧毁，利用伟力回流，感应排难蛊」`E:V3-104190`。
- **成形与带出**：「在其中，墨瑶将雏形彻底温养成形，便带着招灾蛊，利用福地排难的良机，偷偷潜回外界」`E:V3-104194`。
- **留下后手**：「若是薄青再次冲击失败，招灾蛊也毁于天劫地灾，那么她还会再进来福地，再度炼成招灾蛊」`E:V3-104196`。
- **传承链条**：墨瑶夺运道真传失败后「只好利用所得的部分传承，退而求其次，炼出招灾蛊」`E:V3-111120`（说话人：墨瑶意志）；方源「找到了墨瑶留下来的传承，重新炼出招灾蛊」`E:V3-114408`。

#### 合理推导

- **依据**：`E:V3-104190`＋`E:V3-104522`；**结论**：招灾蛊的配方不是通用知识，而是**必须借用真阳楼排难蛊这一"设施级"条件**才能完成——炼制地点与设施是硬前提；**不确定性**：方源重炼时是否用了同一设施、还是另有办法，原文只写"重新炼出"，未给过程。
- **依据**：`E:V3-104196`＋`E:V3-114408`；**结论**：这是一条**可重复的传承链**（墨瑶炼成→身陨→方源据其传承重炼），招灾蛊不是唯一制品，但同一时间的持有者唯一（"仙蛊唯一"之例，另见 `E:V5-270586` 净魂仙蛊条）；**不确定性**：仙蛊唯一原则在招灾蛊上原文未直接宣示，本页只作旁证引用，不当作自己的明文结论。

#### 《问真》设计意义

- "炼蛊需要借某处设施的伟力"是一条可玩的**地点依赖规则**：稀缺蛊的产出绑定地图节点，而不是绑定材料清单。
- 传承链（前人炼成→遗传承→后人重炼）给出了**跨代获取高转蛊**的正当路径，可作为长线任务骨架。

### 五、使用边界：不能盲目催动、凡身不能装载、喂养有实物成本

#### 原著事实

- **归入"不可盲试"名单**：「譬如招灾蛊、春秋蝉，这类仙蛊万万不能盲目催动」`E:V4-123238`（该句列在"熟悉陌生仙蛊"的三条弊端中）。
- **凡人阶段无法炼化**：「招灾蛊虽然已经彻底成型，但方源还炼化不了」`E:V3-104542`；「没有成仙，就没有仙窍，无法装载招灾蛊」`E:V3-104556`。
- **暴露即招觊觎**：「公然拿出去的话，仙蛊气息弥漫，必会引来无数的觊觎者」`E:V3-104556`。
- **可交易性**：方源盘算「就算自己不用，放入宝黄天中贩卖，也能换得一笔巨额仙元石」`E:V3-104244`。
- **喂养实物**：「招灾蛊方源早已经喂过，是用的六头大蛇的黑血」`E:V5-200070`。
- **成为累赘的另一面**：炼成后他「最终虽然炼成了招灾蛊，但却用不了」`E:V3-104786`；且需承担把七转仙蛊屋近水楼台归还灵缘斋的遗命 `E:V3-104768`。

#### 合理推导

- **依据**：`E:V3-104542`＋`E:V3-104556`；**结论**：**仙蛊与仙窍是绑定关系**——持有仙蛊不等于可用，必须先成仙（有仙窍）才能装载与炼化；支付时点被拆成两段：炼成时付资源，成仙时才付"可用性"；**不确定性**：原文未说仙窍容量是否有限、一只仙窍能装几枚仙蛊。
- **依据**：`E:V5-200070`；**结论**：喂养成本以**实物素材**计价（六头大蛇黑血），而"饥饿的仙蛊强行催用会导致仙蛊死亡"是净魂仙蛊条的明文 `E:V4-128016`，故招灾蛊亦属"需持续投入"的资产；**不确定性**：招灾蛊的喂养周期与单次用量原文未给。

#### 《问真》设计意义

- **可采规则（两段式获得）**：炼成≠可用，把"获得"与"启用"拆成两个里程碑，能让高转蛊的获取曲线更平缓，也给玩家一个明确的阶段目标（成仙）。
- **可采规则（暴露风险）**：持有仙蛊本身是情报事件（`E:V3-104556`），可做成"持有即背负被觊觎的代价"，让强力资产自带负面。

### 六、命名与双 id 边界：原著无独立成词的「灾蛊」

#### 原著事实

- **穷举口径**：全书出现「招灾蛊」的段落共 43 处，最早为 `E:V3-104120`（独立成句的呼喝「招灾蛊！」），随后是给出品阶与效用的 `E:V3-104130`、`E:V3-104132`。
- **「灾蛊」不是独立词**：以「灾蛊」为检索词，全书命中 43 行，与「招灾蛊」的 43 行**完全相同**（差集为空）——即全部 43 处「灾蛊」都出现在「招灾蛊」这一字符串内部，本批**未检得**「灾蛊」独立成词的用例。（穷举口径，无单行可挂 E-ID）
- **同一段原文被两个 wiki/游戏 id 引用**：`roster-3.md` 中 `heaven_atk_1_12_gu`（灾蛊）与 `luck_atk_1_03_gu`（招灾蛊）两条目登记**同一锚点** `E:V3-104130`。

#### 合理推导

- **依据**：上述穷举结果；**结论**：这是一个**子串命名的双 id 现象**（与同批被剔除的 `refine_log_2_03_gu`「合炼蛊」、`light_atk_1_04_gu`「光蛊」同类），而不是"两个不同实体恰好同名"；**不确定性**：本批只证明"未检得独立用例"，**不等于**原著不存在名为「灾蛊」的别的蛊——不得把"未找到"写成"原著没有"。
- **判定记录**：本页只登记这一关系与穷举口径，**不改 `roster-3.md`、不改他页**（越批改动会污染该批证据边界）；两个 id 是否合并属产品命名裁定，不在本页权限内。

#### 《问真》设计意义

- 命名层需要一条**独立词校验**：一个 id 若在原著中从不独立出现，就应被视为短语误切的可疑项，纳入待裁定清单，而不是直接建页。
- 对已存在的双 id，把"同锚点"做成**可审计警告**（并存但标记）比强行合并更安全——合并会同时销毁两边的引用链。

## 分析与解读

1. **招灾蛊是"责任转移件"，不是"灾劫制造件"**。中段墨文写得很克制：「招灾蛊能够替蛊仙招灾引难，将地灾天劫脱离原来的目标，勾连到自己的身上」`E:V3-104132`——它改变的是承灾主体。设计上若把它做成"造成伤害"的蛊，等于丢掉原文唯一的机制说明。
2. **它的代价写在"用"之前，而不是"用"之后**。收服门槛是持有者的人格条件（`E:V3-104254`），不满足就直接反噬或自毁（`E:V3-104256`）；这是原著少见地把"资格"放在"效果"上游的写法，也让它的持有者名单天然很短。
3. **受益方与支付方系统性分离**。墨瑶用蛊是"为了保护心中的爱郎"`E:V3-104222`；方源则计划用它"陷害他人"`E:V3-104246`。同一个机制被两种相反动机使用，说明它的本质是**权力让渡的接口**——这也是它成为黎山仙子一类"人脉型蛊"的经济基础（对照 `E:V4-139894` 对山盟蛊的同一定位）。
4. **获得被拆成两段**：炼成（付资源，`E:V3-104522`）与可用（成仙有仙窍，`E:V3-104556`）之间隔着一整个境界。这条原文不需要任何补充设定，天然构成"拿到了但用不了"的成长曲线。
5. **本页最可审计的发现是命名层而非机制层**：「招灾蛊」43 处与「灾蛊」43 处集合完全重合，说明 `heaven_atk_1_12_gu`／`luck_atk_1_03_gu` 这一对 id 是**同段原文的两种切法**。这属于"可审计警告"而不是错误，处理方式应是登记与并存，而不是 1:1 合并。
