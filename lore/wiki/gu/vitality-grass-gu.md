# 九叶生机草

南疆古月山寨的**二转草蛊治疗系核心**，机制是「资源产出＋治疗＋喂养链」三重复合：本体常驻掌心、只负责把真元转成叶片；治疗能力落在撕下来的一次性生机叶上。正文按主题三层组织：**原著事实**（带 E-ID 短引）→ **合理推导** → **《问真》设计意义**（只登记改编、张力与可采用规则，数值以游戏仓库为唯一真相源）。

## 主题档案

### 一、身份、形态与转数

- **原著事实** [已确认]
  - 形态：小巧玲珑、翠绿根须如人参参须、半透明根茎宛如翡翠、九片圆形碧叶相互掩映、围绕根茎组成一个圆盘（E:V1-016488）。
  - 转数与类别：二转蛊虫、具备治疗作用（E:V1-016490）；后文复述「正是二转草蛊——九叶生机草」（E:V1-017088）。炼化后常驻掌心：草尖、九片碧叶与翡翠草茎自掌心冒出、参须状草根不露出（E:V1-017084）；念头一动整株缩回掌心、化为绿色印记（E:V1-017116）。
  - 对照实体：原文明确它「和生息草也就没有什么太大的区别了」（E:V1-016492）——生息草是一只**独立**的一转草蛊（另见爱别离合炼材料 E:V1-011800、某治疗蛊师的本命蛊 E:V1-013046），不得与九叶生机草混为一物。
  - 定位：「它易于炼化，瞬间治疗，喂养便宜」（E:V1-016500）；外出的蛊师「都会常备一两片」（E:V1-016504）。
- **合理推导** [合理推导]
  - 依据：形态三段（16488、17084、17116）＋「每一片叶子…就是一棵生机叶」（16494）＋「它的优势只在于。能够催生出一转生机叶」（26952）。结论：它是一株**可反复取叶的活体生产装置**，本体不因治疗而消失，价值主体落在叶片上；「几片叶对应什么效果」在原文中**无差别**——九叶等质，每叶各产一只生机叶。
  - 不确定性：16490 只说本体「具备治疗作用」，其疗效、是否需直接使用本体，原文未展开；不得据此把本体写成主动治疗技能（26950 反而说其治疗「显得孱弱」）。叶序影响疗效之类的表述在原文中不存在，属 `原著未明确`，不可推出进阶叶、变异叶。
- **《问真》设计意义**
  - 可直接采用：本体＝产能位（一个占位、长期在线），治疗＝可堆叠的一次性消耗物，天然形成「一件常驻装备＋一叠药片」的两层结构。
  - 映射边界：`game/data/refinement_recipes.json` 的 `kind:"fixed"` 以「蛊A＋蛊B→蛊C」表达合成，**无法表达**「同一只蛊反复产出另一只蛊」的生产关系；本页的产能机制在配方 schema 中无处安放，属改编缺口（不宜硬塞进 recipe）。
  - 改编声明：把生机叶做成「一次治疗即消耗」是原著明文（16496），可直接映射；把它做成"战斗内即时回血技能"则偏离——原文的治疗对象是伤员恢复，不是战场血气条。

### 二、生机叶：一次性治疗消耗品的机制与边界

- **原著事实** [已确认]
  - 产出方式：「它真正的价值在于，它的每一片叶子，若撕下来，就是一棵生机叶」（E:V1-016494）；「一转级数，属于消耗型，用一次就消失」（E:V1-016496）；摘叶有轻微痛感，类似拔掉一根头发（E:V1-017094）。
  - 冷却（关键限制）：「使用了一片生机叶疗伤之后，一个小时之内，其他的生机叶将没有治疗的效果」（E:V1-016498）——不能靠连续吞叶叠加治疗量。
  - 疗效口径：原文用「它易于炼化，瞬间治疗，喂养便宜」（E:V1-016500）与角色经验表述——古月野视它为保命之物「有时候，一片生机叶能挽救自己的一条命」（E:V1-024708）。后者是人物自述，不是疗效量化。
  - 分流派：到蛊仙层次，生机叶被归为**木道治疗蛊虫**，与星道救星蛊、水道春雨蛊、风道清风蛊等并列（E:V5-297318）。
- **合理推导** [合理推导]
  - 依据：「用一次就消失」（16496）＋「一小时内其他叶无效」（16498）＋「瞬间治疗」（16500）。结论：单次治疗的**有效窗口只有一次**，之后一小时进入无效期；因此"单叶强度"与"可用频率"是两个独立参数，做数值时不能只看其一。
  - 不确定性：疗伤上限（能治多重的伤）、生效速度量纲、冷却是否随转数变化，原文均未给 → `待取证`。
- **《问真》设计意义**
  - 可采用规则：「一次性消耗＋一小时内不可叠加」是一对很好的负向约束，能阻止"抱一堆叶子无限回血"，比单纯提高药价更有设计价值。
  - 改编缺口：`refinement_recipes.json` 有 `stone_cost`、`materials` 等成本字段，但**没有冷却/使用间隔字段**；"一小时冷却"若要做进游戏，需新增运行时状态而非配方字段。

### 三、本体产能与催生成本

- **原著事实** [已确认]
  - 催生动作：「我动用真元灌入到生机草中，就能让它生长出新的叶子」（E:V1-016508）；方源个案——摘完九叶后掌中只剩光秃草茎，催动淡红色二转真元包裹草茎，嫩芽自底层冒出、由粉绿长成深碧成熟叶（E:V1-017098、E:V1-017104）。
  - 成本量化（方源二转个案）：「消耗了两成真元。」（E:V1-017106）；他只有四成四的真元海，「也就意味着，他只能一口气催生出两片生机草叶」（E:V1-017108）；需来回「催生→拿元石回真元→再催生」，半天才重新长满九片（E:V1-017114）。
  - 时间成本：催生九片要耗掉大半天（E:V1-018234）；方源据此拒绝代理「每天多催一些」——「催生出九片生机叶，已经是极限了，浪费了我许多修行的时间」（E:V1-017292，`[对话|已核]`，说话人：方源）。
- **合理推导** [合理推导]
  - 依据：两成真元/片（17106）＋四成四真元海一次两片（17108）＋半天补满九片（17114）＋「大半天」（18234）。结论：产能同时受**真元预算**与**时间**双约束，方源二转期日产能上限≈九片、且要占掉大半日。
  - 三方记账（按 L0 纪律）：**支付方**＝持有者（真元＋时间）；**受益方**＝持有者（收获生机叶）与其顾客；**支付时点**＝催生当下。
  - 不确定性：两成/片是方源丙等资质、二转初期的个案，不得外推为通用效率表；家族后勤蛊师轮流催生的节奏是否与单人一致，原文未给（`待取证`）。
- **《问真》设计意义**
  - 可直接采用：把产能建模成「真元 → 消耗品」的转换率＋时间成本，而不是"每分钟自动产出"；持有一株生机草＝持有一个需要投入的产线，符合原著"移动的金矿，但要花时间挖"。
  - 改编缺口：配方 schema 无「产出」类条目（只有 input→output 的合成），产能机制需另立结构或由脚本层实现。

### 四、经济：市价时间线与代售链

- **原著事实** [已确认]
  - 基准价：一片生机叶＝一转蛊虫，市价 50 块元石；九片即 450 块（E:V1-017120）。对照：普通一转蛊约 250 块，而「生机叶这种消耗类的一转蛊，则是五十块元石一片」（E:V2-047250）。家族原本卖价 55 块（E:V1-017290、E:V1-020548）。
  - 随时间上涨（狼潮周期）：方源向古月青书开价 65 块，其时家族已提价到 60（E:V1-020544、E:V1-020550）；对古月野报到 68→70→72 块（E:V1-024768、E:V1-024780）；对代理下令统一提到 70 块（E:V1-024826）；旁人转述他「一片生机叶居然要卖八十块元石」（E:V1-025032）；方源记忆中狼潮最猛烈时「甚至炒到过一百块的高价」（E:V1-020572）。
  - 稀缺与需求：死亡伤残越多、价格越高，「甚至是有市无货」（E:V1-024678）；狼潮临近需求增大，方源售价越来越高（E:V1-020424）。
  - 代售链：方源不直接零售，全部卖给商铺店主江牙由其对外贩卖（E:V1-017256）；江牙赚差价、方源成其金主（E:V1-017278）；家族卖 55、江牙按方源吩咐只卖 50 时「果然是供不应求」（E:V1-017290）。
  - 退场与替代：方源后来把九叶生机草上缴、改用兜率花（E:V1-027806）；他判二转九叶生机草治疗能力本就不令人满意（E:V1-026950、E:V1-027808），理想替代是三转的生生不息蛊（持续治疗、耗真元少）、不死草（存一线生机）与自力更生蛊（依宿主力量）（E:V1-027810）。
- **合理推导** [合理推导]
  - 依据：50→55/60→65→70→80→（记忆）100 的完整报价序列（17120、17290、20544/20550、24768/24826、25032、20572）＋「有市无货」（24678）。结论：生机叶是**强周期消耗品**，价格由伤亡率驱动；持有者赚的是时间差与信息差（方源靠前世记忆预判狼潮）。
  - 不确定性：各报价为喊价/成交口径混杂；「记忆中的一百块」是方源前世经验，不能当实证行情；两个 50 块口径（E:V1-017120 与 E:V2-047250）分属青茅山与通幽商铺，不能简单等同。
- **《问真》设计意义**
  - 可直接采用：生机叶做成"基础治疗药片"，价格随战事/兽潮事件上调——用事件驱动价格而非固定价，可复用 `caravan_offers` 一类的商队/报价结构。
  - 设计张力：同一物品在"自用（保命）"与"出售（元石）"间取舍，方源 400+ 元石/天的收益以放弃修行时间为代价（18234、17292）。这是可玩的资源分配张力，比"自动产生金币"更贴原著。

### 五、喂养链：喂什么、产出什么、谁受益

- **原著事实** [已确认]
  - 自身喂养成本≈0：「只需水和阳光，它就能存活，因此喂养起来，几乎不花成本」（E:V1-017124）。
  - 产出→元石→喂养他蛊：出售生机叶赚元石，「能支撑他的修行，还有喂养其他蛊虫」（E:V1-018372）；九叶生机草是方源「最主要的经济支撑」（E:V1-025128）；「很大一部分的喂养费用，都是靠它支撑下来的」（E:V1-027018）；狼潮前后生机叶价格要涨，有它在手「二转修行的元石就不愁」（E:V1-018374）。
  - 收益的有限性：用四味酒虫精炼真元后元石消耗增加，「单靠贩卖生机叶的收入，已经不足以持平他的修行消耗了」（E:V1-020090）。
  - 喂养负担是活跃机制：方源一边催生生机叶赚元石维持修行，一边收集酒虫与隐石蛊晋升的材料（E:V1-019152）；他亦自述「也有不少的蛊虫需要喂养」（E:V1-017968）。
- **合理推导** [合理推导]
  - 依据：零成本存活（17124）＋产出换元石（18372、25128、27018）＋收入不足以持平（20090）。结论：这是一条**自养型资源链**——生机草几乎不吃元石，却持续产出可换元石的消耗品，把"喂养"从支出转成收入，用以覆盖**其他蛊虫**的喂养。
  - 三方记账（按 L0 纪律）：**支付方**＝持有者（催生时付真元与时间）；**受益方**＝持有者得元石、购买生机叶的蛊师得保命手段、代理（江牙）得差价、家族（统一生产时）得更多生机叶（E:V1-025144）；**支付时点**＝催生当下付真元/时间、售出时收元石、叶被使用时「一次性消失＋一小时冷却」生效（16496、16498）。
  - 不确定性：原文未给"九叶生机草自身是否还需额外食料"或"叶能否反过来喂养其他蛊"的明文——本链的关键是**元石中转**，不是生机叶直接当饲料。
- **《问真》设计意义**
  - 可直接采用：把生机草建成"以时间换货币"的产线节点，形成「产出品→元石→喂养其他蛊虫」的闭环，而不是一只单纯的战斗蛊。
  - 改编声明：「喂养便宜」是原文（17124），可映射为低喂养成本；但把整条链压成"每天自动 +N 元石"会丢掉 18234/17292 的时间成本与 20090「收入不够用」的张力，属过度简化。

### 六、家族管控、珍稀蛊对照与配置位

- **原著事实** [已确认]
  - 珍稀蛊共性：酒虫、黑白豕蛊、九叶生机草这类珍稀蛊虫，「家族高层都希望掌控住，为整个家族服务」（E:V1-017136）。
  - 家族集体产能：山寨另有数人掌握此蛊（E:V1-017128），另有五株九叶生机草是家族集体财产，「每天都有专门的后勤蛊师，执行生产任务，轮流催生出大量的生机叶」（E:V1-017130）。
  - 垄断与权位：「家族中的大部分九叶生机草都掌控在药姬的手中，依靠售卖生机叶，她极大地巩固了自己的权力和地位」（E:V1-025096）；她以此「巩固权位，加深影响力，维系人脉关系」（E:V1-025126）。
  - 强制上缴：狼潮凶猛时药堂颁布通告，「药堂勒令所有拥有九叶生机草的蛊师们，都将手中的九叶生机草暂时上缴给家族」（E:V1-025110）；围观者视为好消息，因「九叶生机草集中起来，统一生产，代表着更多的生机叶」（E:V1-025144）。
  - 与酒虫的对照：古月青书代表家族求购酒虫，还想「一同收购方源的黑豕蛊，甚至是九叶生机草」（E:V1-020462）；方源对九叶生机草一口回绝、列为非卖品（E:V1-020464），对生机叶供应则另作谈判（E:V1-020542）。
  - 与黑白豕蛊的对照：黑豕蛊的最优晋升是钢鬃蛊，方源因已有白玉蛊在手、用处不大，愿换成鱼鳞蛊（E:V1-020468）；九叶生机草则绝不换。
  - 地位跃迁改变谈判性质：方源晋升三转即成家老，与药姬平起平坐，上缴从"上驭下"变为「一种平等的交易，利益的交换」（E:V1-027016）；他因此以上缴换「奖赐令」（E:V1-027038）。
  - 配置位：方源六方面配置为——攻击血月蛊、防御天蓬蛊、移动雷翼蛊、存储兜率花、侦察地听肉耳草，治疗位「治疗有九叶生机草」（E:V1-017342、E:V1-027804）。
  - 增幅（跨页）：木魅蛊令青书渐成树精后，青藤蛊、松针蛊与生机叶等木行蛊「威力也将得到增幅」（E:V1-023856）；增幅对象是**叶片**而非草本体，且无节制用木魅会变成死树人（E:V1-023862）。
- **合理推导** [合理推导]
  - 依据：珍稀蛊高层都想掌控（17136）＋家族五株集体财产与后勤蛊师统一生产（17130）＋药姬垄断售卖巩固权位（25096、25126）＋强征通告（25110）。结论：九叶生机草是**家族级战略物资**，个人持有者面临"被收购/被上缴"的体制性压力，控制它＝控制治疗供给＝控制人脉与地位。这与酒虫形成两种珍稀资源化的对照：生机草靠**产能垄断与体制强征**，酒虫靠**秘方稀缺与个人竞购**。
  - 不确定性：上缴后是否补偿、补偿标准原文未给（方源的补偿是政治性的「奖赐令」，个案）；五株集体财产的具体产出量未核。
- **《问真》设计意义**
  - 可直接采用：把"治疗物资"设为可被势力强征的战略资源，就能一键生成"个人产出—势力接管"的冲突线，比单纯交易更有剧情张力。
  - 与配方 schema 的关系：本页的家族管控机制**不进配方 schema**（属经济/势力层），只登记为设计张力；配方层可映射的只有「生机叶＝一转消耗类物品」这一类别/物价定位。

## 待核对

- [待取证] 生机叶的疗伤上限与生效速度量纲：原文只给「瞬间治疗」与「一片能救命」（16500、24708），未给能治多重的伤、几秒生效。
- [待取证] 家族五株集体财产的单株产出节奏、后勤蛊师轮值规模；催生效率是否随资质/转数变化（方源「两成真元/片」不得外推）。
- [原著未明确] 九叶是否等质、叶序有无差异；「第 N 片叶」这类分层效果在原文中无任何表述。
- [原著未明确] 生机叶能否直接作为其他蛊虫的食料——原文只写"出售生机叶换元石以喂养其他蛊虫"（18372），无"叶即饲料"明文。
- [待取证] 生机叶价格的适用范围：青茅山基准 50 块/片（E:V1-017120、E:V1-017290），另有异域商铺同报 50 块/片（E:V2-047250）；两地数值相同而市场不同，不据此推断全南疆统一定价。各报价为喊价/成交口径混杂，「甚至炒到过一百块的高价」（E:V1-020572）出自方源的记忆，不能当实证行情。
- [合理推导] 「生机草＝家族级战略物资」（主题六）由 17136＋17130＋25096＋25110 串接，原文未自述该因果；上缴补偿标准无明文。
