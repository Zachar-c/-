# M0 六蛊原著边界

本页只记录 M0 六蛊白名单的原著身份、证据层级与 Adaptation/Unchecked 边界。不写游戏数值、战斗实现与合炼配方细节。

M0 六蛊：小光蛊、月光蛊、石皮蛊、玉皮蛊、白豕蛊、刀翅血蝠蛊。单蛊详述见[小光蛊](small-light-gu.md)与[月光蛊](moonlight-gu.md)；本页覆盖其余四只的身份证据。

## 原著明确内容

- 小光蛊：身份 Canon。学堂蛊室墙角处拿取、共五只（根原文 `蛊真人-clean.txt` 9704–9706 行）；古月博明言辅助月光蛊令月刃攻击更强（9774 行附近）；双蛊同催实战用例（10926–10940 行）；可参与合炼的凡蛊（15708–15710 行）。
- 月光蛊：身份 Canon。详见[月光蛊](moonlight-gu.md)（镇族秘法培育、一转层次、月刃机制与消耗均有逐段核验）。
- 石皮蛊：身份 Canon。学堂蛊室选蛊场景出现（根原文 `蛊真人-clean.txt` 9600 行“又看到一只石皮蛊”）；与铜皮蛊外形相似、身体灰扑如石头工艺品（9602 行）；与铜皮蛊、铁皮蛊、玉皮蛊、兽皮蛊同属一个护防系列（9614–9618 行附近）。
- 玉皮蛊：身份 Canon。与铜皮蛊等同属一个系列、为该系列最珍稀者、市价仅次于酒虫（根原文 `蛊真人-clean.txt` 9614–9618 行）；学堂蛊室当时无此蛊（9620 行附近）；后证明可与白豕蛊合炼晋升成白玉蛊（12402 行）。
- 白豕蛊：身份 Canon。豕蛊家族四只之一（花/粉/黑/白，9686–9700 行附近：9670 行）；黑、白豕蛊能力为改造蛊师身躯、从根本上增长气力，且所得力量永久归蛊师所有、蛊死亦留存（9688–9692 行）；市价高于酒虫（9694–9698 行）；方源得白豕蛊并计入蛊虫持有（9992、10048 行）；可与玉皮蛊合炼晋升白玉蛊（12402 行）。
- 刀翅血蝠蛊：身份 Canon、名称与品阶关系有直接证据。野外刀翅血蝠群场景点名“三转刀翅血蝠蛊”（根原文 `蛊真人-clean.txt` 31864 行）；该群为特殊集群、蛊师只需操纵唯一雄蝠即可间接号令全部雌蝠（31900 行）；另有刀翅血蝠、血滴子、血狂蛊合炼秘方线索（31898 行附近）。

## 资料整理

- 本页六蛊之外的 M0 锁定事项（四战试炼结构、匿名固定角色、HP/true_qi/thoughts 资源、局间奖励）属于游戏设计契约，不属于原著事实，不在本页断言。
- M0 各蛊战斗效果一律标 Adaptation：身份已确认，但 M0 的战斗抽象不是原著数值。原著只给出身份与机制方向（如白豕蛊日积月累增力、血蝠集群号令），未给出 M0 式单次结算数值。

## 分析与解读

- 小光蛊→月光蛊协同是单向个案，不得升级为一切光道蛊通用规则（见[小光蛊](small-light-gu.md)）。
- 石皮蛊与玉皮蛊是同一护防系列的高低两端：石皮为学堂蛊室可见的寻常护防蛊，玉皮为该系列最珍稀者。不得用玉皮蛊的稀有度反推石皮蛊的价值，也不得用其他护防蛊的能力代填二者。
- 白豕蛊核心误读防范：原著是持续改造身躯、日积月累的永久增力，不是单次攻击加成；M0 式单次结算只能标 Adaptation。
- 刀翅血蝠蛊核心误读防范：原著证据指向集群（雄蝠号令雌蝠）与三转实例；M0 以单蛊形式与一转定位使用属于 Adaptation，不得声称原著存在同名一转单体形态。
- 白豕蛊 + 玉皮蛊 → 白玉蛊的合炼关系有原文线索（12402 行），但完整配方与转数链不在 M0 范围，本页不断言配方细节。

## 待核对

- 石皮蛊：品阶原文直述、用途上限、限制条件尚未逐段穷举；不得用玉皮蛊或其他护防蛊代填。
- 玉皮蛊：除系列归属、稀有度、市价与合炼线索外，饲料、消耗、完整用途尚未逐段穷举；当前 M0 护防抽象不得当原著机制。
- 白豕蛊：单次增力量级、持续时间、喂养条件尚未逐段穷举；M0 结算抽象外的任何数值化表述都缺依据。
- 刀翅血蝠蛊：一转形态是否存在原文依据尚未找到；M0 的品阶落点与单体战斗形态属 Adaptation。
- 小光蛊：品阶、饲料、消耗、持续时间、全部适配蛊虫尚未建立完整条目（同[小光蛊](small-light-gu.md)待核对）。
