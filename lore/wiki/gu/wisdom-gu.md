# 智慧蛊

## 核心定义

智慧蛊是九转蛊虫，作用是提供灵感与推算能力，并有明确代价与取得门槛。

## 原著明确内容

- 整理资料把智慧蛊记为九转蛊，核心作用是提供灵感、支撑推算（推演仙蛊方）。对应笔记锚点：C 的 141 行（「智慧蛊=九转，无限灵感（给思路）……推算过量会反噬受伤（131000）」）、22 行（「真传秘境近无上真传（九转智慧蛊）疯狂燃寿」）、34 行（「智慧蛊=给灵感，师法自然=天地直接给答案」，122168–122500）。
- 使用代价有两条记录：一是智慧光晕持续照射会把使用者变成活死人／尸体状态，二是推算过量会反噬受伤。对应笔记锚点：C 的 32 行（120568–121300）、141 行。
- 《人祖传》出处线索：人祖、古月阴荒先后献出中年才得到智慧蛊。对应笔记锚点：C 的 111 行（110968 附近）。
- 隐喻索引把「智慧蛊逃脱」列为第 3 节，释义为「智慧不能被强行降服，只能被更智慧者赢得；炫耀降服方法等于交出钥匙」。对应笔记锚点：`记忆库/04-人祖传-隐喻索引.md` 第 9、52 行。
- Run 1 记录：天庭入侵琅琊福地的目标记为方源、九转智慧蛊与吞并琅琊福地助修宿命蛊；战果包含智慧蛊被方源带走。对应笔记锚点：G 的 18 行（292678、295736）。
- Run 2 记录：方源以七彩漩涡诓走智慧蛊入至尊仙窍。对应笔记锚点：H1 的 53 行（323792–323977）。
- 紫薇仙子以星宿棋盘发动星投；笔记记为若得智慧蛊可升九转星宿棋盘。对应笔记锚点：H1 的 60 行（325284）。

## 分析与解读

- 智慧蛊在叙事上把「信息优势」具象化了：它可以理解为灵感与推算能力的来源，而不是直接的攻伐手段。
- 它把力量与代价绑定在一起：这解释了为什么取得和使用都有门槛，持续照射与过量推算都会带来明确代价。
- 涉及《人祖传》的一句与 `themes/ren-zu-zhuan.md` 第 3 节一致：智慧不能靠强迫取得，炫耀降服方法反而会暴露自身。
