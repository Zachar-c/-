# 次要人物总表（二期）

本页是[全书主要人物总表](roster.md)的第二期：收录复现配角约 50 人，按势力/域分组，每条 1–2 行身份锚点，供 C 线按剧情顺序精蒸馏与《问真》NPC/阵营设计定位。格式与锚点约定同主表；条目默认《资料整理》层级（笔记转述），标注"已核"的行经本批回读原文。

## 原著明确内容

本批抽样核验行（其余见《资料整理》）：

- "此代的新人中，万龙坞出了应生机，灵缘斋出了凤金煌，灵蝶谷出了萧七星，我们仙鹤门实在难以争锋" `蛊真人-clean.txt:69616` `[对话|已核]`（说话人：鹤风扬）。
- 庙明神与方源等深入悔哭海域 `蛊真人-clean.txt:354194`–`354210` `[叙事|已核]`（本批回读窗口）。

## 资料整理

### 中洲·天庭系（含诛魔榜）

- **白沧水**：天庭八转；监天塔炼道蛊阵四八转之一（D2 158282–158296）；被薄青斩杀（D2 174972–175062）；出阵中武庸送友风之役（H1 315148–315357）。
- **炼九生、碧晨天**：天庭八转（D2 158282–158296 四八转围监天塔）；碧晨天另见逆流河求方源护马赵被拒（F2a 238440–238456）。
- **金珠子**：天庭中天门守卫，金珠仙王杀招（H1 315510–315893）。**花子**：太阳宫"牺牲"实为假死（H1 315510–315893）。
- **厉煌**：天庭八转，Run 1 被方源万剑鬼蛟＋万一鬼蛟剑＋落魄印斩杀（H1 321148–321391）；光阴长河两战再杀（H1 头部 Run 2 记述）。
- **周雄信**：天庭信道八转、流言笼（G 313326–313795）；Run 1 被方源示弱反杀、春剪斩首（G 313764–313794）；毛脚山战场以流言笼困杀池曲由（I2a 360048–360086）；战部渡再杀周雄信（J2a 415612–415852，轮次归属待核）。
- **赤心行者**：出关收古月方正为徒，方正接任诛魔榜榜主（H2 350498–350876）。
- **叶凡**：陆畏因之徒；陆畏因为其复仇阵前叛投天庭（H1 322530–322713）。**青仇**：与幽魂相斗、被炸成三段（I2a 头部；I2b 383722–383724）。
- **玉珠子、赵山河、万紫红、朱雀儿**：天庭系八转混战群像（毛脚山战场 I 360001–361000；玉珠子克刘流溜 H1 321148；万紫红仙墓苏醒 H1 316274；赵山河帝君城拦截战 H2 358280）。

### 中洲·门派与散修

- **石磊（仙猴王）**：战仙宗七转；繁星洞天与尸龙/七星子连番死战、战利品被方源偷走（C 134620–136400）；前世五域乱战后接任中洲第一战力。
- **千竹仙、命河谷主、绝空神母**：赴繁星洞天救援石磊三仙（D1 135652–135750）。
- **妙音仙子（白兔姑娘）**：气相；五相赌斗门过关（H1 336918–337125）；借石予方源（G 271980）。
- **毒娘子**：北原紫毒福地、七转、梦境第三霸主、入游梦（C 152000–153000）——按福地活动语境暂列中洲组，归属待核。
- **彭达**：卷六开篇穿越者（I2a 头部，360001 区间）。
- **苏尚书、苏琪涵、杜志晓、李小白**：天妒仙蛊交易与桃花运线人物（I2b 402728–403115）；苏尚书天道蛊虫解说已核（`蛊真人-clean.txt:402750`–`402764`）。

### 东海

- **宋启元、青岳安、华彩云、张阴**：东海正道八转（H1 316454–316643）；张阴绝命阴雷（G 311814）、毁西漠房家资源点嫁祸董陆沉（H2 343606）。
- **容婆、扬子河、石淼**：伏击龙公的散修/魔仙（G 311348–311362）。**阳骏**：散修，识破方源海蛇化身（G 311882–311888）；后期还人情抢购心血仙蛊（H2 350498–350876）。
- **庙明神**：借石十万予方源（G 271950）；组八仙探苍蓝龙鲸、同入悔哭海（H2 350876–351279，已核窗口）。
- **吴帅**：方源分身之一（与气海老祖并列，I2b 383802）；立两天联盟（I2a 头部）；一生梦境（H2 头部）；与海底兽人古族续百万年盟约（H2 343606）。
- **夏琳、赵露**：鲛人圣庭圣女与"篡改记忆的假姐姐"（G 309000–309158）。
- **焚天魔女、黎山仙子**：姐妹相认（D2 171336–172629）；焚天魔女率东海僵盟援军回北原；黎山仙子三仙之一（C 130000 现身威慑；D2 158118 拒援）。

### 西漠

- **房家三巨头：房功、房睇长、房化生**（J2b 423558）；房睇长耗尽豆神宫兵卒（I2a 360002–360016）、剖析方源"只重实际利益"（J 430006–430026）、壁画世界寻神帝城之秘（J2a 414256–414460）；房化生刁难方源（`蛊真人-clean.txt:328870` 节题窗口，已核"房家太上客卿长老"）。
- **唐方明、唐烂柯**：唐家光阴支流；弃车保帅与卖人情抉择（G 270044–270058；J2b 424556）。
- **董陆沉**：被张阴/扬子河毁资源点嫁祸（H2 343606–343916）。

### 南疆

- **池曲由、池伤**：南疆池家；池曲由阵道大宗师（义天山封锁阵"三曲九池阵"设计者，E 37；识破无空腾挪阵 H1 315148–315357；智汗阵 F2b 247620–247908）；被周雄信流言笼困杀（I2a 360048–360086）；池伤为方源"肉靶"对手（F2b 247358–248190）。
- **柴火熊、铁心剑、乔波**：影宗强袭超级蛊阵战例对手（F2b 251798–252992）。**巴十八**：忍耐者，被解决（H1 330476–330668）。**夏槎**：沦为废人后被方源敲诈（H2 343606–343916）。
- **武独秀**：武庸之母；玉清滴风小竹楼原主（F2b 250904–251034）；武庸阴影 (I2a 365436–365452)。
- **雪胡老祖**：与方源结盟（苛刻奴仆式盟约，F2b 240000–240072）；炼鸿运齐天蛊失败毁大雪山福地（F2b 240040）；率十余蛊仙争运道真传（C 118968–119600）；盗北原僵盟仙僵墓地、洗劫黑家铁鹰福地（D2 168800–172629）。
- **万寿娘子**：受信蛊放影无邪一行入第一雪峰（F2a 236434–236518）；受伤（F2b 240948、243298）；人情链人物（F2b 256584–256596）。**沐凌澜**：慷慨赴死抱雪胡下河（F2a 238322–238352）。

### 北原

- **马英杰、马赵**：马家；马英杰假托马尊立威（B 89944–90020）；马赵河中排名战第一、被秦百胜俘虏为拍卖货品（F2a 238322–238352；C 131800–132200）；巨阳意志树藤死保（C 114968–115500）。
- **黑城**：黑楼兰生父（焚天魔女布局苏仙儿打入黑家内部、与黑城生下黑楼兰，原文 203650 `[叙事|已核]`）与复仇对象（影宗盟约者、百日大战参与者、黑牢仙蛊屋丢失者），三战黑城（D2 171336–172629）；因四大太上长老修炼青城纵横有后遗症、不能分散外出，黑城借得黑牢仙蛊屋并执掌黑家最高权柄（原文 256236 `[叙事|已核]`，原"待核"项已清）；黑家围攻战中本家称之为叛徒（原文 203906 `[对话|已核]`）。
- **葛谣**：自荐同行方源（常山阴马甲期，B 78922–78986）。
- **邓左岩、万车震**：被盗天魔尊坑死的两位八转蛊仙（"见面曾相识"传说，C 131800–132200）。
- **墨坦桑**：仙僵；建议方源混入北原僵盟（C 131800–132200）；助琅琊地灵解气道封禁（C 笔记 96 行）；星罗城任务榜人物（J2b 428196）。

### 影宗·僵盟·地灵与异人

- **百足天君**：百足洞天主人，宴请秦百胜（D1 135112–135189）；通缉柳贯一（F2a 225876–225884）；为巨阳当血道交易中间人两头受气（J2b 430206）；为吞并黑家早做打算、联结药皇，以自身血脉后裔为主建立百足家（原文 204400–204412、221790 `[叙事|已核]`），黑家大战了结后于黑家大本营宣告"黑家残存者皆已投靠。从今以后，此处将是我百足家的领土"、黑家长老齐声"我等愿舍弃家名，改姓百足！"（原文 205462–205466 `[对话|已核]`，说话人：百足天君/黑家长老们）。与黑楼兰黑家后世活动不冲突，裁定见《待核对》。
- **黑菟**：紫山真君授黑菟真传（F2b 256566–256580）。**鹰姬**：押回败军老鬼（G 282046–282060）。
- **黄史上人**：石莲岛陷阱被方源反杀（F-225001 笔记头部）。
- **琅琊地灵**：琅琊福地地灵；与方源多笔交易（神念蛊/通天蛊换星门蛊秘方 B 85322–85366；四六分账 D1 135102–135110）；Run 1 被方源魂爆击杀（G 294004–294062）；Run 2 琅琊守卫战翻盘后福地被方源吞并、晋升八转（H1 头部）；泥沼蟹量产蟹军（C 122968–123300）。
- **狐仙（福地地灵）**：方源首座福地地灵；治伤、地灾、仙窍死终局线索（B 75722–75854；C 130074–130400 附庸关系）。
- **戚发**：戚家投降（H1 336918–337125）。**章丽**：梦境探索人物（F2b 250148–250188）。
- **战部渡**：自由残缺变＝亚仙尊（J2a 414090–414178）；冲顶被星宿棋盘传走、杀周雄信（J2a 415612–415852）。

### 商队·商家城·白骨山（弧三，C 线当前区间）

- **李然**：演武场对手（方源演戏一击致伤＋认输，B2 52632–52824）。**魏央**：奉命查证商心慈血脉非夺舍（B2 47404–47528）。
- **陈双金**：商队无主商货分配起争执者（A 44540–44957）。**商拓海**：假蛊风波告密者（I2b 403010–403046）。**田蓝**：商燕飞暗派丫鬟、打探黑土白云来历（B2 47514–47528）。
- **灰骨才子（肉骨上师）**：白骨山四转正道传承主，骨肉团圆蛊独创者，独身未竟（A 37404–37470、39772–40007）。**百生百花**：前世十年后百家寨举族迁来得传承、成五转正道双星（A 37404–37470，方源前世记忆 `[信念]` 语境）。

## 分析与解读

- 本页与主表的分工：主表收"驱动剧情的决策者"，本页收"复现的功能性配角"；两者合起来覆盖剧情、NPC 阵营与关卡的实体检索需求。
- 大量配角存在跨 Run 状态（周雄信两次死亡、厉煌两杀、琅琊地灵两轮结局）：引用时必须标注 Run 1/Run 2，禁止跨轮拼线（同[宿命大战](../events/fate-war.md)边界）。

## 待核对

- **"百足家吞并黑家"已裁定（2026-09-25 维护批回原文核验）**：被吞并的黑家即黑楼兰的北原黑家（黄金家族、大本营铁鹰福地，原文 127694、203836 `[叙事|已核]`），非笔记笔误、不存在两个黑家。因果链：黑楼兰被指与捣毁八十八角真阳楼案有涉而方源在逃，黑家"背锅"遭北原蛊仙界围攻（原文 203540、203550–203554 `[叙事|已核]`）；黑家势弱、无八转坐镇，唯四大太上长老青城纵横战阵（原文 203564–203572 `[叙事|已核]`）；百足天君为吞并黑家建立百足家、事先付出惨重代价与其余四位八转达成协议（原文 216734 `[叙事|已核]`）；战后黑家残存者投靠并舍弃家名改姓百足（原文 205462–205466 `[对话|已核]`），后文追认"最终被百足家吞并"（原文 236478 `[叙事|已核]`）。黑楼兰本人当时随影无邪在外（原文 203540 `[叙事|已核]`），家族覆灭后化名黑月独行（原文 417052 `[叙事|已核]`）——其"后世活动"系个人线，与家族实体覆灭不冲突。
- 周雄信两次死亡（G 313764 Run 1 / J2a 415612）的轮次归属未核；战部渡"自由残缺变"机制未核（A 线 KM 体系范围）。
- 毒娘子（北原紫毒福地）列入中洲组的依据薄弱，域属待核；马赵的确切构成（人名组合）未核。
- 黑菟、鹰姬、青仇、千竹仙等仅单点锚点；威灵仰、罗然的域属与身份未核。
