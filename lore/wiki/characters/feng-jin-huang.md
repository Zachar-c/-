# 凤金煌

凤九歌与白晴仙子的女儿，灵缘斋年轻蛊师，后被寄望成为大梦仙尊。凤金煌本人、梦翼仙蛊、天意规划中的“大梦种子”是不同概念；预期并不等于她已经成尊。

## 原著明确内容

- 凤金煌在中洲十派大比武中夺得第一，并进入狐仙传承。`chapter_0366` `para_066`–`para_071`。
- 狐仙传承竞争时，她求胜心切，凡人之身强催梦翼仙蛊，原文指出有失忆或痴呆风险；她仍选择承担代价。方源先一步登顶后将她踩下悬崖。`chapter_0406` `para_142`–`para_151`、`para_172`–`para_182`。
- 方源判断她因梦翼仙蛊尚不能被自己杀死，这是方源当时对实力与风险的评估，不是凤金煌免疫伤害的普遍事实。`chapter_0406` `para_176`–`para_181`。
- 她与凤九歌是父女；宿命大战阶段凤金煌操纵阵法、催动仙道杀招阻挡方源，凤九歌称赞她并承认其功劳。`chapter_1750` `para_036`–`para_041`。
- 凤九歌被称为凤金煌的护道人；龙公及天庭将她视作未来大梦仙尊的重要人选。护道人身份与“未来成尊”期待不等于凤金煌已经加入天庭或成为尊者。`chapter_1597` `para_010`。
- 后期她开创出完美纯梦求真体，能够压制方源的相关梦道手段；这使她成为天庭对抗方源的重要人物。`chapter_1942` `para_061`、`para_067`、`para_093`。

## 资料整理

- 凤金煌的父母关系由 `chapter_1750` 明确称谓及凤九歌的保护行为确认；早期另有一段“孙女”称谓与直系父女叙述不一致，总表将其暂判为对话歧义，见[全书主要人物总表](roster.md)凤金煌条。
- 梦翼仙蛊使她进入梦境与传承线；遇空绝老仙、得到炼道真意及炼道境界提升，见总表旧章节范围 `chapter_1410` 之后，相关状态变化待本页逐段补录。
- 她曾随龙公参与东海龙宫争夺，并在 Run 2 阻拦方源；相关状态和轮次见总表与宿命大战资料，引用时不得跨 Run 拼接。

## 关键关系与判断

- **凤九歌、白晴仙子**：父母。凤九歌对她有保护与期待，也在战场上肯定她的实际贡献；不应把父亲的“大梦仙尊”期望写成凤金煌自愿接受的固定目标。
- **方源**：狐仙传承中的竞争者与宿命大战中的对手；凤金煌曾因梦翼受到方源顾忌，也曾主动阻拦方源。双方关系随事件和轮次变化。
- **天庭、龙公**：天庭将凤金煌视作大梦仙尊候选并提供护道人保护。她的潜力是天庭的规划，不是已经兑现的命运。
- **个人动机**：早期表现出强烈的求胜心；后来在传承、父女关系与天庭战事中行动。不能把早期好胜心直接外推成她全部生涯的唯一动机。

## 分析与解读

凤金煌的“天才”身份与实际成长之间有明显落差：她曾在梦翼风险前以意志强行求胜，也在后期发展出能影响尊者级战局的梦道成果。她是大梦仙尊候选，但大梦成尊仍属规划和未来期待，不是现有状态。
