# 中洲炼蛊大会

## 核心定义

中洲炼蛊大会是天庭借助炼道和成功道痕推进宿命蛊修复的关键事件，也是方源与天庭正面交锋的战场之一。现有资料明确包含两次轮回记录：上一轮（Run 1）与当前重生轮回（Run 2）各举办一次；本页首先防止两轮混淆，再记录大会与宿命蛊修复、帝君城大战的关系。

## 时间线边界

### 上一轮轮回（Run 1）

- 天庭以本届炼蛊大会推进宿命蛊修复，冰塞川称其应为最后一场；大会期间方源袭击报名点并造成大量蛊师死伤。
- 大会决赛设于帝君城，随后爆发天庭危局下的帝君城大战，多位八转战力参战。

### 当前重生轮回（Run 2）

- 中洲炼蛊大会再次开启，方源发表公开宣言，白凝冰等人破坏报名点。
- 现有 H2 资料只记录到大会开启与破坏报名点阶段，不能据此补写本轮大会的决赛归属与最终胜负。

## 参与者

- **天庭**：大会的组织与秩序维护方，把大会产生的成功道痕用于宿命蛊修复。
- **龙公**：以誓言担保不许任何人破坏大会的天庭核心战力（Run 1 记录）。
- **方源**：袭击报名点、破坏大会秩序的一方；两轮均有破坏记录，但手段与公开程度不同。
- **白凝冰等人**：Run 2 记录中参与破坏报名点的一方。
- **冰塞川**：Run 1 记录中点明本届大会应为最后一场的言说者。
- **参赛蛊师**：大会的参赛主体；Run 1 记录方源袭击造成蛊师死亡上万；死伤口径未细分（对应笔记锚点：G 的 313228–313300）。

## 关键转折

- 天庭把炼蛊大会的成功道痕用于修复宿命蛊，使一场炼道盛会升级为宿命冲突的终局环节；详见[宿命大战](fate-war.md)与[宿命蛊](../gu/fate-gu.md)。
- 龙公以誓言担保大会不受破坏，但方源仍袭击报名点；誓言与袭击的对抗把大会从竞技推向战争。
- 决赛设于帝君城（天下第一凡蛊屋），随后爆发十多位八转战力参战的帝君城大战；大会场地直接转为战场。
- Run 2 中方源转入公开宣言，白凝冰等人破坏报名点；与 Run 1 的暗中袭击形成对照，但两轮差异的完整意义仍需对照阅读。

## 主题冲突

- 秩序盛会与蓄意破坏
- 整体修复目标与个体蛊师生命
- 公开誓言与实际战力对抗
- 两次轮回中同一事件的不同走法

## 分析与解读

- 炼蛊大会的叙事功能是把天庭的长期修复工程压缩为一个可见的集体场景：成功道痕来自众多蛊师的炼蛊成功，而代价由参赛者与被袭击者承担。
- 两轮对照阅读时，Run 1 的重点是誓言—袭击—决赛—大战的连续升级，Run 2 目前只记录到开启与宣言—破坏；不能把 Run 1 的帝君城大战结局直接套用到 Run 2。
- 大会同时是炼道主题与宿命主题的交叉点；炼道层面的胜负与宿命层面的修复进度是两条不同的线，不应互相替代。
