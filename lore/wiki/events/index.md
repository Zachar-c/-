# 事件与舞台

> 一页给剧情读者与同人作者：故事按什么发生、每页事件何时/谁/为何重要、你该从哪一页进。

## 怎么用本页

- **跟主线顺序**：先读[全书故事骨架总览](story-arc-overview.md)的「按弧跳转」表定弧，再进该弧事件页；时间序即下方「按叙事弧」分组。
- **按舞台找**：只想查某地域发生过什么 → 「按地域速查」。
- **按冲突找**：只想找某主题相关事件 → 「按主题速查」。
- 每条链接后一句「何时/谁/为何重要」；逐事件细节（EVT-ID 事件链、参与者、因果表）在各事件页内，本页不复述。
- 边界：事件页是剧情导航，不替代原文，也不把游戏节点当作原著事件。

## 分组导航

### 总览

- [全书故事骨架总览](story-arc-overview.md) —— 何时：十三弧全程（约 426–437,061 行）；谁：以弧为单位的全书主链与各弧主事人；为何重要：先看这里决定读哪一弧，弧间因果与 Run 1/Run 2 对照也在这里。

### 按叙事弧（时间序）

#### 卷一 · 南疆青茅山（弧一–二）

- [青茅山](qing-mao-mountain.md) —— 何时：方源重生至学堂立足（弧一，约 426–15,500 行）；谁：方源、古月一族、花酒行者遗藏线；为何重要：全书资源逻辑的起点，遗产/遗藏/春秋蝉三条线在此埋下。
- [狼潮](wolf-tide.md) —— 何时：小兽潮至青茅山覆灭（弧二）；谁：方源、白凝冰、古月青书、方正；为何重要：卷末不可逆变化是青茅覆灭与旧身份丢失，方正对照线从此开启。

#### 卷二 · 南疆商路与福地（弧三–四）

- [南疆商队与商家城](south-caravan.md) —— 何时：黄龙江逃生至推商心慈登少主（弧三）；谁：方源、白凝冰、商心慈、商睚眦；为何重要：交易伦理主题登场，商心慈与白凝冰的关系为卷末决裂铺垫。
- [三王福地](three-kings-mountain.md) —— 何时：三王福地犬王传承至定仙游炼成（弧四）；谁：方源、白凝冰、凤金煌；为何重要：白凝冰冰刃刺心决裂，定仙游的代价把主线转入北原。

#### 卷三 · 北原王庭与仙僵（弧五–六）

- [王庭之争](royal-court.md) —— 何时：常山阴入北原至八十八角真阳楼攻略开局（弧五）；谁：方源、黑楼兰、太白云生；为何重要：信任与权力能否被定价在此试探，宿命蛊（已坏）与天意正式入局。
- [真阳楼崩塌](true-yang-collapse.md) —— 何时：碎窍升仙至繁星洞天探底（弧六）；谁：方源、黑楼兰、秦百胜；为何重要：升仙代价为仙僵化，仙僵身份是卷四全部行动的前提。

#### 卷四 · 中洲、僵盟与梦境（弧七–八）

- [僵盟潜伏与梦境三层](zangmeng-ambush.md) —— 何时：仙僵入中洲至三层梦境探索（弧七）；谁：方源（沙黄/星象子双马甲）、秦百胜、影宗；为何重要：僵盟背后是影宗台面布置，方源第一次预测失败、承认自己也是棋子。
- [中洲炼蛊大会](central-plain-refinement-conference.md) —— 何时：大会预选至宿命修复五成威能（弧八，嵌于弧七行域）；谁：方源、方正、天庭与十大古派；为何重要：炼蛊大会实为天庭修复宿命的机器，修复成功是义天山决战的直接压力源。

#### 卷四末–卷五 · 义天山与两轮宿命大战（弧九–十二）

- [义天山大战与二次重生](yitian-mountain.md) —— 何时：正魔大战至至尊仙胎易主（弧九，卷四后段）；谁：方源、影无邪、砚石老人、影宗；为何重要：春秋蝉可靠性崩塌、方源夺至尊仙体重生，天外之魔身份曝光转入全五域通缉。
- [逆流河](reverse-flow-river.md) —— 何时：冒名武遗海潜伏至星投入侵琅琊（弧十，卷五前段）；谁：方源、太白云生、幽魂、紫薇仙子；为何重要：方源成为棋手的前夜，红莲真传早取是 Run 2 与 Run 1 的关键差异。
- [石莲岛与红莲真传争夺](stone-lotus-island-contest.md) —— 何时：Run 1 毁岛到 Run 2 尽收真传（弧十–十二，光阴长河）；谁：方源、凤九歌、幽魂；为何重要：红莲真传七道的归属线，也是两轮轮回的关键分叉（本页防两轮混淆）。
- [天庭入侵琅琊福地](langya-blessed-land-invasion.md) —— 何时：Run 1/Run 2 两轮琅琊攻防（弧十）；谁：紫薇仙子等天庭八转 vs 方源；为何重要：Run 2 琅琊守卫战是方源翻盘节点；内容已归宿命大战域，本页仅存交叉引用。
- [宿命大战](fate-war.md) —— 何时：Run 1（约 270,001–323,421）与 Run 2（323,422–360,000）两轮（弧十一–十二）；谁：龙公、星宿、方源、红莲、袁琼都；为何重要：宿命蛊名存实亡、五域合一，Run 1 是 Run 2 行动的情报起点。

#### 卷六 · 三尊博弈与断点（弧十三）

- [疯魔窟终局](feng-mo-ku.md) —— 何时：尊者格局解密至断点留白（弧十三，360,001–437,061）；谁：方源、星宿、巨阳、幽魂、无极、乐土；为何重要：永生从来就不存在；全书止于三尊争夺野生九转光蛊的断点，之后不续写。
