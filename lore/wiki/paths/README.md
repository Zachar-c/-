# 阅读路径

> 给所有读者：五条人向阅读路径的总入口——按身份选路，不按目录硬啃。

## 怎么用本页

先认领「你是谁、要干什么」，点进对应路径页。每条路径页内有逐步阅读清单（每步一句为什么读）与常见坑。路径只做导航，事实与规则在各实体/事件/规则页。

## 五条路径

- [五分钟看懂世界](five-minute-world.md) —— 普通访客：骨架 → 修炼/资质 → 五域 → 蛊虫循环，建立世界坐标。
- [跟上方源一生](follow-fang-yuan.md) —— 剧情读者：故事弧 → 人物总表 → 关键事件簇，跟住行动线。
- [同人写作](fanfic-writer.md) —— 创作者：人物动机/关系 → 时代背景 → 世界限制 → 禁止误读。
- [查设定/证据](lore-researcher.md) —— 研究者：规则索引 → canon → 证据回查，拿到可追溯依据。
- [做《问真》](wenzhen-dev.md) —— 开发：规则/数值边界 → 游戏数据分界，避免层间污染。
