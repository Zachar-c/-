## 世界一眼

跨页最重要结论（原 Key Findings，按主题重组）。细节与争议以各页为准；需要精确原话或处理冲突时回查 [`source/README.md`](source/README.md)。

### 世界骨架

- **修炼体系**：蛊师一至九转、每转分初/中/高/巅峰四阶；一至五转为凡人蛊师（真元青铜→赤铁→白银→黄金→紫晶），六转脱凡入仙，九转称尊者（分仙尊/魔尊）`canon-index:CAN-CULTIVATION-001/002/003`。见[修炼体系](world/cultivation-system.md)。
- **资质**：以元海占空窍比例表达，丁 2-3 成 / 丙 4-5 成 / 乙 6-7 成 / 甲 8-9 成；甲等之上有十绝体，元海圆满但伴空窍崩毁与早夭风险 `canon-index:CAN-APTITUDE-001/002`。见[空窍与资质](world/aptitude-and-aperture.md)。
- **真元与破境**：一份二转赤铁真元抵十份一转青铜真元；一转巅峰冲二转的晶膜一般要至少五成五墨绿真元，四成四的丙等元海不能靠即时付款直接突破。酒虫提纯已有真元一个小境界，不回元；白豕蛊催用增力时耗元，已获得的肉身力量可不耗元发挥。见[真元](world/primeval-essence.md)、[酒虫](gu/wine-insect-gu.md)、[白豕蛊](gu/white-boar-strength-gu.md)，`canon-index:CAN-ESSENCE-001/CAN-BREAKTHROUGH-001/CAN-WINE-001/CAN-STRENGTH-001`。
- **五域格局**：南疆、北原、西漠、东海、中洲五域环绕为"宇"，光阴长河贯穿过去现在未来为"宙"（`蛊真人-clean.txt:73950` 已核）；"西荒"是长生天四荒仙人头衔、非地域名（231010 已核）。四域粗粒度入口见[世界规则](world/index.md)地域节。
- **流派源流与分支**：太古宇道/宙道→远古元始（气道/奴道）、星宿（智道/星道）→上古无极（律道）、狂蛮（变化道/力道）→中古元莲（木道）、盗天（偷道）、巨阳（运道）。分支口径：力道分兽力虚影流/气象天地流/人力钧力流三支；智道三元念意情、衍生情道与魅道；炼道分毛民天地流/人族隔绝流两大流派，后期方源估量境界版图共四块（以自然炼蛊/以蛊炼天地/以人炼蛊/以蛊炼人）；律道衍生禁道、虚道（`canon-index:CAN-PATH-001…005`）。境界阶梯 普通→大师→宗师→大宗师→无上大宗师（"准 X"过渡）。总表见[流派总表](world/path-roster.md)，各流派独立页见[世界规则索引](world/index.md)流派节。

### 生存与经济

- **南疆生态**：人族以山寨聚居，山寨与商队互相依赖；兽潮是周期性天灾，蛊师是守护山寨的中坚 `canon-index:CAN-NANJIANG-001/003`、`CAN-BEAST-TIDE-001`。
- **兽潮机制**：兽潮由兽群链式迁徙形成（扩张→压缩→迁移→连锁）；狼巢分万兽王/百兽王/千兽王三级；山寨防御受"扩建悖论"锁死规模，见[兽潮](world/beast-tide.md)、[狼潮](events/wolf-tide.md)。
- **货币层级**：凡间元石→蛊仙仙元石（硬通货）→青提仙元（自产自用），仙元石可 1:1 抽取转青提（123706–123724 已核）；黄金/紫晶舍利蛊受严苛管禁、兼作仙蛊催化（86500 已核）。见[经济与资源总表](world/economy-roster.md)。

### 蛊、炼与战斗

- **蛊虫循环**：养蛊-用蛊-炼蛊构成持续压力，一般蛊师养四五只同转蛊；相似蛊可共用喂养并组合联动——这是战斗多样性的核心来源 `canon-index:CAN-GU-CARE-001`、`CAN-GU-SYNERGY-001`。
- **炼蛊与杀招同构**：任何一记杀招都可看做一份炼蛊残方（方源炼道准无上语境，E:V5-290800 已核）；杀招浓缩成蛊=预先固化，省临场步骤与心智消耗，但威能未必更强、易被针对、失变招；仙蛊升转有法则上限——绝大多数仙蛊极限八转、能上九转的只占极小部分。见[炼蛊术语体系](rules/refinement.md) REF-013…022、[杀招连招并招体系](rules/killer-moves.md) KM-013…018。
- **蛊虫-炼蛊-杀招链**：蛊虫＝大道碎片、材料＝道痕聚集（401146）；蛊方＝工艺路线（基础蛊＋搭配蛊＋材料，可逐级递进或改良替换，100780）；炼蛊五步＝前提（蛊方/材料/炼道境界）→炼前推演（152834、156002）→分步执行（雏形、火候、时间窗）→手法与辅助（复投/纷纷手/骤雨、蛊阵、流派环境）→成败产物（失败＝仙材道痕交融＋材料反噬）。杀招＝多蛊组合，与炼蛊双向互通：杀招可浓缩固化成蛊（省心智、失变招），蛊方可推算成杀招、杀招即炼蛊残方。总纲见[蛊虫、蛊方、炼蛊与杀招](world/gu-refine-killer-chain.md)。

### 人

- **方源马甲链**：古月方源→黑土→常山阴→八臂仙人→沙黄→武遗海→柳贯一→气海老祖→大爱仙尊（自封），按剧情推进换用；白凝冰同期马甲"白云"。引用马甲名前先查[全书主要人物总表](characters/roster.md)归一表，不得当作独立人物。
- **异人联盟的胁迫式成形**：宿命大战后冰晶仙王以"当场发难无人能挡＋谎称鲛人联合异人对人族动手"双机制胁迫鲛人王庭（EPUB `chapter_2000`），设三场赌约仍败于吴帅；然吴帅反手自立盟主，"输的人赢了，赢的人反而输了"——中立小国在大争之世被裹挟的典型样本。详见[东海](world/east-sea.md)、事件 EVT-FMK-014A/014B/014C。

### 后断点三尊格局（2026-09-30 蒸馏批）

- **盗天机与升仙大潮**：方源以九转盗天机杀招（核心九转天机蛊＋八转大盗蛊）借蛊师升仙师法自然之机盗取天意所知，收益绝大多数来自盗天机而非新生蛊仙本身；人道收获最意外，根源是星宿衍化仙阵。限制：情报用多被天意调整、洞天不可侦查、依赖师法自然。见[灾劫体系](rules/tribulation.md)、[疯魔窟终局](events/feng-mo-ku.md) EVT-FMK-173。
- **衍化仙蛊必须野生、炼化即废**：功能前提而非选择——一旦被炼化即成无用之物（无极试过）；大阵因此须在有天意的天庭内运行、保密成本极高。见[星宿仙尊](characters/star-constellation.md)、[蛊虫总表](gu/roster.md)。
- **元始复活打破均势**：星宿以气海老祖还原气功果续上元始复活；巨阳从"星宿甘愿放弃中洲"反推出复活尊者，完整推断链见[巨阳仙尊](characters/roster.md)条；天庭双尊"理念一致"联手胜过任何单打独斗。见[天庭](world/heavenly-court.md)、EVT-FMK-175–178。
- **双尊默契与幽魂结构性压制**：双尊封锁方源炼九转的默契之下互不信任又投鼠忌器；幽魂被神志不清/只剩黑天天灵/目标锁死/战力最低/被当搅局工具五条结构性约束压制。见[长生天](world/longevity-heaven.md)、[幽魂](characters/roster.md)、EVT-FMK-174。

- 检索顺序建议：本页 / 分类 `index.md` → 实体·事件·规则页 → canon-index → 原文。
