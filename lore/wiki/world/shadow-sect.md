# 影宗

## 原著明确内容

- 影宗在叙事中最早出现于三王山区间：仇九以海誓蛊立誓守护生死门秘密，"如果你也加入影宗，那就是自己人，我就可以说给你听了"（E:V2-071236）`[对话|已核]`（说话人：仇九）。
- 紫山真君一生回闪：十万年前七分魂出生死门、与黄破无极真传、创慧剑蛊、创"与天意同化"、苏醒、授黑菟真传、万寿娘子人情、女蛊师炎道真传、少年太白云生选第三道真传 `蛊真人-clean.txt:256462`–`256630`（本批未逐段回读，笔记层级 F2b，见《资料整理》）。
- **创宗与七色代号（2026-09-26 系统补强批核验）**：影宗自幽魂魔尊陨落、魂归生死门开始创建（E:V5-197628）`[叙事|已核]`；其分魂建宗——"本来是十个分魂，但成功出来的只有我们七个""我等七人。就分别代号赤橙黄绿青蓝紫""就叫影宗吧，如影子般不引人注目"（E:V4-186730）`[对话|已核]`（说话人：影宗第一代分魂）；"幽魂魔尊生前天下无敌，死后又建立影宗"（E:V5-191196）`[叙事|已核]`；幽魂自述"我本体魔尊幽魂，创建影宗、僵盟，炼制至尊仙胎"（E:V5-198636）`[对话|已核]`（说话人：幽魂）。
- **色衔口径（两时间线并存）**：义天山期"青正使竟杀了蓝副使"（175698，青＝薄青）；今生"影宗蓝正使，仙僵七星子" `蛊真人-clean.txt:182868`、`蛊真人-clean.txt:184024` `[叙事|已核]`；另有影宗副使秦百胜（159918）。色彩序列源出七分魂赤橙黄绿青蓝紫创宗代号（186740）。

## 资料整理

以下条目来自读书笔记的整理转述，未完成逐段原文核验，不得当作原著原文事实。

- **十万年谋局**：紫山真君自封紫金石九万年、屡醒屡疯（天意所致）（F2a 238598–238606）；影宗曾延缓大时代五百年、剿灭大梦仙尊（F2b 242700–242736，影无邪释"大时代"）。
- **幕后台面双层**：僵盟背后是影宗的台面布置（00-总览弧七）；蓝副使（七星子仙僵）接密令"天庭已修复宿命蛊，你那边必须先行启动"（D2 174440–174456）；职务色衔正使/副使（青正使＝薄青、蓝副使＝七星子，D2 175664–176032）。
- **核心成员**：紫山真君（宗主级，影宗大能，见[人物总表](../characters/roster.md)）；影无邪（义天山后主事之一，F2b 240452–240464）；砚石老人（天机仙蛊与人造十绝体研究者、实为幽魂分魂所创，G 276530–276542）；黑楼兰、白凝冰（入影宗，F2b 240452–240464）；方源以沙黄/柳贯一名义接触并最终继任影宗之主（F-225001 笔记头部；256896–256900 参拜影宗新主）。
- **关键行动**：义天山大战设局献祭（00-总览弧九）；梦境大战败亡、幽魂本体被天庭俘虏、方源继任宗主后紫薇揭穿其身份（F-225001 笔记头部）；人造十绝体批量炼制（紫山真君以"分割自身魂魄"为代价，F2b 253720–253724、256858）。
- **对天庭**：影宗与天庭长期对峙；紫山真君"与天意同化"策略（打入天意内部、策反命运棋子，F2b 248756–248834）。
- **潜伏与渗透（2026-09-26 系统补强批）**：五百年前世"影宗潜伏，幽魂暗中掌控了天庭"（395536）、幽魂意志自述"潜伏天庭，拖延了大时代来临将近五百年"（269484）、计划"甚至要将天庭完全渗透操纵！"（242726 `[对话|已核]`，说话人：影宗）；手段为魂道搜魂改造——紫薇仙子被历次搜魂改造而不自知（363188、"紫薇仙子被幽魂改造，忠心耿耿"383782）；宿命大战中正元老人被魂球收服（"老奴拜见主上！"363580、"已经被魔尊幽魂强行收服"365380），成为幽魂催动天庭人道手段的钥匙（365270）；幽魂携正元/紫薇主仆三人潜行（367836–367844），命二人"重建影宗，为我招兵买马"（367952），二人自称"我们二位代表的是真正的影宗"（374300）。
- **成员结局（段六）**：正元老人被秦鼎菱等俘虏、紫薇仙子与影无邪在逃遭天庭通缉（385330、385420、433826"派遣人手，大力搜寻紫薇仙子"）；二人赴两天不断接近幽魂魔尊（434392），途中中天籁濒死、被叛庭的凤九歌所救（434438）。另：影宗曾在琅琊福地安插内奸（338666）；宋紫星（血龙）系影宗中人、幽魂分身（395556）。
- **"总纲"用词考订**：全书 rg "总纲" 零命中——影宗最高纲领性表述为"十万年大计"（207512"夺走了影宗谋划十万年的最大成果"）与至尊仙胎炼制（204144"耗费近十万年光阴……才堪堪功成"）；外部题库"影宗总纲"系用词错位。

## 分析与解读

- 影宗的组织人格是"以十万年为单位的对天意/天庭持久战"：延缓大时代、剿灭大梦仙尊、经营僵盟台面、人造十绝体量产，都服务于消耗战逻辑，而非一时争夺。
- 方源继任宗主是该组织线的叙事转折：从"被影子利用的棋子"变为"执棋者"，Run 2 中洲混乱诸役（屠逍遥岛等）均以影宗资源执行（G 314132–314363）。

## 待核对

- 影宗创立时间与创宗者：已核——幽魂陨落后七分魂建宗（186730–186740、197628，2026-09-26 补强批），原"十万年语境来自紫山真君个人时间线"之保留解除；影宗与生死门的组织关系仍待核（仇九誓约只证明影宗涉入生死门秘密）；海誓蛊机制未核。
- 正使/副使的完整职级与色彩序列：七色代号源出已核（186740）；正使/副使职级全表与"蓝副使→蓝正使"的时间线口径差仍待核；影宗在 Run 1（前世轮回）中的形态未核。
