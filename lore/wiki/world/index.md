## 写同人要知道的世界限制

短路径：**代价 → 规则边界 → 常见误读**。写之前过一遍，能避开大多数「原著里不这么运转」的硬伤。详细证据在各链接页，这里只给入口和一句话约束。

### 一、代价（这个世界不白给力量）

1. **养蛊是持续破产压力**——蛊师通常只养四五只同转蛊（养不起加用不起）；蛊食按日消耗，境界提升后蛊食标准也升。先读 [蛊的饲养与炼化](gu-care-and-refinement.md)。
2. **炼化必遭反抗**——炼化即抹去蛊意志，中断会被驱除殆尽；意志极刚强者会反噬空窍。先读 [蛊的饲养与炼化](gu-care-and-refinement.md)。
3. **合炼须秘方、失败很贵**——有些蛊不能合炼；失败可能材料反噬，甚至经济崩溃、成长线报废。先读 [蛊虫、蛊方、炼蛊与杀招](gu-refine-killer-chain.md)。
4. **杀招组合必有弊端**——后遗症不可避免、只分严重微弱；威力大则真元消耗巨大。浓缩成蛊省心智但失变招、易被针对。先读 [杀招连招并招体系](../rules/killer-moves.md)、[蛊的饲养与炼化](gu-care-and-refinement.md)。
5. **越级催动代价惨重**——一转蛊师常态只用一转蛊，硬用高转蛊如婴儿挥大铁锤。先读 [修炼体系](cultivation-system.md)。
6. **资质有代价**——十绝体元海圆满但伴空窍崩毁与早夭风险。先读 [资质与空窍](aptitude-and-aperture.md)。
7. **升仙不可回头**——凡人成仙含碎窍等步骤，碎窍不可逆。先读 [资质与空窍](aptitude-and-aperture.md)、[世界操作系统](world-operating-system.md)。
8. **灾劫会毁掉经营成果**——地灾可毁福地、资源大量毁损须重建；渡劫虽增道痕，但同流派增幅、异流派可能冲突。先读 [修炼体系](cultivation-system.md)、[灾劫体系](../rules/tribulation.md)。
9. **仙僵不是免费变强**——仙元不能自产、福地定期崩解、战力往往低于正常蛊仙，且失去渡劫积累道痕的途径。先读 [修炼体系](cultivation-system.md)仙僵代价段。

### 二、规则边界（别把个案写成公理）

1. **凡仙分界**——一到五转为凡、六到九转成仙；六转蛊即仙蛊、同种同世只存一只。先读 [修炼体系](cultivation-system.md)。
2. **个案不外推**——月芒蛊合炼、万我骨架、连招/并招个例、破境路线都是个案，**杀招通用合成公式不存在**，不得虚构。先读 [蛊的饲养与炼化](gu-care-and-refinement.md)《待核对》。
3. **流派境界标尺不是通则**——单个流派个案（如奴道驱役）不得外推为全流派通用规则。先读 [流派境界五级](../rules/path-realms.md)。
4. **界壁变化分 Run**——Run 1 炼蛊大会「缩减」、Run 1 宿命大战收尾「彻底消弭」，**不得并入 Run 2**，不得合并解读。见[世界地理](#世界地理)界壁事件入口。
5. **地图未完成**——五域完整地图、域间距离、详细谱系仍未建模；缺失不等于不存在，也不等于可以随意填。见[世界地理](#世界地理)末段。
6. **规则页与世界页分工**——流派页只收流派级事实；道痕、灾劫、炼蛊术语、杀招体系、梦道在 [rules/](../rules/index.md)，别在同人设定里另起一套。

### 三、常见误读（原文明文不这么写）

1. **天道 ≠ 天意 ≠ 宿命蛊 ≠ 天庭**——四者是规则碎片、天地意志、制度组织，不是「天道→天意→宿命蛊→天庭」的单向流水线。先读 [世界操作系统](world-operating-system.md)天道外环。
2. **「天意安排」不抹掉人物选择**——任何「都是天意安排」的写法都抹平了红莲、方源的反抗路径。先读 [世界操作系统](world-operating-system.md)、[天庭](heavenly-court.md)。
3. **某人认为 X ≠ 世界规则 X**——角色台词、传闻、信念要标说话人与真假状态，不得升级为世界规则（如「智慧蛊是星宿本命蛊」只是对话/未决）。见 [Wiki 编辑约定](../AGENTS.md)认知标记。
4. **西荒不是西漠**——「西荒」是长生天四荒仙人的头衔，不是地域名。见 [西漠](west-desert.md)。
5. **青茅山三族 ≠ 整个南疆地图**——早期三寨分布只针对青茅山局部，不可外推为南疆固定地图。见 [南疆](south-jiang.md)。
6. **多轮回结果不得拼成一条线**——上一轮宿命大战与当前重生轮回要分轮说明，不得合并结局。见 [天庭](heavenly-court.md)。
7. **「阵道仙蛊屋」不是术语**——全书 0 命中，不得使用；蛊屋本质是固定化杀招。见 [阵道](formation-path.md)、[蛊的饲养与炼化](gu-care-and-refinement.md)。
8. **资质上限是倾向不是硬墙**——丁丙乙甲的转数上限为倾向表述，不是不可逾越的数值墙。见 [修炼体系](cultivation-system.md)。
9. **飞轮不是单向因果链**——仙窍→仙元→灾劫→道痕是条件依赖与阶段边界，资源不会自动变仙元，花费仙元也不是灾劫的直接条件。见 [世界操作系统](world-operating-system.md)、[修炼体系](cultivation-system.md)分析层。
