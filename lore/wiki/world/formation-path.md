# 阵道

阵道在远古时代末期创造出来，但真正祖师不可考证 `EPUB chapter_1339 para_011` `[对话|已核]`（说话人：图事成）；与气道、智道同一时代产生，论资排辈比变化道更早 `EPUB chapter_1339 para_017` `[对话|已核]`（说话人：图事成）。

## 原著明确内容

- 精意："阵道，是以一道内涵万道" `EPUB chapter_1339 para_020` `[对话|已核]`（说话人：方源）；"阵道可谓是所有流派当中，最为复杂的一门了" `EPUB chapter_1339 para_021` `[对话|已核]`（说话人：图事成）。
- 蛊阵分类：有单纯蛊阵、复合蛊阵之分，还有阵中阵 `EPUB chapter_1345 para_082` `[叙事|已核]`。
- 宗师标尺：孙名录布置出十二重复合蛊阵，已是北原公认第一阵道宗师；方源推断布三十重蛊阵者"必定就是大宗师了"（甚至可能无上大宗师）`EPUB chapter_0943 para_009` `[对话|已核]`（说话人：方源，推断语境）；如此精妙的布置必是阵道大宗师手笔 `EPUB chapter_0942 para_073` `[对话|已核]`（说话人：方源）。
- 五行大法师：北原八转散仙，专修阵道、擅长模拟金木水火土五大流派，阵道大宗师（长生天招揽）`EPUB chapter_1715 para_019` `[对话|已核]`（说话人：凤九歌）。
- 池曲由：池家阵道大宗师，能借助自然道痕布阵 `EPUB chapter_1807 para_069` `[叙事|已核]`。
- 造诣深厚的炼道蛊仙都有自己的炼道蛊阵（大雪山福地北原魔道炼蛊第一阵融合十二道蛊阵）`EPUB chapter_0942 para_089` `[对话|已核]`（说话人：方源）。
- 方源达到律道大宗师、阵道宗师境界 `EPUB chapter_1815 para_066` `[叙事|已核]`。
- 长生天拥有八极大阵（仅一见、无原理展开）`EPUB chapter_2242 para_096` `[叙事|已核]`。

## 分析与解读

- 阵道是"组合器"流派：以蛊阵为形态、以"一道内涵万道"为精意，与杀招体系（连招/并招，见 [杀招连招并招体系](../rules/killer-moves.md)）同属多蛊协同层；复合蛊阵重数（十二重/三十重）是境界的外显标尺，与 [流派境界五级](../rules/path-realms.md) 的境界轴对应。
- "最复杂"（246684）解释了阵道宗师稀少且多兼修（五行大法师模拟五派、池曲由借自然道痕）：阵道天然是跨流派整合位。

## 待核对

- 复合蛊阵的原理细节（重数与威能关系、阵道仙蛊构成）未系统核验；"阵道仙蛊屋"作为固定术语全书 0 命中，不得使用。
- 方源阵道境界晋升时序（准大师→大师→准宗师→宗师）分散于笔记锚点，未逐条回原文。
