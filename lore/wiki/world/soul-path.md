# 魂道

## 原著明确内容

- 魂道是专注魂魄修行的流派，与力道齐名，上古辉煌而魂道经久不衰，至今仍是一大流派；开创者为幽魂魔尊，九转蛊仙（78240–78250 行，第十七节《幽魂魔尊》）。短引：“统称为魂道蛊师”“他便是幽魂魔尊”。
- 幽魂魔尊的九转地位另有旁证：与巨阳仙尊一样同为九转蛊师，且被称作玩弄魂魄的大行家（110682–110690 行，第一百九十四节《长生难难难》）。短引：“同样都是九转蛊师”“开创魂道”。
- 魂魄有生死极限：常人只能将魂魄提升到一百倍，俗称百人魂，多一丝则魂魄爆炸消散（78228–78236 行，第十七节《幽魂魔尊》）。短引：“俗称百人魂”。
- 魂魄底蕴是可比较的量：幽魂现身段以“远超亿人魂”衡量魂魄底蕴，并把魂魄由虚返实、干涉物质、凝如肉身记为魂道的极致（185612–185620 行，第三百六十三节《幽魂？幽魂！》）。短引：“魂魄由虚返实”“绝对远超亿人魂”。
- 底蕴有从低到高的详细层次：一人魂、十人魂、百人魂……百万人魂、千万人魂、亿人魂，十人魂即相当于十个成年人的总和（273656–273662 行，第四百四十一节《百万人魂》）。短引：“相当于十个成年人的总和”。
- 方源借助圣地与手段曾达到百万人魂的级数（273654–273656 行，第四百四十一节《百万人魂》）。短引：“已经有了百万人魂的级数”。
- 魂道修行有三要素：壮魂、炼魂、安魂，三者相辅相成（332470–332474 行，第七百七十六节《名震天下！》；201828–201832 行，第七十一节《我意蛊》）。短引：“分别是壮魂、炼魂、安魂”。
- 壮魂首选荡魂山，炼魂首选落魄谷，得一山一谷则可魂道大成；两地并称魂修二圣地（78254–78256 行，第十七节《幽魂魔尊》；93474–93478 行，第一百零三节《先挑狼王》复述同段）。短引：“壮魂首选荡魂山”。
- 炼魂的具体手段：落魄谷中有迷惘雾令魂魄松散，又有落魄风切割魂魄，魂魄经此拷打越加凝练（78238 行，第十七节《幽魂魔尊》）。短引：“能令魂魄松散”“就会越加凝练精诚”。
- 壮魂的具体手段：胆识蛊是用于壮魂的极品第一蛊，直接增长底蕴且无副作用、效率极高；方源的千人魂即由此修炼而成（93482–93484 行，第一百零三节《先挑狼王》）。短引：“直接增长底蕴”。
- 壮魂的时间基准：普通蛊师把魂魄积累到千人级通常需二十年左右，方源借胆识蛊半年不到即达千人级（93486–93490 行，第一百零三节《先挑狼王》）。短引：“通常需要二十年左右的时间”。
- 炼魂与壮魂须配合：落魄谷炼魂去杂质如锻铁成钢，荡魂山胆识蛊令魂魄数量节节攀高，质变与量变结合则底蕴一日千里（182802–182808 行，第三百四十九节《炼化薄青的仙蛊》）。短引：“质变、量变相互结合”。
- 凝魂名录：神魂蛊、龙魂蛊、冰魂蛊、梦魂蛊、月魂蛊、将魂蛊、怨魂蛊、诗魂蛊等均可凝练魂魄，助突破百人魂至千人魂乃至万人魂（78260 行，第十七节《幽魂魔尊》）。短引：“都可以凝练我的魂魄”。
- 凝魂名录的完整款与差异妙处：市集所列另有马魂蛊、英魂蛊、气魄蛊、体魄蛊、云魄蛊、风魄蛊、虎魄蛊种种，均能凝魂且各有不同妙处，如冰魂增益冰类蛊虫、龙魂裨益龙力一系（81812–81826 行，第三十七节《钧力蛊》）。短引：“这些蛊虫，都能凝魂”。
- 狼魂蛊改造：三转狼魂蛊单只售价七千七百枚元石，效用可叠加，单只不足以凝练百人魂（81836–81840 行，第三十七节《钧力蛊》）。短引：“一只售价七千七百枚元石”“效用可以叠加”。
- 狼人魂形态：方源用九次狼魂蛊凝练后，人形百人魂转为半人半狼的狼人魂，比原先强大数倍，之后可再壮魂至千人魂乃至万人魂，万人魂之上还有亿人魂等（81920–81946 行，第三十八节《蛮家挑战》）。短引：“俗称狼人魂”“要强大数倍”。
- 魂道最高造诣形象：幽魂魔尊之魂超越亿人魂，有千臂千手、三个头颅，三颗头颅各有异相（81948 行，第三十八节《蛮家挑战》）。短引：“有千臂千手，三个头颅”。
- 安魂手段：安魂首选迷魂湖中的安魂汤，《人祖传》早有记载；魂魄修到一定程度易与肉身脱离，饮安魂汤可解魂不附体之患（332474–332478 行，第七百七十六节《名震天下！》；369024–369028 行，第八节《打开局面》复述）。短引：“名为安魂汤”。
- 真实魂道蛊之一净魂仙蛊：魂道蛊仙辅助修行之物，能精炼魂魄剔除杂质，但用过头会连精华一并剔除；它是杀招万我的核心蛊，动用万我会消耗魂魄底蕴（123190–123198 行，第十四节《辨认仙蛊》）。短引：“便是杀招万我的核心蛊”。
- 真实魂道蛊之二摄魂蛊：魂道仙蛊，充当摄魂杀招的核心，一摄即把羊枯魂魄摄取出来（331984–332012 行，第七百七十四节《吞吞吞！》）。短引：“有了这只仙蛊充当核心”。
- 命牌蛊与魂灯蛊：武家宗祠所置之蛊，方源认祖归宗时当场炼出置放；各家宗族祠堂普遍存放命牌蛊或魂灯蛊（227566 行，第一百九十九节《登场南疆》；250478–250482 行，第三百二十二节《兄去弟继掌权柄》）。短引：“置放在武家的宗祠之中”。
- 跨流派价值：不止魂道蛊师需要，奴道、炼道等流派也需要魂魄底蕴；蛊师升仙时魂魄也是人气浓郁与否的重要因素（130438–130440 行，第五十八节《暴利！》）。短引：“也需要魂魄的底蕴”。
- 奴道与魂道同源旁证：自古奴魂不分家，奴道最初从魂道衍生，后结合太古智道才真正独立；驭兽蛊、奴隶蛊即对魂魄与心智的控制（81830–81834 行，第三十七节《钧力蛊》）。短引：“自古奴魂不分家”。
- 幽魂真传的荒魂突破体系（根原文 433,572–433,598 行，断点前窗口，2026-09-25 核验）：人的魂魄上限为亿人魂——种族局限；红莲魔尊打坏宿命蛊后，经幽魂魔尊推陈出新，打破人体限制发生质变，从亿人魂突破到荒魂，再十荒魂、百荒魂……亿荒魂；亿荒魂为幽魂真传终点，能形成三头六臂的千臂魔魂、准九转战力、直接力抗灾劫——“这是魂修的顶点，也是整个天地所能包含的极限”。
- **人性规则**：“人魂就是人魂，突破到荒魂，原本纯粹的人性中便增添兽性，或者更深刻地说，是天性！”亿荒魂中人性占据部分十分稀少、天然野性占绝大多数；幽魂魔尊神智散尽、遵循兽性而为，正是该弊端的显现（E:V6-433584–433588）。
- 魂道歧途论（人道对照）：以前人道没有发展，人的极限便是亿人魂——幽魂魔尊当年不得不做出突破，“实际上是踏入歧途”；方源以沈伤贡献的人道修行成果两相对比后确认此弊端（E:V6-433592–433594）。
- 魂道起源深意：幽魂魔尊原本想开创杀道、吞并黑天天灵没有成功，转而开创了魂道（E:V6-433598）。

本批未使用 `notes:` / `memory:` 作主证据，无新增整理条目；以下仅作定位说明，尚未完成逐段原文核验的内容不得当作原著事实。

## 分析与解读

- 壮魂管数量、炼魂管质量、安魂固成果：三者相辅相成，凝魂蛊族与兽魂改造落在“炼魂/凝练”一侧，胆识蛊落在“壮魂”一侧，安魂汤落在“固持”一侧。缺安魂手段时只能隔段时间修行一次（332480–332482 行），这是修行节奏约束，不是数值公式。
- 底蕴是可增长的存量：百→千→万→百万→千万→亿的阶梯是原文明示的量级序列；本页只转述已见档位，不推导未见的中间档换算率。
- 狼人魂是“人魂改兽魂”的实例：改造后可继续壮魂，说明兽魂形态与底蕴量级是两个维度，不得把某一形态读成固定上限。
- 跨流派与升仙两条把魂魄底蕴连出魂道本流派：这是魂魄值得投入修行的原文依据；具体与肉身、真元如何分配资源，原文只给方向（谁也不会嫌魂魄太强），不给配比公式。
- 壮魂有内在风险，且原文已明示：常人魂魄以百人魂为生死极限，再壮大一丝即魂魄爆炸
  （78230–78236 行），而原文同时指出「魂魄光是壮大，只是数量上的优势。还得精炼凝结，
  才是质量上的优势」（78240 行）。据此，**凝练（炼魂）是壮魂的安全前提**——
  这条约束把“壮魂、炼魂、安魂”三要素连成一个有风险的内在平衡，而不是三个可独立堆叠的增益。
- 荒魂体系是"力量上限"与"人性稀释"的交换（分析层）：亿荒魂带来准九转战力与力抗灾劫的能力，但人性被天然野性稀释——这是魂道版的代价规则，与灾劫体系"力量增长必伴随考验"的模型同构（见[灾劫体系](../rules/tribulation.md)、[道痕体系](../rules/dao-marks.md)）。
- 魂道歧途论是人道视角的判定（分析层）：以人道发展停滞为前提，幽魂的突破才是"歧途"；若人道发展出替代路径，判定可能改变——沈伤人道成果与幽魂真传的对照是关键证据链，完整机制待核验。
- 用字校正（`RUL-2026-09-19-007`）：L0 原话“挡尸蛊可以撞魂”系同音误记，实为
  「胆识蛊可以壮魂」（“挡尸”“撞魂”原文 0 命中；「胆识蛊」514 命中、「壮魂」42 命中）；
  “落魄蛊可以炼魂”同理，实为「落魄谷可以炼魂」（“蛊”“谷”同音）。两条校正后均与原文一致，
  故本页事实层按校正后的用字收录。
