# 北原

## 原著明确内容

- 蛊师世界有南疆、北原、西漠、东海、中洲五域环绕，此为"宇"；光阴长河贯穿过去、现在、未来，此为"宙" `蛊真人-clean.txt:73950` `[叙事|已核]`（原文该行作"中州"，全书通行写法为中洲）。
- 北原环境恶劣，每十年一场暴风雪席卷整个北原，"暴风如刀搜刮一切"，野外埋设的传承会因此损毁 `蛊真人-clean.txt:90008`–`90010` `[叙事|已核]`。
- 四荒仙人是东荒、南荒、西荒、北荒四位八转仙人 `蛊真人-clean.txt:231010` `[叙事|已核]`；冰塞川为西荒仙人、与巨阳仙尊同时代的八转传奇与宙道大能，被巨阳三次出手降服后入长生天 `蛊真人-clean.txt:311990`–`312000` `[对话|已核]`（说话人：花子、五行大法师）。
- 长生天是巨阳仙尊居住之地（方源对草原少女语，伪装常山阴身份语境） `蛊真人-clean.txt:78910` `[对话|已核]`（说话人：方源）。
- **疯魔窟（2026-09-26 系统补强批核验）**：北原十大凶地之一（218884、219156、345912 三处明文）——中洲页旧条将其列为中洲地标系归属错误，已订正；"表面上是北原的十大凶地之一，其实却是无极魔尊晚年特意打造，用来追寻永生的奥秘"（219156 `[对话|已核]`，说话人：楚度）、"疯魔窟却是无极魔尊一手制造"（218720）、为其晚年居所（219168）。共九层（346000）：第一层黄土大地猛兽凶植（409624）、第二层炙热火岩石滩（409672）、第三层云雾缭绕猛兽隐藏有雾都（409682 附近；死蛊仙冤魂相伴凝结成雾都鬼城 409688）、第七层道痕堆叠光华璀璨（409710）、第八层衍生世界/天道演变（346692）——第八层虚空中元莲创建青莲道场、狂蛮蛮荒大世界、乐土黄土大世界（395996）；每隔一段时间魔音从最深第九层传出、辐射九层，万物疯狂厮杀（346008–346012）。最底层（第九层）藏九转衍化蛊超级蛊阵（219168）、元境（395980"疯魔窟的确是在最底层，元境"）、书山（411246）及龙公移入的生死门与部分天庭仙墓（396060）；方源首次探索止步第八层（356884）；历代尊者"几乎也都进入过疯魔窟中探索"（404374），巨阳曾入第八层得知当年四尊补天内情（413488）。双尊棋局：无极攻天庭逼星宿对弈、棋局暗通疯魔窟，"真正决定胜负的最终场地，还在疯魔窟"（395986–395994）。终局：无极因宿命蛊尚在另起炉灶推演永生（410592），第八层"三界一统"（418490）后亲自试混沌、自认"还谈不上永生"（421422），最终"永生——从来就不存在"、破碎成事实浮冰碎块（421608–421614）；元境被巨阳联合方源特意破坏（419882）；方源在疯魔窟之争中以炼道成尊（422102 节题《方源成尊！》、422922"晋升成为炼道魔尊"）、"当之无愧的第一赢家"（423170）。事件侧锚点见[全书故事骨架总览](../events/story-arc-overview.md)弧十三。

## 资料整理

以下条目来自读书笔记的整理转述，未完成逐段原文核验，不得当作原著原文事实。

- **王庭福地**：巨阳仙尊所留，类似天梯山、遍布历代传承，可庇护十年暴风雪；王庭十年之主机制（黑楼兰前世问鼎）；王庭福地在弧六崩塌（B 89022–90121、89944–90020；00-总览弧五/弧六）。
- **八十八角真阳楼**：需巨阳仙尊血脉标准方可入；巨阳建楼"就是为了它的倒塌"，捣毁真阳楼者＝关键人物（B 89022–90121；H1 320064–320068；H2 357248–357318）。
- **英雄大会**：玉田、猛丘、草府、天川等，合纵连横、吸纳部族的传统（B 89022–90121）。
- **北原拍卖大会**：秦百胜筹办，含换仙蛊环节与运道传承（C 131800–132200、152000–153000）。
- **势力**：黑家（黑楼兰、黑城半月重组、六转仙蛊屋黑牢 C 127724–128300）、葛家（葛谣 B 78922–78986）、马家（常山阴＝方源掌马家 C 90001–91500）、赵家（赵怜云 C 90001–91500）、长生天（劫运坛、血海、四荒仙人、巨阳遗产 H1 316274–316452）、僵盟北原分部（沙黄＝方源 D1 135112–135189）、毒娘子（紫毒福地、梦境第三霸主 C 152000–153000）。
- **关键事件**：王庭之争（弧五）、真阳楼攻略与王庭福地崩塌（弧六）、北原僵盟潜伏（弧七）、劫运坛攻天庭（Run 1，见[宿命大战](../events/fate-war.md)）。

## 分析与解读

- 北原的行动节律由十年暴风雪塑造：传承埋设、福地庇护、大会档期都围绕它展开，是"环境约束行为"最明显的域。
- 巨阳遗产（王庭福地、真阳楼、长生天、运道）构成北原权力结构的底层，各方争夺本质是遗产再分配。
