# 虚道

虚道是从律道中衍生出来的小流派 `蛊真人-clean.txt:347178` `[叙事|已核]`；"虚道，这只是一个小流派"但理念独特——"讲究虚虚实实，万法不沾，先天不败" `蛊真人-clean.txt:347182` `[叙事|已核]`。

## 原著明确内容

- 理念明文："虚道，曾于上古时代盛行一时，理念是逍遥自得，避难而无敌" `蛊真人-clean.txt:73156` `[叙事|已核]`。
- **时代两说（显式张力，不得合并）**：图事成源流总述称虚道"现代"（近古）产生 `蛊真人-clean.txt:246670` `[对话|已核]`（说话人：图事成）；而叙事另称其"曾于上古时代盛行一时"（73156）。可能解释（仅为假设）：上古已兴、近古一度式微后再起，未验证。
- 传承实例：炎家少主炎君"继承太古虚道传承，闭关了五年" `蛊真人-clean.txt:67820` `[对话|已核]`（说话人：炎家下属）；炎军"继承上古虚道传承，最擅长躲避攻伐" `蛊真人-clean.txt:73152` `[对话|已核]`（说话人：方源）——67818 人名作"炎君"、73152 作"炎军"，疑原文人名异写；"太古/上古"两处措辞亦不一，照录。
- 境界机制："要提升虚道境界，本质上仍旧是律道真意" `蛊真人-clean.txt:347194` `[叙事|已核]`；另 331406"虚道也是从律道中划分……但也没有完全脱离律道" `[叙事|已核]`。
- 墨瑶论虚道：讲究虚实相生，一到五转以虚为主，六转后攻守兼备 `蛊真人-clean.txt:107916` `[对话|已核]`（说话人：墨瑶）。
- 仙蛊实例：六转虚道仙蛊飞熊虚像蛊（八十八角真阳楼关卡奖励）`蛊真人-clean.txt:107758` `[叙事|已核]`；弄虚蛊可令飞熊虚像蛊由实化虚、躲避一切攻击 `蛊真人-clean.txt:107932` `[对话|已核]`（说话人：墨瑶）。
- 实战形态：炎军动用虚道蛊虫由实化虚躲避进攻 `蛊真人-clean.txt:74684` `[叙事|已核]`；东方长凡虚道造诣深厚能结成虚阵，虚化整阵蛊虫而不妨碍运转 `蛊真人-clean.txt:143914`、`143922` `[叙事|已核]`。
- 起源：蛊师流派中的虚道，是蛊仙虚无邪从虚兽身上获得的灵感 `蛊真人-clean.txt:143366` `[对话|已核]`（说话人：黎山仙子）。
- 至高奥义：虚窍（天庭掌握）`蛊真人-clean.txt:347190`、`335298` `[叙事|已核]`；九虚洞天蛊仙几乎都专修虚道，整个洞天都能虚化、令灾劫无效 `蛊真人-clean.txt:310344` `[叙事|已核]`。
- 人物：不真子是灵缘斋太上长老、七转虚道蛊仙 `蛊真人-clean.txt:230810` `[叙事|已核]`；虚道蛊仙本来就数量稀少 `蛊真人-clean.txt:233290` `[叙事|已核]`；魔尊幽魂的虚道境界为大宗师级数 `蛊真人-clean.txt:186102` `[叙事|已核]`。

## 分析与解读

- 虚道是"防御/规避极化"的流派：万法不沾、先天不败（347182）与洞天级虚化（310344）指向同一设计——以"不存在"换生存；与人类隔绝流炼蛊（[炼道](refinement-path.md)）同样带"隔绝"色彩但分属不同维度，不得混写。
- 虚兽→虚无邪→虚道的灵感链（143366）是"流派可由异兽启发"的实例，与变化道等"一道外映万道"的框架互补。
