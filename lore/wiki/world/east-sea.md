## 分析与解读

- 东海是"正面战场之外的第二海洋政治圈"：正道八转、散修魔仙、龙宫、僵盟总部、异种族势力在同一水域多层叠加；龙宫归属（帝藏生）是 Run 1/Run 2 差异的关键节点之一。
- 引用龙宫相关事件时注意 Run 1/Run 2 分界，不得合并（见[宿命大战](../events/fate-war.md)）。
- **胁迫结构是「武力威慑＋谣言杠杆」双机制**：当场发难是即时压力（鲛人无八转可挡），谣言是延时压力（借人族之手灭鲛人）；两者叠加使「拒绝」的期望代价高于「接受」，从而把「求联盟」实质化为「强求联合」。这解释了叙事定性"软中带硬"而非赤裸宣战——冰晶要的是联盟成员，不是歼灭战果。
- **谣言对鲛人特别有效的三个前提**（缺一不可）：①宿命大战后"异族崛起"已成公共知识，人族神经紧绷；②人族本就觊觎王庭，只差一个动手借口（乐土影响消退）；③鲛人是五域唯一异族超级势力，目标显著。谎言真假不重要——"不管人族相不相信这个谎言，都会利用这个谎言"。
- **赌约是胁迫的「体面化」台阶**：把"你必须加入"包装成"你有机会拒绝"，但赔率设计使鲛人必须连胜三场才能脱身，而冰晶只需不败。前两场（全族战阵＋七转仙蛊屋）尽出仍败，说明双方战力差不是赌约能抹平的。
- **两难的深层结构**：鲛人每个选项都在「现在灭族」与「将来灭族」之间摇摆——动用底牌=立即成为众矢之的；不动用=赌约必败被迫入盟；请外援=要价不菲或未必能胜。最终解（请吴帅）之所以成立，是因为吴帅有独立动机（接触洞天势力），不是单纯施援——这为后续"赌胜却仍被卷入联盟"埋下因果。
- **"输的人赢了，赢的人反而输了"是本事件的命题级反转**：鲛人赢了赌约却失去中立（被吴帅联盟裹挟）；冰晶输了赌约却达成战略目标（异人联盟成形且由更强的吴帅牵头）。事件层胜负与战略层胜负相反，是弧十三"联盟金融化"主题的前置样本（对照 EVT-FMK-049/121）。
