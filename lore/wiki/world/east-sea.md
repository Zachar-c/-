# 东海

## 原著明确内容

- 蛊师世界有南疆、北原、西漠、东海、中洲五域环绕，此为"宇"；光阴长河贯穿过去、现在、未来，此为"宙" `蛊真人-clean.txt:73950` `[叙事|已核]`（原文该行作"中州"，全书通行写法为中洲）。
- 僵盟于卷三明确提出（节题"破产和僵盟"）；方源转述师傅提点加入僵盟，太白云生问"僵盟，这是一个什么样的组织？" `蛊真人-clean.txt:121572`–`121686` `[对话|已核]`（说话人：方源、太白云生）。

## 资料整理

以下条目来自读书笔记的整理转述，未完成逐段原文核验，不得当作原著原文事实。

- **龙宫**：被梦境遮护，天庭发现但龙公铩羽（G 310044–310110）；东海龙宫争夺战（凤金煌随龙公清障；容婆、扬子河、石淼、张阴四散修/魔仙伏击，宋启元、青岳安、华彩云等东海正道八转陆续卷入，G 311308–311998）；龙公强夺龙宫是为收服帝藏生（H1 316454–316643）；龙宫如梦令（H1 319406）；龙宫后归方源（00-总览弧十二）。
- **藏龙窟**：龙公十年谋命运蛊之地（00-总览弧八）；东海八转破封印大阵图谋龙宫（H1 316454–316643）。
- **东海正道八转**：宋启元、青岳安、华彩云、沈从声、张阴等（H1 316454–316643）；沈从声音道、"绕梁之音"活捉悲风老人（H1 316454–316643；I2a 365470–365486）。
- **散修与魔仙**：容婆、扬子河、石淼、张阴（G 311348–311362）；阳骏识破方源海蛇化身（G 311882–311888）。
- **万龙坞**：凶雷恶人（分身杀招魅蓝电影）、雷神子蓄八头六转战力；宋紫星（血龙、七转叛徒）（C 130900–131800）。
- **僵盟**：总部设东海（00-总览弧七"东海总部星象子"）；北原、中洲设分部（沙黄任职北原 D1 135112；星宿仙僵前世入主中洲分部 C 133800–134400）。
- **沈家**：沈伤（"百年东仙首"，gu 总表已核 354786）、沈从声（H2 350876–351279）。
- **种族与圣地**：鲛人圣庭（夏琳圣女、镇魔悔哭海＝乐土仙尊镇压悔悟魔仙之地，G 309000–309158）；海底兽人"古族"（与吴帅分身续百万年盟约，H2 343606–343916）。

## 分析与解读

- 东海是"正面战场之外的第二海洋政治圈"：正道八转、散修魔仙、龙宫、僵盟总部、异种族势力在同一水域多层叠加；龙宫归属（帝藏生）是 Run 1/Run 2 差异的关键节点之一。
- 引用龙宫相关事件时注意 Run 1/Run 2 分界，不得合并（见[宿命大战](../events/fate-war.md)）。
