# 蛊的饲养与炼化

养蛊、用蛊、炼蛊三件并列事的规则页：饲养是持续负担、炼化是与蛊意志的对抗、炼制受秘方约束。本页按 schema v2.1 组织——核心规则以表格承载，每行带 E: 证据 ID 或 canon-index 引用。

## 原著明确内容

- 蛊虫需要特定食物或条件维持，饲养不是可有可无的背景设定；缺少食物可能影响蛊虫状态，甚至造成损失。
- 炼化蛊虫需要对应的修为、真元和方法；蛊虫本身的品阶与蛊师的境界会影响成功率和可操作范围。
- 部分蛊虫可以在功能或饲料上形成协同，但"有协同"不等于所有同类蛊都能无条件叠加。
- 小光蛊可用于辅助月光蛊的炼化；整理资料还记录了它与月光刃效果之间的协同。
- 本批窗口核验（根原文 `蛊真人-clean.txt` 906–3454 行，第 4–20 节，均为一转新人个案、不得泛化为所有蛊虫的通用规则）：蛊为天地精华生灵、天生有意志，炼化即抹去其意志、必遭反抗（1830–1834 行）；月光蛊案例为半小时耗三成真元仅炼化十二分之一，中断后约六小时被驱除殆尽、等同重头再炼，故须一边以元石补充、一边持续祭炼巩固（1840–1900 行）；蛊虫意志有强弱之分，弱者绝望投降后炼化轻松，顽强者（如疑为花酒行者本命的酒虫）抵抗超出寻常一转界限（2034–2038、2936–2946 行）；意志极刚强的蛊虫会孤注一掷反噬空窍、不成功则成仁，酒虫反噬即其例（3160–3170 行）；方源借春秋蝉气息镇压残留意志愿意后速炼两蛊，此为借助外力气息的个案手段（3340–3390 行）；炼酒虫估算至少十一块、至多十六块元石，方源两天两夜耗十二块仅炼化十五分之一（2812–2818、3150 行）。
 - 本批窗口新增（根原文 `蛊真人-clean.txt` 3456–4757 行，第 21–29 节，均为一转新人个案、不得泛化）：月光蛊每天两顿、早晚各两片月兰花瓣，日耗四片；花瓣无存储手段只存五天，一块元石购十片（3798–3802、3811–3812、3834 行）；酒虫一坛青竹酒（两块元石）支撑四天，次等酒量大且惹人怀疑，方源按长远直接买青竹酒（3811–3812、3820–3823 行）；春秋蝉直接从光阴之河饮水维持生机，光阴之河无形无色、近在咫尺（3811–3818 行）；蛊室定期有免费领蛊机会、额外获取须付费，草人傀儡售三块、成本约一块半加真元投入（3764–3784 行）；方源本批账目：资产曾达四十四块半（遗藏加方正元石加头名奖），炼蛊前期六块半、喂养十四块半、生活费半块，剩二十块（3838–3846 行）；二转普通蛊每天元石消耗一至两块（3887–3889 行）；蛊师通常只养四五头同等级蛊虫，主因养不起加用不起，所谓养蛊如养情妇（3900–3926 行）；境界提升后蛊食标准亦升（3924 行）；一转期月刃三四发即耗尽真元、养多亦用不出（3910–3914 行）。
 - 本批窗口新增（根原文 `蛊真人-clean.txt` 跨阶段抽样，均为个案、不得泛化为通用合成规则）：炼、养、用为三件并列事，炼之下分单炼与合炼，合炼须有秘方、有些蛊虫之间不能合炼，秘方为先祖无数实践与数不清失败后总结，古月一族对月光蛊研究最深、已握两个五转秘方（15724–15734 行）；合炼个案为月光蛊加两只小光蛊合炼二转月芒蛊、白豕蛊加玉皮蛊合炼白玉蛊，前者主攻、后者主防，方源元石只够一次之用、选白玉蛊为明智但若失败则经济崩溃、无法继承遗产、成长严重拖延（15708–15720 行）；意志极刚强蛊虫反噬罕见、孤注一掷不成功则成仁，酒虫反噬意志越过真元直降空窍元海，须凝聚全部精神全力对抗、不能有丝毫外界干扰（3160–3170 行）；四转呕心婴泣蛊材料不罕见但难度颇高，方源以近炼道大师才能试十多次尽数失败，失败气流撞毁窗棂薄膜（93334–93340 行）。
 - 本批窗口新增（杀招组合与代价，均为个案、不得泛化）：杀招即不同蛊虫组合、功效叠加，或单方面绝伦、或兼顾多面（105506 行，墨瑶述）；蛊屋本质是杀招、只是形式固定，八十八角真阳楼与近水楼台之功用单蛊提供不了、须组合才达到（105514 行）；任何杀招既为组合运用必有弊端，后遗症不可避免、只分严重微弱，六臂天尸王经完善威力翻番、时长一炷香、位列墨瑶记忆前五（106762 行）；六臂天尸王已无法再改进，方源忧过多使用变僵尸、须另行解决后遗症（106772 行）；杀招威力惊人则真元消耗巨大且多有缺陷，失理智之力不足虑（98114 行）；三人合体三头六臂战力暴涨但不持久，拖久则记忆混乱、彻底丧失自我、沦为疯傻（98124 行）。
 - 本批窗口新增（推演与高阶组合，均为个案、不得泛化）：推演仙蛊方因素太多、凡蛊意志不够消耗，方源催乐山乐水蛊先易后难先攻九成九残方（123432–123434 行）；琅琊地灵质疑方源无底蕴（明明力道仙僵），太白云生实为信智慧蛊（123466–123476 行）；方源立智慧光晕中片刻完善九成九残方至十成（123480–123486 行）；推演蛊方一靠底蕴二靠灵感，底蕴不足则难、底蕴深厚亦常卡数年数十年上百年（123492 行）；冰钻星尘杀招由都敏俊星蛊传承、寒纱与六九星尘前身（半空仙元石购得）、智慧光晕无限灵感、重生亲见威力所得方向四者结合而成，单靠智慧蛊无前身亦无法推出（124286–124320 行）；智慧之光灵感无限，为推演蛊方、仙蛊方、凡道杀招、仙道杀招的无上利器（140664 行）；凶雷恶人数年参悟雷神子、方源借智慧蛊顶多把月，黑楼兰凡道杀招推仙级至少数年、方源估计半月，万我即其断续推算之仙道杀招（135052–135062 行）；炼前须头脑不断推演正炼逆炼之失败、综合多方案选最精炼者，须风险低且时间少、精心比较排列（152834–152844 行）；炼制仙蛊前须调状态至巅峰、心静神清、对仙蛊方研究推演无数遍（156002 行）；仙道连招为两种以上仙道杀招先后爆发之威力提升或效果共鸣，愤怒小鸟加火囚为其例，超时或先催火囚则威力大减且易躲，原理为临时道痕残留（炎道道痕为火囚垫基），能设想者须大宗师境界，焚天魔女连招支撑不十呼吸即近崩解（171840–171874 行）；并招为仙道杀招著名技巧之一，上古剑蛟变并万我成万蛟、非简单叠加，经七转巅峰道痕增幅登顶七转杀招极限，万我素以量多质次著称、并招后天差地别（266794–266830 行）；自由残缺变为态度、变异、变通三核心之并招，繁琐复杂、作用肉身，一旦失败轻则重伤、重则死亡、切记勿轻试（365072 行）。正炼、逆炼有本批直接证据（152834 行），合炼有本批直接证据（15728–15734 行）；升炼本批未见直接证据，不列入事实层。

## 分析与解读

 - 以下为关系模型，不是严格因果公式，也不是原著明文；回答时必须声明这是分析层。
 - 粗粒度循环（关系模型）：蛊方/知识 → 材料与炼制 → 蛊虫 → 组合成杀招 → 实战反馈 → 推演与改良。不存在已核验的全量配方表；月芒蛊、白玉蛊、万我等个案不得升级为通用合成规则；连招与并招不得自动合并为同一术语；游戏中伤害、消耗、稀有度不写入本页事实层。
 - 炼化、炼制、饲养三者分开：炼化指收服单蛊、抹去其意志（意志反抗与反噬为其证据）；炼制涉及按蛊方/秘方炼成蛊虫；单炼、合炼、正炼、逆炼是本批原文出现的炼蛊方式或术语，其完整分类尚未系统核验；饲养指按日供给蛊食与资源维持（月兰花瓣、青竹酒、光阴饮水、二转日耗与四五头惯例为其证据）。三者不可混成一件事。
 - 蛊方/秘方是能力获得的约束：有些蛊虫之间不能合炼（15734 行），秘方须无数实践与失败总结（15734 行），无秘方不知如何合炼（15732–15734 行），推演残方须底蕴与灵感（123492 行）。约束不在蛊虫本身，而在知识。
 - 单体到杀招：单蛊功效单一（105506 行），杀招为多蛊组合叠加（105506 行），蛊屋为固定化杀招（105514 行）。组合必有弊端与后遗症（106762 行），消耗随威力放大（98114 行）。
 - 杀招、连招、并招边界（仅说明本批案例，不穷尽杀招组合类型）：杀招为多蛊组合用法沉淀；本批连招案例表现为两种以上仙道杀招先后爆发之威力提升或共鸣、有时间与顺序窗口、原理为临时道痕（171840–171858 行）；本批并招案例是将剑蛟变与万我合为万蛟（266794–266796 行），并招被称为仙道杀招著名技巧之一。上述术语不得互换，也不构成杀招组合的完整分类。
 - 推演要素：底蕴（123474 行之问、123492 行之答）、灵感（智慧光晕无限灵感，140664 行）、前身/传承（寒纱与六九星尘、都敏俊传承，124308–124320 行）、方向（重生亲见威力，124318 行）、意志/仙元成本（凡蛊意志不够耗、催乐山乐水，123432 行；九云环两块、冰钻星尘四块仙元石，124290–124304 行）、头脑预演与状态（152834–152844、156002 行）。这些因素在样本中反复影响推演，但不能视为所有推演的绝对必要条件；底蕴深厚亦可卡数十年上百年（123492 行）。
 - 跨阶段观察（本批证据）：炼养用三分与合炼须秘方；组合代价与后遗症、推演底蕴与灵感及成本在样本中反复出现；失败通常伴随材料、时间或身体代价，具体后果依个案而异。个案（不得泛化）：月芒/白玉配料、万我骨架、连招之炎道残留垫基、并招之剑蛟变加万我、自由残缺变三核心。
 - 任何蛊虫页面都应同时回答三件事：能做什么、吃什么、需要什么代价。
 - 组合效果必须注明是原著明确描述、由多个能力推得，还是仅仅是读者策略分析。
