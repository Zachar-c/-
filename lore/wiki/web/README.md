# 网站窗口

> 给想用浏览器看图的人：这里放可直接打开的网页产物。目前只有关系图谱演示，**不是**完整 wiki 站点。

## 怎么用本页

1. 看下面「能看什么」确定要开哪个窗口（当前仅一个）。
2. 按「人如何打开」在本地浏览器打开对应 HTML。
3. 要读文字正文、走阅读路径，仍回 [wiki 根入口](../index.md)；网页只做浏览便利，**不承载新事实**。

## 人如何打开

以 [蛊虫关系图谱](gu-relations/蛊虫关系图谱.html) 为例（路径：`lore/wiki/web/gu-relations/蛊虫关系图谱.html`）：

- **资源管理器**：进入 `lore/wiki/web/gu-relations/`，双击 `蛊虫关系图谱.html`，用系统默认浏览器打开。
- **PowerShell**：`start "lore/wiki/web/gu-relations/蛊虫关系图谱.html"`
- **可选本地服务**（若浏览器限制 file:// 资源）：在仓库根执行 `python -m http.server 8000`，再访问 `http://127.0.0.1:8000/lore/wiki/web/gu-relations/蛊虫关系图谱.html`
- 页面引用在线字体（Noto Serif/Sans SC）；断网时回退系统字体，**内容与布局不受影响**。
- 不需要构建、不需要 npm、不需要启动后端——单文件 HTML，打开即看。

## 边界（不新做站点）

- 本目录只登记**已经做好**的网页窗口产物；当前没有统一 wiki 站点、没有站内搜索、没有图数据库前端、没有部署地址。
- 完整阅读路径与分类导航以 [`../index.md`](../index.md) 及各目录 `index.md` 为准。
- 网页与 wiki 正文冲突时：以 wiki + 原文为准；改事实先改 wiki，再决定是否同步网页。
- 新增网页窗口时同批完成：①在本 README 的「能看什么」表登记「如何打开 + 能看什么 + 同源正文」；②在 [`../index.md`](../index.md) 分类入口挂真实链接；③确认不引入构建步骤或外部部署依赖。
