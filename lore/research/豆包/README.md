# 豆包 · 纯净工作区

> 建立：2026-08-12。本目录只放"以原文为底本"的纯净材料，不含大纲、细纲、设定集、读书笔记、旧稿等二手内容（信息有损或已作废）。

## 核心原则
- 正文 = 对 `蛊真人-clean.txt` 对应行段的**重组与删减**：保留原句、原对话、原心理，删重复与冗余，跨"节"合并成章；删除段用"……（原文 X–Y，此处从略）"标注。
- **不凭空创作**。续写时先读原文行段，再写精编。
- 目标读者：**重温的老读者**——删减可以更激进，但关键信息、人物弧光、伏笔必须保留。
- 质量标准：资深读者"感觉不到改过"。

## 工作流程
```
1. 读结构地图，确定本章覆盖的节范围
2. 第一遍：粗删（按手册删必删类+明显可删类）
3. 第二遍：精修（调整衔接、补过渡句、检查完整性）
4. 第三遍：通读（检查节奏、通顺性）
5. 过质检清单
6. 更新红绿对照（只记关键决策）
7. 更新本 README 的章节进度表
```
