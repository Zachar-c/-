# 重写记忆库 README

本目录位于分支 `分支：六卷精编版/`，是《蛊真人》重写项目的最新权威记忆库。写正文前先读本目录。

**可信度层级**：原文（`蛊真人-clean.txt` 与《人祖传》.txt）＞ 读书笔记 ＞ 其他产物（本目录各文件、总纲、细纲、正文等一切派生文档）。事实判断以原文为准；原文未及或存歧义处，以读书笔记为准；任何产物与读书笔记冲突时，以读书笔记为准。读书笔记仅作检索与辅助核对，不作为独立事实源。
