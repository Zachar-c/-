# 收敛为单一原著精编线：仓库重构设计

日期：2026-08-24
状态：已与维护者确认

## 1. 目的与边界

本仓库从"小说资料整理 + 肉鸽游戏原型"双线收敛为**一条极简的《蛊真人》原著编辑线**：以原文为唯一底本，按删减原则手册重组删减，产出六卷精编正文。游戏方向整体退出仓库（git 历史可追溯）。

不做的事：

- 不改动 `精编/` 内任何正文、笔记、记忆库、细纲的内容，只做移动、改名、删除和文档改写。
- 不合并两条精编线的分章差异（主线卷一仅 001–003 章；豆包线 001–004 章边界不同，不并入）。
- 不推送远端。

## 2. 目标目录结构

```text
README.md                  # 重写：定位、导航、进度、方法摘要
AGENTS.md                  # 重写：纯编辑纪律的协作约定
精编/
  README.md                # 合并原 正文/README 与豆包 README 的方法+进度信息
  全书总纲.md
  蛊真人-clean.txt          # 底本 437060 行（自 分支：六卷精编版 移入）
  《人祖传》.txt
  精编删减原则手册.md        # 自 豆包 吸收
  tools/                   # 自 豆包 吸收：analyze_structure.py、结构分析报告.md、卷一结构地图.md
  记忆库/                  # 原样保留
  细纲/                    # 原样保留
  读书笔记/                # 原样保留
  正文/
    卷一-青茅-原文精编/

```

即 `分支：六卷精编版/` 改名为 `精编/` 并吸收豆包方法论文件。`正文/` 及其子目录相对底本的路径（`../蛊真人-clean.txt`、`../记忆库/…`）在改名后保持有效，不需要改正文内的相对引用。

## 4. 文档改写要点

### 根 README.md（重写）

- 定位：单一用途仓库——《蛊真人》原著精编。
- 目录导航：`精编/` 各子目录一句话说明。
- 进度快照：卷一原文精编 3 章（001–003）、卷四原文精编 11 章。
- 方法一句话：以原文为唯一底本，重组删减，不凭空创作；标准见《精编删减原则手册》。

### AGENTS.md（重写）

删除全部游戏规则，替换为编辑协作约定：

1. 工作边界：只编辑 `精编/`；`精编/正文/` 内已有章节不做未经确认的批量改动。
2. 编辑纪律：以 `蛊真人-clean.txt` 为唯一底本；删减标准以《精编删减原则手册》为准；记忆库、细纲、读书笔记仅作导航定位，不是内容来源；不凭空创作。
3. 流程：每章完成后更新《精编》README 进度表与红绿对照。
4. 约定：提交信息 ASCII、小而聚焦；开始前读相关文档与 `git status`；保留用户未提交改动。

### 精编/README.md（新建，吸收两处旧 README）

- 方法（以原文为唯一底本、三遍工作流、质检清单指引）。
- 章节进度表：卷一、卷四已完成章节及对应原文行段（沿用现有记录）。
- 指向《精编删减原则手册》《全书总纲》与工具。

### 精编/正文/README.md（修订）

- 目录表移除"卷一-青茅（旧稿，作废）"行。
- 进度描述更新为当前实际状态。

## 5. 提交策略

master 上三个聚焦提交，不推送，按此顺序执行（规划文档须存活到最后一步）：

1. `chore: converge novel editing into single line` —— 吸收豆包手册与工具、改名主线目录为 `精编/`、执行第 3 节中除游戏文档外的删除项、新建/修订 `精编` 层 README。
2. `docs: rewrite readme and agents for editing-only repo` —— 重写根 README 与 AGENTS.md。
3. `chore: remove game prototype docs and data` —— 删 `docs/`、`肉鸽设计-原始数据/`。

说明：本设计文档与后续实施计划位于 `docs/superpowers/` 下，属于规划用文档；它们随第 3 个提交一并删除（历史可查），此后仓库中不存在 `docs/`。

## 6. 验证清单

- 每个提交后 `git status` 干净。
- 重构完成后顶层仅剩：`.gitignore`、`.worktrees/`（本地忽略）、`AGENTS.md`、`README.md`、`精编/`。
- `精编/正文/*/README.md` 及章节内相对引用抽查有效（`../蛊真人-clean.txt`、`../记忆库/…`）。
- `python 精编/tools/analyze_structure.py` 可运行并能在新位置找到底本；若脚本内置路径假设失效，仅允许最小修改脚本内路径常量并在提交说明中注明。
- 全仓检索确认无指向已删路径的残留引用（`豆包`、`旧稿归档`、`肉鸽设计`、`superpowers`、`分支：六卷精编版`）。
