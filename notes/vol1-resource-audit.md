# 第一卷资源与购买力审计

审校范围：第一部《魔性不改》第001—199节；卷末资产状态以第199节正式卷界为准。

## 经济尺度

| 层级 | 典型支出 | 裁决原则 |
|---|---|---|
| 凡人家庭 | 粮食、住房、衣物、普通酒食 | 一块元石的生活月数尚有冲突，改文前统一消费篮子 |
| 一转蛊师 | 生活、蛊食、炼蛊、真元补充 | 数块至数十块会显著影响进度 |
| 二转蛊师 | 多只蛊的喂养、任务装备、疗伤 | 珍稀一转蛊约数百块可作为锚点 |
| 三转家老 | 多蛊体系、属员、战备和政治往来 | 周补贴百至三百可成立，但须结合职责 |
| 脉系与家族 | 数千至数万元、产业、库存、灵泉 | 万元级必须说明组织来源，不作私人零钱 |

## 已确认价格锚点

- 青竹酒约两块一坛；月兰花瓣与低阶蛊食构成持续日耗。
- 黑豕蛊、白豕蛊等珍稀一转蛊约六百块量级。
- 赤铁舍利蛊标价三千，成交预期五千至八千，属于稀缺溢价。
- 狼潮时期家老补贴高于和平时期，反映战备消耗。
- 一万元同窗供奉是多人汇集；四万元来自漠脉组织资金且分期交付；五万元全部投入天元宝莲。

## 151—180实施记录

- 三千元石按家老身份、俸禄与资产担保的记账借款处理，不是无条件赠款。
- 近万元由数十名旧同窗分别贡献数十至数百块汇集而成。
- 四万元明确来自漠脉产业收益和组织库存，并分批交付；正文同时保留账目、人情与政治债。
- 往生草蛊未能交付，方源在第180节仍缺治疗手段，该风险不得在后续无故消失。

## 改文前必须完成的核算

1. 用第8-30节每一笔可确认收入、支出和余额反推FD002。
2. 用第81节前余额、奖励后消费及第91节起始资产反推FD007。
3. 统一“一块元石可供凡人家庭多久”的口径，并回测酒价、房租、侍卫工资和猎物价格。
4. 核查“学堂每日上千元石”统计对象；若仅指学员口粮则下调，若指全部蛊室则补明范围。
5. 以灵泉产出和脉系产业估算五万元占家族储备的比例。
