# 第一卷人物状态账

## 状态字段

每个阶段同时核验：修为与伤势、资源、公开身份、真实目标、已知信息、关系变化和阶段结束状态。

|---|---|---|---|

|---|---|---|
| 1-20 | 从哥哥阴影中的自卑少年变为甲等天才；被舅父舅母收养；与方源决裂 | 不能一步变成纯粹仇敌，仍有依赖、模仿和求认可 |
| 21-90 | 在学堂和家族资源扶持下成长；逐渐获得自信；先晋二转 | 对哥哥的嫉妒、恐惧和竞争欲必须随具体事件加深 |
| 91-150 | 接受正统培养并参与战斗；认可家族道路 | 不能用后期经历提前替换其当前正道信念 |
| 151-190 | 狼潮和三族大比中成熟，成为古月寨希望 | 战绩增长要匹配甲等资源与实战代价 |
| 191-199 | 在鹤灾中重伤失忆片段；因资质被天鹤上人带走 | 卷末不是“被救”一句带过，而是人生道路与方源彻底分流 |

| 人物 | 目标 | 卷末状态与边界 |
|---|---|---|

| 古月一代 | 以血脉、血颅蛊和元泉完成数百年资质谋算 | “成魔”自白是自我解释而非客观真理；最终计划被方源、白凝冰和天鹤上人共同破坏 |
| 天鹤上人 | 寻回血海机缘并向师兄复仇 | 五转御鹤者；先清除四转变量；依靠铁喙飞鹤皇处理血河蟒；最终带走方正 |

## 三寨领导层

- 狼潮前：三位四转族长均是地方最高公开战力。
- 狼潮后：三寨均有重大损失，熊寨首先覆灭，古月与白家残余仍互相提防。
- 鹤灾中：三位族长必须有可辨认的死亡或失去战力过程，不能只汇总为“接连战死”。
- 卷末：青茅山原有政治秩序彻底终结，不留下可无成本恢复的完整山寨体系。

## 第151—180节落点

- 方源：三转初阶；已取得生铁蛊与四万元石；仍缺治疗草蛊；春秋蝉压力迫使其当夜摘莲。
- 方正：主动向铁若男提供赤脉与方源的旧日联系，但其证言受个人伤痛和信息局限影响，不是作者代言。
- 铁若男：能够确认赤城开窍作弊的高度可能性；对方源仅形成重点嫌疑，尚无足以定罪的证据。
- 白凝冰：找到死前行动方向，与方源的短暂协作仍以求战和自身兴趣为基础，不提前转为稳定同盟。
