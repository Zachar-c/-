# 《蛊真人》全书精编审查意见

> **文件性质：审查议题来源，非正式裁决。** 本文记录全书级风险、假说和建议，不表示其中每项判断均已证实。除已经由用户明确裁决并进入各卷裁决表的项目外，正文不得仅凭本文直接修改。逐项证据、状态与最终去向统一登记在 `notes/full-book-audit-register.md`。

## 审查前提

- 本书已经完本。本次工作是对全书原文的出版级深度精编，不以连载期的临时表述为最终准则。
- 后期反复印证、能够支撑全书因果的成熟世界观优先于前期孤立叙述；人物受限认知、传闻和官方史书可以保留，但全知叙述与硬规则必须统一。
- 保留作品的冷峻、功利、黑暗底色及人物的价值冲突。处理对象是作者越位说教、重复怨怼、无证据的全知断言、网页连载残留和硬设定冲突，而不是删去思想张力。
- 原则是最小有效修改：每一处修补都应说明其证据、影响范围、最小改法及下游连锁影响。

## A 级候选：优先核证的硬设定

### 1. 兽群阶位与青茅山狼潮

统一兽王对应关系：百兽王为二转、千兽王为三转、万兽王为四转、兽皇为五转。该对应是综合威胁尺度，不等于无条件单挑平级；伤势、真元、蛊虫组合、地形、阵势、族群数量和消耗均须计入。

青茅山狼潮应改为三支数万规模的主狼群。雷冠头狼与狡电狈为四转万兽王，不能被误升格为兽皇。三寨均有四转家主，并不自动推导出每一支狼群首领都是五转；熊寨覆灭需由狡电狈的智慧、残狼、误判、损耗和三寨互不信任共同构成因果。

### 2. 年代、尊者与流派史

前期对元莲仙尊、盗天魔尊及各时代的笼统年代表述，须以完本后的尊者序列和历史分期复核。气道、力道、魂道不可被写成同一“上古流派”；奴道也不可被一句“出自魂道”简化为单一路径的总源头。

处理时应区分“某角色以凡人视野说错或不知”与“叙述者宣布历史事实”。前者可保留并加以限定，后者必须改正或改为不确定的史料转述。

### 3. 三王福地与地灵存续

若上古被统一为数百万年前，三王传承中近六转尺度的福地、地灵及其灾劫存续便不能自然成立。必须二选一：校正传承的年代等级，或补足特殊存续机制、资源来源和灾劫规避条件。不得仅以“地灵一直等到今天”跨过数百万年的寿命与灾劫账。

### 4. 地理尺度与旅行时间

早期低转蛊师乘河、步行或常规飞行数日便跨越大半南疆，与后期南疆的宏大尺度冲突；仙鹤上人跨域所需时间亦须复核。保留剧情节点，但必须通过路线、坐骑、传送条件、时间跨度或“局部区域”修正尺度，不能让低阶角色无成本跨越后期定义的大域。

### 5. 元石经济与资产尺度

青茅山万余元石、商量山和王庭动辄百万的金额，不能继续作为同一层级的随手现金。应区分个人现款、家老/脉系资产、家族库藏、商贸流水、抵押物及仙级资产。

大额交易必须交代来源、调拨方式、账面性质、义务或政治代价。以此消除连载期的数字跳跃，而非机械缩小后期金额。凡俗元石与仙材、仙元、福地收益不可混算。

### 6. 五转与蛊仙人口基数

前期“南疆约百位五转蛊师”等说法，应限定为角色认知、公开名册或局部区域统计；否则无法与后期蛊仙数量、升仙难度和各方势力规模相容。福地光阴倍率、灾劫频率、寿命消耗与低转蛊仙存量必须纳入人口推演。修订目标不是压低后期人物数量，而是避免早期全知数字封死世界规模。

### 7. 至尊仙窍面积的数值链

“五亿亩”与“五亿万亩”属于高度疑似笔误，后续扩展至“五百亿亩”必须有可核查的资源、吞窍、灾劫和时间链。统一单位后逐次核算，避免用模糊大数掩盖成长幅度。

## 王庭篇：巨阳特意与尊者实力的判定

审查假说：王庭真阳楼内的巨阳意志并非完整的巨阳仙尊，不应与文末巨阳的本体级布置直接等量比较。其是否可严格定义为借特意蛊形成、脱离本体且经历十余万年消耗的残余管理意志，以及它对真阳楼、储备仙元和预设指令的依赖程度，均须按原文出现顺序逐项核证。

文本本身已给出多重约束：意志思考会消耗，长期衰减后须沉睡；特意可被针对性克制；楼主令的通行容量狭窄；意志不能独立驱动真阳楼，须依赖黄杏仙元；仙元又被中洲长期筹备封印；同时它被方源灾劫、地灵、智慧光及异人/外来者等事件牵制。其最高优先级是清除天外之魔，因而会与守楼、资源保存等命令发生竞争。

因此，不能把真阳楼失守写成“巨阳故意放方源离开”。后期“我建成此楼，就是为了它的倒塌”所指，是以真阳楼未来崩毁作为向北原同族发出进攻天庭信号的长线预案；方源提前且异常地摧毁真阳楼、造成的大量资源流失、智慧蛊得失和传承外泄，并非均可归入巨阳预设结果。

文末巨阳的镇运天宫、巨阳仙僵及以九转运道杀招针对天庭的布局，属于本体及核心遗产层面的战争设计；真阳楼残意则是衰耗的边缘管理节点。二者对象、权限、资源和目标不同，不能用后者的失败反推尊者本体实力失真。

但此处仍有 B 级叙事问题：早期对“仙尊意志无敌”的高位措辞过满，而后续大量克制手段层层叠加，阅读体验像为失败预制的首领战。精编应提前、明确地交代残意的权限边界、资源依赖、睡眠代价和命令冲突，并将绝对化判断改为条件化判断。这样保留方源破局的爽点，也不会消耗尊者威严。

## 中期重点问题

### 1. 仙僵困局的权重

生死仙窍、涅槃火、至尊仙胎等解决路径连续出现，会使仙僵困局从文明级绝境退化为等待下一张答案。应分别建立不可复制条件、资源成本、失败风险、时间窗口和受益者限制；前一条路径失效或难以普及的原因必须先于下一条捷径出现。

### 2. 至尊仙胎的代价前置

至尊仙体的强项密集释放，而“吞并仙窍维持稳定”等重大缺陷出现偏晚。应在优势展示阶段即埋入饥饿感、资源负担、身份暴露风险或难以长期维持的征兆，使代价成为能力结构的一部分，而非后期补丁。

### 3. 影宗、义天山与身份控制

天意、春秋蝉等后期解释能承担部分因果，但影无邪的身份暴露、控制链断裂和敌方行动窗口仍应逐环审查。对手不能在缺少明确动机和约束的情况下持续“把门开着”。每一次脱身、误判或援手都应落到信息差、代价、命令优先级或不可兼顾的资源上。

## 连载痕迹与作者投射

保留角色基于处境发出的锋利判断、制度冷酷和价值冲突；不保留作者借角色之口反复宣布宇宙真理、直接训诫读者或以无证据的现代化评论替代情节。

具体处理：

- 同一结论反复三次以上、未新增人物转折、情节信息或伏笔功能的，压缩为最有力的一次。
- 将抽象怨怼还原为可见的制度、交易、选择、利益和代价，让读者自行得出判断。
- 对全知断言补证据、改为角色认知，或删除其越位部分；不把有效的留白和人物直觉改成案情报告。
- 清理广告、作者 PS、投票通知、重复章段、乱码和网页转载残留。

## 可执行的全书审校机制

维护六本台账：年代与历史、地理与旅行、经济与资源、战力与消耗、人口与升仙、关键物资/能力成本。每发现一处问题，均按以下字段登记：

| 字段 | 要求 |
| --- | --- |
| 等级 | A 为硬冲突，B 为因果/尺度不足，C 为文字和重复问题 |
| 位置 | 章节、原句或可检索锚点 |
| 证据 | 前后文本与完本设定的交叉依据 |
| 影响 | 对人物、战力、经济、年代或伏笔的具体影响 |
| 最小修补 | 改数值、改叙述视角、补条件、调顺序或删除重复 |
| 下游复核 | 受此修改影响、必须回查的后续章节 |

每一处改动以“保住情节功能和人物锋芒”为验收标准。不能为了设定正确而把战斗、心理铺垫、反转或哲思段落压缩成提纲；也不能为了保留原句而让完成版世界观继续自相矛盾。
