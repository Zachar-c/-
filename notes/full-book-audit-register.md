# 《蛊真人》全书总审查核证登记表

## 文件职责

本表承接 `full-book-editorial-review-2026-08-08.md` 中的审查意见，将“看起来存在冲突”与“已经确认应如何修改”分开。

- 审查意见只提供问题和核证方向，不直接授权修改正文。
- 每项必须先核对原文位置、后期稳定设定、叙述视角和下游影响。
- 只有状态为“已裁决”的项目，才能进入对应卷的 `decision-register` 并据此改文。
- 证据不足时，优先采用角色认知、史料转述或中性表述，不虚构补丁。

## 状态定义

| 状态 | 含义 |
| --- | --- |
| 待定位 | 已提出问题，尚未收齐原文锚点 |
| 核证中 | 已开始收集前后证据，尚无结论 |
| 待用户裁决 | 证据允许两种以上自洽方案，需要用户选择 |
| 已裁决 | 证据与方案均已确认，可进入卷级裁决表 |
| 不成立 | 交叉核验后确认不存在冲突，不改正文 |

## 单项核证记录模板

每个项目进入“核证中”后，应在专项文件或本表下追加：

1. 原文位置与原句摘要。
2. 叙述主体：旁白、角色、史书、传闻或谎言。
3. 支持审查主张的后期证据。
4. 反证、例外和可能的另一种解释。
5. 风险：不改与误改分别会破坏什么。
6. 最小修法及其下游复核范围。
7. 裁决结果、用户确认日期和进入哪个卷级裁决表。
